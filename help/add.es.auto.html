Nombre de host de Internet
Aquí debe ingresar el nombre de host completo resoluble del sistema que se agrega o su dirección IP si no tiene una entrada DNS.
Descripción del sistema
Este campo es para ingresar una descripción de su elección para identificar el sistema, como el servidor de alojamiento primario Xen .
Modo de inicio de sesión raíz
Para administrar un sistema, Cloudmin necesita iniciar sesión de forma remota a través de SSH. En esta sección, debe ingresar la contraseña de root para SSH o seleccionar una clave registrada en Cloudmin que la cuenta de root esté configurada para aceptar.
Versión del protocolo SSH
De manera predeterminada, Cloudmin utiliza el protocolo SSH versión 2 más nuevo y casi universalmente implementado para conectarse a sistemas administrados, pero si el sistema que está agregando solo admite SSH 1, puede seleccionarlo aquí.
Nombre de usuario SSH
Esto normalmente es root , pero si el sistema tiene otro usuario con UID 0 que le gustaría usar, ingréselo aquí.
Modo de inicio de sesión de Webmin
Si Webmin o Virtualmin ya está instalado en el sistema que se está agregando, debe seleccionar las credenciales de autenticación correctas en esta sección. Si la contraseña de Webmin es la misma que la cuenta raíz de Unix, seleccione Iniciar sesión como raíz con la misma contraseña que el modo Unix . Si Webmin usa un inicio de sesión diferente, elija Iniciar sesión como e ingrese el nombre de usuario y contraseña correctos.
Si Webmin se está ejecutando en modo SSL, deberá marcar la casilla Usar SSL para conectarse a Webmin . Este es el valor predeterminado para la mayoría de las instalaciones, especialmente cuando Webmin se configura como parte de la pila de Virtualmin.
Puerto Webmin
Si Webmin se ejecuta en el puerto predeterminado 10000, puede dejar este campo sin cambios. De lo contrario, debe ingresar el número de puerto correcto.
¿Permitir la creación de dominios de Virtualmin?
Esta configuración determina si el servidor recién agregado puede tener dominios de Virtualmin agregados. Por lo general, querrá dejar este conjunto en Sí .
