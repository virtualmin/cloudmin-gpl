Nom d'hôte Internet
Ici, vous devez entrer le nom d'hôte résolvable complet du système ajouté, ou son adresse IP s'il n'a pas d'entrée DNS.
Description du système
Ce champ sert à entrer une description de votre choix pour identifier le système, comme le serveur d'hébergement Xen principal .
Mode de connexion root
Pour gérer un système, Cloudmin doit s'y connecter à distance via SSH. Dans cette section, vous devez soit saisir le mot de passe root pour SSH, soit sélectionner une clé enregistrée auprès de Cloudmin que le compte root est configuré pour accepter.
Version du protocole SSH
Par défaut, Cloudmin utilise le protocole SSH version 2 le plus récent et presque universellement déployé pour se connecter aux systèmes gérés, mais si le système que vous ajoutez prend uniquement en charge SSH 1, vous pouvez le sélectionner ici.
Nom d'utilisateur SSH
C'est normalement root , mais si le système a un autre utilisateur avec UID 0 que vous souhaitez utiliser à la place, entrez-le ici.
Mode de connexion Webmin
Si Webmin ou Virtualmin est déjà installé sur le système en cours d'ajout, vous devez sélectionner les informations d'authentification correctes dans cette section. Si le mot de passe Webmin est le même que le compte root Unix, sélectionnez la connexion en tant que root avec le même mot de passe que le mode Unix . Si Webmin utilise une connexion différente, choisissez Connexion en tant que et entrez le nom d'utilisateur et le mot de passe corrects.
Si Webmin s'exécute en mode SSL, vous devrez cocher la case Utiliser SSL pour vous connecter à Webmin . Il s'agit de la valeur par défaut pour la plupart des installations, en particulier lorsque Webmin est configuré dans le cadre de la pile Virtualmin.
Port Webmin
Si Webmin s'exécute sur le port par défaut 10000, vous pouvez laisser ce champ inchangé. Sinon, vous devez entrer le bon numéro de port.
Autoriser la création de domaines Virtualmin?
Ce paramètre détermine si le serveur nouvellement ajouté peut avoir des domaines Virtualmin ajoutés. En règle générale, vous souhaiterez laisser cet ensemble à Oui .
