Internet hostname
Here you must enter the full resolvable hostname of the system being added, or its IP address if it has no DNS entry.
System description
This field is for entering a description of your choice to identify the system, like Primary Xen hosting server.
Root login mode
In order to manage a system, VM2 needs to remotely login to it via SSH. In this section, you must either enter the root password for SSH, or select a key registered with VM2 that the root account is configured to accept.
SSH protocol version
By default VM2 uses the newer and almost universally deployed SSH version 2 protocol to connect to managed systems, but if the system you are adding only supports SSH 1 you can select it here.
Webmin login mode
If Webmin or Virtualmin is already installed on the system being added, you must select the correct authentication credentials in this section. If the Webmin password is the same as the Unix root account, select the Login as root with same password as Unix mode. If Webmin uses a different login, choose Login as and enter the correct username and password.
If Webmin is running in SSL mode, you will need to check the Use SSL to connect to Webmin box. This is the default for most installs, especially when Webmin is setup as part of the Virtualmin stack.
Webmin port
If Webmin is running on the default port 10000, you can leave this field un-changed. Otherwise, you must enter the correct port number.
Allow creation of Virtualmin domains?
This setting determines if the newly added server can have Virtualmin domains added to it. Typically you will want to leave this set to Yes.
