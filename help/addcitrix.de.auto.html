Vorhandene Citrix Xen-VM hinzufügen
Auf dieser Seite können Sie ein vorhandenes System, das in einer Citrix Xen-Instanz ausgeführt wird, unter die Kontrolle von Cloudmin stellen, sodass die Virtualmin-Domänen von einer zentralen Konsole aus verwaltet werden können. Es können nur Zonen auf Hostsystemen hinzugefügt werden, die bereits auf der Seite Citrix Xen- Hostsysteme hinzugefügt wurden. Die im Formular angezeigten Felder sind:
Citrix Xen-Hosting-System
In diesem Menü müssen Sie den Computer auswählen, auf dem die Instanz gehostet wird.
Citrix Xen VM
Klicken Sie auf die Schaltfläche neben diesem Feld, um eine Liste aller VMs auf dem ausgewählten Host aufzurufen, und wählen Sie diejenige aus, die Sie hinzufügen möchten.
