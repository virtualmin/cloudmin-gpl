Agregar Citrix Xen VM existente
Esta página le permite llevar un sistema existente que se ejecuta dentro de una instancia de Citrix Xen bajo el control de Cloudmin, de modo que sus dominios de Virtualmin se puedan administrar desde una consola central. Solo se pueden agregar zonas en sistemas host que ya se han agregado en la página de sistemas host Citrix Xen . Los campos que se muestran en el formulario son:
Sistema de alojamiento Citrix Xen
Desde este menú debe seleccionar la máquina en la que está alojada la instancia.
Citrix Xen VM
Haga clic en el botón al lado de este campo para que aparezca una lista de todas las máquinas virtuales en el host elegido y seleccione la que desea agregar.
