Ajouter une machine virtuelle Citrix Xen existante
Cette page vous permet de placer un système existant s'exécutant à l'intérieur d'une instance Citrix Xen sous le contrôle de Cloudmin, afin que ses domaines Virtualmin puissent être gérés à partir d'une console centrale. Seules les zones des systèmes hôtes qui ont déjà été ajoutées sur la page Systèmes hôtes Citrix Xen peuvent être ajoutées. Les champs affichés sur le formulaire sont:
Système d'hébergement Citrix Xen
Dans ce menu, vous devez sélectionner la machine sur laquelle l'instance est hébergée.
Citrix Xen VM
Cliquez sur le bouton à côté de ce champ pour afficher une liste de toutes les machines virtuelles sur l'hôte choisi, puis sélectionnez celle que vous souhaitez ajouter.
