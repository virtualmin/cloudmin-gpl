Add Existing Citrix Xen VM
This page allows you to bring an existing system running inside a Citrix Xen instance under the control of Cloudmin, so that its Virtualmin domains can be managed from a central console. Only zones on host systems that have already been added on the Citrix Xen Host Systems page can be added. The fields displayed on the form are :
Citrix Xen hosting system
From this menu you must select the machine on which the instance is hosted.
Citrix Xen VM
Click the button next to this field to bring up a list of all VMs on the chosen host, and select the one you want to add.
