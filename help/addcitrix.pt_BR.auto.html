Adicionar VM Citrix Xen existente
Esta página permite colocar um sistema existente em execução em uma instância do Citrix Xen sob o controle do Cloudmin, para que seus domínios do Virtualmin possam ser gerenciados a partir de um console central. Apenas zonas nos sistemas host que já foram adicionados na página Citrix Xen Host Systems podem ser adicionadas. Os campos exibidos no formulário são:
Sistema de hospedagem Citrix Xen
Nesse menu, você deve selecionar a máquina na qual a instância está hospedada.
Citrix Xen VM
Clique no botão ao lado deste campo para exibir uma lista de todas as VMs no host escolhido e selecione o que você deseja adicionar.
