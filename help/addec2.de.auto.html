Vorhandenes System hinzufügen
Auf dieser Seite können Sie ein vorhandenes System, das auf dem EC2-Dienst von Amazon ausgeführt wird, unter die Kontrolle von Cloudmin stellen, sodass die Virtualmin-Domänen von einer zentralen Konsole aus verwaltet werden können. Natürlich können nur EC2-Instanzen hinzugefügt werden, die von Konten erstellt wurden, die bei Cloudmin auf der Seite EC2-Konto registriert sind. Die im Formular angezeigten Felder sind:
EC2-Konto
In diesem Menü müssen Sie die Amazon-Kontonummer auswählen, der die EC2-Instanz gehört.
EC2-Instanz-ID
Wenn Sie ein einzelnes EC2-Konto haben, ist dieses Feld ein Menü zum Auswählen einer nicht geänderten Instanz, die diesem Konto gehört. Wenn mehrere Konten vorhanden sind, ist dies ein Textfeld, in dem Sie entweder die Instanz-ID eingeben oder sie aus einem Popup-Fenster auswählen können, das beim Klicken auf die Schaltfläche ... angezeigt wird.
