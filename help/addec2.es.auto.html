Agregar sistema existente
Esta página le permite llevar un sistema existente que se ejecuta en el servicio EC2 de Amazon bajo el control de Cloudmin, de modo que sus dominios de Virtualmin se puedan administrar desde una consola central. Naturalmente, solo se pueden agregar instancias EC2 creadas por cuentas registradas con Cloudmin en la página Cuenta EC2 . Los campos que se muestran en el formulario son:
Cuenta EC2
En este menú, debe seleccionar el número de cuenta de Amazon que posee la instancia EC2.
ID de instancia EC2
Si tiene una sola cuenta EC2, este campo será un menú para seleccionar una instancia no administrada que sea propiedad de esa cuenta. Si existen varias cuentas, este será un campo de texto para ingresar el ID de la instancia o seleccionarlo desde una ventana emergente que aparece cuando se hace clic en el botón ...
