Ajouter un système existant
Cette page vous permet de placer un système existant fonctionnant sur le service EC2 d'Amazon sous le contrôle de Cloudmin, afin que ses domaines Virtualmin puissent être gérés à partir d'une console centrale. Naturellement, seules les instances EC2 créées par des comptes enregistrés auprès de Cloudmin sur la page Compte EC2 peuvent être ajoutées. Les champs affichés sur le formulaire sont:
Compte EC2
Dans ce menu, vous devez sélectionner le numéro de compte Amazon propriétaire de l'instance EC2.
ID d'instance EC2
Si vous avez un seul compte EC2, ce champ sera un menu pour sélectionner une instance non gérée appartenant à ce compte. S'il existe plusieurs comptes, il s'agira d'un champ de texte permettant soit de saisir l'ID d'instance, soit de le sélectionner dans une fenêtre contextuelle qui apparaît lorsque le bouton ... est cliqué.
