Aggiungi sistema esistente
Questa pagina ti consente di portare un sistema esistente in esecuzione sul servizio EC2 di Amazon sotto il controllo di Cloudmin, in modo che i suoi domini Virtualmin possano essere gestiti da una console centrale. Naturalmente, è possibile aggiungere solo istanze EC2 create da account registrati con Cloudmin nella pagina Account EC2 . I campi visualizzati nel modulo sono:
Conto EC2
Da questo menu è necessario selezionare il numero di account Amazon proprietario dell'istanza EC2.
ID istanza EC2
Se si dispone di un singolo account EC2, questo campo sarà un menu per la selezione di un'istanza non gestita di proprietà di tale account. Se esistono più account, questo sarà un campo di testo per inserire l'ID istanza o selezionarlo da una finestra pop-up che appare quando si fa clic sul pulsante ...
