Adicionar sistema existente
Esta página permite colocar um sistema existente em execução no serviço EC2 da Amazon sob o controle do Cloudmin, para que seus domínios do Virtualmin possam ser gerenciados a partir de um console central. Naturalmente, somente as instâncias do EC2 criadas por contas registradas no Cloudmin na página Conta do EC2 podem ser adicionadas. Os campos exibidos no formulário são:
Conta EC2
Nesse menu, você deve selecionar o número da conta Amazon que possui a instância do EC2.
ID da instância do EC2
Se você tiver uma única conta EC2, esse campo será um menu para selecionar uma instância não gerenciada pertencente a essa conta. Se existirem várias contas, esse será um campo de texto para inserir o ID da instância ou selecioná-lo em uma janela pop-up que aparece quando o botão ... é clicado.
