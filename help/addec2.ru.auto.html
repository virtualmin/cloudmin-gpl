Добавить существующую систему
На этой странице вы можете перевести существующую систему, работающую в сервисе Amazon EC2, под управление Cloudmin, чтобы управлять ее доменами Virtualmin с центральной консоли. Естественно, можно добавить только экземпляры EC2, созданные учетными записями, зарегистрированными в Cloudmin на странице учетной записи EC2 . Поля, отображаемые в форме:
EC2 аккаунт
В этом меню вы должны выбрать номер учетной записи Amazon, которому принадлежит экземпляр EC2.
Идентификатор экземпляра EC2
Если у вас есть одна учетная запись EC2, это поле будет меню для выбора необработанного экземпляра, принадлежащего этой учетной записи. Если существует несколько учетных записей, это будет текстовое поле для ввода идентификатора экземпляра или его выбора во всплывающем окне, которое появляется при нажатии кнопки ....
