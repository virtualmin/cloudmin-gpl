Vorhandenes System hinzufügen
Auf dieser Seite können Sie ein vorhandenes System, das auf dem GCE-Dienst von Google ausgeführt wird, unter die Kontrolle von Cloudmin stellen, sodass die Virtualmin-Domänen von einer zentralen Konsole aus verwaltet werden können. Natürlich können nur GCE-Instanzen hinzugefügt werden, die von Projekten erstellt wurden, die bei Cloudmin auf der Seite GCE- Projekte registriert sind. Die im Formular angezeigten Felder sind:
GCE-Projekt
In diesem Menü müssen Sie das Google-Konto und das GCE-Projekt auswählen, dem die hinzuzufügende Instanz gehört.
Name der GCE-Instanz
Hier können Sie aus einer Liste aller mit dem ausgewählten Projekt verknüpften Instanzen die hinzuzufügende Instanz auswählen.
