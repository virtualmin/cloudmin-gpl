Agregar sistema existente
Esta página le permite llevar un sistema existente que se ejecuta en el servicio GCE de Google bajo el control de Cloudmin, de modo que sus dominios de Virtualmin se puedan administrar desde una consola central. Naturalmente, solo se pueden agregar instancias GCE creadas por proyectos registrados con Cloudmin en la página Proyectos GCE . Los campos que se muestran en el formulario son:
Proyecto CME
En este menú, debe seleccionar la cuenta de Google y el proyecto GCE que posee la instancia para agregar.
Nombre de instancia de GCE
Aquí puede seleccionar la instancia específica para agregar, de una lista de todos los asociados con el proyecto elegido.
