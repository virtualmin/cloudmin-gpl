Ajouter un système existant
Cette page vous permet de mettre un système existant fonctionnant sur le service GCE de Google sous le contrôle de Cloudmin, afin que ses domaines Virtualmin puissent être gérés à partir d'une console centrale. Naturellement, seules les instances GCE créées par des projets enregistrés auprès de Cloudmin sur la page Projets GCE peuvent être ajoutées. Les champs affichés sur le formulaire sont:
Projet GCE
Dans ce menu, vous devez sélectionner le compte Google et le projet GCE qui possède l'instance à ajouter.
Nom d'instance GCE
Ici, vous pouvez sélectionner l'instance spécifique à ajouter, à partir d'une liste de tous les associés au projet choisi.
