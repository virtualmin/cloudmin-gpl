Add Existing System
This page allows you to bring an existing system running on Google's GCE service under the control of Cloudmin, so that its Virtualmin domains can be managed from a central console. Naturally, only GCE instances created by projects registered with Cloudmin on the GCE Projects page can be added. The fields displayed on the form are :
GCE project
From this menu you must select the Google account and GCE project that owns the instance to add.
GCE instance name
Here you can select the specific instance to add, from a list of all associated with the chosen project.
