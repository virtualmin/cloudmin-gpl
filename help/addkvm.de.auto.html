Vorhandene KVM-Instanz hinzufügen
Auf dieser Seite können Sie ein vorhandenes System, das in einer KVM-Instanz ausgeführt wird, unter die Kontrolle von Cloudmin stellen, sodass die Virtualmin-Domänen von einer zentralen Konsole aus verwaltet werden können. Es können nur Zonen auf Hostsystemen hinzugefügt werden, die bereits auf der Seite KVM- Hostsysteme hinzugefügt wurden. Die im Formular angezeigten Felder sind:
KVM-Hosting-System
In diesem Menü müssen Sie den Computer auswählen, auf dem die Instanz gehostet wird.
KVM-Prozess zu verwalten
Klicken Sie auf die Schaltfläche neben diesem Feld, um eine Liste aller KVM-Instanzen auf dem ausgewählten Host aufzurufen, und wählen Sie diejenige aus, die Sie hinzufügen möchten.
