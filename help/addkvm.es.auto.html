Agregar instancia KVM existente
Esta página le permite llevar un sistema existente que se ejecuta dentro de una instancia de KVM bajo el control de Cloudmin, de modo que sus dominios de Virtualmin se puedan administrar desde una consola central. Solo se pueden agregar zonas en sistemas host que ya se han agregado en la página de sistemas host KVM . Los campos que se muestran en el formulario son:
Sistema de alojamiento KVM
Desde este menú debe seleccionar la máquina en la que está alojada la instancia.
Proceso KVM para gestionar
Haga clic en el botón junto a este campo para que aparezca una lista de todas las instancias de KVM en el host seleccionado y elija la que desea agregar.
