Ajouter une instance KVM existante
Cette page vous permet de placer un système existant s'exécutant dans une instance KVM sous le contrôle de Cloudmin, afin que ses domaines Virtualmin puissent être gérés à partir d'une console centrale. Seules les zones des systèmes hôtes qui ont déjà été ajoutées sur la page Systèmes hôtes KVM peuvent être ajoutées. Les champs affichés sur le formulaire sont:
Système d'hébergement KVM
Dans ce menu, vous devez sélectionner la machine sur laquelle l'instance est hébergée.
Processus KVM à gérer
Cliquez sur le bouton à côté de ce champ pour faire apparaître une liste de toutes les instances KVM sur l'hôte sélectionné, puis choisissez celle que vous souhaitez ajouter.
