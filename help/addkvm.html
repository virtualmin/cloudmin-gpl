Add Existing KVM Instance
This page allows you to bring an existing system running inside a KVM instance under the control of Cloudmin, so that its Virtualmin domains can be managed from a central console. Only zones on host systems that have already been added on the KVM Host Systems page can be added. The fields displayed on the form are :
KVM hosting system
From this menu you must select the machine on which the instance is hosted.
KVM process to manage
Click the button next to this field to bring up a list of all KVM instances on the selected host, and choose the one you want to add.
