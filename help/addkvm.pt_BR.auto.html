Adicionar instância KVM existente
Esta página permite colocar um sistema existente em execução dentro de uma instância KVM sob o controle do Cloudmin, para que seus domínios do Virtualmin possam ser gerenciados a partir de um console central. Somente zonas nos sistemas host que já foram adicionados na página Sistemas Host KVM podem ser adicionadas. Os campos exibidos no formulário são:
Sistema de hospedagem KVM
Nesse menu, você deve selecionar a máquina na qual a instância está hospedada.
Processo KVM para gerenciar
Clique no botão ao lado deste campo para exibir uma lista de todas as instâncias KVM no host selecionado e escolha a que você deseja adicionar.
