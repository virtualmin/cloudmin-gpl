Direcciones IP estáticas EC2
Normalmente, las instancias de EC2 que cree utilizando Cloudmin reciben una dirección IP aleatoriamente. Esto es adecuado para algunas aplicaciones como el procesamiento por lotes, pero no es así para el alojamiento web, de correo o DNS donde se necesita una IP fija, incluso si la instancia se cae y tiene que ser reemplazada.

Afortunadamente, EC2 le permite solicitar direcciones estáticas asociadas con su cuenta. Cada dirección puede asignarse a un único sistema virtual y reemplazará su dirección asignada dinámicamente.

Esta página enumera todas las direcciones IP estáticas de sus cuentas EC2 y le permite solicitar una nueva. Solicitar una dirección es gratuito, pero hay cargos por hora para direcciones no asignadas y para transferir IP entre instancias EC2.
