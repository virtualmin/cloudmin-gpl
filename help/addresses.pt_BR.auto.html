Endereços IP estáticos do EC2
Normalmente, as instâncias do EC2 que você cria usando o Cloudmin recebem um endereço IP aleatoriamente. Isso é adequado para alguns aplicativos, como processamento em lote, mas não para hospedagem na Web, correio ou DNS, onde é necessário um IP fixo - mesmo que a instância ocorra e precise ser substituída.

Felizmente, o EC2 permite solicitar endereços estáticos associados à sua conta. Cada endereço pode ser atribuído a um único sistema virtual e substituirá o endereço atribuído dinamicamente.

Esta página lista todos os endereços IP estáticos pertencentes às suas contas EC2 e permite solicitar um novo. A solicitação de um endereço é gratuita, mas há cobranças por hora de endereços não atribuídos e de transferência de IPs entre instâncias do EC2.
