Vorhandenen VServer hinzufügen
Auf dieser Seite können Sie ein vorhandenes System, das in einer Linux VServer-Instanz ausgeführt wird, unter die Kontrolle von Cloudmin stellen, sodass die Virtualmin-Domänen von einer zentralen Konsole aus verwaltet werden können. Es können nur Zonen auf Hostsystemen hinzugefügt werden, die bereits auf der Seite VServer- Hostsysteme hinzugefügt wurden. Die im Formular angezeigten Felder sind:
VServer-Hosting-System
In diesem Menü müssen Sie den Computer auswählen, auf dem die Instanz gehostet wird.
Name der VServer-Instanz
Wenn Sie ein einzelnes Hostsystem haben, ist dieses Feld ein Menü zum Auswählen einer nicht geänderten Instanz auf diesem Host. Wenn mehrere Hosts vorhanden sind, ist dies ein Textfeld, in dem Sie entweder den Instanznamen eingeben oder ihn aus einem Popup-Fenster auswählen können, das beim Klicken auf die Schaltfläche ... angezeigt wird.
