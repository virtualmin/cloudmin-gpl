Agregar un servidor virtual existente
Esta página le permite llevar un sistema existente que se ejecuta dentro de una instancia de Linux VServer bajo el control de Cloudmin, de modo que sus dominios de Virtualmin se puedan administrar desde una consola central. Solo se pueden agregar zonas en los sistemas host que ya se han agregado en la página VServer Host Systems . Los campos que se muestran en el formulario son:
Sistema de alojamiento VServer
Desde este menú debe seleccionar la máquina en la que está alojada la instancia.
Nombre de instancia de VServer
Si tiene un sistema host único, este campo será un menú para seleccionar una instancia no gestionada en ese host. Si existen varios hosts, este será un campo de texto para ingresar el nombre de la instancia o seleccionarlo desde una ventana emergente que aparece cuando se hace clic en el botón ...
