Add Existing VServer
This page allows you to bring an existing system running inside a Linux VServer instance under the control of Cloudmin, so that its Virtualmin domains can be managed from a central console. Only zones on host systems that have already been added on the VServer Host Systems page can be added. The fields displayed on the form are :
VServer hosting system
From this menu you must select the machine on which the instance is hosted.
VServer instance name
If you have a single host system, this field will be a menu for selecting an un-mananged instance on that host. If multiple hosts exist, this will be a text field for either entering the instance name, or selecting it from a popup window that appears when the ... button is clicked.
