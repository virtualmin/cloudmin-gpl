Adicionar VServer existente
Esta página permite colocar um sistema existente em execução dentro de uma instância do Linux VServer sob o controle do Cloudmin, para que seus domínios do Virtualmin possam ser gerenciados a partir de um console central. Somente zonas nos sistemas host que já foram adicionados na página VServer Host Systems podem ser adicionadas. Os campos exibidos no formulário são:
Sistema de hospedagem VServer
Nesse menu, você deve selecionar a máquina na qual a instância está hospedada.
Nome da instância do VServer
Se você tiver um único sistema host, esse campo será um menu para selecionar uma instância não gerenciada nesse host. Se existirem vários hosts, este será um campo de texto para inserir o nome da instância ou selecioná-lo em uma janela pop-up que aparece quando o botão ... é clicado.
