Agregar instancia Xen existente
Esta página le permite llevar un sistema existente que se ejecuta dentro de una instancia de Xen bajo el control de Cloudmin, para que sus dominios de Virtualmin se puedan administrar desde una consola central. Solo se pueden agregar zonas en los sistemas host que ya se han agregado en la página Xen Host Systems . Los campos que se muestran en el formulario son:
Sistema de alojamiento Xen
Desde este menú debe seleccionar la máquina en la que está alojada la instancia.
Instancia de Xen
Si tiene un sistema host único, este campo será un menú para seleccionar una instancia no gestionada en ese host. Si existen varios hosts, este será un campo de texto para ingresar el nombre de la instancia o seleccionarlo desde una ventana emergente que aparece cuando se hace clic en el botón ...
Archivo de configuración de Xen en el sistema de alojamiento
Para administrar la instancia, Cloudmin necesita saber la ubicación del archivo .cfg Xen desde el que se creó originalmente. Ingrese la ruta completa al archivo de configuración en el sistema host aquí.
