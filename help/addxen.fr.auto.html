Ajouter une instance Xen existante
Cette page vous permet de placer un système existant exécuté dans une instance Xen sous le contrôle de Cloudmin, afin que ses domaines Virtualmin puissent être gérés à partir d'une console centrale. Seules les zones sur les systèmes hôtes qui ont déjà été ajoutées sur la page Xen Host Systems peuvent être ajoutées. Les champs affichés sur le formulaire sont:
Système d'hébergement Xen
Dans ce menu, vous devez sélectionner la machine sur laquelle l'instance est hébergée.
Instance Xen
Si vous avez un seul système hôte, ce champ sera un menu pour sélectionner une instance non gérée sur cet hôte. S'il existe plusieurs hôtes, il s'agira d'un champ de texte permettant soit de saisir le nom de l'instance, soit de le sélectionner dans une fenêtre contextuelle qui apparaît lorsque le bouton ... est cliqué.
Fichier de configuration Xen sur le système d'hébergement
Pour gérer l'instance, Cloudmin doit connaître l'emplacement du fichier Xen .cfg il a été créé à l'origine. Entrez donc ici le chemin complet du fichier de configuration sur le système hôte.
