Add Existing Xen Instance
This page allows you to bring an existing system running inside a Xen instance under the control of VM2, so that its Virtualmin domains can be managed from a central console. Only zones on host systems that have already been added on the Xen Host Systems page can be added. The fields displayed on the form are :
Xen hosting system
From this menu you must select the machine on which the instance is hosted.
Xen instance
If you have a single host system, this field will be a menu for selecting an un-mananged instance on that host. If multiple hosts exist, this will be a text field for either entering the instance name, or selecting it from a popup window that appears when the ... button is clicked.
Xen configuration file on hosting system
In order to manage the instance, VM2 needs to know the location of the Xen .cfg file that it was originally created from. So enter the full path to the config file on the host system here.
