Aggiungi istanza Xen esistente
Questa pagina consente di portare un sistema esistente in esecuzione all'interno di un'istanza Xen sotto il controllo di Cloudmin, in modo che i suoi domini Virtualmin possano essere gestiti da una console centrale. È possibile aggiungere solo le zone sui sistemi host che sono già state aggiunte nella pagina Sistemi host Xen . I campi visualizzati nel modulo sono:
Sistema di hosting Xen
Da questo menu è necessario selezionare la macchina su cui è ospitata l'istanza.
Istanza Xen
Se hai un singolo sistema host, questo campo sarà un menu per selezionare un'istanza non gestita su quell'host. Se esistono più host, questo sarà un campo di testo per inserire il nome dell'istanza o selezionarlo da una finestra pop-up che appare quando si fa clic sul pulsante ...
File di configurazione di Xen sul sistema di hosting
Per gestire l'istanza, Cloudmin deve conoscere la posizione del file .cfg Xen da cui è stato originariamente creato. Quindi inserisci qui il percorso completo del file di configurazione sul sistema host.
