Adicionar instância Xen existente
Esta página permite colocar um sistema existente em execução em uma instância do Xen sob o controle do Cloudmin, para que seus domínios do Virtualmin possam ser gerenciados a partir de um console central. Somente zonas nos sistemas host que já foram adicionados na página Xen Host Systems podem ser adicionadas. Os campos exibidos no formulário são:
Sistema de hospedagem Xen
Nesse menu, você deve selecionar a máquina na qual a instância está hospedada.
Instância Xen
Se você tiver um único sistema host, esse campo será um menu para selecionar uma instância não gerenciada nesse host. Se existirem vários hosts, este será um campo de texto para inserir o nome da instância ou selecioná-lo em uma janela pop-up que aparece quando o botão ... é clicado.
Arquivo de configuração do Xen no sistema de hospedagem
Para gerenciar a instância, o Cloudmin precisa saber o local do arquivo .cfg do Xen do qual foi originalmente criado. Portanto, digite o caminho completo para o arquivo de configuração no sistema host aqui.
