Vorhandene Solaris-Zone hinzufügen
Auf dieser Seite können Sie ein vorhandenes System, das in einer Solaris-Zone ausgeführt wird, unter die Kontrolle von Cloudmin stellen, sodass die Virtualmin-Domänen von einer zentralen Konsole aus verwaltet werden können. Es können nur Zonen auf Hostsystemen hinzugefügt werden, die bereits auf der Seite Solaris Zones Host Systems hinzugefügt wurden. Die im Formular angezeigten Felder sind:
Hosting-System von Solaris Zones
In diesem Menü müssen Sie den Computer auswählen, auf dem die Zone gehostet wird.
Zonenname
Wenn Sie ein einzelnes Hostsystem haben, ist dieses Feld ein Menü zum Auswählen einer nicht geänderten Zone auf diesem Host. Wenn mehrere Hosts vorhanden sind, ist dies ein Textfeld, in dem Sie entweder den Zonennamen eingeben oder ihn aus einem Popup-Fenster auswählen können, das angezeigt wird, wenn Sie auf die Schaltfläche ... klicken.
