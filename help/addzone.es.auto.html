Agregar zona Solaris existente
Esta página le permite llevar un sistema existente que se ejecuta dentro de una Zona Solaris bajo el control de Cloudmin, de modo que sus dominios de Virtualmin se puedan administrar desde una consola central. Solo se pueden agregar zonas en sistemas host que ya se han agregado en la página Sistemas Solaris Zones Host . Los campos que se muestran en el formulario son:
Sistema de alojamiento de zonas Solaris
Desde este menú debe seleccionar la máquina en la que está alojada la zona.
Nombre de zona
Si tiene un único sistema host, este campo será un menú para seleccionar una zona no gestionada en ese host. Si existen varios hosts, este será un campo de texto para ingresar el nombre de la zona o seleccionarlo desde una ventana emergente que aparece cuando se hace clic en el botón ...
