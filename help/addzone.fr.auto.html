Ajouter une zone Solaris existante
Cette page vous permet de placer un système existant exécuté dans une zone Solaris sous le contrôle de Cloudmin, afin que ses domaines Virtualmin puissent être gérés à partir d'une console centrale. Seules les zones sur les systèmes hôtes qui ont déjà été ajoutés sur les systèmes hôte des zones Solaris la page peuvent être ajoutés. Les champs affichés sur le formulaire sont:
Système d'hébergement Solaris Zones
Dans ce menu, vous devez sélectionner la machine sur laquelle la zone est hébergée.
Nom de zone
Si vous avez un seul système hôte, ce champ sera un menu pour sélectionner une zone non gérée sur cet hôte. S'il existe plusieurs hôtes, ce sera un champ de texte pour saisir le nom de la zone ou le sélectionner dans une fenêtre contextuelle qui apparaît lorsque le bouton ... est cliqué.
