Add Existing Solaris Zone
This page allows you to bring an existing system running inside a Solaris Zone under the control of VM2, so that its Virtualmin domains can be managed from a central console. Only zones on host systems that have already been added on the Solaris Zones Host Systems page can be added. The fields displayed on the form are :
Solaris Zones hosting system
From this menu you must select the machine on which the zone is hosted.
Zone name
If you have a single host system, this field will be a menu for selecting an un-mananged zone on that host. If multiple hosts exist, this will be a text field for either entering the zone name, or selecting it from a popup window that appears when the ... button is clicked.
