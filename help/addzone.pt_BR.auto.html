Adicionar zona existente do Solaris
Esta página permite colocar um sistema existente em execução dentro de uma Zona Solaris sob o controle do Cloudmin, para que seus domínios do Virtualmin possam ser gerenciados a partir de um console central. Somente zonas nos sistemas host que já foram adicionados na página Sistemas Solaris Zones Host podem ser adicionadas. Os campos exibidos no formulário são:
Sistema de hospedagem Solaris Zones
Nesse menu, você deve selecionar a máquina na qual a zona está hospedada.
Nome da zona
Se você tiver um único sistema host, esse campo será um menu para selecionar uma zona não gerenciada nesse host. Se existirem vários hosts, este será um campo de texto para inserir o nome da zona ou selecioná-lo em uma janela pop-up que aparece quando o botão ... é clicado.
