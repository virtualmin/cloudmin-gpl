Systemwarnungen
Eine Cloudmin-Systemwarnung überwacht ein oder mehrere verwaltete Systeme und prüft, ob eine Variable wie freier Speicher, CPU-Auslastung oder freier Speicherplatz über oder unter einem bestimmten Schwellenwert liegt. In diesem Fall kann eine E-Mail an den Hauptadministrator, die Systembesitzer oder andere Adressen gesendet werden.

Diese Seite listet alle vorhandenen Warnungen auf und zeigt die Systeme an, auf denen sie ausgelöst werden. Um eine neue Warnung zu erstellen, klicken Sie auf den Link Neue Systemwarnung hinzufügen. Daraufhin wird eine Seite zur Eingabe der Details angezeigt. Um Warnungen zu entfernen, aktivieren Sie die Kontrollkästchen daneben und klicken Sie auf die Schaltfläche Ausgewählte Warnungen löschen.

Die Systeme, die jeder Alarm überwacht, können Host für Host, über Gruppenmitgliedschaft, nach Eigentümer oder nach Virtualisierungstyp ausgewählt werden. Oder Sie können eine Warnung erstellen, die alle bekannten Systeme überwacht.

Jede Warnung enthält eine oder mehrere Regeln, von denen jede eine zu überwachende Variable (wie die CPU-Auslastung), einen Schwellenwert (wie 0,9), einen Zeitraum, für den die Variable den Schwellenwert überschreiten muss, und eine Reihe von Systemen angibt, auf denen dies geschehen muss für den Alarm zu feuern.

Wenn eine Warnung ausgelöst wird, kann eine E-Mail an den Cloudmin-Hauptadministrator, die Eigentümer der entsprechenden Systeme oder an andere Adressen Ihrer Wahl gesendet werden. Jede Warnung kann auch ein Intervall zwischen Nachrichten angeben.
