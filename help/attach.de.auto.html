Angehängte EC2-Volumes
Auf dieser Seite werden EC2-Volumes aufgelistet, die bereits an dieses System angeschlossen sind, und Sie können ein neues Volume hinzufügen, falls eines definiert wurde. Wenn Sie ein Volume hinzufügen, können Sie optional ein Dateisystem darauf erstellen und in einem Verzeichnis bereitstellen. Cloudmin erstellt das Dateisystem jedoch nicht neu, wenn festgestellt wird, dass bereits eines vorhanden ist.

Bestehende Volumes können vom System getrennt werden, ohne dass die darin enthaltenen Daten verloren gehen. Cloudmin versucht, das Gerät des Volumes zu entfernen. Dies ist jedoch nicht möglich, wenn es aktiv verwendet wird - beispielsweise von einem Webserver oder einer MySQL-Datenbank. Nach dem Trennen kann das Volume an ein anderes System angeschlossen werden.
