Volúmenes EC2 adjuntos
Esta página enumera los volúmenes EC2 ya conectados a este sistema y le permite agregar un nuevo volumen si se ha definido alguno. Al agregar un volumen, opcionalmente puede crear un sistema de archivos en él y montarlo en algún directorio; sin embargo, Cloudmin no volverá a crear el sistema de archivos si detecta que ya existe.

Los volúmenes existentes se pueden separar del sistema sin ninguna pérdida de los datos que contienen. Cloudmin intentará desmontar el dispositivo del volumen, pero esto no es posible si está en uso activo, por ejemplo, por un servidor web o una base de datos MySQL. Una vez separado, el volumen se puede conectar a un sistema diferente.
