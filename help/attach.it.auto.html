Volumi EC2 allegati
Questa pagina elenca i volumi EC2 già collegati a questo sistema e consente di aggiungere un nuovo volume se ne è stato definito uno. Quando si aggiunge un volume, è possibile avere un file system creato su di esso e montato su una directory, ma Cloudmin non ricrea il file system se rileva che esiste già.

I volumi esistenti possono essere staccati dal sistema senza alcuna perdita dei dati in essi contenuti. Cloudmin tenterà di disinstallare il dispositivo del volume, ma ciò non è possibile se è in uso attivo, ad esempio un server Web o un database MySQL. Una volta rimosso, il volume può essere collegato a un altro sistema.
