Volumes EC2 anexados
Esta página lista os volumes do EC2 já conectados a este sistema e permite adicionar um novo volume, se houver algum definido. Ao adicionar um volume, você pode, opcionalmente, ter um sistema de arquivos criado e montado em algum diretório - no entanto, o Cloudmin não recriará o sistema de arquivos se detectar que ele já existe.

Os volumes existentes podem ser desanexados do sistema sem perda dos dados que eles contêm. O Cloudmin tentará desmontar o dispositivo do volume, mas isso não é possível se estiver em uso ativo - por exemplo, por um servidor Web ou banco de dados MySQL. Uma vez desconectado, o volume pode ser anexado a um sistema diferente.
