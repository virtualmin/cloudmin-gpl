Compress archives with gzip

When enabled, backups use gzip-compressed .tar.gz archives. When disabled, they use uncompressed .tar archives. Compression is enabled by default. Both formats contain the same machine data and checksums, and restore accepts either format.

Compression can reduce transfer time and destination space, but uses CPU and can make the backup take longer. Already compressed or encrypted disk contents may shrink very little. Cloudmin finishes source cleanup before compression starts.

Compression does not remove the need for temporary full disk copies.
