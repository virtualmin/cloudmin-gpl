Prepare running machines

A responding guest agent lets Cloudmin freeze filesystem writes briefly and take a snapshot while the machine keeps running. Databases and other applications may need their own preparation for a consistent backup.

The shutdown method stops the machine cleanly before copying and restarts it afterward. It is required when a machine has both file and LVM disks. Machines that were already stopped stay stopped.

A failed shutdown stops the backup. Cloudmin does not force power off. If live UEFI backup fails because firmware variables changed, retry with a clean shutdown. Use the job recovery action if cleanup fails.
