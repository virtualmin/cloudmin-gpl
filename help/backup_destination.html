Backup destination

Backups can use local or mounted storage, SFTP, or a supported cloud provider. Set up remote directories and storage accounts first. Mount NFS storage on this host before using it.

S3 requires the AWS CLI, Azure the Azure CLI, and Backblaze the B2 CLI. Google and Dropbox require OAuth application credentials and a refresh token. The destination account needs write access, read access for restore, and delete access for retention.

Archives contain guest credentials and are not encrypted by Cloudmin. Keep them private. Remote backups still need local temporary space.
