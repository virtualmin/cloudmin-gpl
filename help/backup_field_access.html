Access key or OAuth client ID
  • S3: the access key ID for the AWS or S3-compatible account.
  • Backblaze B2: the application key ID.
  • Google Cloud Storage or Google Drive: your OAuth application's client ID.
  • Dropbox: your Dropbox application's app key.

Enter the matching secret separately. Google and Dropbox also require an OAuth refresh token obtained for that same application and account. Authorize the application before using this form.
