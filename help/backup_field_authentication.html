Authentication

Password shows a username and password. Enter the remote account's login name and password; no username is prefilled. The account must allow SFTP and have access to the backup directory. Password transfers require sshpass on the Cloudmin host.

Private key file on this host uses an absolute path to a private SSH key on the Cloudmin host. Install its public key in the remote account's authorized_keys. The key must work without a passphrase prompt; backup jobs cannot answer prompts or use your workstation's SSH agent.

The username is hidden in private-key mode. Switching to this mode keeps the username entered under Password, or uses root when it is blank. To use a different key login, enter its username under Password first, then select Private key file on this host. Switching to a key clears any saved password.

When editing a schedule, a saved password is never sent back to the browser. Leave its field blank to keep it, enter a replacement to change it, or select Clear saved value to remove it. Password mode still requires a password.

Server identity is checked separately. Unknown servers and changed host keys require fingerprint confirmation before a transfer.
