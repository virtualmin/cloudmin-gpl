Authentication

The remote account must allow SFTP and have access to the backup directory. Password login requires sshpass on this host.

For key login, enter an absolute path to a private key on this host and install its public key in the remote account. The key must work without a passphrase prompt.

Key login keeps the username entered in password mode, or uses root if blank. To change it, enter the username in password mode before switching to key login.

When editing a schedule, a blank password keeps the saved value. Enter a replacement or explicitly clear it. Switching to key login clears the saved password.
