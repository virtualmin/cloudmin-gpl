SSH server

Enter the remote server's hostname or IP address. Enter its port and login in their separate fields; do not enter an sftp:// URL or user@host.

Cloudmin reuses matching trusted entries from root's ~/.ssh/known_hosts and /etc/ssh/ssh_known_hosts on the Cloudmin host. An unknown server prompts you to confirm its fingerprints. Check them with the server administrator before choosing Trust Host Key.

If a key changes, transfers stop. A legitimate change, such as a server reinstallation, can be approved with Trust New Host Key after verifying the new fingerprints. Cloudmin saves that approval privately without editing the host's SSH files. Schedules cannot approve keys: use the form to approve the change before their next run.

SSH verifies the server's key on every transfer. This is separate from the password or private key used to log in.
