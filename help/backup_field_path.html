Directory or folder

Enter the archive directory or folder, without a filename. Parent-directory components (..) are not allowed.

  • Local storage: an absolute path such as /var/backups/cloudmin. Existing directories must not be symlinks or writable by other users. Mount remote storage first.
  • SFTP: an existing absolute directory on the remote server.
  • S3, Google Cloud Storage, Azure or Backblaze: an optional prefix inside the bucket, such as cloudmin/daily.
  • Dropbox: a folder relative to the accessible root, without a leading slash.
  • Google Drive: an existing folder name or nested path, not a folder ID or sharing URL.
