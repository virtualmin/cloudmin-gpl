Directory or folder

Enter the directory or folder that holds the archives, not an archive filename. For restore, enter the filename separately.

  • Local storage: an absolute path on this host, such as /var/backups/cloudmin. A missing backup directory is created privately. An existing directory must not be a symlink or be writable by group or other users. For mounted storage, mount it before running the backup.
  • SSH: an existing absolute directory on the remote server, such as /srv/backups. The chosen login needs access to it. Wildcards are not allowed.
  • S3, Google Cloud Storage, Azure and Backblaze: an optional object prefix inside the bucket or container, such as cloudmin/daily. Leave it blank to use the bucket or container root.
  • Dropbox: a folder relative to the account or application's accessible root, without a leading slash. Leave it blank for that root.
  • Google Drive: an existing folder name or nested path, such as Backups/Cloudmin. Enter names, not a folder ID or sharing URL.

Paths are literal: parent-directory components (..) are not accepted.
