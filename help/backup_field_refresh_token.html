OAuth refresh token

Enter a refresh token issued for the Google or Dropbox account and application configured above. Cloudmin exchanges it for a short-lived access token when it transfers an archive. An access token cannot be used in this field.

Authorize the application outside this form with access to the required storage. It needs write permission for backups, read permission for restore, and delete permission for retention or manual deletion. If authorization is revoked, obtain a new refresh token.

When editing a schedule, leave this field blank to keep its saved token for the same provider. Enter a new token to replace it. Clear saved value removes the stored token, but Google and Dropbox still require one to save the destination.
