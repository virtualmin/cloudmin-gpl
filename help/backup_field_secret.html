Secret key or OAuth client secret

Enter the secret that matches the selected provider: an S3 secret access key, Azure storage account key, Backblaze application key, Google OAuth client secret, or Dropbox app secret. For Azure, use an account key, not a SAS URL.

Saved schedule secrets are never sent back to the browser. Leave this field blank to keep the saved value for the same provider, or enter a replacement. Clear saved value removes it, but the chosen provider still requires a secret to save the destination. Changing providers does not reuse the old secret.
