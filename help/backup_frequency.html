Run

Choose how often the backup runs. Only the time fields used by that choice are shown:

  • Hourly: once each hour, at the selected minute. For example, minute 15 runs at 00:15, 01:15, 02:15 and so on.
  • Daily: every day at the selected hour and minute.
  • Weekly: on the selected day of the week, at the chosen time.
  • Monthly: on the selected day of each month, at the chosen time.
  • Yearly: on the selected month and day each year, at the chosen time.

All times use the Cloudmin host's timezone and a 24-hour clock. New schedules default to daily at 02:00. The schedule must be enabled to run automatically.

Calendar dates that do not occur are skipped: a monthly run on day 31 will not run in April, and a yearly run on February 29 runs only in leap years. Choose a day from 1 to 28 if a monthly backup must run every month.

Selected machines are backed up one at a time. Runs of the same schedule do not overlap. Other backups or disk work can delay a run.
