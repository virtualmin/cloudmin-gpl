Virtual machines

All virtual machines selects every machine on this host when you submit a manual backup. A schedule selects them when each run starts, so it also includes machines created after the schedule was saved. Selected virtual machines backs up only the checked machines.

Each machine gets its own full archive. Selecting several machines queues their disk work to avoid copying them all at once. Choose how to prepare running machines under Backup options. Stopped machines remain stopped.

Backups support managed file disks, attached media, LVM and LVM-thin disks. They do not capture RAM or unmanaged host devices. A backup of a machine with disk snapshots contains independent disk copies, not its snapshot history.
