Copias de seguridad del sistema
Cloudmin le permite hacer una copia de seguridad de los sistemas de archivos de los sistemas virtuales, ya sea de forma regular o bajo demanda a través de la interfaz de usuario web. Las copias de seguridad están limitadas a los sistemas que posee, y pueden estar limitadas aún más por la cantidad de espacio en disco otorgada para las copias de seguridad en su plan, si usted es el propietario del sistema.

Al crear una copia de seguridad, puede seleccionar los sistemas a incluir y un destino. El destino puede ser uno de:

  • Destino predeterminado para el sistema host
    Esta es una ubicación elegida por el administrador maestro de Cloudmin, como un directorio en un sistema de respaldo centralizado o el host para los sistemas virtuales seleccionados.

  • Servidor SSH remoto
    Este puede ser cualquier sistema accesible a través de SSH, incluso uno no administrado por Cloudmin.

  • Servidor FTP remoto
    Este puede ser cualquier sistema accesible a través de FTP que permita cargas.

Al definir una copia de seguridad, puede seleccionar si los sistemas virtuales se cerrarán durante el proceso o no. Esto interrumpirá cualquier servicio que puedan estar realizando, pero asegura la coherencia del sistema de archivos y las bases de datos que alojan. Los sistemas que se cerraron se reiniciarán cuando se complete la copia de seguridad.

Una copia de seguridad también puede tener una programación, que define con qué frecuencia se ejecuta automáticamente, y una dirección de correo electrónico para enviar un informe de copia de seguridad o un informe de falla.
