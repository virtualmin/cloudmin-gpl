System Backups
Cloudmin allows you to backup the filesystems of virtual systems, either on a regular schedule or on demand via the web UI. Backups are limited to systems you own, and may be further limited by the amount of disk space granted for backups in your plan, if you are a system owner.

When creating a backup, you can select the systems to include and a destination. The destination can be one of :

  • Default destination for host system
    This is a location chosen by the Cloudmin master administrator, such as a directory on a centralized backup system or the host for the selected virtual systems.

  • Remote SSH server
    This can be any system accessible via SSH, even one not managed by Cloudmin.

  • Remote FTP server
    This can be any system accessible via FTP that allows uploads.

When defining a backup, you can select if virtual systems will be shut down during the process or not. This will interrupt any serving they might be performing, but ensures consistency of the filesystem and any databases they host. Systems that were shut down will be re-started when the backup completes.

A backup can also have a schedule, which defines how often it is automatically run, and an email address to send a backup report or failure report to.
