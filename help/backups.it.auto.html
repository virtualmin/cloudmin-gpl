Backup di sistema
Cloudmin ti consente di eseguire il backup dei filesystem dei sistemi virtuali, su una pianificazione regolare o su richiesta tramite l'interfaccia utente web. I backup sono limitati ai sistemi di tua proprietà e possono essere ulteriormente limitati dalla quantità di spazio su disco concesso per i backup nel tuo piano, se sei un proprietario del sistema.

Quando si crea un backup, è possibile selezionare i sistemi da includere e una destinazione. La destinazione può essere una di:

  • Destinazione predefinita per il sistema host
    Questa è una posizione scelta dall'amministratore principale di Cloudmin, come una directory su un sistema di backup centralizzato o l'host per i sistemi virtuali selezionati.

  • Server SSH remoto
    Questo può essere qualsiasi sistema accessibile tramite SSH, anche uno non gestito da Cloudmin.

  • Server FTP remoto
    Questo può essere qualsiasi sistema accessibile via FTP che consenta il caricamento.

Quando si definisce un backup, è possibile selezionare se i sistemi virtuali verranno arrestati durante il processo o meno. Ciò interromperà qualsiasi servizio che potrebbero essere in esecuzione, ma garantisce la coerenza del file system e di tutti i database che ospitano. I sistemi arrestati verranno riavviati al termine del backup.

Un backup può anche avere una pianificazione, che definisce la frequenza con cui viene eseguito automaticamente, e un indirizzo e-mail a cui inviare un rapporto di backup o un rapporto di errore.
