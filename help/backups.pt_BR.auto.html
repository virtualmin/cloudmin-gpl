Backups do sistema
O Cloudmin permite fazer backup dos sistemas de arquivos dos sistemas virtuais, regularmente, ou sob demanda, através da interface do usuário da web. Os backups são limitados aos sistemas que você possui e podem ser ainda mais limitados pela quantidade de espaço em disco concedido para backups em seu plano, se você for o proprietário do sistema.

Ao criar um backup, você pode selecionar os sistemas a serem incluídos e um destino. O destino pode ser um dos seguintes:

  • Destino padrão para o sistema host
    Este é um local escolhido pelo administrador principal do Cloudmin, como um diretório em um sistema de backup centralizado ou o host dos sistemas virtuais selecionados.

  • Servidor SSH remoto
    Pode ser qualquer sistema acessível via SSH, mesmo que não seja gerenciado pelo Cloudmin.

  • Servidor FTP remoto
    Pode ser qualquer sistema acessível via FTP que permita uploads.

Ao definir um backup, você pode selecionar se os sistemas virtuais serão encerrados durante o processo ou não. Isso interromperá qualquer veiculação que eles possam estar executando, mas garante a consistência do sistema de arquivos e de todos os bancos de dados que eles hospedam. Os sistemas que foram desligados serão reiniciados quando o backup for concluído.

Um backup também pode ter um agendamento, que define com que frequência é executado automaticamente, e um endereço de email para o qual enviar um relatório de backup ou de falha.
