Резервные копии системы
Cloudmin позволяет создавать резервные копии файловых систем виртуальных систем, либо по регулярному расписанию, либо по запросу через веб-интерфейс. Резервное копирование ограничено системами, которыми вы владеете, и может быть дополнительно ограничено объемом дискового пространства, предоставленного для резервного копирования в вашем плане, если вы являетесь владельцем системы.

При создании резервной копии вы можете выбрать системы для включения и место назначения. Пункт назначения может быть одним из:

  • Назначение по умолчанию для хост-системы
    Это местоположение, выбранное главным администратором Cloudmin, такое как каталог в централизованной системе резервного копирования или хост для выбранных виртуальных систем.

  • Удаленный SSH сервер
    Это может быть любая система, доступная через SSH, даже не управляемая Cloudmin.

  • Удаленный FTP-сервер
    Это может быть любая система, доступная через FTP, которая позволяет загружать файлы.

При определении резервной копии вы можете выбрать, будут ли виртуальные системы закрываться во время процесса или нет. Это прервет любое обслуживание, которое они могут выполнять, но гарантирует согласованность файловой системы и любых баз данных, которые они размещают. Системы, которые были закрыты, будут перезапущены после завершения резервного копирования.

Резервная копия также может иметь расписание, которое определяет частоту ее автоматического запуска, и адрес электронной почты, на который следует отправить отчет о резервной копии или отчет об ошибке.
