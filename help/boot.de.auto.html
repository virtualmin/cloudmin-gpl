Startmethode ändern
Auf dieser Seite können Sie auswählen, wie ein virtuelles System gestartet werden soll. Dies bestimmt normalerweise, ob es einen eigenen Kernel oder die Kernelversion vom Hostsystem verwendet. Nicht alle Startmethoden sind für alle virtuellen Systeme verfügbar. Beispielsweise kann eine Methode ohne installierten Kernel nicht von dieser starten.

Sie können auch auswählen, von welchem virtuellen Festplattengerät das System gestartet werden soll. Beim Erstellen eines leeren Systems wird dieses möglicherweise zunächst auf die CD-ROM eingestellt, kann jedoch nach Abschluss der Erstellung auf die Festplatte geändert werden.
