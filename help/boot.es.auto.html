Cambiar método de arranque
Esta página le permite seleccionar cómo se inicia un sistema virtual. Esto generalmente determina si usa su propio núcleo o la versión del núcleo del sistema host. No todos los métodos de arranque están disponibles para todos los sistemas virtuales; por ejemplo, uno sin un núcleo instalado no podrá arrancar desde él.

También puede seleccionar desde qué dispositivo de disco virtual se iniciará el sistema. Al crear un sistema vacío, esto puede configurarse inicialmente en el CD-ROM, pero puede cambiarse al disco duro una vez completada la creación.
