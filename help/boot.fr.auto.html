Changer la méthode de démarrage
Cette page vous permet de sélectionner le mode de démarrage d'un système virtuel. Cela détermine généralement s'il utilise son propre noyau ou la version du noyau du système hôte. Toutes les méthodes de démarrage ne sont pas disponibles pour tous les systèmes virtuels - par exemple, une sans noyau installé ne pourra pas démarrer à partir de celui-ci.

Vous pouvez également sélectionner le périphérique de disque virtuel à partir duquel le système démarrera. Lors de la création d'un système vide, celui-ci peut être initialement défini sur le CD-ROM, mais peut être modifié sur le disque dur une fois la création terminée.
