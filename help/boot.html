Change Boot Method
This page allows you to select how a virtual system is booted. This typically determines if it uses its own kernel, or the kernel version from the host system. Not all boot methods are available for all virtual systems - for example, one without a kernel installed will not be able to boot from it.

You can also select whick virtual disk device the system will boot from. When creating an empty system this might be initially set to the CD-ROM, but can be changed to the hard disk after creation is complete.
