Alterar método de inicialização
Esta página permite que você selecione como um sistema virtual é inicializado. Isso normalmente determina se ele usa seu próprio kernel ou a versão do kernel do sistema host. Nem todos os métodos de inicialização estão disponíveis para todos os sistemas virtuais - por exemplo, um sem um kernel instalado não poderá inicializá-lo.

Você também pode selecionar em qual dispositivo de disco virtual o sistema será inicializado. Ao criar um sistema vazio, isso pode ser definido inicialmente no CD-ROM, mas pode ser alterado para o disco rígido após a conclusão da criação.
