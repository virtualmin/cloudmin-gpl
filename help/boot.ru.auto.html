Изменить способ загрузки
На этой странице вы можете выбрать способ загрузки виртуальной системы. Это обычно определяет, использует ли оно свое собственное ядро или версию ядра из хост-системы. Не все методы загрузки доступны для всех виртуальных систем - например, один из них без установленного ядра не сможет загрузиться с него.

Вы также можете выбрать виртуальное дисковое устройство, с которого будет загружаться система. При создании пустой системы это может быть первоначально установлено на CD-ROM, но может быть изменено на жесткий диск после завершения создания.
