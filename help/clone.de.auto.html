Klonsystem
Auf dieser Seite können Sie einen Klon eines vorhandenen virtuellen Systems erstellen, der eine Kopie der Festplatten des Originals mit demselben Kennwort, demselben Besitz und denselben Ressourcenbeschränkungen enthält. Es werden ein neuer Hostname und neue IP-Adressen zugewiesen, um Konflikte mit dem Original zu vermeiden. Der neue Klon wird auf demselben System wie das Original gehostet, das über ausreichend freien RAM und Speicherplatz verfügt.

Um einen Klon zu erstellen, müssen Sie ein neues Hostnamenpräfix und eine Beschreibung für den neuen Klon eingeben. In der Regel wird ein Domänenname automatisch an den Hostnamen angehängt, vorausgesetzt, auf dem Hostsystem ist eine DNS-Domäne konfiguriert.

Standardmäßig werden dem neuen Klon IP-Adressen automatisch aus dem auf seinem Host eingerichteten Zuordnungsbereich zugewiesen. Sie können jedoch festlegen, dass IPs stattdessen manuell eingegeben werden, wenn Sie dazu berechtigt sind.
