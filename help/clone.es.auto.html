Sistema de clonación
Esta página le permite crear un clon de un sistema virtual existente, que tendrá una copia de los discos del original, la misma contraseña, propiedad y límites de recursos. Se le asignará un nuevo nombre de host y direcciones IP, para evitar conflictos con el original. El nuevo clon estará alojado en el mismo sistema que el original, que tiene suficiente RAM libre y espacio en disco.

Para crear un clon, debe ingresar un nuevo prefijo de nombre de host y una descripción para el nuevo clon. Normalmente, un nombre de dominio se agregará automáticamente al nombre de host, suponiendo que el sistema host tenga configurado un dominio DNS.

Por defecto, el nuevo clon tendrá direcciones IP asignadas automáticamente desde la configuración del rango de asignación en su host. Sin embargo, puede seleccionar ingresar IP manualmente en su lugar, si tiene permisos para hacerlo.
