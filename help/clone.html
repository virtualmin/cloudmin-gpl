Clone System
This page allows you to create a clone of an existing virtual system, which will have a copy of the original's disks, the same password, ownership and resource limits. It will be assigned a new hostname and IP addresses, in order to avoid conflicting with the original. The new clone will be hosted on the same system as the original, which much have enough free RAM and disk space.

To create a clone you must enter a new hostname prefix and a description for the new clone. Typically a domain name will be automatically appended to the hostname, assuming that the host system has a DNS domain configured.

By default the new clone will have IP addresses assigned automatically from the allocation range setup on its host. However, you can select to enter IPs manually instead, if you have permissions to do this.
