Sistema di clonazione
Questa pagina consente di creare un clone di un sistema virtuale esistente, che avrà una copia dei dischi dell'originale, la stessa password, gli stessi limiti di proprietà e risorse. Verranno assegnati un nuovo nome host e indirizzi IP, al fine di evitare conflitti con l'originale. Il nuovo clone sarà ospitato sullo stesso sistema dell'originale, che ha abbastanza spazio libero su RAM e su disco.

Per creare un clone è necessario inserire un nuovo prefisso del nome host e una descrizione per il nuovo clone. In genere un nome di dominio verrà automaticamente aggiunto al nome host, presupponendo che il sistema host abbia un dominio DNS configurato.

Per impostazione predefinita, il nuovo clone avrà indirizzi IP assegnati automaticamente dall'impostazione dell'intervallo di allocazione sul proprio host. Tuttavia, puoi selezionare invece di inserire manualmente gli IP, se disponi delle autorizzazioni per farlo.
