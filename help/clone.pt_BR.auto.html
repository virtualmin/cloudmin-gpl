Sistema de clonagem
Esta página permite criar um clone de um sistema virtual existente, que terá uma cópia dos discos do original, a mesma senha, propriedade e limites de recursos. Será atribuído um novo nome de host e endereços IP, a fim de evitar conflitos com o original. O novo clone será hospedado no mesmo sistema que o original, que possui bastante RAM e espaço em disco suficientes.

Para criar um clone, você deve inserir um novo prefixo de nome de host e uma descrição para o novo clone. Normalmente, um nome de domínio será automaticamente anexado ao nome do host, supondo que o sistema host tenha um domínio DNS configurado.

Por padrão, o novo clone terá endereços IP atribuídos automaticamente a partir da configuração do intervalo de alocação em seu host. No entanto, você pode optar por inserir IPs manualmente, se tiver permissões para fazer isso.
