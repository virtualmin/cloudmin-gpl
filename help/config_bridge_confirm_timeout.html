Bridge confirmation timeout in seconds

Time allowed to apply a host bridge change, reconnect and click Keep Network Settings. The timer starts before Cloudmin applies the change. The default is 180 seconds; allowed values are 120 to 900 seconds.

The minimum leaves time for the apply service, which can run for up to 90 seconds. Without confirmation, Cloudmin restores the previous network settings.

Changing this value does not extend a pending change. Restarting the host before confirmation also restores the previous settings.
