Image catalogue columns
Choose which columns appear in the Image Catalogue tab. The Image column is always shown so you can open an entry's details or edit a custom image. Columns appear in their standard order.

Download size shows the estimated file size, separate from the virtual machine's minimum disk capacity. It uses the last known size or the bundled estimate. An unavailable size is shown as Unknown.

This setting applies to all users of this module and does not change the download selector, stored images, or catalogue entries.
