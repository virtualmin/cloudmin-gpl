Link-Ziel für zusätzliche Dokumentation
Wenn diese Option aktiviert ist, wird in der oberen rechten Ecke der Seite Systeminformationen für alle Benutzer ein zusätzlicher Dokumentationslink angezeigt. Dies kann verwendet werden, um auf eine standortspezifische Dokumentation zu verlinken, z. B. auf Ihr eigenes Cloudmin-Benutzerhandbuch.
