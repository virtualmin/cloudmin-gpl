Maximum image file size in GiB

Choose Available space to limit imports by the free space on the host, or enter a maximum file size in GiB. This setting applies to catalogue downloads, custom URLs, browser uploads and files imported from the host.

The limit applies to the image file, not the virtual disk capacity recorded inside it. Imports also need space in temporary storage and the destination storage pool. Temporary copies may require additional space. Cloudmin leaves a 256 MiB reserve on each filesystem it checks.
