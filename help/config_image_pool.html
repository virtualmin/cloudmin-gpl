Default storage pool for image imports

Choose the storage pool initially selected for image downloads, browser uploads and host-file imports. The destination remains editable on the import form.

Automatic is the default. It selects an active directory, filesystem or NFS pool named default, or the first available pool of these types. The form also uses automatic selection when the preferred pool is unavailable.

You can save a stopped pool as the preference, but it must be active before the import form can select it. This setting does not move existing images or change storage defaults in virtual machine templates.
