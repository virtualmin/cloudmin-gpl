Module settings

Settings are grouped by purpose. Choose a category to adjust the host connection, virtual machine display and creation, remote connections, images, networking or storage.

These settings apply to all Cloudmin users on this host. Cloudmin remembers one connection tab per Webmin user. SSH login settings are saved separately for each user and virtual machine. The SSH port from the last successful login is shared by all users of that virtual machine.

Templates and plans control defaults such as guest accounts, software, CPU, memory and disk size. Edit those presets to change creation defaults.
