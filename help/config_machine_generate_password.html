Generate an initial password?

When enabled, Cloudmin fills the password field with a random password when you open the virtual machine creation form. You can see, copy or replace the password before creating the virtual machine. This option is disabled by default. When disabled, the field starts empty and hides what you type.

Guest setup uses a password hash. If automatic Webmin registration is enabled, Cloudmin also saves the initial password in the host's protected Servers Index configuration.
