Create a host SSH key for each new virtual machine?

When enabled, Cloudmin creates a separate SSH key for each new virtual machine and adds its public key to the initial guest account. This is enabled by default and applies in addition to the guest authentication settings on the creation form.

The private key is stored in Cloudmin's private data directory, separate from administrator keys. The SSH tab in Remote Access can use it without asking for a guest password. Cloudmin removes it during cleanup after a failed creation or when Cloudmin deletes the virtual machine. Changing this setting does not add or remove keys on existing virtual machines.
