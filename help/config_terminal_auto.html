Connect automatically when opening the SSH tab?

Automatic connection is disabled by default, so opening the SSH tab shows the connection form.

When enabled, Cloudmin connects using the virtual machine's shared SSH port and your saved username and authentication method. The first attempt uses the form defaults. You still enter passwords and confirm SSH host keys in the terminal.

Cloudmin saves the username and authentication method separately for each user and virtual machine. The SSH port from the last successful login is shared by all users of that virtual machine.

Failed logins return to the form. Failed or unfinished attempts pause automatic connection until a login succeeds. Use Connection settings above the terminal to open the form at any time.
