Enable Virtualmin installation?

When enabled, new virtual machines can install Virtualmin GPL or Pro after their initial setup. This option is enabled by default.

When disabled, Cloudmin hides Virtualmin settings in creation and template forms and rejects API and CLI requests to install it. Templates that select Virtualmin directly or inherit it from Default Template are hidden and cannot be used by ID or name until installation is enabled again.

Template settings are preserved for use when installation is enabled again. Existing virtual machines and jobs already submitted keep their settings. This option does not affect package installation or setup scripts.
