Show Webmin connection choices and a trust warning?

When enabled, Cloudmin shows a trust warning and offers direct access in a new tab or embedded access. This option is enabled by default.

When disabled, registered Webmin instances open in the embedded view immediately. Use this only when all registered virtual machines are fully trusted: a compromised guest's Webmin pages can compromise the host and other virtual machines through your host session.

Changed IP addresses still require confirmation. Permissions and registration requirements stay the same.
