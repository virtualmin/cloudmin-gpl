Zaregistrujte hostitele Docker
Tato stránka umožňuje informovat Cloudmin, že stávající systém, který spravuje, je vhodný pro hostování kontejnerů Docker. K tomu je třeba vyplnit následující pole:

Systém hostující kontejnery Docker
Z nabídky musíte vybrat systém, který má nainstalovaný software a verzi jádra potřebnou ke spuštění Dockeru. Cloudmin zatím nemá schopnost automaticky instalovat tyto balíčky.

Přidejte systémy Docker do domény DNS
Pokud hlavní systém Cloudmin provozuje server DNS, zobrazí se v tomto poli nabídka místních domén DNS, do kterých bude přidán název hostitele nově vytvořených instancí Docker. Protože adresy IP kontejneru Docker se mohou při restartu změnit, Cloudmin automaticky aktualizuje jakýkoli záznam DNS, který vytvoří, aby odpovídal nové IP.

Přepněte účet Docker Hub
Chcete-li nahrát obrázky Docker do rozbočovače, musíte se nejprve zaregistrovat k účtu na adrese https://hub.docker.com/ a poté zde zadat přihlašovací údaje pro tento účet. Není to však nutné, pokud plánujete používat pouze místní obrázky.

Na rozdíl od jiných typů virtualizace neexistují žádná pole pro přidělování IP adres nebo výchozí cíl zálohování, protože Cloudmin při používání Dockeru tyto funkce dosud nepodporuje.
