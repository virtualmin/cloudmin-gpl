Registrieren Sie den Docker-Host
Auf dieser Seite können Sie Cloudmin mitteilen, dass ein vorhandenes System, das es verwaltet, zum Hosten von Docker-Containern geeignet ist. Dazu müssen folgende Felder ausgefüllt werden:

System, das Docker-Container hostet
Im Menü müssen Sie ein System auswählen, auf dem die Software installiert ist, und die Kernelversion, die zum Ausführen von Docker erforderlich ist. Cloudmin kann diese Pakete noch nicht automatisch installieren.

Hinzufügen von Docker-Systemen zur DNS-Domäne
Wenn auf dem Master-Cloudmin-System ein DNS-Server ausgeführt wird, wird in diesem Feld ein Menü mit lokalen DNS-Domänen angezeigt, zu denen der Hostname neu erstellter Docker-Instanzen hinzugefügt wird. Da sich die IP-Adressen des Docker-Containers beim Neustart ändern können, aktualisiert Cloudmin automatisch alle von ihm erstellten DNS-Einträge, um sie an die neue IP anzupassen.

Docker Hub-Konto wechseln
Um Docker-Bilder in den Hub hochzuladen, müssen Sie sich zunächst unter https://hub.docker.com/ für ein Konto registrieren und dann hier die Anmeldedaten für dieses Konto eingeben. Dies ist jedoch nicht erforderlich, wenn Sie nur lokale Bilder verwenden möchten.

Im Gegensatz zu anderen Virtualisierungstypen gibt es keine Felder für die Zuweisung von IP-Adressen oder ein Standard-Sicherungsziel, da diese Funktionen von Cloudmin bei Verwendung von Docker noch nicht unterstützt werden.
