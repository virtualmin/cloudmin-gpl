Registrar Docker Host
Esta página le permite decirle a Cloudmin que un sistema existente que administra es adecuado para alojar contenedores Docker. Para hacer esto, se deben completar los siguientes campos:

Sistema de alojamiento de contenedores Docker
En el menú, debe seleccionar un sistema que tenga el software instalado y la versión del núcleo necesaria para ejecutar Docker. Cloudmin aún no tiene la capacidad de instalar estos paquetes automáticamente.

Agregar sistemas Docker al dominio DNS
Si el sistema Cloudmin maestro ejecuta un servidor DNS, este campo mostrará un menú de dominios DNS locales a los que se agregará el nombre de host de las instancias de Docker recién creadas. Debido a que las direcciones IP del contenedor Docker pueden cambiar al reiniciar, Cloudmin actualizará automáticamente cualquier registro DNS que cree para que coincida con la nueva IP.

Cambiar cuenta de Docker Hub
Para cargar imágenes de Docker en el Hub, primero debe registrarse para obtener una cuenta en https://hub.docker.com/ y luego ingresar los detalles de inicio de sesión para esa cuenta aquí. Sin embargo, esto no es necesario si planea usar solo imágenes locales.

A diferencia de otros tipos de virtualización, no hay campos para la asignación de direcciones IP o un destino de copia de seguridad predeterminado, ya que Cloudmin aún no admite estas características cuando usa Docker.
