Enregistrer l'hôte Docker
Cette page vous permet d'indiquer à Cloudmin qu'un système existant qu'il gère est adapté à l'hébergement de conteneurs Docker. Pour ce faire, les champs suivants doivent être remplis:

Système hébergeant des conteneurs Docker
Dans le menu, vous devez sélectionner un système sur lequel le logiciel est installé et la version du noyau requise pour exécuter Docker. Cloudmin n'a pas encore la possibilité d'installer ces packages automatiquement.

Ajouter des systèmes Docker au domaine DNS
Si le système Cloudmin maître exécute un serveur DNS, ce champ affichera un menu de domaines DNS locaux auxquels le nom d'hôte des instances Docker nouvellement créées sera ajouté. Étant donné que les adresses IP du conteneur Docker peuvent changer au redémarrage, Cloudmin mettra automatiquement à jour tout enregistrement DNS qu'il crée pour correspondre à la nouvelle IP.

Changer de compte Docker Hub
Pour télécharger des images Docker sur le Hub, vous devez d'abord vous inscrire à un compte sur https://hub.docker.com/ , puis saisir les informations de connexion pour ce compte ici. Cependant, cela n'est pas nécessaire si vous prévoyez d'utiliser uniquement des images locales.

Contrairement à d'autres types de virtualisation, il n'y a pas de champs pour l'allocation d'adresse IP ou une destination de sauvegarde par défaut, car ces fonctionnalités ne sont pas encore prises en charge par Cloudmin lors de l'utilisation de Docker.
