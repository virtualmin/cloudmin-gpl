Registra Docker Host
Questa pagina consente di dire a Cloudmin che un sistema esistente che gestisce è adatto per ospitare container Docker. Per fare ciò, è necessario compilare i seguenti campi:

Sistema che ospita container Docker
Dal menu è necessario selezionare un sistema in cui è installato il software e la versione del kernel richiesta per eseguire Docker. Cloudmin non ha ancora la possibilità di installare questi pacchetti automaticamente.

Aggiungi i sistemi Docker al dominio DNS
Se il sistema Cloudmin master esegue un server DNS, questo campo mostrerà un menu di domini DNS locali a cui verrà aggiunto il nome host delle istanze Docker appena create. Poiché gli indirizzi IP del contenitore Docker possono cambiare al riavvio, Cloudmin aggiornerà automaticamente qualsiasi record DNS creato in modo che corrisponda al nuovo IP.

Cambia account Hub Docker
Per caricare le immagini Docker sull'hub, è necessario prima registrarsi per un account su https://hub.docker.com/, quindi inserire qui i dettagli di accesso per tale account. Ciò non è necessario se si prevede di utilizzare solo immagini locali.

A differenza di altri tipi di virtualizzazione, non esistono campi per l'allocazione dell'indirizzo IP o una destinazione di backup predefinita, poiché queste funzionalità non sono ancora supportate da Cloudmin quando si utilizza Docker.
