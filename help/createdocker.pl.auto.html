Zarejestruj hosta dokera
Ta strona pozwala poinformować Cloudmin, że istniejący system, którym zarządza, jest odpowiedni do hostowania kontenerów Docker. W tym celu należy wypełnić następujące pola:

System hostujący kontenery Docker
Z menu musisz wybrać system z zainstalowanym oprogramowaniem i wersją jądra wymaganą do uruchomienia Dockera. Cloudmin nie ma jeszcze możliwości automatycznego instalowania tych pakietów.

Dodaj systemy dokerów do domeny DNS
Jeśli w głównym systemie Cloudmin działa serwer DNS, w tym polu będzie wyświetlane menu lokalnych domen DNS, do których zostanie dodana nazwa hosta nowo utworzonych instancji Docker. Ponieważ adresy IP kontenera Docker mogą się zmieniać przy ponownym uruchomieniu, Cloudmin automatycznie zaktualizuje każdy utworzony przez siebie rekord DNS, aby pasował do nowego adresu IP.

Przełącz konto Docker Hub
Aby przesłać obrazy Dockera do Centrum, musisz najpierw zarejestrować konto na https://hub.docker.com/, a następnie wprowadzić tutaj dane logowania do tego konta. Nie jest to jednak konieczne, jeśli planujesz używać tylko lokalnych obrazów.

W przeciwieństwie do innych typów wirtualizacji, nie ma pól do przydzielania adresów IP ani domyślnego miejsca docelowego kopii zapasowej, ponieważ te funkcje nie są jeszcze obsługiwane przez Cloudmin podczas korzystania z Dockera.
