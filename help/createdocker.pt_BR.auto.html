Registrar host do Docker
Esta página permite que você informe ao Cloudmin que um sistema existente que ele gerencia é adequado para hospedar contêineres do Docker. Para fazer isso, os seguintes campos devem ser preenchidos:

Sistema que hospeda contêineres Docker
No menu, você deve selecionar um sistema com o software instalado e a versão do kernel necessária para executar o Docker. O Cloudmin ainda não tem a capacidade de instalar esses pacotes automaticamente.

Adicionar sistemas Docker ao domínio DNS
Se o sistema Cloudmin principal executar um servidor DNS, esse campo mostrará um menu de domínios DNS locais aos quais o nome do host das instâncias do Docker recém-criadas será adicionado. Como os endereços IP do contêiner do Docker podem mudar na reinicialização, o Cloudmin atualizará automaticamente qualquer registro DNS criado para corresponder ao novo IP.

Alternar conta do Hub Docker
Para fazer upload de imagens do Docker no Hub, você deve primeiro registrar uma conta em https://hub.docker.com/ e inserir os detalhes de login dessa conta aqui. Isso não é necessário se você planeja usar apenas imagens locais.

Ao contrário de outros tipos de virtualização, não há campos para alocação de endereço IP ou destino de backup padrão, pois esses recursos ainda não são suportados pelo Cloudmin ao usar o Docker.
