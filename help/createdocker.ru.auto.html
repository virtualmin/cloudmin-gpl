Регистрация Docker Host
На этой странице вы можете сообщить Cloudmin, что существующая система, которой он управляет, подходит для размещения контейнеров Docker. Для этого необходимо заполнить следующие поля:

Система хостинга Docker контейнеров
В меню вы должны выбрать систему с установленным программным обеспечением и версией ядра, необходимой для запуска Docker. Cloudmin пока не имеет возможности устанавливать эти пакеты автоматически.

Добавить Docker системы в домен DNS
Если в основной системе Cloudmin работает DNS-сервер, в этом поле будет отображаться меню локальных DNS-доменов, в которые будет добавлено имя хоста вновь созданных экземпляров Docker. Поскольку IP-адреса контейнера Docker могут измениться при перезагрузке, Cloudmin автоматически обновит любую DNS-запись, созданную в соответствии с новым IP-адресом.

Переключить учетную запись Docker Hub
Чтобы загрузить изображения Docker в Hub, вы должны сначала зарегистрировать учетную запись на https://hub.docker.com/, а затем ввести здесь данные для входа в эту учетную запись. Это не нужно, если вы планируете использовать только локальные изображения.

В отличие от других типов виртуализации, здесь нет полей для выделения IP-адресов или места назначения для резервного копирования по умолчанию, так как Cloudmin пока не поддерживает эти функции при использовании Docker.
