Docker Ana Bilgisayarını Kaydedin
Bu sayfa, Cloudmin'e yönettiği mevcut bir sistemin Docker kapsayıcılarını barındırmak için uygun olduğunu söylemenizi sağlar. Bunu yapmak için aşağıdaki alanların doldurulması gerekir:

Docker kapsayıcılarını barındıran sistem
Menüden Docker'ı çalıştırmak için yazılımın yüklü olduğu bir sistem ve çekirdek sürümü gerekir. Cloudmin henüz bu paketleri otomatik olarak yükleyemez.

Docker sistemlerini DNS etki alanına ekleme
Ana Cloudmin sistemi bir DNS sunucusu çalıştırıyorsa, bu alanda yeni oluşturulan Docker örneklerinin ana bilgisayar adının ekleneceği yerel DNS etki alanlarının bir menüsü gösterilir. Docker kapsayıcı IP adresleri yeniden başlatıldığında değişebileceğinden, Cloudmin oluşturduğu tüm DNS kayıtlarını yeni IP ile eşleşecek şekilde otomatik olarak güncelleyecektir.

Docker Hub hesabını değiştir
Docker görüntülerini Hub'a yüklemek için önce https://hub.docker.com/ adresinden bir hesaba kaydolmanız ve ardından söz konusu hesabın giriş ayrıntılarını buraya girmeniz gerekir. Yine de yalnızca yerel görüntüleri kullanmayı planlıyorsanız buna gerek yoktur.

Diğer sanallaştırma türlerinden farklı olarak, bu özellikler Docker kullanılırken henüz Cloudmin tarafından desteklenmediği için IP adresi tahsisi veya varsayılan yedekleme hedefi için alan yoktur.
