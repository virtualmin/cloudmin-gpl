Añadir cuenta EC2
Una vez que se haya registrado para obtener una cuenta con el servicio EC2 de Amazon, puede usar esta página para registrar esa cuenta en Cloudmin. La descripción de la cuenta puede ser cualquier texto que elija para identificar la cuenta, mientras que la ID de la cuenta, la ID de la clave de acceso y la clave de acceso secreta deben ser los números proporcionados por Amazon.

Cuando se hace clic en el botón Crear , se verifican los detalles de su cuenta. Además, Cloudmin se pondrá en contacto con el servidor de Virtualmin para autorizar a su cuenta a usar imágenes de máquina (AMI) que contengan la pila completa de software de Virtualmin. Esto le permite crear rápidamente nuevos sistemas de alojamiento web que se ejecutan en el servicio EC2.
