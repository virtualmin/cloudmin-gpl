Ajouter un compte EC2
Une fois que vous avez ouvert un compte avec le service EC2 d'Amazon, vous pouvez utiliser cette page pour enregistrer ce compte auprès de Cloudmin. La description du compte peut être n'importe quel texte de votre choix pour identifier le compte, tandis que l' ID du compte, l' ID de la clé d'accès et la clé d'accès secrète doivent être les numéros fournis par Amazon.

Lorsque vous cliquez sur le bouton Créer , les détails de votre compte seront vérifiés. De plus, Cloudmin contactera le serveur de Virtualmin pour autoriser votre compte à utiliser des images de machine (AMI) contenant la pile logicielle Virtualmin complète. Cela vous permet de créer rapidement de nouveaux systèmes d'hébergement Web fonctionnant sur le service EC2.
