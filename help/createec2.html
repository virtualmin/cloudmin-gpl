Add EC2 Account
Once your have signed up for an account with Amazon's EC2 service, you can use this page to register that account with VM2. The Account description can be any text of your choice to identify the account, while the Account ID, Access key ID and Secret access key must be the numbers provided by Amazon.

When the Create button is clicked, your account details will be verified. In addition, VM2 will contact Virtualmin's server to authorize your account to use machine images (AMIs) containing the full Virtualmin software stack. This allows you to quickly create new web hosting systems running on the EC2 service.
