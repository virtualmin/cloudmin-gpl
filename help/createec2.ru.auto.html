Добавить учетную запись EC2
После того как вы зарегистрировали учетную запись в сервисе Amazon EC2, вы можете использовать эту страницу для регистрации этой учетной записи в Cloudmin. Описание учетной записи может быть любым текстом на ваш выбор для идентификации учетной записи, в то время как идентификатор учетной записи, идентификатор ключа доступа и секретный ключ доступа должны быть номерами, предоставленными Amazon.

При нажатии кнопки «Создать» данные вашей учетной записи будут проверены. Кроме того, Cloudmin свяжется с сервером Virtualmin, чтобы авторизовать вашу учетную запись для использования образов компьютеров (AMI), содержащих полный программный стек Virtualmin. Это позволяет быстро создавать новые системы веб-хостинга, работающие на сервисе EC2.
