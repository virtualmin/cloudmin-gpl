CGE-Projekt hinzufügen
Sobald Sie sich für ein Konto und ein Projekt beim Compute Engine-Dienst von Google angemeldet haben, können Sie dieses Projekt auf dieser Seite bei Cloudmin registrieren. Das Google- you@gmail.com muss verwendet werden, um die E-Mail-Adresse Ihres Kontos you@gmail.com . you@gmail.com ist normalerweise so wie you@gmail.com . Und das Feld Projektname muss Ihren einzigartigen GCE Projekt - ID enthalten.

Der Rest der Felder muss basierend auf den von Google bereitgestellten OAuth-Token ausgefüllt werden, wenn Sie API-Zugriff auf das Projekt gewähren, wie auf der Dokumentationsseite Hinzufügen eines GCE-Projekts dokumentiert.

Wenn Sie auf Erstellen klicken, werden Sie von Cloudmin zur Eingabe eines zusätzlichen OAuth-Tokens aufgefordert und anschließend alle Projektdetails überprüft. Das Projekt kann dann zum Erstellen von GCE-Instanzen verwendet werden.
