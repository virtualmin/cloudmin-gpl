Agregar proyecto CGE
Una vez que se haya registrado para una cuenta y proyecto con el servicio Compute Engine de Google, puede usar esta página para registrar ese proyecto con Cloudmin. El campo de la cuenta de Google debe usarse para ingresar la dirección de correo electrónico de su cuenta, que generalmente es algo como you@gmail.com . Y el campo Nombre del proyecto debe contener su ID de proyecto GCE único.

El resto de los campos se deben completar en función de los tokens OAuth proporcionados por Google cuando otorga acceso API al proyecto, como se documenta en la página de documentación Agregar un proyecto GCE .

Cuando haga clic en Crear , Cloudmin le pedirá un token OAuth adicional y luego verificará todos los detalles del proyecto. El proyecto será utilizable para crear instancias de GCE.
