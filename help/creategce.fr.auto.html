Ajouter un projet CGE
Une fois que vous vous êtes inscrit pour un compte et un projet avec le service Compute Engine de Google, vous pouvez utiliser cette page pour enregistrer ce projet auprès de Cloudmin. Le champ de compte Google doit être utilisé pour entrer l'adresse e-mail de votre compte, qui est généralement quelque chose comme you@gmail.com . Et le champ Nom du projet doit contenir votre ID de projet GCE unique.

Les autres champs doivent être remplis en fonction des jetons OAuth fournis par Google lorsque vous accordez l'accès API au projet, comme indiqué sur la page de documentation Ajouter un projet GCE .

Lorsque vous cliquez sur Créer , Cloudmin vous demandera un jeton OAuth supplémentaire, puis vérifiera tous les détails du projet. Le projet sera alors utilisable pour créer des instances GCE.
