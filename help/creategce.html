Add CGE Project
Once your have signed up for an account and project with Google's Compute Engine service, you can use this page to register that project with Cloudmin. The Google account field must be used to enter your account email address, which is typically something like you@gmail.com. And the Project name field must contain your unique GCE project ID.

The rest of the fields must be filled in based on the OAuth tokens supplied by Google when you grant API access to the project, as documented on the Adding a GCE Project documentation page.

When you click Create, Cloudmin will prompt you for an additional OAuth token and then verify all the project details. The project will then be usable for creating GCE instances.
