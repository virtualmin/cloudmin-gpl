Adicionar projeto CGE
Depois de se inscrever em uma conta e um projeto no serviço Compute Engine do Google, você poderá usar esta página para registrar esse projeto no Cloudmin. O campo da conta do Google deve ser usado para inserir o endereço de e-mail da sua conta, que normalmente é algo como you@gmail.com . E o campo Nome do projeto deve conter seu ID do projeto GCE exclusivo.

O restante dos campos deve ser preenchido com base nos tokens OAuth fornecidos pelo Google quando você concede acesso à API para o projeto, conforme documentado na página de documentação Adicionando um projeto GCE .

Quando você clica em Criar , o Cloudmin solicita um token OAuth adicional e verifica todos os detalhes do projeto. O projeto será utilizável para criar instâncias de GCE.
