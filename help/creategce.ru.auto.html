Добавить проект CGE
После того, как вы зарегистрировали учетную запись и проект в службе Google Compute Engine, вы можете использовать эту страницу для регистрации этого проекта в Cloudmin. Поле учетной записи Google должно использоваться для ввода адреса электронной почты вашей учетной записи, который обычно является чем-то вроде you@gmail.com . И поле Имя проекта должно содержать ваш уникальный идентификатор проекта GCE.

Остальные поля должны быть заполнены на основе токенов OAuth, предоставленных Google при предоставлении доступа API к проекту, как описано на странице документации Добавление проекта GCE .

Когда вы нажмете «Создать» , Cloudmin предложит вам ввести дополнительный токен OAuth, а затем проверит все детали проекта. Затем проект можно будет использовать для создания экземпляров GCE.
