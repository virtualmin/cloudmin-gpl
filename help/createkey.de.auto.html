SSH-Schlüssel erstellen
Auf dieser Seite können Sie ein neues öffentliches / privates SSH-Schlüsselpaar erstellen oder eines manuell erstellten unter die Kontrolle von Cloudmin stellen. Sie müssen eine Beschreibung für den Schlüssel eingeben und dann eine der Optionen für die Quelle für den neuen Schlüssel auswählen:
Wird vom Systemmanager generiert
Cloudmin erstellt mit dem Befehl ssh-keygen einen neuen Schlüssel auf Ihrem System. Sofern Sie keine wirklich alte SSH-Version installiert haben, handelt es sich um einen Schlüssel der Version 2.
In vorhandener Datei
Der Schlüssel in der Datei auf dem Server, der in das nebenstehende Textfeld eingegeben wurde, wird verwendet. Sie müssen nur den privaten Schlüssel eingeben - Cloudmin berechnet den öffentlichen Schlüssel automatisch daraus. Dieser Schlüssel kann jedoch nicht durch eine Passphrase geschützt werden.
In hochgeladener Datei
Wie die vorherige Option, aber der private Schlüssel kann sich in einer Datei befinden, die von dem System hochgeladen wurde, auf dem Ihr Browser ausgeführt wird.
In das Textfeld unten eingefügt
Wie die letzten beiden Optionen, aber Sie müssen die privaten Schlüsseldaten kopieren und in das Textfeld einfügen.
Generieren Sie einen neuen EC2-Schlüssel
Diese Option wird nur angezeigt, wenn Sie mindestens ein EC2-Konto bei Cloudmin registriert haben. Bei Auswahl dieser Option generiert EC2 einen neuen Schlüssel, der Ihrem Konto zugeordnet ist, und gibt die privaten Schlüsseldaten an Cloudmin zurück. Um EC2-Instanzen zu erstellen, muss mindestens ein SSH-Schlüssel von EC2 registriert sein.
Vorhandenen EC2-Schlüssel importieren
Wenn Sie mit EC2 bereits manuell einen SSH-Schlüssel erstellt haben (möglicherweise mit dem Befehl ec2-add-keypair ), kann er für die Verwendung durch Cloudmin registriert werden, indem Sie den Schlüsselnamen aus diesem Menü auswählen und den Text des privaten Schlüssels in das folgende Feld einfügen.
