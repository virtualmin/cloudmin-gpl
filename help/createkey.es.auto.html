Crear clave SSH
Esta página le permite generar un nuevo par de claves público / privado SSH, o traer uno que ha sido creado manualmente bajo el control de Cloudmin. Debe ingresar una descripción para la clave y luego seleccionar una de las opciones para la Fuente para la nueva clave :
Generado por el administrador del sistema
Cloudmin creará una nueva clave en su sistema, utilizando el comando ssh-keygen . A menos que tenga instalada una versión SSH realmente antigua, esta será una clave de la versión 2.
En archivo existente
Se usará la clave en el archivo en el servidor ingresado en el campo de texto adyacente. Solo necesita ingresar la clave privada: Cloudmin calculará la clave pública automáticamente. Sin embargo, esta clave no se puede proteger con una frase de contraseña.
En archivo subido
Al igual que la opción anterior, pero la clave privada puede estar en un archivo cargado desde el sistema en el que se ejecuta su navegador.
Pegado en el cuadro de texto a continuación
Como las dos últimas opciones, pero debe copiar y pegar los datos de la clave privada en el cuadro de texto.
Generar nueva clave EC2
Esta opción solo aparece si tiene al menos una cuenta EC2 registrada en Cloudmin. Cuando se selecciona, EC2 generará una nueva clave asociada con su cuenta y pasará los datos de la clave privada a Cloudmin. Para crear instancias EC2, debe tener al menos una clave SSH de EC2 registrada.
Importar clave EC2 existente
Si ya ha creado manualmente una clave SSH con EC2 (quizás utilizando el comando ec2-add-keypair ), Cloudmin puede registrarla para su uso seleccionando el nombre de la clave de este menú y pegando el texto de la clave privada en el cuadro a continuación.
