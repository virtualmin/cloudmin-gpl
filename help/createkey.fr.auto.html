Créer une clé SSH
Cette page vous permet de générer une nouvelle paire de clés publique / privée SSH, ou d'en apporter une qui a été créée manuellement sous le contrôle de Cloudmin. Vous devez entrer une description pour la clé, puis sélectionner l'une des options pour la source de la nouvelle clé :
Généré par le gestionnaire de système
Cloudmin créera une nouvelle clé sur votre système, à l'aide de la commande ssh-keygen . À moins que vous n'ayez une très ancienne version SSH installée, ce sera une clé de version 2.
Dans un fichier existant
La clé du fichier sur le serveur entrée dans le champ de texte adjacent sera utilisée. Il vous suffit de saisir la clé privée - Cloudmin calculera automatiquement la clé publique à partir de celle-ci. Cette clé ne peut cependant pas être protégée par une phrase secrète.
Dans le fichier téléchargé
Comme l'option précédente, mais la clé privée peut se trouver dans un fichier téléchargé depuis le système sur lequel votre navigateur s'exécute.
Collé dans la zone de texte ci-dessous
Comme les deux dernières options, mais vous devez copier et coller les données de la clé privée dans la zone de texte.
Générer une nouvelle clé EC2
Cette option n'apparaît que si vous avez au moins un compte EC2 enregistré auprès de Cloudmin. Une fois sélectionné, EC2 générera une nouvelle clé associée à votre compte et transmettra les données de clé privée à Cloudmin. Pour créer des instances EC2, vous devez avoir enregistré au moins une clé SSH d'EC2.
Importer la clé EC2 existante
Si vous avez déjà créé manuellement une clé SSH avec EC2 (peut-être en utilisant la commande ec2-add-keypair ), elle peut être enregistrée pour être utilisée par Cloudmin en sélectionnant le nom de la clé dans ce menu et en collant le texte de la clé privée dans la case ci-dessous.
