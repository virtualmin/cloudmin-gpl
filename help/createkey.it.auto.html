Crea chiave SSH
Questa pagina ti consente di generare una nuova coppia di chiavi pubblica / privata SSH o di portarne una creata manualmente sotto il controllo di Cloudmin. È necessario immettere una descrizione per la chiave, quindi selezionare una delle opzioni per Origine per nuova chiave :
Generato dal gestore di sistema
Cloudmin creerà una nuova chiave sul tuo sistema, usando il comando ssh-keygen . A meno che non sia installata una versione SSH molto vecchia, questa sarà una chiave della versione 2.
Nel file esistente
Verrà utilizzata la chiave nel file sul server immessa nel campo di testo adiacente. Devi solo inserire la chiave privata: Cloudmin calcolerà automaticamente la chiave pubblica da essa. Tuttavia, questa chiave non può essere protetta da una passphrase.
Nel file caricato
Come l'opzione precedente, ma la chiave privata può trovarsi in un file caricato dal sistema su cui è in esecuzione il browser.
Incollato nella casella di testo qui sotto
Come le ultime due opzioni, ma è necessario copiare e incollare i dati della chiave privata nella casella di testo.
Genera nuova chiave EC2
Questa opzione appare solo se hai almeno un account EC2 registrato con Cloudmin. Se selezionato, EC2 genererà una nuova chiave associata al tuo account e restituirà i dati della chiave privata a Cloudmin. Per creare istanze EC2, è necessario disporre di almeno una chiave SSH da EC2 registrata.
Importa chiave EC2 esistente
Se hai già creato manualmente una chiave SSH con EC2 (forse utilizzando il comando ec2-add-keypair ), può essere registrata per l'uso da Cloudmin selezionando il nome della chiave da questo menu e incollando il testo della chiave privata nella casella sottostante.
