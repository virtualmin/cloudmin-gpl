Criar chave SSH
Esta página permite gerar um novo par de chaves pública / privada SSH ou trazer um que foi criado manualmente sob o controle do Cloudmin. Você deve inserir uma descrição para a chave e, em seguida, selecionar uma das opções para a Origem da nova chave :
Gerado pelo gerente do sistema
O Cloudmin criará uma nova chave no seu sistema, usando o comando ssh-keygen . A menos que você tenha uma versão SSH realmente antiga instalada, esta será uma chave da versão 2.
No arquivo existente
A chave no arquivo no servidor inserido no campo de texto adjacente será usada. Você só precisa inserir a chave privada - o Cloudmin calculará a chave pública automaticamente. Essa chave não pode ser protegida por uma senha.
No arquivo carregado
Como a opção anterior, mas a chave privada pode estar em um arquivo carregado no sistema em que o navegador é executado.
Colado na caixa de texto abaixo
Como as duas últimas opções, mas você deve copiar e colar os dados da chave privada na caixa de texto.
Gerar nova chave EC2
Esta opção aparece apenas se você tiver pelo menos uma conta EC2 registrada no Cloudmin. Quando selecionado, o EC2 gera uma nova chave associada à sua conta e passa os dados da chave privada de volta ao Cloudmin. Para criar instâncias do EC2, você deve ter pelo menos uma chave SSH do EC2 registrada.
Importar chave EC2 existente
Se você já criou manualmente uma chave SSH com o EC2 (talvez usando o comando ec2-add-keypair ), ela pode ser registrada para uso pelo Cloudmin, selecionando o nome da chave neste menu e colando o texto da chave privada na caixa abaixo.
