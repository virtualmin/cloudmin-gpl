Создать ключ SSH
На этой странице вы можете сгенерировать новую пару открытых / закрытых ключей SSH или перенести созданную вручную под управление Cloudmin. Вы должны ввести описание ключа, а затем выбрать один из вариантов источника для нового ключа :
Сгенерировано системным менеджером
Cloudmin создаст новый ключ в вашей системе, используя команду ssh-keygen . Если у вас не установлена действительно старая версия SSH, это будет ключ версии 2.
В существующем файле
Будет использован ключ в файле на сервере, введенный в смежное текстовое поле. Вам нужно только ввести закрытый ключ - Cloudmin из него автоматически вычислит открытый ключ. Этот ключ не может быть защищен парольной фразой.
В загруженном файле
Как и предыдущий вариант, но закрытый ключ может находиться в файле, загруженном из системы, в которой работает ваш браузер.
Вставлено в текстовое поле ниже
Как и в двух последних вариантах, но вы должны скопировать и вставить данные закрытого ключа в текстовое поле.
Создать новый ключ EC2
Эта опция появляется, только если у вас есть хотя бы одна учетная запись EC2, зарегистрированная в Cloudmin. Если выбран этот параметр, EC2 сгенерирует новый ключ, связанный с вашей учетной записью, и передаст данные личного ключа обратно в Cloudmin. Для создания экземпляров EC2 у вас должен быть зарегистрирован как минимум один ключ SSH из EC2.
Импортировать существующий ключ EC2
Если вы уже вручную создали ключ SSH с EC2 (возможно, с помощью команды ec2-add-keypair ), его можно зарегистрировать для использования в Cloudmin, выбрав имя ключа из этого меню и вставив текст закрытого ключа в поле ниже.
