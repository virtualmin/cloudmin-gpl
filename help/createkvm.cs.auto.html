Zaregistrovat hostitele KVM
Tato stránka umožňuje informovat Cloudmin, že stávající systém, který spravuje, je vhodný pro hostování instancí KVM. K tomu je třeba vyplnit následující pole:

Systém hostující KVM
Z nabídky musíte vybrat fyzický systém, který má nainstalovaný software a verzi jádra potřebnou ke spuštění KVM. Cloudmin zatím nemá schopnost automaticky instalovat tyto balíčky.
Základní adresář pro virtuální systémy
Zde musíte zadat adresář, pod kterým budou vytvořeny instance KVM, které již musí existovat ve vybraném hostitelském systému. Protože instance KVM využívají velké množství místa na disku (každé 2 GB nebo více), měli byste zvolit místní adresář s dostatkem místa.
Přidejte systémy KVM do domény DNS
Pokud hlavní systém Cloudmin provozuje server DNS, zobrazí se v tomto poli nabídka místních domén DNS, do kterých bude přidán název hostitele nově vytvořených instancí KVM. Důrazně doporučujeme, abyste si před použitím KVM a Cloudmin nastavili server DNS a ujistili se, že jej lze spravovat pomocí Webminu, aby nové instance měly rozlišitelné názvy hostitelů.
Rozsah přidělování IP adres
Při vytvoření instance KVM může Cloudmin automaticky přiřadit IP adresu. IP bude převzato z rozsahu zadaného v tomto poli vyhledáním adres, které nepoužívá žádný jiný virtuální systém a neodpovídají na ping.
