Registrieren Sie den KVM-Host
Auf dieser Seite können Sie Cloudmin mitteilen, dass ein vorhandenes System, das es verwaltet, zum Hosten von KVM-Instanzen geeignet ist. Dazu müssen folgende Felder ausgefüllt werden:

System, das KVMs hostet
Im Menü müssen Sie ein physisches System auswählen, auf dem die Software installiert ist, und die Kernelversion, die zum Ausführen von KVM erforderlich ist. Cloudmin kann diese Pakete noch nicht automatisch installieren.
Basisverzeichnis für virtuelle Systeme
Hier müssen Sie ein Verzeichnis eingeben, unter dem KVM-Instanzen erstellt werden, die auf dem ausgewählten Hostsystem bereits vorhanden sein müssen. Da KVM-Instanzen viel Speicherplatz belegen (jeweils 2 GB oder mehr), sollten Sie ein lokales Verzeichnis mit viel Speicherplatz auswählen.
Fügen Sie der DNS-Domäne KVM-Systeme hinzu
Wenn auf dem Master-Cloudmin-System ein DNS-Server ausgeführt wird, wird in diesem Feld ein Menü mit lokalen DNS-Domänen angezeigt, zu denen der Hostname neu erstellter KVM-Instanzen hinzugefügt wird. Es wird dringend empfohlen, einen DNS-Server einzurichten und sicherzustellen, dass er über Webmin verwaltet werden kann, bevor Sie KVM und Cloudmin verwenden, damit neue Instanzen auflösbare Hostnamen haben.
IP-Adresszuweisungsbereich
Wenn eine KVM-Instanz erstellt wird, kann Cloudmin ihr automatisch eine IP-Adresse zuweisen. Die IP wird aus dem Bereich entnommen, den Sie in dieses Feld eingeben, indem Adressen gefunden werden, die von keinem anderen virtuellen System verwendet werden und nicht auf Pings reagieren.
