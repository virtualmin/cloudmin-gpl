Registrare l'host KVM
Questa pagina ti consente di dire a Cloudmin che un sistema esistente che gestisce è adatto per l'hosting di istanze KVM. Per fare ciò, è necessario compilare i seguenti campi:

Sistema che ospita KVM
Dal menu è necessario selezionare un sistema fisico con il software installato e la versione del kernel richiesta per eseguire KVM. Cloudmin non ha ancora la possibilità di installare questi pacchetti automaticamente.
Directory di base per sistemi virtuali
Qui è necessario inserire una directory in cui verranno create le istanze KVM, che devono già esistere sul sistema host selezionato. Poiché le istanze KVM utilizzano una grande quantità di spazio su disco (2 GB o più ciascuna), è necessario scegliere una directory locale con molto spazio.
Aggiungi sistemi KVM al dominio DNS
Se il sistema Cloudmin master esegue un server DNS, questo campo mostrerà un menu di domini DNS locali a cui verrà aggiunto il nome host delle istanze KVM appena create. Si consiglia vivamente di configurare un server DNS e assicurarsi che possa essere gestito tramite Webmin prima di utilizzare KVM e Cloudmin, in modo che le nuove istanze abbiano nomi host risolvibili.
Intervallo di allocazione dell'indirizzo IP
Quando viene creata un'istanza KVM, Cloudmin può assegnare automaticamente un indirizzo IP per esso. L'IP verrà preso dall'intervallo immesso in questo campo, trovando gli indirizzi che non sono utilizzati da nessun altro sistema virtuale e non rispondono ai ping.
