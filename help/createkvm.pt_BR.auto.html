Registrar host KVM
Esta página permite que você informe ao Cloudmin que um sistema existente que ele gerencia é adequado para hospedar instâncias KVM. Para fazer isso, os seguintes campos devem ser preenchidos:

Sistema que hospeda KVMs
No menu, você deve selecionar um sistema físico que tenha o software instalado e a versão do kernel necessária para executar o KVM. O Cloudmin ainda não tem a capacidade de instalar esses pacotes automaticamente.
Diretório base para sistemas virtuais
Aqui você deve inserir um diretório no qual as instâncias do KVM serão criadas, que já devem existir no sistema host selecionado. Como as instâncias KVM usam uma grande quantidade de espaço em disco (2 GB ou mais cada), você deve escolher um diretório local com bastante espaço.
Adicionar sistemas KVM ao domínio DNS
Se o sistema Cloudmin principal executar um servidor DNS, esse campo mostrará um menu de domínios DNS locais aos quais o nome do host das instâncias KVM recém-criadas será adicionado. É altamente recomendável que você configure um servidor DNS e verifique se ele pode ser gerenciado através do Webmin antes de usar o KVM e o Cloudmin, para que novas instâncias tenham nomes de host resolvíveis.
Intervalo de alocação de endereço IP
Quando uma instância KVM é criada, o Cloudmin pode atribuir um endereço IP para ela automaticamente. O IP será obtido do intervalo digitado nesse campo, encontrando endereços que não estão sendo usados por nenhum outro sistema virtual e não respondem a pings.
