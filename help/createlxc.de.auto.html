Registrieren Sie den LXC-Host
Auf dieser Seite können Sie Cloudmin mitteilen, dass ein vorhandenes System, das es verwaltet, zum Hosten von LXC-Containern geeignet ist. Dazu müssen folgende Felder ausgefüllt werden:

System, das LXC-Container hostet
Im Menü müssen Sie ein System auswählen, auf dem die Software installiert ist, und die Kernelversion, die zum Ausführen von LXC erforderlich ist. Cloudmin kann diese Pakete noch nicht automatisch installieren.
Basisverzeichnis für virtuelle Systeme
Hier müssen Sie ein Verzeichnis eingeben, unter dem LXC-Container erstellt werden, die auf dem ausgewählten Hostsystem bereits vorhanden sein müssen. Da LXC-Container viel Speicherplatz belegen (jeweils 2 GB oder mehr), sollten Sie ein lokales Verzeichnis mit viel Speicherplatz auswählen.
Hinzufügen von LXC-Systemen zur DNS-Domäne
Wenn auf dem Cloudmin-Mastersystem ein DNS-Server ausgeführt wird, wird in diesem Feld ein Menü mit lokalen DNS-Domänen angezeigt, zu denen der Hostname neu erstellter LXC-Container hinzugefügt wird. Es wird dringend empfohlen, einen DNS-Server einzurichten und sicherzustellen, dass er über Webmin verwaltet werden kann, bevor Sie LXC und Cloudmin verwenden, damit neue Container auflösbare Hostnamen haben.
IP-Adresszuweisungsbereich
Wenn ein LXC-Container erstellt wird, kann Cloudmin ihm automatisch eine IP-Adresse zuweisen. Die IP wird aus dem Bereich entnommen, den Sie in dieses Feld eingeben, indem Adressen gefunden werden, die von keinem anderen virtuellen System verwendet werden und nicht auf Pings reagieren.
