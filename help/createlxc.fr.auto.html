Enregistrer l'hôte LXC
Cette page vous permet de dire à Cloudmin qu'un système existant qu'il gère est adapté à l'hébergement de conteneurs LXC. Pour ce faire, les champs suivants doivent être remplis:

Système hébergeant des conteneurs LXC
Dans le menu, vous devez sélectionner un système sur lequel le logiciel est installé et la version du noyau requise pour exécuter LXC. Cloudmin n'a pas encore la possibilité d'installer ces packages automatiquement.
Répertoire de base pour les systèmes virtuels
Ici, vous devez entrer un répertoire dans lequel les conteneurs LXC seront créés, qui doit déjà exister sur le système hôte sélectionné. Étant donné que les conteneurs LXC utilisent une grande quantité d'espace disque (2 Go ou plus chacun), vous devez choisir un répertoire local avec beaucoup d'espace.
Ajouter des systèmes LXC au domaine DNS
Si le système Cloudmin maître exécute un serveur DNS, ce champ affichera un menu de domaines DNS locaux auxquels le nom d'hôte des conteneurs LXC nouvellement créés sera ajouté. Il est fortement recommandé de configurer un serveur DNS et de vous assurer qu'il peut être géré via Webmin avant d'utiliser LXC et Cloudmin, afin que les nouveaux conteneurs aient des noms d'hôtes résolvables.
Plage d'allocation d'adresses IP
Lorsqu'un conteneur LXC est créé, Cloudmin peut lui attribuer automatiquement une adresse IP. L'IP sera prise dans la plage que vous entrez dans ce champ, en trouvant des adresses qui ne sont pas utilisées par un autre système virtuel et qui ne répondent pas aux pings.
