Registrare l'host LXC
Questa pagina ti permette di dire a Cloudmin che un sistema esistente che gestisce è adatto per ospitare container LXC. Per fare ciò, è necessario compilare i seguenti campi:

Sistema che ospita contenitori LXC
Dal menu è necessario selezionare un sistema in cui è installato il software e la versione del kernel richiesta per eseguire LXC. Cloudmin non ha ancora la possibilità di installare questi pacchetti automaticamente.
Directory di base per sistemi virtuali
Qui è necessario inserire una directory in cui verranno creati i contenitori LXC, che devono già esistere sul sistema host selezionato. Poiché i contenitori LXC utilizzano una grande quantità di spazio su disco (almeno 2 GB ciascuno), è necessario scegliere una directory locale con molto spazio.
Aggiungi sistemi LXC al dominio DNS
Se il sistema Cloudmin master esegue un server DNS, questo campo mostrerà un menu di domini DNS locali a cui verrà aggiunto il nome host dei contenitori LXC appena creati. Si consiglia vivamente di configurare un server DNS e assicurarsi che possa essere gestito tramite Webmin prima di utilizzare LXC e Cloudmin, in modo che i nuovi contenitori dispongano di nomi host risolvibili.
Intervallo di allocazione dell'indirizzo IP
Quando viene creato un contenitore LXC, Cloudmin può assegnare automaticamente un indirizzo IP per esso. L'IP verrà preso dall'intervallo immesso in questo campo, trovando gli indirizzi che non sono utilizzati da nessun altro sistema virtuale e non rispondono ai ping.
