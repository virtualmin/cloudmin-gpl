Registrar host LXC
Esta página permite que você diga ao Cloudmin que um sistema existente que ele gerencia é adequado para hospedar contêineres LXC. Para fazer isso, os seguintes campos devem ser preenchidos:

Sistema que hospeda contêineres LXC
No menu, você deve selecionar um sistema que tenha o software instalado e a versão do kernel necessária para executar o LXC. O Cloudmin ainda não tem a capacidade de instalar esses pacotes automaticamente.
Diretório base para sistemas virtuais
Aqui, você deve inserir um diretório no qual os contêineres LXC serão criados, que já devem existir no sistema host selecionado. Como os contêineres LXC usam uma grande quantidade de espaço em disco (2 GB ou mais cada), você deve escolher um diretório local com bastante espaço.
Adicionar sistemas LXC ao domínio DNS
Se o sistema Cloudmin principal executar um servidor DNS, este campo mostrará um menu de domínios DNS locais aos quais o nome do host dos contêineres LXC recém-criados será adicionado. É altamente recomendável que você configure um servidor DNS e verifique se ele pode ser gerenciado através do Webmin antes de usar o LXC e o Cloudmin, para que novos contêineres tenham nomes de host resolvíveis.
Intervalo de alocação de endereço IP
Quando um contêiner LXC é criado, o Cloudmin pode atribuir um endereço IP para ele automaticamente. O IP será obtido do intervalo digitado nesse campo, encontrando endereços que não estão sendo usados por nenhum outro sistema virtual e não respondem a pings.
