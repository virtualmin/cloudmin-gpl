OpenVZ-Hostsysteme
Bevor Cloudmin virtuelle Systeme mit OpenVZ-Containern erstellen kann, müssen Sie die Hostsysteme registrieren, auf denen OpenVZ auf dieser Seite ausgeführt wird. Cloudmin verfügt über eine dreischichtige Architektur, in der das Mastersystem (auf dem die Cloudmin-Webmin-Oberfläche ausgeführt wird) von den Systemen getrennt ist, auf denen Container gehostet werden, die wiederum von den OpenVZ-Systemen selbst getrennt sind.

Bevor ein OpenVZ-Hostsystem hier registriert werden kann, müssen Sie es zunächst über den Link Physisches System hinzufügen unter System hinzufügen im linken Menü unter die Kontrolle von Cloudmin bringen.

Wenn Cloudmin ein System bekannt ist, verwenden Sie den Link System für OpenVZ-Hosting registrieren, um den Registrierungsprozess zu starten.
