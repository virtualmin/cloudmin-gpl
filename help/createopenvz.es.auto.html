OpenVZ Host Systems
Antes de que Cloudmin pueda crear sistemas virtuales utilizando contenedores OpenVZ, debe registrar los sistemas host en los que se ejecutará OpenVZ utilizando esta página. Cloudmin tiene una arquitectura de tres capas, en la que el sistema maestro (en el que se ejecuta la interfaz de Cloudmin Webmin) está separado de los sistemas que alojan contenedores, que a su vez están separados de los propios sistemas OpenVZ.

Antes de que un sistema host OpenVZ pueda registrarse aquí, primero debe ponerlo bajo el control de Cloudmin usando el enlace Agregar sistema físico en Agregar sistema en el menú de la izquierda.

Una vez que Cloudmin conoce un sistema, use el enlace Registrar un sistema para el alojamiento de OpenVZ para iniciar el proceso de registro.
