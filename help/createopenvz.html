OpenVZ Host Systems
Before Cloudmin can create any virtual systems using OpenVZ containers, you must register the host systems on which OpenVZ will run using this page. Cloudmin has a three-layer architecture, in which the master system (on which the Cloudmin Webmin interface runs) is separate from the systems that host containers, which are in turn separate from the OpenVZ systems themselves.

Before an OpenVZ host system can be registered here, you must first bring it under Cloudmin's control using the Add physical system link under Add system on the left menu.

Once a system is known to Cloudmin, use the Register a system for OpenVZ hosting link to start the registration process.
