Sistemas host OpenVZ
Antes de o Cloudmin criar qualquer sistema virtual usando contêineres OpenVZ, você deve registrar os sistemas host nos quais o OpenVZ será executado usando esta página. O Cloudmin possui uma arquitetura de três camadas, na qual o sistema mestre (no qual a interface do Cloudmin Webmin é executada) é separado dos sistemas que hospedam contêineres, que por sua vez são separados dos próprios sistemas OpenVZ.

Para que um sistema host OpenVZ possa ser registrado aqui, primeiro você deve colocá-lo sob o controle do Cloudmin usando o link Adicionar sistema físico em Adicionar sistema no menu esquerdo.

Uma vez que um sistema é conhecido pelo Cloudmin, use o link Registrar um sistema para hospedagem OpenVZ para iniciar o processo de registro.
