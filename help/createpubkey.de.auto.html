Fügen Sie den öffentlichen SSH-Schlüssel hinzu
Auf dieser Seite können Sie Cloudmin einen vorhandenen öffentlichen SSH-Schlüssel hinzufügen, der als Sekundärschlüssel auf neu erstellten virtuellen Systemen verwendet werden kann. Sie müssen eine Beschreibung für den Schlüssel eingeben und dann eine der Optionen für die Quelle für den öffentlichen Schlüssel auswählen:
In vorhandener Datei
Der Schlüssel in der Datei auf dem Server, der in das nebenstehende Textfeld eingegeben wurde, wird verwendet. Sie müssen nur den privaten Schlüssel eingeben - Cloudmin berechnet den öffentlichen Schlüssel automatisch daraus. Dieser Schlüssel kann jedoch nicht durch eine Passphrase geschützt werden.
In hochgeladener Datei
Wie die vorherige Option, aber der private Schlüssel kann sich in einer Datei befinden, die von dem System hochgeladen wurde, auf dem Ihr Browser ausgeführt wird.
In das Textfeld unten eingefügt
Wie die letzten beiden Optionen, aber Sie müssen die privaten Schlüsseldaten kopieren und in das Textfeld einfügen.
