Ajouter une clé publique SSH
Cette page vous permet d'ajouter une clé publique SSH existante à Cloudmin, pour l'utiliser comme clé secondaire sur les systèmes virtuels nouvellement créés. Vous devez entrer une description pour la clé, puis sélectionner l'une des options pour la source pour la clé publique :
Dans un fichier existant
La clé du fichier sur le serveur entrée dans le champ de texte adjacent sera utilisée. Il vous suffit de saisir la clé privée - Cloudmin calculera automatiquement la clé publique à partir de celle-ci. Cette clé ne peut cependant pas être protégée par une phrase secrète.
Dans le fichier téléchargé
Comme l'option précédente, mais la clé privée peut se trouver dans un fichier téléchargé depuis le système sur lequel votre navigateur s'exécute.
Collé dans la zone de texte ci-dessous
Comme les deux dernières options, mais vous devez copier et coller les données de la clé privée dans la zone de texte.
