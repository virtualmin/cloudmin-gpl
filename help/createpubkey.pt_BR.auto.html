Adicionar chave pública SSH
Esta página permite adicionar uma chave pública SSH existente ao Cloudmin, para uso como chave secundária em sistemas virtuais recém-criados. Você deve inserir uma descrição para a chave e, em seguida, selecionar uma das opções para a Origem da chave pública :
No arquivo existente
A chave no arquivo no servidor inserido no campo de texto adjacente será usada. Você só precisa inserir a chave privada - o Cloudmin calculará a chave pública automaticamente. Essa chave não pode ser protegida por uma senha.
No arquivo carregado
Como a opção anterior, mas a chave privada pode estar em um arquivo carregado no sistema em que o navegador é executado.
Colado na caixa de texto abaixo
Como as duas últimas opções, mas você deve copiar e colar os dados da chave privada na caixa de texto.
