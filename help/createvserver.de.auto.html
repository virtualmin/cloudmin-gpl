Registrieren Sie den VServer-Host
Auf dieser Seite können Sie Cloudmin mitteilen, dass ein vorhandenes System, das es verwaltet, zum Hosten von VServer-Instanzen geeignet ist. Dazu müssen folgende Felder ausgefüllt werden:

Systemhosting von VServern
Im Menü müssen Sie ein physisches System auswählen, auf dem die Software installiert ist, und den für VServer erforderlichen Kernel-Patch. Cloudmin kann diese Pakete noch nicht automatisch installieren.
Basisverzeichnis für virtuelle Systeme
Hier müssen Sie ein Verzeichnis eingeben, unter dem Xen-Instanzen erstellt werden, die bereits auf dem ausgewählten Hostsystem vorhanden sein müssen. Da Xen-Instanzen viel Speicherplatz belegen (jeweils 2 GB oder mehr), sollten Sie ein lokales Verzeichnis mit viel Speicherplatz auswählen.
Hinzufügen von VServer-Systemen zur DNS-Domäne
Wenn das Cloudmin-Mastersystem einen DNS-Server ausführt, wird in diesem Feld ein Menü mit lokalen DNS-Domänen angezeigt, zu denen der Hostname neu erstellter VServer-Instanzen hinzugefügt wird. Es wird dringend empfohlen, einen DNS-Server einzurichten und sicherzustellen, dass er über Webmin verwaltet werden kann, bevor Sie VServers und Cloudmin verwenden, damit neue Instanzen auflösbare Hostnamen haben.
IP-Adresszuweisungsbereich
Wenn eine VServer-Instanz erstellt wird, kann Cloudmin ihr automatisch eine IP-Adresse zuweisen. Die IP wird aus dem Bereich entnommen, den Sie in dieses Feld eingeben, indem Adressen gefunden werden, die von keinem anderen virtuellen System verwendet werden und nicht auf Pings reagieren.
Basisnetzwerkschnittstelle
Standardmäßig erstellt Cloudmin VServers-Instanzen, deren Netzwerkschnittstellen eine virtuelle Schnittstelle auf dem primären Ethernet eth0 des eth0 . Wenn dieser Host über mehrere Schnittstellen verfügt, können Sie hier einen anderen Namen eth1 ppp0 . B. eth1 oder ppp0 .
Auf VServern zu installierende Distribution
Wenn VServer-Instanzen nach dem herkömmlichen manuellen Installationsprozess erstellt werden, kann ausgewählt werden, welche Linux-Distribution installiert werden soll. Wenn auf Ihrem VServer-Host Debian oder Ubuntu ausgeführt wird, haben Sie die Wahl zwischen den Distributionen wie sarge und edgy . Unter Fedora können Sie eine Kernversion wie fc5 oder fc6 .
Wenn Automatisch entscheiden ausgewählt ist, werden neue VServer mit derselben Verteilung wie das Hostsystem erstellt. Andernfalls können Sie eine Distribution auswählen, indem Sie hier einen der oben genannten Distributionsnamen eingeben.
Auf VServern zu installierende Pakete
Wenn VServer-Instanzen nach dem herkömmlichen Verfahren erstellt werden (und nicht nach einem Cloudmin-Systemabbild), sind in der Regel nur sehr wenige Pakete installiert, die nicht für das Basisbetriebssystem erforderlich sind. Sie können zusätzliche Pakete installieren lassen, indem Sie sie über die Kontrollkästchen in diesem Feld auswählen.
