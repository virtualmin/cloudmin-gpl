Registrarse VServer Host
Esta página le permite decirle a Cloudmin que un sistema existente que administra es adecuado para alojar instancias de VServer. Para hacer esto, se deben completar los siguientes campos:

Sistema de alojamiento de VServers
En el menú, debe seleccionar un sistema físico que tenga el software instalado y el parche de kernel requerido para VServers. Cloudmin aún no tiene la capacidad de instalar estos paquetes automáticamente.
Directorio base para sistemas virtuales
Aquí debe ingresar un directorio en el que se crearán las instancias de Xen, que ya deben existir en el sistema host seleccionado. Debido a que las instancias de Xen usan una gran cantidad de espacio en disco (2 GB o más cada una), debe elegir un directorio local con mucho espacio.
Agregar sistemas VServer al dominio DNS
Si el sistema Cloudmin maestro ejecuta un servidor DNS, este campo mostrará un menú de dominios DNS locales a los que se agregará el nombre de host de las instancias VServer recién creadas. Se recomienda encarecidamente que configure un servidor DNS y se asegure de que se pueda administrar a través de Webmin antes de usar VServers y Cloudmin, para que las nuevas instancias tengan nombres de host resolubles.
Rango de asignación de dirección IP
Cuando se crea una instancia de VServer, Cloudmin puede asignarle una dirección IP automáticamente. La IP se tomará del rango que ingrese en este campo, buscando direcciones que no estén en uso por ningún otro sistema virtual y que no respondan a los pings.
Interfaz de red base
De forma predeterminada, Cloudmin creará instancias de VServers cuyas interfaces de red son una interfaz virtual en el ethernet primario eth0 del host. Si este host tiene múltiples interfaces, puede ingresar un nombre diferente aquí, como eth1 o ppp0 .
Distribución para instalar en VServers
Cuando las instancias de VServer se crean mediante el proceso de instalación manual tradicional, es posible seleccionar qué distribución de Linux instalar. Si su host VServer ejecuta Debian o Ubuntu, puede elegir sus distribuciones, como sarge y edgy , que en Fedora puede seleccionar una versión principal como fc5 o fc6 .
Cuando se selecciona Decidir automáticamente , se crearán nuevos VServers con la misma distribución que el sistema host. De lo contrario, puede seleccionar una distribución ingresando uno de los nombres de distribución antes mencionados aquí.
Paquetes para instalar en VServers
Cuando las instancias de VServer son creadas por el proceso tradicional (en lugar de una imagen del sistema Cloudmin), generalmente tienen muy pocos paquetes instalados aparte de los necesarios para el sistema operativo base. Puede elegir tener instalados paquetes adicionales seleccionándolos usando las casillas de verificación en este campo.
