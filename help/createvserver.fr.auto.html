Enregistrer l'hôte VServer
Cette page vous permet d'indiquer à Cloudmin qu'un système existant qu'il gère est adapté à l'hébergement d'instances VServer. Pour ce faire, les champs suivants doivent être remplis:

Système hébergeant des VServers
Dans le menu, vous devez sélectionner un système physique sur lequel le logiciel est installé et le correctif du noyau requis pour les VServers. Cloudmin n'a pas encore la possibilité d'installer ces packages automatiquement.
Répertoire de base pour les systèmes virtuels
Ici, vous devez entrer un répertoire dans lequel les instances Xen seront créées, qui doit déjà exister sur le système hôte sélectionné. Étant donné que les instances Xen utilisent une grande quantité d'espace disque (2 Go ou plus chacun), vous devez choisir un répertoire local avec beaucoup d'espace.
Ajouter des systèmes VServer au domaine DNS
Si le système Cloudmin maître exécute un serveur DNS, ce champ affichera un menu de domaines DNS locaux auxquels le nom d'hôte des instances VServer nouvellement créées sera ajouté. Il est fortement recommandé de configurer un serveur DNS et de vous assurer qu'il peut être géré via Webmin avant d'utiliser VServers et Cloudmin, afin que les nouvelles instances aient des noms d'hôtes résolvables.
Plage d'allocation d'adresses IP
Lorsqu'une instance VServer est créée, Cloudmin peut lui attribuer automatiquement une adresse IP. L'IP sera prise dans la plage que vous entrez dans ce champ, en trouvant des adresses qui ne sont pas utilisées par un autre système virtuel et qui ne répondent pas aux pings.
Interface réseau de base
Par défaut, Cloudmin créera des instances VServers dont les interfaces réseau sont une interface virtuelle sur le eth0 Ethernet principal de l'hôte. Si cet hôte possède plusieurs interfaces, vous pouvez saisir ici un nom différent, comme eth1 ou ppp0 .
Distribution à installer sur VServers
Lorsque les instances VServer sont créées par le processus d'installation manuelle traditionnel, il est possible de sélectionner la distribution Linux à installer. Si votre hôte VServer exécute Debian ou Ubuntu, vous avez le choix entre leurs distributions, telles que sarge et edgy , qui sur Fedora vous pouvez sélectionner une version de base telle que fc5 ou fc6 .
Lorsque Décider automatiquement est sélectionné, de nouveaux VServers seront créés avec la même distribution que le système hôte. Sinon, vous pouvez sélectionner une distribution en entrant ici l'un des noms de distribution susmentionnés.
Packages à installer sur VServers
Lorsque les instances VServer sont créées par le processus traditionnel (plutôt qu'à partir d'une image système Cloudmin), elles ont généralement très peu de packages installés en dehors de ceux nécessaires au système d'exploitation de base. Vous pouvez choisir d'installer des packages supplémentaires en les sélectionnant à l'aide des cases à cocher de ce champ.
