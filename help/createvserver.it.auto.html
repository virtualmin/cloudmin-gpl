Registrare l'host VServer
Questa pagina consente di dire a Cloudmin che un sistema esistente che gestisce è adatto per l'hosting di istanze VServer. Per fare ciò, è necessario compilare i seguenti campi:

Sistema che ospita VServers
Dal menu è necessario selezionare un sistema fisico con il software installato e la patch del kernel richiesta per VServers. Cloudmin non ha ancora la possibilità di installare questi pacchetti automaticamente.
Directory di base per sistemi virtuali
Qui è necessario inserire una directory in cui verranno create le istanze Xen, che devono già esistere sul sistema host selezionato. Poiché le istanze Xen utilizzano una grande quantità di spazio su disco (almeno 2 GB ciascuna), è necessario scegliere una directory locale con molto spazio.
Aggiungi sistemi VServer al dominio DNS
Se il sistema Cloudmin master esegue un server DNS, questo campo mostrerà un menu di domini DNS locali a cui verrà aggiunto il nome host delle istanze VServer appena create. Si consiglia vivamente di configurare un server DNS e assicurarsi che possa essere gestito tramite Webmin prima di utilizzare VServers e Cloudmin, in modo che le nuove istanze abbiano nomi host risolvibili.
Intervallo di allocazione dell'indirizzo IP
Quando viene creata un'istanza VServer, Cloudmin può assegnare automaticamente un indirizzo IP per essa. L'IP verrà preso dall'intervallo immesso in questo campo, trovando gli indirizzi che non sono utilizzati da nessun altro sistema virtuale e non rispondono ai ping.
Interfaccia di rete di base
Per impostazione predefinita, Cloudmin creerà istanze VServers le cui interfacce di rete sono un'interfaccia virtuale su Ethernet primario dell'host eth0 . Se questo host ha più interfacce, puoi inserire qui un nome diverso, come eth1 o ppp0 .
Distribuzione da installare su VServers
Quando le istanze VServer vengono create dal tradizionale processo di installazione manuale, è possibile selezionare quale distribuzione Linux installare. Se il tuo host VServer esegue Debian o Ubuntu puoi scegliere tra le loro distribuzioni, come sarge e edgy , che su Fedora puoi selezionare una versione core come fc5 o fc6 .
Quando si seleziona Decide automaticamente , verranno creati nuovi VServers con la stessa distribuzione del sistema host. Altrimenti puoi selezionare una distro inserendo qui uno dei nomi di distribuzione summenzionati.
Pacchetti da installare su VServers
Quando le istanze VServer vengono create dal processo tradizionale (anziché da un'immagine del sistema Cloudmin), in genere hanno pochissimi pacchetti installati oltre a quelli necessari per il sistema operativo di base. Puoi scegliere di avere pacchetti aggiuntivi installati selezionandoli usando le caselle di controllo in questo campo.
