Registrar o host do VServer
Esta página permite que você diga ao Cloudmin que um sistema existente que ele gerencia é adequado para hospedar instâncias do VServer. Para fazer isso, os seguintes campos devem ser preenchidos:

Sistema que hospeda VServers
No menu, você deve selecionar um sistema físico que tenha o software instalado e o patch do kernel necessário para os VServers. O Cloudmin ainda não tem a capacidade de instalar esses pacotes automaticamente.
Diretório base para sistemas virtuais
Aqui você deve inserir um diretório no qual as instâncias do Xen serão criadas, que já devem existir no sistema host selecionado. Como as instâncias do Xen usam uma grande quantidade de espaço em disco (2 GB ou mais cada), você deve escolher um diretório local com bastante espaço.
Adicionar sistemas VServer ao domínio DNS
Se o sistema Cloudmin principal executar um servidor DNS, esse campo mostrará um menu de domínios DNS locais aos quais o nome do host das instâncias VServer recém-criadas será adicionado. É altamente recomendável que você configure um servidor DNS e verifique se ele pode ser gerenciado através do Webmin antes de usar o VServers e o Cloudmin, para que novas instâncias tenham nomes de host resolvíveis.
Intervalo de alocação de endereço IP
Quando uma instância do VServer é criada, o Cloudmin pode atribuir um endereço IP para ela automaticamente. O IP será obtido do intervalo digitado nesse campo, encontrando endereços que não estão sendo usados por nenhum outro sistema virtual e não respondem a pings.
Interface de rede básica
Por padrão, o Cloudmin criará instâncias do VServers cujas interfaces de rede são uma interface virtual na Ethernet principal eth0 do host. Se esse host tiver várias interfaces, você poderá inserir um nome diferente aqui, como eth1 ou ppp0 .
Distribuição para instalar nos VServers
Quando as instâncias do VServer são criadas pelo processo de instalação manual tradicional, é possível selecionar qual distribuição do Linux instalar. Se o seu host do VServer executar o Debian ou o Ubuntu, você poderá escolher suas distribuições, como sarge e edgy , que no Fedora você pode selecionar uma versão principal, como fc5 ou fc6 .
Quando a opção Decidir automaticamente é selecionada, novos VServers serão criados com a mesma distribuição que o sistema host. Caso contrário, você pode selecionar uma distribuição inserindo um dos nomes de distribuição mencionados aqui.
Pacotes a serem instalados nos VServers
Quando as instâncias do VServer são criadas pelo processo tradicional (e não a partir de uma imagem do sistema Cloudmin), elas geralmente possuem muito poucos pacotes instalados além daqueles necessários para o sistema operacional base. Você pode optar por ter pacotes adicionais instalados, selecionando-os usando as caixas de seleção neste campo.
