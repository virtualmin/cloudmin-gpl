Zaregistrujte Xen Host
Tato stránka vám umožní říct Cloudmin, že existující systém, který spravuje, je vhodný pro hostování instancí Xen. K tomu je třeba vyplnit následující pole:

Systém hostující xeny
Z nabídky musíte vybrat fyzický systém, který má nainstalovaný software a verzi jádra potřebnou ke spuštění Xenu. Cloudmin zatím nemá schopnost automaticky instalovat tyto balíčky.
Základní adresář pro virtuální systémy
Zde musíte zadat adresář, pod kterým budou vytvořeny instance Xen, které již musí existovat ve vybraném hostitelském systému. Protože instance Xenu využívají velké množství místa na disku (každá 2 GB nebo více), měli byste zvolit místní adresář s dostatkem místa.
Přidejte systémy Xen do domény DNS
Pokud hlavní systém Cloudmin provozuje server DNS, zobrazí se v tomto poli nabídka místních domén DNS, do kterých bude přidán název hostitele nově vytvořených instancí Xen. Důrazně doporučujeme, abyste si před použitím Xen a Cloudmin nastavili server DNS a zajistili jeho správu prostřednictvím Webminu, aby nové instance měly rozlišitelné názvy hostitelů.
Rozsah přidělování IP adres
Po vytvoření instance Xen může Cloudmin pro ni automaticky přiřadit IP adresu. IP bude převzato z rozsahu zadaného v tomto poli vyhledáním adres, které nepoužívá žádný jiný virtuální systém a neodpovídají na ping.
