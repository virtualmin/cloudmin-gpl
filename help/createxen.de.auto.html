Registrieren Sie Xen Host
Auf dieser Seite können Sie Cloudmin mitteilen, dass ein vorhandenes System, das es verwaltet, zum Hosten von Xen-Instanzen geeignet ist. Dazu müssen folgende Felder ausgefüllt werden:

System, das Xens hostet
Im Menü müssen Sie ein physisches System auswählen, auf dem die Software installiert ist, und die Kernelversion, die zum Ausführen von Xen erforderlich ist. Cloudmin kann diese Pakete noch nicht automatisch installieren.
Basisverzeichnis für virtuelle Systeme
Hier müssen Sie ein Verzeichnis eingeben, unter dem Xen-Instanzen erstellt werden, die bereits auf dem ausgewählten Hostsystem vorhanden sein müssen. Da Xen-Instanzen viel Speicherplatz belegen (jeweils 2 GB oder mehr), sollten Sie ein lokales Verzeichnis mit viel Speicherplatz auswählen.
Hinzufügen von Xen-Systemen zur DNS-Domäne
Wenn auf dem Master-Cloudmin-System ein DNS-Server ausgeführt wird, wird in diesem Feld ein Menü mit lokalen DNS-Domänen angezeigt, zu denen der Hostname neu erstellter Xen-Instanzen hinzugefügt wird. Es wird dringend empfohlen, einen DNS-Server einzurichten und sicherzustellen, dass er über Webmin verwaltet werden kann, bevor Sie Xen und Cloudmin verwenden, damit neue Instanzen auflösbare Hostnamen haben.
IP-Adresszuweisungsbereich
Wenn eine Xen-Instanz erstellt wird, kann Cloudmin automatisch eine IP-Adresse zuweisen. Die IP wird aus dem Bereich entnommen, den Sie in dieses Feld eingeben, indem Adressen gefunden werden, die von keinem anderen virtuellen System verwendet werden und nicht auf Pings reagieren.
