Enregistrer l'hôte Xen
Cette page vous permet d'indiquer à Cloudmin qu'un système existant qu'il gère est adapté à l'hébergement d'instances Xen. Pour ce faire, les champs suivants doivent être remplis:

Système d'hébergement Xens
Dans le menu, vous devez sélectionner un système physique sur lequel le logiciel est installé et la version du noyau requise pour exécuter Xen. Cloudmin n'a pas encore la possibilité d'installer ces packages automatiquement.
Répertoire de base pour les systèmes virtuels
Ici, vous devez entrer un répertoire dans lequel les instances Xen seront créées, qui doit déjà exister sur le système hôte sélectionné. Étant donné que les instances Xen utilisent une grande quantité d'espace disque (2 Go ou plus chacun), vous devez choisir un répertoire local avec beaucoup d'espace.
Ajouter des systèmes Xen au domaine DNS
Si le système maître Cloudmin exécute un serveur DNS, ce champ affichera un menu de domaines DNS locaux auxquels le nom d'hôte des instances Xen nouvellement créées sera ajouté. Il est fortement recommandé de configurer un serveur DNS et de vous assurer qu'il peut être géré via Webmin avant d'utiliser Xen et Cloudmin, afin que les nouvelles instances aient des noms d'hôtes résolvables.
Plage d'allocation d'adresses IP
Lorsqu'une instance Xen est créée, Cloudmin peut lui attribuer automatiquement une adresse IP. L'IP sera prise dans la plage que vous entrez dans ce champ, en trouvant des adresses qui ne sont pas utilisées par un autre système virtuel et qui ne répondent pas aux pings.
