Registrare Solaris Zones Host
Questa pagina ti consente di dire a Cloudmin che un sistema esistente che gestisce è adatto alle zone di hosting. Per fare ciò, è necessario compilare i seguenti campi:

Zone di hosting del sistema
Dal menu è necessario selezionare un sistema fisico che esegue Solaris 10 o versioni successive su hardware X86 e Sparc. Poiché Solaris viene fornito con tutti i pacchetti e il supporto del kernel necessari per le zone, qualsiasi sistema con spazio su disco sufficiente dovrebbe funzionare correttamente.
Directory di base per le zone
Qui è necessario inserire una directory in cui verranno create le zone, che devono già esistere sul sistema host selezionato. Poiché le zone possono consumare una grande quantità di spazio su disco, questo dovrebbe trovarsi su un filesystem con molto spazio libero.
Aggiungi sistemi in zone al dominio DNS
Se il sistema Cloudmin master esegue un server DNS, questo campo mostrerà un menu di domini DNS locali a cui verrà aggiunto il nome host delle zone appena create. Si consiglia vivamente di configurare un server DNS e assicurarsi che possa essere gestito tramite Webmin prima di utilizzare zone e Cloudmin, in modo che le nuove istanze abbiano nomi host risolvibili.
Intervallo di allocazione dell'indirizzo IP
Quando viene creata una zona Solaris, Cloudmin può assegnare automaticamente un indirizzo IP per essa. L'IP verrà preso dall'intervallo immesso in questo campo, trovando gli indirizzi che non sono utilizzati da nessun altro sistema virtuale e non rispondono ai ping.
Interfaccia di rete di base
Per impostazione predefinita, Cloudmin creerà zone le cui interfacce di rete sono un'interfaccia virtuale sulla prima interfaccia Ethernet dell'host, come bge0 . Se questo host ha più interfacce, puoi inserire qui un nome diverso, come bge1 .
