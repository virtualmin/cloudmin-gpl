Registrar o host do Solaris Zones
Esta página permite que você informe ao Cloudmin que um sistema existente que ele gerencia é adequado para hospedar zonas. Para fazer isso, os seguintes campos devem ser preenchidos:

Zonas de hospedagem do sistema
No menu, você deve selecionar um sistema físico executando o Solaris 10 ou posterior no hardware X86 e Sparc. Como o Solaris vem com todos os pacotes e suporte ao kernel necessários para zonas, qualquer sistema com espaço em disco suficiente deve funcionar bem.
Diretório base para zonas
Aqui você deve inserir um diretório no qual as zonas serão criadas, que já devem existir no sistema host selecionado. Como as zonas podem consumir uma grande quantidade de espaço em disco, isso deve estar em um sistema de arquivos com bastante espaço livre.
Adicionar sistemas em zonas ao domínio DNS
Se o sistema Cloudmin principal executar um servidor DNS, este campo mostrará um menu de domínios DNS locais aos quais o nome do host das zonas recém-criadas será adicionado. É altamente recomendável que você configure um servidor DNS e verifique se ele pode ser gerenciado através do Webmin antes de usar zonas e Cloudmin, para que novas instâncias tenham nomes de host resolvíveis.
Intervalo de alocação de endereço IP
Quando uma zona Solaris é criada, o Cloudmin pode atribuir um endereço IP automaticamente. O IP será obtido do intervalo digitado nesse campo, encontrando endereços que não estão sendo usados por nenhum outro sistema virtual e não respondem a pings.
Interface de rede básica
Por padrão, o Cloudmin criará zonas cujas interfaces de rede são uma interface virtual na primeira interface Ethernet do host, como bge0 . Se esse host tiver várias interfaces, você poderá inserir um nome diferente aqui, como bge1 .
