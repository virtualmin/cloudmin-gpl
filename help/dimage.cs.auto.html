Vytvořte obrázek Docker
Kontejnery Docker nelze vytvořit z běžných obrázků Cloudmin - místo toho musí být vytvořeny z nativních obrázků Docker, které jsou uloženy samostatně na každém hostiteli. Obrázky lze stáhnout z Docker Hubu (na stránce Search Docker Images ) nebo pomocí této stránky vytvořit z existujícího kontejneru.

Obrázek má následující atributy, které jsou nastaveny v tomto formuláři:

Název obrázku
Jedinečný název tohoto obrázku. Pokud máte účet Docker Hub, mělo by to začínat vaším uživatelským jménem Docker následovaným /, například yourlogin/imagename .

Popis obrázku a jméno autora
Krátký lidsky čitelný popis obrázku a jeho autora. Většinou jsou užitečné, když nahrajete obrázek do Docker Hubu.

Výchozí příkaz pro spuštění na vytvořených systémech
Toto pole nastavuje příkaz shellu, který bude spuštěn uvnitř kontejneru vytvořeného z tohoto obrázku při spuštění. Obvykle se tím spustí server jako MySQL na Nginxu, ale také by mohlo být tak jednoduché jako sleep 99999999 pro vytvoření obrazu, který funguje spíš jako VM.

Porty k otevření na vytvořených systémech
Pokud je na tomto obrázku spuštěn server přístupný k síti, měli byste zde zadat porty TCP, na kterých server naslouchá.

Značky obrázků
Volitelný seznam krátkých značek pro tento obrázek, jako latest nebo version-3 .

Nahrát do centra Docker po vytvoření?
Pokud je zde vybráno Ano a dokončení vytváření obrázků bude nahráno do Docker Hubu pod účtem nakonfigurovaným v hostitelském systému kontejneru. To umožňuje stažení obrazu jinými uživateli Docker.
