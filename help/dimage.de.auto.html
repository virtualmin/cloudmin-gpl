Erstellen Sie ein Docker-Image
Docker-Container können nicht aus regulären Cloudmin-Images erstellt werden. Stattdessen müssen sie aus nativen Docker-Images erstellt werden, die auf jedem Host separat gespeichert werden. Bilder können entweder vom Docker Hub (auf der Seite Docker-Bilder suchen ) heruntergeladen oder über diese Seite aus einem vorhandenen Container erstellt werden.

Ein Bild hat die folgenden Attribute, die in diesem Formular festgelegt sind:

Bildname
Ein eindeutiger Name für dieses Bild. Wenn Sie ein Docker Hub-Konto haben, sollte dies mit Ihrem Docker-Benutzernamen beginnen, gefolgt von einem /, wie yourlogin/imagename .

Bildbeschreibung und Name des Autors
Eine kurze, für Menschen lesbare Beschreibung des Bildes und seines Autors. Diese sind meistens nützlich, wenn Sie das Bild in den Docker Hub hochladen.

Standardbefehl zur Ausführung auf erstellten Systemen
Dieses Feld legt den Shell-Befehl fest, der beim Start in einem Container ausgeführt wird, der aus diesem Image erstellt wurde. Dies startet sleep 99999999 einen Server wie MySQL unter Nginx, kann aber auch so einfach wie sleep 99999999 , um ein Image zu erstellen, das sich eher wie eine VM sleep 99999999 .

Ports, die auf erstellten Systemen geöffnet werden sollen
Wenn in diesem Image ein Server ausgeführt wird, auf den über das Netzwerk zugegriffen werden kann, sollten Sie die TCP-Ports eingeben, die der Server hier überwacht.

Bild-Tags
Eine optionale Liste mit kurzen Tags für dieses Bild, z. B. die latest oder version-3 .

Nach der Erstellung auf den Docker-Hub hochladen?
Wenn hier Ja ausgewählt ist und die Image-Erstellung abgeschlossen ist, wird es unter dem auf dem Host-System des Containers konfigurierten Konto in den Docker Hub hochgeladen. Dadurch kann das Bild von anderen Docker-Benutzern heruntergeladen werden.
