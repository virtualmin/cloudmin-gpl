Crear imagen de Docker
Los contenedores Docker no se pueden crear a partir de imágenes regulares de Cloudmin, sino que se deben crear a partir de imágenes nativas de Docker, que se almacenan por separado en cada host. Las imágenes pueden descargarse desde Docker Hub (en la página Buscar imágenes de Docker ) o crearse desde un contenedor existente utilizando esta página.

Una imagen tiene los siguientes atributos, que se establecen en este formulario:

Nombre de la imágen
Un nombre único para esta imagen. Si tiene una cuenta Docker Hub, esto debería comenzar con su nombre de usuario Docker seguido de un /, como su nombre de yourlogin/imagename .

Descripción de la imagen y nombre del autor
Una breve descripción legible por humanos para la imagen y su autor. Estos son principalmente útiles si sube la imagen al Docker Hub.

Comando predeterminado para ejecutar en sistemas creados
Este campo establece el comando de shell que se ejecutará dentro de un contenedor creado a partir de esta imagen al inicio. Por lo general, esto inicia un servidor como MySQL en Nginx, pero también podría ser tan simple como sleep 99999999 para crear una imagen que actúa más como una VM.

Puertos para abrir en sistemas creados
Si esta imagen ejecuta un servidor accesible en red, debe ingresar los puertos TCP que el servidor escucha aquí.

Etiquetas de imagen
Una lista opcional de etiquetas cortas para esta imagen, como la latest o la version-3 .

¿Cargar en Docker Hub después de la creación?
Si se selecciona Sí aquí y se completa la creación de la imagen, se cargará al Docker Hub en la cuenta configurada en el sistema host del contenedor. Esto permite que otros usuarios de Docker descarguen la imagen.
