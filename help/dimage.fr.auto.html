Créer une image Docker
Les conteneurs Docker ne peuvent pas être créés à partir d'images Cloudmin normales - ils doivent plutôt être créés à partir d'images Docker natives, qui sont stockées séparément sur chaque hôte. Les images peuvent être téléchargées à partir du Docker Hub (sur la page Rechercher des images Docker ) ou créées à partir d'un conteneur existant à l'aide de cette page.

Une image possède les attributs suivants, définis dans ce formulaire:

Nom de l'image
Un nom unique pour cette image. Si vous avez un compte Docker Hub, cela devrait commencer par votre nom d'utilisateur Docker suivi d'un /, comme yourlogin/imagename .

Description de l'image et nom de l'auteur
Une courte description lisible par l'homme pour l'image et son auteur. Celles-ci sont surtout utiles si vous téléchargez l'image sur le Docker Hub.

Commande par défaut à exécuter sur les systèmes créés
Ce champ définit la commande shell qui sera exécutée dans un conteneur créé à partir de cette image au démarrage. En règle générale, cela démarre un serveur comme MySQL sur Nginx, mais peut également être aussi simple que sleep 99999999 pour créer une image qui agit davantage comme une machine virtuelle.

Ports à ouvrir sur les systèmes créés
Si cette image exécute un serveur accessible par le réseau, vous devez entrer ici les ports TCP sur lesquels le serveur écoute.

Tags d'image
Une liste facultative de balises courtes pour cette image, comme la latest ou la version-3 .

Télécharger sur le hub Docker après la création?
Si Oui est sélectionné ici et que la création d'image est terminée, elle sera téléchargée sur le Docker Hub sous le compte configuré sur le système hôte du conteneur. Cela permet à l'image d'être téléchargée par d'autres utilisateurs Docker.
