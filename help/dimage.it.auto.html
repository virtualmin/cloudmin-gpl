Crea immagine Docker
I contenitori Docker non possono essere creati da normali immagini Cloudmin, ma devono essere creati da immagini Docker native, che vengono archiviate separatamente su ciascun host. Le immagini possono essere scaricate dall'hub Docker (nella pagina Cerca immagini Docker ) oppure create da un contenitore esistente utilizzando questa pagina.

Un'immagine ha i seguenti attributi, che sono impostati in questo modulo:

Nome dell'immagine
Un nome univoco per questa immagine. Se disponi di un account Docker Hub, questo dovrebbe iniziare con il tuo nome utente Docker seguito da un /, come il tuo yourlogin/imagename .

Descrizione dell'immagine e nome dell'autore
Una breve descrizione leggibile dall'uomo per l'immagine ed è l'autore. Sono utili soprattutto se carichi l'immagine sull'hub Docker.

Comando predefinito da eseguire sui sistemi creati
Questo campo imposta il comando shell che verrà eseguito all'interno di un contenitore creato da questa immagine all'avvio. In genere questo avvia un server come MySQL su Nginx, ma potrebbe anche essere semplice come sleep 99999999 per creare un'immagine che agisce più come una VM.

Porte da aprire sui sistemi creati
Se questa immagine esegue un server accessibile in rete, è necessario inserire qui le porte TCP su cui il server è in ascolto.

Tag immagine
Un elenco facoltativo di tag brevi per questa immagine, come l' latest o la version-3 .

Caricare nell'hub Docker dopo la creazione?
Se si seleziona Sì e la creazione dell'immagine viene completata, verrà caricata nell'hub Docker con l'account configurato sul sistema host del contenitore. Ciò consente di scaricare l'immagine da altri utenti Docker.
