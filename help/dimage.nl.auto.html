Docker-afbeelding maken
Docker-containers kunnen niet worden gemaakt op basis van gewone Cloudmin-images, maar moeten worden gemaakt op basis van native Docker-images, die afzonderlijk op elke host worden opgeslagen. Afbeeldingen kunnen worden gedownload vanaf de Docker Hub (op de Search Docker Images- pagina) of gemaakt vanuit een bestaande container met behulp van deze pagina.

Een afbeelding heeft de volgende kenmerken die op dit formulier zijn ingesteld:

Afbeelding naam
Een unieke naam voor deze afbeelding. Als u een Docker Hub-account, moet deze beginnen met uw Docker gebruikersnaam gevolgd door een /, zoals yourlogin/imagename .

Beschrijving van afbeelding en naam van auteur
Een korte, voor mensen leesbare beschrijving van de afbeelding en de auteur. Deze zijn vooral handig als u de afbeelding uploadt naar de Docker Hub.

Standaardopdracht om uit te voeren op gemaakte systemen
Dit veld stelt de shell-opdracht in die wordt uitgevoerd in een container die bij het opstarten is gemaakt op basis van deze afbeelding. Meestal start dit een server zoals MySQL op Nginx, maar het kan ook zo eenvoudig zijn als sleep 99999999 om een afbeelding te maken die meer op een VM lijkt.

Poorten om te openen op gemaakte systemen
Als deze afbeelding een voor het netwerk toegankelijke server uitvoert, moet u de TCP-poorten invoeren waarnaar de server hier luistert.

Afbeeldingstags
Een optionele lijst met korte tags voor deze afbeelding, zoals latest of version-3 .

Na het maken uploaden naar de Docker-hub?
Als Ja hier is geselecteerd en het maken van afbeeldingen is voltooid, wordt het geüpload naar de Docker Hub onder het account dat is geconfigureerd op het hostsysteem van de container. Hierdoor kan de afbeelding worden gedownload door andere Docker-gebruikers.
