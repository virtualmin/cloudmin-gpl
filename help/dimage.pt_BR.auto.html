Criar imagem do Docker
Os contêineres do Docker não podem ser criados a partir de imagens comuns do Cloudmin - eles devem ser criados a partir de imagens nativas do Docker, que são armazenadas separadamente em cada host. As imagens podem ser baixadas do Docker Hub (na página Pesquisar Imagens do Docker ) ou criadas a partir de um contêiner existente usando esta página.

Uma imagem possui os seguintes atributos, definidos neste formulário:

Nome da imagem
Um nome exclusivo para esta imagem. Se você possui uma conta no Docker Hub, isso deve começar com o nome de usuário do Docker seguido por /, como yourlogin/imagename .

Descrição da imagem e nome do autor
Uma breve descrição legível por humanos para a imagem e seu autor. Isso é útil principalmente se você carregar a imagem no Docker Hub.

Comando padrão para executar nos sistemas criados
Este campo define o comando do shell que será executado dentro de um contêiner criado a partir desta imagem na inicialização. Normalmente, isso inicia um servidor como MySQL no Nginx, mas também pode ser tão simples quanto sleep 99999999 para criar uma imagem que funciona mais como uma VM.

Portas a serem abertas nos sistemas criados
Se esta imagem executar um servidor acessível pela rede, insira as portas TCP em que o servidor escuta aqui.

Tags de imagem
Uma lista opcional de tags curtas para esta imagem, como a latest ou a version-3 .

Carregar no hub do Docker após a criação?
Se Sim estiver selecionado aqui e a criação da imagem for concluída, ela será carregada no Docker Hub na conta configurada no sistema host do contêiner. Isso permite que a imagem seja baixada por outros usuários do Docker.
