Создать изображение Docker
Контейнеры Docker нельзя создавать из обычных образов Cloudmin - вместо этого они должны создаваться из собственных образов Docker, которые хранятся отдельно на каждом хосте. Изображения можно либо загрузить из Docker Hub (на странице «Поиск изображений Docker» ), либо создать из существующего контейнера с помощью этой страницы.

Изображение имеет следующие атрибуты, которые задаются в этой форме:

Название изображения
Уникальное имя для этого изображения. Если у вас есть учетная запись Docker Hub, она должна начинаться с вашего имени пользователя Docker, за которым следует /, например yourlogin/imagename .

Описание изображения и имя автора
Краткое удобочитаемое описание изображения и его автора. Это в основном полезно, если вы загружаете изображение в Docker Hub.

Команда по умолчанию для запуска на созданных системах
Это поле устанавливает команду оболочки, которая будет запускаться внутри контейнера, созданного из этого образа при запуске. Как правило, это запускает сервер, такой как MySQL, на Nginx, но также может быть таким же простым, как sleep 99999999 для создания образа, который больше похож на виртуальную sleep 99999999 .

Порты, которые нужно открыть в созданных системах
Если на этом образе запущен сервер, доступный по сети, вы должны ввести порты TCP, которые сервер прослушивает здесь.

Теги изображения
Необязательный список коротких тегов для этого изображения, например, latest или version-3 .

Загрузить в Docker хаб после создания?
Если здесь выбрано «Да» и создание образа завершается, оно будет загружено в Docker Hub под учетной записью, настроенной в хост-системе контейнера. Это позволяет загружать изображение другим пользователям Docker.
