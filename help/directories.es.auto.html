Directorios de imagen de disco
Esta página le permite definir directorios del sistema host que se pueden seleccionar al crear un sistema virtual. Las imágenes de disco virtual (para Xen y KVM) o el contenido del sistema de archivos (para LXC, OpenVZ, VServers y Zonas) se almacenarán en el directorio elegido, en lugar del valor predeterminado del sistema host.

Esta característica se puede utilizar para dividir el almacenamiento del sistema virtual entre diferentes unidades o tipos de almacenamiento, como disco local frente a NFS, discos duros rápidos frente a lentos o sistemas de archivos montados sobre RAID frente a montados sin redundancia.

Cada directorio puede limitarse a su uso por parte de sistemas host seleccionados, tipos de virtualización y propietarios de sistemas. Esto le permite definir directorios en discos más rápidos y caros que solo pueden ser utilizados por root .
