Directory delle immagini del disco
Questa pagina consente di definire le directory del sistema host che possono essere selezionate durante la creazione di un sistema virtuale. Le immagini del disco virtuale (per Xen e KVM) o il contenuto del filesystem (per LXC, OpenVZ, VServers e Zones) verranno archiviati nella directory scelta, anziché nel valore predefinito del sistema host.

Questa funzione può essere utilizzata per dividere l'archiviazione del sistema virtuale tra unità o tipi di archiviazione diversi, come disco locale vs NFS, dischi rigidi veloce vs lento o filesystem montati su RAID vs montati senza ridondanza.

Ogni directory può essere limitata all'uso da parte di sistemi host selezionati, tipi di virtualizzazione e proprietari di sistemi. Ciò consente di definire directory su dischi più veloci e più costosi utilizzabili solo da root .
