Editar disco
Esta página muestra los detalles de un disco virtual existente y le permite cambiar el dispositivo al que está asignado en el sistema virtual. Si el disco se asigna desde un archivo en el sistema host, también puede cambiar su tamaño, pero solo si el sistema no se está ejecutando actualmente.

Cambiar el tamaño expandirá o contraerá el sistema de archivos EXT2 o EXT3 en el disco y volverá a crear un archivo utilizado para la memoria virtual. Cloudmin no expande automáticamente otros tipos de sistemas de archivos.
