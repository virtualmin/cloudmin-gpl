Edit Disk
This page shows the details of an existing virtual disk, and allows you to change the device it is mapped to on the virtual system. If the disk is mapped from a file on the host system, you can also change it's size, but only if the system is not currently running.

Changing the size will expand or contract the EXT2 or EXT3 filesystem on the disk, and re-create a file used for virtual memory. Other filesystem types are currently not automatically expanded by VM2.
