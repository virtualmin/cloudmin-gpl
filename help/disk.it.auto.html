Modifica disco
Questa pagina mostra i dettagli di un disco virtuale esistente e consente di modificare il dispositivo su cui è mappato sul sistema virtuale. Se il disco è mappato da un file sul sistema host, è anche possibile modificarne le dimensioni, ma solo se il sistema non è attualmente in esecuzione.

La modifica delle dimensioni espande o contrae il file system EXT2 o EXT3 sul disco e ricrea un file utilizzato per la memoria virtuale. Altri tipi di filesystem non vengono attualmente espansi automaticamente da Cloudmin.
