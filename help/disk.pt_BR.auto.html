Editar disco
Esta página mostra os detalhes de um disco virtual existente e permite alterar o dispositivo para o qual ele é mapeado no sistema virtual. Se o disco estiver mapeado a partir de um arquivo no sistema host, você também poderá alterar seu tamanho, mas apenas se o sistema não estiver em execução no momento.

Alterar o tamanho expandirá ou contrairá o sistema de arquivos EXT2 ou EXT3 no disco e recriará um arquivo usado para memória virtual. Outros tipos de sistema de arquivos atualmente não são expandidos automaticamente pelo Cloudmin.
