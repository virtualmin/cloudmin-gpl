Festplattendatei erstellen
Auf dieser Seite können Sie einem System eine neue virtuelle Festplatte hinzufügen, deren Daten einzeln auf dem Hostserver gespeichert werden. Die Felder Neue Datenträgerdatei und Gerät auf virtuellem System sollten automatisch mit verfügbaren Pfaden ausgefüllt werden, die auf bereits im System vorhandenen Datenträgern basieren.

Alles , was Sie eingeben müssen , ist die Dateigröße Neue Platte, das Dateisystem wählen Sie die Festplatte mit ( in der Regel Linux EXT3) zu formatieren, und gegebenenfalls ein Verzeichnis geben Sie die neue Festplatte auf im virtuellen System zu montieren.

Wenn das System aktuell ausgeführt wird, werden die Änderungen erst beim nächsten Neustart vollständig übernommen. Andernfalls werden sie beim Start angewendet.
