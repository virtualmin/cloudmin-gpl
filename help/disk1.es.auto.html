Crear archivo de disco
Esta página le permite agregar un nuevo disco virtual a un sistema, cuyos datos se almacenarán de forma individual en el servidor host. Los campos Nuevo archivo de disco y Dispositivo en sistema virtual se deben completar automáticamente con las rutas disponibles basadas en discos que ya están en el sistema.

Todo lo que necesita ingresar es el Nuevo tamaño de archivo del disco , seleccione el sistema de archivos para formatear el disco (normalmente Linux EXT3) y, opcionalmente, ingrese un directorio para montar el nuevo disco en el sistema virtual.

Si el sistema se está ejecutando actualmente, los cambios no se aplicarán completamente hasta el próximo reinicio. De lo contrario, se aplicarán cuando se inicie.
