Créer un fichier disque
Cette page vous permet d'ajouter un nouveau disque virtuel à un système, dont les données seront stockées une seule pour sur le serveur hôte. Les champs Nouveau fichier disque et Périphérique sur le système virtuel doivent être remplis automatiquement avec les chemins disponibles en fonction des disques déjà sur le système.

Tout ce que vous devez saisir est la nouvelle taille de fichier disque , sélectionnez le système de fichiers avec lequel formater le disque (généralement Linux EXT3), et entrez éventuellement un répertoire pour monter le nouveau disque dans le système virtuel.

Si le système est en cours d'exécution, les modifications ne seront pas entièrement appliquées avant le prochain redémarrage. Sinon, ils seront appliqués lors de son démarrage.
