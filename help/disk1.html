Create Disk File
This page allows you to add a new virtual disk to a system, whose data will be stored a single for on the host server. The New disk file and Device on virtual system fields should be filled in automatically with available paths based on disks already on the system.

All you need to enter is the New disk file size, select the filesystem to format the disk with (typically Linux EXT3), and optionally enter a directory to mount the new disk on in the virtual system.

If the system is current running, the changes will not be fully applied until the next reboot. Otherwise, they will be applied when it is started up.
