Crea file su disco
Questa pagina consente di aggiungere un nuovo disco virtuale a un sistema, i cui dati saranno archiviati per un singolo sul server host. I campi Nuovo file su disco e Dispositivo su sistema virtuale devono essere compilati automaticamente con percorsi disponibili basati su dischi già presenti nel sistema.

Tutto ciò che devi inserire è la dimensione del nuovo file del disco , selezionare il filesystem con cui formattare il disco (in genere Linux EXT3) e, facoltativamente, inserire una directory su cui montare il nuovo disco nel sistema virtuale.

Se il sistema è attualmente in esecuzione, le modifiche non verranno applicate completamente fino al prossimo riavvio. In caso contrario, verranno applicati all'avvio.
