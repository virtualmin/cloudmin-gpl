Criar arquivo de disco
Esta página permite adicionar um novo disco virtual a um sistema cujos dados serão armazenados um único no servidor host. Os campos Novo arquivo de disco e Dispositivo no sistema virtual devem ser preenchidos automaticamente com os caminhos disponíveis com base nos discos já existentes no sistema.

Tudo o que você precisa digitar é o novo tamanho do arquivo do disco , selecione o sistema de arquivos para formatar o disco (normalmente Linux EXT3) e, opcionalmente, insira um diretório para montar o novo disco no sistema virtual.

Se o sistema estiver em execução no momento, as alterações não serão totalmente aplicadas até a próxima reinicialização. Caso contrário, eles serão aplicados quando for inicializado.
