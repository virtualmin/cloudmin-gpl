Festplattengerät hinzufügen
Auf dieser Seite können Sie einem System eine neue virtuelle Festplatte hinzufügen, indem Sie eine vorhandene Datei oder ein reales Gerät auf dem Hostsystem verwenden. Ersteres ist nützlich, wenn Sie bereits eine Datei von einem anderen System haben. Versuchen Sie jedoch nicht, dieselbe Festplatte zwei laufenden Systemen gleichzeitig zur Verfügung zu stellen, da dies zu einer Beschädigung der Daten führen kann.

Das Hinzufügen eines realen Geräts kann nützlich sein, um Zugriff auf ein CD- oder DVD-Laufwerk zu gewähren oder um ein LVM-Volume oder sogar eine reale Partition einem virtuellen System zuzuordnen, um die Leistung zu steigern.

Wenn Sie möchten, dass die vorhandene Festplatte mit einem neuen Dateisystem neu formatiert wird, wählen Sie den Typ aus dem Dateisystem aus, der auf einer neuen Festplatte erstellt werden soll . Wenn Sie möchten, dass es auch auf dem virtuellen System bereitgestellt wird, geben Sie ein Mount-Verzeichnis in das Feld Neue Festplatte bereitstellen als ein.

Wenn das System aktuell ausgeführt wird, werden die Änderungen erst beim nächsten Neustart vollständig übernommen. Andernfalls werden sie beim Start angewendet.
