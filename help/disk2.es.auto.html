Agregar dispositivo de disco
Esta página le permite agregar un nuevo disco virtual a un sistema, utilizando un archivo existente o un dispositivo real en el sistema host. El primero es útil si ya tiene un archivo de otro sistema, pero no intente hacer que el mismo disco esté disponible para dos sistemas en ejecución a la vez, ya que esto causará daños en los datos.

Agregar un dispositivo real puede ser útil para otorgar acceso a una unidad de CD o DVD, o para asignar un volumen LVM o incluso una partición real a un sistema virtual para un mayor rendimiento.

Si desea volver a formatear el disco existente con un nuevo sistema de archivos, seleccione el tipo del Sistema de archivos para crear en un nuevo disco . Si también desea que se monte en el sistema virtual, ingrese un directorio de montaje en el campo Montar nuevo disco como .

Si el sistema se está ejecutando actualmente, los cambios no se aplicarán completamente hasta el próximo reinicio. De lo contrario, se aplicarán cuando se inicie.
