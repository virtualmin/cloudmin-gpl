Aggiungi dispositivo disco
Questa pagina consente di aggiungere un nuovo disco virtuale a un sistema, utilizzando un file esistente o un dispositivo reale sul sistema host. Il primo è utile se si dispone già di un file da un altro sistema, ma non provare a rendere lo stesso disco disponibile per due sistemi in esecuzione contemporaneamente, poiché ciò provocherebbe il danneggiamento dei dati.

L'aggiunta di un dispositivo reale può essere utile per consentire l'accesso a un'unità CD o DVD o per mappare un volume LVM o persino una partizione reale su un sistema virtuale per migliorare le prestazioni.

Se si desidera riformattare il disco esistente con un nuovo filesystem, selezionare il tipo dal filesystem da creare sul nuovo disco . Se lo si desidera anche montato sul sistema virtuale, immettere una directory di montaggio nel campo Monta nuovo disco come .

Se il sistema è attualmente in esecuzione, le modifiche non verranno applicate completamente fino al prossimo riavvio. In caso contrario, verranno applicati all'avvio.
