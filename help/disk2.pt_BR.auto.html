Adicionar dispositivo de disco
Esta página permite adicionar um novo disco virtual a um sistema, usando um arquivo ou dispositivo real existente no sistema host. O primeiro é útil se você já possui um arquivo de outro sistema - mas não tente disponibilizar o mesmo disco para dois sistemas em execução ao mesmo tempo, pois isso causará corrupção de dados.

Adicionar um dispositivo real pode ser útil para conceder acesso a uma unidade de CD ou DVD ou mapear um volume LVM ou até uma partição real para um sistema virtual para aumentar o desempenho.

Se você deseja que o disco existente seja formatado novamente com um novo sistema de arquivos, selecione o tipo no sistema de arquivos a ser criado no novo disco . Se você também deseja montá-lo no sistema virtual, insira um diretório de montagem no campo Montar novo disco como .

Se o sistema estiver em execução no momento, as alterações não serão totalmente aplicadas até a próxima reinicialização. Caso contrário, eles serão aplicados quando for inicializado.
