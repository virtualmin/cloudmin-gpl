Datenträger verwalten
Auf dieser Seite werden alle virtuellen Festplatten angezeigt, die für ein einzelnes von Cloudmin verwaltetes System verfügbar sind. Jede Festplatte ist im Wesentlichen eine Zuordnung zwischen einer Datei oder einer realen Festplatte auf dem Hostsystem und einem Festplattengerät auf dem virtuellen System. In den meisten Fällen werden reguläre Dateien wie /xen/foo.img SCSI-Datenträgern wie /dev/sda1 .

Auf dieser Seite können Sie Ihrem System neue Festplatten hinzufügen (über die Links über und unter der Liste), die Größe vorhandener Festplatten ändern (indem Sie darauf klicken) oder eine oder mehrere Festplatten entfernen, indem Sie sie auswählen und auf die Schaltfläche Löschen klicken .
