Manage Disks
This page displays all virtual disks available to a single system managed by Cloudmin. Each disk is essentially a mapping betweem a file or real disk on the host system, and a disk device on the virtual system. In most cases, regular files like /xen/foo.img are mapped to SCSI disks like /dev/sda1.

This page can be used to add new disks to your system (using the links above and below the list), change the sizes of existing disks (by clicking on them), or remove one or more disks by selecting them and click the Delete button.
