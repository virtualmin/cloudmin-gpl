Gerenciar discos
Esta página exibe todos os discos virtuais disponíveis para um único sistema gerenciado pelo Cloudmin. Cada disco é essencialmente um mapeamento entre um arquivo ou disco real no sistema host e um dispositivo de disco no sistema virtual. Na maioria dos casos, arquivos regulares como /xen/foo.img são mapeados para discos SCSI como /dev/sda1 .

Esta página pode ser usada para adicionar novos discos ao seu sistema (usando os links acima e abaixo da lista), alterar os tamanhos dos discos existentes (clicando neles) ou remover um ou mais discos, selecionando-os e clique no botão Excluir .
