Crear volumen de Docker
Este formulario le permite crear un nuevo volumen de Docker o uno o más hosts. Los campos en el formulario son:
Nombre del volumen
Un nombre único para este volumen.

Sistemas host
El Docker aloja en que se creará este volumen. Tenga en cuenta que a menos que el directorio de origen ya esté compartido a través de NFS, los contenedores creados en diferentes hosts no verán los mismos archivos.

Conductor
El controlador de volumen determina cómo se accede al almacenamiento subyacente. De manera predeterminada, Docker solo admite el controlador de archivos locales , pero se pueden instalar otros. Consulte https://docs.docker.com/engine/extend/plugins/ para obtener una lista de los complementos de controladores disponibles.
Si se selecciona Predeterminado , Cloudmin usará el controlador de archivos locales a menos que seleccione un directorio de host a continuación, en cuyo caso, usará archivos locales persistentes .

Fuente
De manera predeterminada (a menos que se elija un controlador personalizado), Docker creará un directorio en el host para cada nuevo volumen, generalmente en /var/lib/docker . Para especificar un directorio alternativo, seleccione Ruta en el sistema host e ingréselo aquí.
Tenga en cuenta que esto solo funcionará si se ha instalado el complemento local-persist . Los archivos y las instrucciones de instalación están disponibles en https://github.com/CWSpear/local-persist .

Opciones de volumen personalizadas
Cada controlador admite una serie de opciones que se pueden usar para controlar dónde se almacenan los archivos, qué tan grande es el volumen y más. Esta tabla le permite ingresar opciones que actualmente no son compatibles con la IU de Cloudmin.
