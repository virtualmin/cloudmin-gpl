Créer un volume Docker
Ce formulaire vous permet de créer un nouveau volume Docker ou un ou plusieurs hôtes. Les champs du formulaire sont:
Nom du volume
Un nom unique pour ce volume.

Systèmes hôtes
Le Docker héberge sur lequel ce volume sera créé. Notez qu'à moins que le répertoire source ne soit déjà partagé via NFS, les conteneurs créés sur différents hôtes ne verront pas les mêmes fichiers.

Chauffeur
Le pilote de volume détermine comment accéder au stockage sous-jacent. Par défaut, Docker prend uniquement en charge le pilote de fichiers locaux , mais d'autres peuvent être installés. Voir https://docs.docker.com/engine/extend/plugins/ pour une liste des plugins de pilotes disponibles.
Si Par défaut est sélectionné, Cloudmin utilisera le pilote de fichiers locaux sauf si vous sélectionnez un répertoire hôte ci-dessous - dans ce cas, il utilisera des fichiers locaux persistants .

La source
Par défaut (sauf si un pilote personnalisé est choisi), Docker créera un répertoire sur l'hôte pour chaque nouveau volume, généralement sous /var/lib/docker . Pour spécifier un autre répertoire, sélectionnez Chemin sur le système hôte et entrez-le ici.
Notez que cela ne fonctionnera que si le plug local-persist in de local-persist a été installé. Les fichiers et les instructions d'installation sont disponibles sur https://github.com/CWSpear/local-persist .
