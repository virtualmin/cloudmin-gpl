Crea volume Docker
Questo modulo consente di creare un nuovo volume Docker o uno o più host. I campi nel modulo sono:
Nome volume
Un nome univoco per questo volume.

Sistemi host
Docker ospita il volume su cui verrà creato questo volume. Si noti che, a meno che la directory di origine non sia già condivisa tramite NFS, i contenitori creati su host diversi non vedranno gli stessi file.

autista
Il driver del volume determina come accedere all'archiviazione sottostante. Per impostazione predefinita, Docker supporta solo il driver di file locali , ma è possibile installarne altri. Consulta https://docs.docker.com/engine/extend/plugins/ per un elenco dei plug-in dei driver disponibili.
Se si seleziona Predefinito , Cloudmin utilizzerà il driver dei file locali a meno che non si selezioni una directory host in basso, nel qual caso utilizzerà i file locali persistenti .

fonte
Per impostazione predefinita (a meno che non sia stato scelto un driver personalizzato), Docker creerà una directory sull'host per ogni nuovo volume, in genere in /var/lib/docker . Per specificare una directory alternativa, selezionare Percorso sul sistema host e immetterlo qui.
Nota che funzionerà solo se è stato installato il plugin local-persist . I file e le istruzioni di installazione sono disponibili su https://github.com/CWSpear/local-persist .

Opzioni di volume personalizzate
Ogni driver supporta una serie di opzioni che possono essere utilizzate per controllare dove sono archiviati i file, quanto è grande il volume e altro ancora. Questa tabella consente di inserire opzioni che non sono attualmente supportate dall'interfaccia utente di Cloudmin.
