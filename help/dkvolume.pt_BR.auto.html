Criar volume do Docker
Este formulário permite criar um novo volume do Docker ou um ou mais hosts. Os campos no formulário são:
Nome do volume
Um nome exclusivo para este volume.

Sistemas host
O Docker hospeda o qual este volume será criado. Observe que, a menos que o diretório de origem já esteja compartilhado via NFS, os contêineres criados em hosts diferentes não verão os mesmos arquivos.

Motorista
O driver de volume determina como o armazenamento subjacente é acessado. Por padrão, o Docker suporta apenas o driver de arquivos locais , mas outros podem ser instalados. Consulte https://docs.docker.com/engine/extend/plugins/ para obter uma lista dos plugins de driver disponíveis.
Se Padrão estiver selecionado, o Cloudmin usará o driver de arquivos locais , a menos que você selecione um diretório de host abaixo - nesse caso, ele usará arquivos locais persistentes .

Fonte
Por padrão (a menos que um driver personalizado seja escolhido), o Docker criará um diretório no host para cada novo volume, geralmente em /var/lib/docker . Para especificar um diretório alternativo, selecione Caminho no sistema host e insira-o aqui.
Observe que isso só funcionará se o plugin local-persist tiver sido instalado. Arquivos e instruções de instalação estão disponíveis em https://github.com/CWSpear/local-persist .

Opções de volume personalizadas
Cada driver suporta várias opções que podem ser usadas para controlar onde os arquivos são armazenados, qual o tamanho do volume e muito mais. Esta tabela permite inserir opções que atualmente não são suportadas pela interface do usuário do Cloudmin.
