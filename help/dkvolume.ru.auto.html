Создать том Docker
Эта форма позволяет вам создать новый том Docker или один или несколько хостов. Поля в форме:
Название тома
Уникальное имя для этого тома.

Хост системы
Docker хосты, на которых будет создан этот том. Обратите внимание, что если исходный каталог уже не используется совместно через NFS, контейнеры, созданные на разных хостах, не будут видеть одни и те же файлы.

Водитель
Драйвер тома определяет, как осуществляется доступ к базовому хранилищу. По умолчанию Docker поддерживает только драйвер локальных файлов , но другие могут быть установлены. См. Https://docs.docker.com/engine/extend/plugins/ для получения списка доступных плагинов драйверов.
Если выбрано значение по умолчанию , Cloudmin будет использовать драйвер локальных файлов, если вы не выберете каталог хоста ниже - в этом случае он будет использовать постоянные локальные файлы .

Источник
По умолчанию (если не выбран пользовательский драйвер), Docker создает каталог на хосте для каждого нового тома, обычно в /var/lib/docker . Чтобы указать альтернативный каталог, выберите Путь в хост-системе и введите его здесь.
Обратите внимание, что это будет работать, только если установлен плагин local-persist . Файлы и инструкции по установке доступны по адресу https://github.com/CWSpear/local-persist .

Пользовательские параметры громкости
Каждый драйвер поддерживает ряд опций, которые можно использовать для управления местом хранения файлов, размером тома и многим другим. Эта таблица позволяет вам вводить параметры, которые в настоящее время не поддерживаются пользовательским интерфейсом Cloudmin.
