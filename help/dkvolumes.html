Docker Volumes
A Docker volume is a storage location that can be shared between multiple containers, and persists even after a container is deleted. Normally a volume corresponds to a directory on the host system, but volume plugins exist that allow other storage types to be used, like NFS and DRDB.

This page lists all volumes on all registered Docker hosts, and the containers that are using them. You can add a volume with the Create a new Docker volume link, or remove selected volumes by checking them and clicking the Delete Selected Volumes button.
