Mover dominios de Virtualmin
Este formulario le permite mover uno o más dominios de Virtualmin a otro sistema administrado por Cloudmin. Solo los sistemas que Cloudmin sabe que tienen Virtualmin instalado y en funcionamiento pueden seleccionarse como destino.

El proceso de movimiento de dominio utiliza las funciones de copia de seguridad y restauración de Virtualmin. Por defecto, los dominios seleccionados se respaldan en la fuente, se deshabilitan y luego se restauran (y, por lo tanto, se vuelven a crear) en el sistema de destino. Esto protege la pérdida de datos del dominio si la restauración falla en el destino. Sin embargo, ¿puede usar Eliminar de los sistemas de origen? campo para cambiar este comportamiento.

¿ Reasignar direcciones IP privadas? el campo determina (para dominios con IP privadas) si mantendrán sus direcciones existentes en el sistema de destino o si se asignarán nuevas direcciones. Este último se recomienda si la IP privada del dominio no está en la red del sistema de destino.
