Sposta domini Virtualmin
Questo modulo consente di spostare uno o più domini Virtualmin su un altro sistema gestito da Cloudmin. Solo i sistemi che Cloudmin conosce hanno Virtualmin installato e funzionante possono essere selezionati come destinazione.

Il processo di spostamento del dominio utilizza le funzionalità di backup e ripristino di Virtualmin. Per impostazione predefinita, i domini selezionati vengono sottoposti a backup sull'origine, disabilitati e quindi ripristinati (e quindi ricreati) sul sistema di destinazione. Ciò protegge la perdita dei dati del dominio se il ripristino non riesce sulla destinazione. Tuttavia, è possibile utilizzare il Elimina dal sistemi di origine? campo per modificare questo comportamento.

Riassegnare gli indirizzi IP privati? Il campo determina (per i domini con IP privati) se manterranno i loro indirizzi esistenti sul sistema di destinazione o se verranno assegnati nuovi indirizzi. Quest'ultimo è consigliato se l'IP privato del dominio non si trova sulla rete del sistema di destinazione.
