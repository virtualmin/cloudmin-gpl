Mover domínios do Virtualmin
Este formulário permite mover um ou mais domínios do Virtualmin para outro sistema gerenciado pelo Cloudmin. Somente sistemas que o Cloudmin sabe que o Virtualmin está instalado e em funcionamento podem ser selecionados como destino.

O processo de movimentação do domínio usa os recursos de backup e restauração do Virtualmin. Por padrão, os domínios selecionados são armazenados em backup na origem, desabilitados e depois restaurados (e, portanto, recriados) no sistema de destino. Isso protege os dados do domínio de serem perdidos se a restauração falhar no destino. No entanto, você pode usar a opção Excluir dos sistemas de origem? campo para alterar esse comportamento.

Re-alocar endereços IP privados? O campo determina (para domínios com IPs privados) se eles manterão seus endereços existentes no sistema de destino ou se novos endereços serão alocados. Este último é recomendado se o IP privado do domínio não estiver na rede do sistema de destino.
