Docker-Hostsysteme
Bevor Cloudmin virtuelle Systeme mit Docker-Containern erstellen kann, müssen Sie die Hostsysteme registrieren, auf denen Docker auf dieser Seite ausgeführt wird. Cloudmin verfügt über eine dreischichtige Architektur, in der das Mastersystem (auf dem die Cloudmin-Webmin-Oberfläche ausgeführt wird) von den Systemen getrennt ist, auf denen Container gehostet werden, die wiederum von den Docker-Containern selbst getrennt sind.

Bevor ein Docker-Hostsystem hier registriert werden kann, müssen Sie es zunächst über den Link " Physisches System hinzufügen" unter " System hinzufügen" im linken Menü unter die Kontrolle von Cloudmin bringen. Ein einzelnes System kann sowohl Virtualmin-Domänen als auch Container hosten, sofern ausreichend CPU und RAM vorhanden sind. Wählen Sie anschließend das System aus dem Menü Hostsystem zum Hinzufügen aus und klicken Sie auf Start Host hinzufügen .
