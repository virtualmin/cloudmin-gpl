Docker Host Systems
Avant que Cloudmin puisse créer des systèmes virtuels à l'aide de conteneurs Docker, vous devez enregistrer les systèmes hôtes sur lesquels Docker s'exécutera à l'aide de cette page. Cloudmin a une architecture à trois couches, dans laquelle le système maître (sur lequel s'exécute l'interface Cloudmin Webmin) est distinct des systèmes qui hébergent les conteneurs, qui sont à leur tour séparés des conteneurs Docker eux-mêmes.

Avant qu'un système hôte Docker puisse être enregistré ici, vous devez d'abord le placer sous le contrôle de Cloudmin en utilisant le lien Ajouter un système physique sous Ajouter un système dans le menu de gauche. Il est possible pour un système unique d'héberger à la fois des domaines et des conteneurs Virtualmin, tant qu'il dispose de suffisamment de CPU et de RAM. Une fois cela fait, sélectionnez le système dans le menu Système hôte à ajouter , puis cliquez sur Démarrer l'ajout d'hôte .
