Docker Host Systems
Before Cloudmin can create any virtual systems using Docker containers, you must register the host systems on which Docker will run using this page. Cloudmin has a three-layer architecture, in which the master system (on which the Cloudmin Webmin interface runs) is separate from the systems that host containers, which are in turn separate from the Docker containers themselves.

Before a Docker host system can be registered here, you must first bring it under Cloudmin's control using the Add physical system link under Add system on the left menu. It is possible for a single system to both host Virtualmin domains and containers, as long as it has sufficient CPU and RAM. Once this is done, select the system from the Host system to add menu, and click Start Adding Host.
