Docker Host Systems
Prima che Cloudmin possa creare qualsiasi sistema virtuale utilizzando i contenitori Docker, è necessario registrare i sistemi host su cui Docker verrà eseguito utilizzando questa pagina. Cloudmin ha un'architettura a tre livelli, in cui il sistema principale (su cui gira l'interfaccia Cloudmin Webmin) è separato dai sistemi che ospitano i contenitori, che a loro volta sono separati dai contenitori Docker stessi.

Prima che un sistema host Docker possa essere registrato qui, è necessario portarlo sotto il controllo di Cloudmin usando il collegamento Aggiungi sistema fisico sotto Aggiungi sistema nel menu a sinistra. È possibile per un singolo sistema ospitare sia domini e contenitori Virtualmin, purché disponga di CPU e RAM sufficienti. Al termine, selezionare il sistema dal sistema Host per aggiungere il menu e fare clic su Avvia aggiunta host .
