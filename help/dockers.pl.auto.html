Docker Host Systems
Aby Cloudmin mógł utworzyć jakiekolwiek systemy wirtualne przy użyciu kontenerów Docker, musisz zarejestrować systemy hosta, na których Docker będzie działał na tej stronie. Cloudmin ma trójwarstwową architekturę, w której system główny (na którym działa interfejs Cloudmin Webmin) jest niezależny od systemów hostujących kontenery, które z kolei są oddzielne od samych kontenerów Docker.

Aby można było zarejestrować tutaj system hosta Dockera, musisz najpierw przejąć kontrolę nad Cloudmin za pomocą łącza Dodaj fizyczny system w obszarze Dodaj system w menu po lewej stronie. Możliwe jest, aby pojedynczy system hostował domeny i kontenery Virtualmin, o ile ma wystarczającą ilość procesora i pamięci RAM. Po zakończeniu wybierz system z menu Host, aby dodać menu, a następnie kliknij przycisk Rozpocznij dodawanie hosta .
