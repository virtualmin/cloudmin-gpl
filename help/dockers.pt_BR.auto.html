Sistemas Host Docker
Antes de o Cloudmin criar qualquer sistema virtual usando contêineres do Docker, você deve registrar os sistemas host nos quais o Docker será executado usando esta página. O Cloudmin possui uma arquitetura de três camadas, na qual o sistema mestre (no qual a interface do Cloudmin Webmin é executada) é separado dos sistemas que hospedam contêineres, que por sua vez são separados dos próprios contêineres do Docker.

Para que um sistema host do Docker possa ser registrado aqui, primeiro você deve colocá-lo sob o controle do Cloudmin usando o link Adicionar sistema físico em Adicionar sistema no menu esquerdo. É possível que um único sistema hospede domínios e contêineres do Virtualmin, desde que tenha CPU e RAM suficientes. Feito isso, selecione o sistema no sistema Host para adicionar menu e clique em Iniciar Adicionando Host .
