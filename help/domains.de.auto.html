Virtualmin-Domänen

Domänen verwalten

Auf dieser Seite können Sie auf allen von Cloudmin verwalteten Systemen nach Virtualmin-Domänen (virtuellen Servern) suchen. Um Domains zu finden, geben Sie einen Teil oder den gesamten Domainnamen in das Textfeld oben auf der Seite ein und klicken Sie auf die Schaltfläche Suchen . Übereinstimmende Domains werden dann in einer Liste darunter angezeigt.

Um eine Domain zu verwalten, klicken Sie in der Liste auf ihren Namen. Dadurch wird ein separates Browserfenster geöffnet, das automatisch beim Hosting-System mit der ausgewählten Domain angemeldet wird. Es sei denn, die Domäne befindet sich auf demselben System wie Cloudmin. In diesem Fall wird sie im selben Frame angezeigt.

Um eine oder mehrere Domains zu löschen, wählen Sie sie aus den Suchergebnissen aus und klicken Sie auf die Schaltfläche Ausgewählte löschen. Auf ähnliche Weise können Sie mehrere Domains auf verschiedenen Systemen auf einmal mit der Disable Selected und aktivieren Ausgewählte Tasten aktiviert oder deaktiviert werden. Schließlich können Sie mit der Schaltfläche Ausgewählte verschieben eine oder mehrere Domänen von ihren aktuellen Hostsystemen auf einen neuen Host übertragen.

Erstellen einer Domain

Am Ende der Seite befindet sich ein reduzierbarer Abschnitt mit einem Formular zum Hinzufügen einer neuen Domain, das Sie durch Klicken auf das Bild + erweitern können . Geben Sie zum Erstellen einer Domain den Domainnamen, die Beschreibung und das Kennwort ein, genau wie bei der direkten Verwendung von Virtualmin. Alle anderen Einstellungen wie Benutzername, Vorlage und Grenzwerte verwenden die Standardeinstellungen, und die erstellte Domäne ist immer ein virtueller Server der obersten Ebene mit eigenem Webmin- und SSH-Login.

Wenn Sie die Domäne auf einem bestimmten System erstellen möchten, wählen Sie sie im Menü Auf System erstellen aus . Andernfalls können Sie Cloudmin entscheiden lassen, wo es erstellt werden soll, indem Sie das System mit den wenigsten Domänen, der meisten freien Festplatte oder der geringsten CPU-Auslastung finden, abhängig von Ihrer Auswahl.

Um die Steuerung der Funktionen für die neue Domäne aktiviert werden, wählen Sie diese aus der Liste der Funktionen aktivieren. Alle möglichen Funktionen werden angezeigt, aber mit Cloudmin können Sie keine Domäne auf einem System erstellen, das die von Ihnen ausgewählten Funktionen nicht unterstützt. Die standardmäßig aktivierten Funktionen können auf der Seite Standard-Virtualmin-Funktionen gesteuert werden.

Standardmäßig verwenden neue Domänen die primäre gemeinsam genutzte IP-Adresse des ausgewählten Systems. Wählen Sie die Option Ja, automatisch zuweisen aus, damit das Virtualmin-Zielsystem stattdessen eine neue private IP-Adresse zuweist (für SSL-Webhosting erforderlich). Wenn Sie die zu verwendende IP manuell eingeben möchten, wählen Sie Ja mit Adresse und geben Sie sie in das nebenstehende Textfeld ein.

Einige virtuelle Systemtypen wie Solaris Zones und Linux VServer können keine eigenen zusätzlichen privaten IP-Adressen hinzufügen. Für Zielsysteme dieser Typen führt Cloudmin die Zuweisung und Erstellung von IP-Adressen durch, wenn Sie die Option Automatisch zuweisen auswählen.
