Domaines Virtualmin

Gérer les domaines

Cette page peut être utilisée pour rechercher des domaines Virtualmin (serveurs virtuels) sur tous les systèmes gérés par Cloudmin. Pour rechercher des domaines, entrez une partie ou la totalité du nom de domaine dans la zone de texte en haut de la page, puis cliquez sur le bouton Rechercher . Les domaines correspondants seront alors affichés dans une liste en dessous.

Pour gérer un domaine, cliquez sur son nom dans la liste. Cela ouvrira une fenêtre de navigateur séparée qui sera automatiquement connectée au système d'hébergement, avec le domaine sélectionné. Sauf si le domaine est sur le même système que Cloudmin, auquel cas il sera affiché dans le même cadre.

Pour supprimer un ou plusieurs domaines, sélectionnez-les dans les résultats de la recherche et cliquez sur le bouton Supprimer la sélection . De même, vous pouvez désactiver ou activer plusieurs domaines sur différents systèmes à la fois à l'aide des boutons Désactiver la sélection et Activer la sélection . Enfin, vous pouvez transférer un ou plusieurs domaines de leurs systèmes hôtes actuels vers un nouvel hôte avec le bouton Déplacer la sélection .

Création d'un domaine

Au bas de la page se trouve une section pliable contenant un formulaire pour ajouter un nouveau domaine, que vous pouvez développer en cliquant sur l'image + . Pour créer un domaine, saisissez le nom de domaine, la description et le mot de passe, comme vous le feriez lorsque vous utilisez Virtualmin directement. Tous les autres paramètres tels que le nom d'utilisateur, le modèle et les limites utiliseront les valeurs par défaut, et le domaine créé sera toujours un serveur virtuel de niveau supérieur avec sa propre connexion Webmin et SSH.

Si vous souhaitez créer le domaine sur un système spécifique, sélectionnez-le dans le menu Créer sur le système . Sinon, vous pouvez laisser Cloudmin décider où le créer, en trouvant le système avec le moins de domaines, le disque le plus libre ou la plus faible utilisation du processeur, selon votre sélection.

Pour contrôler les fonctionnalités activées pour le nouveau domaine, sélectionnez-les dans la liste Activer les fonctionnalités . Toutes les fonctionnalités possibles sont affichées, mais Cloudmin ne vous permettra pas de créer un domaine sur un système qui ne prend pas en charge les fonctionnalités que vous avez sélectionnées. Les fonctionnalités vérifiées par défaut peuvent être contrôlées sur la page Fonctionnalités Virtualmin par défaut .

Par défaut, les nouveaux domaines utiliseront l'adresse IP partagée principale du système sélectionné. Pour que le système Virtualmin cible alloue à la place une nouvelle adresse IP privée (nécessaire pour l'hébergement Web SSL), sélectionnez l'option Oui, allouer automatiquement . Ou si vous souhaitez saisir manuellement l'adresse IP à utiliser, sélectionnez Oui, avec adresse et entrez-la dans la zone de texte adjacente.

Certains types de systèmes virtuels comme Solaris Zones et Linux VServers ne peuvent pas ajouter leurs propres adresses IP privées supplémentaires, donc pour les systèmes cibles de ces types, Cloudmin effectuera l'allocation et la création d'adresses IP si vous sélectionnez l'option d' allouer automatiquement .
