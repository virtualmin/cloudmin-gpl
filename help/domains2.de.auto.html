Virtualmin-Domänen
Diese Seite listet Virtualmin-Domänen auf, die derzeit auf diesem System gehostet werden. Um eine Domain zu verwalten, klicken Sie in der Liste auf ihren Namen. Um Vorgänge für mehrere Domänen gleichzeitig auszuführen (z. B. Löschen, Deaktivieren, Aktivieren oder Verschieben auf ein neues System), aktivieren Sie die Kontrollkästchen neben diesen und klicken Sie auf die entsprechende Schaltfläche am unteren Rand der Tabelle.

Eine Domäne kann auch speziell auf diesem System über den Link Create Virtualmin domain über oder unter der Tabelle erstellt werden.
