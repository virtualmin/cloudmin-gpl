EC2-Bild bearbeiten
Auf dieser Seite werden alle verfügbaren Informationen zu einem EC2-Image angezeigt, das Sie besitzen, und Sie können steuern, wer Zugriff darauf hat. Im Feld Gewährt an Konten können Sie eine Liste der EC2-Kontonummern eingeben, die über die Berechtigung zum Erstellen eines neuen virtuellen Systems aus diesem Bild verfügen. Alternativ können Sie Zugriff für alle gewähren auswählen , wenn das Bild öffentlich verfügbar sein soll.
