Editar imagen EC2
Esta página muestra toda la información disponible sobre una imagen EC2 de su propiedad y le permite controlar quién tiene acceso a ella. El campo Concedido a cuentas se puede usar para ingresar una lista de números de cuenta EC2 que tendrán permisos para crear un nuevo sistema virtual a partir de esta imagen. Alternativamente, puede seleccionar Conceder acceso a todos si desea que la imagen esté disponible públicamente.
