Modifier l'image EC2
Cette page affiche toutes les informations disponibles sur une image EC2 que vous possédez et vous permet de contrôler qui y a accès. Le champ Accordé aux comptes peut être utilisé pour entrer une liste de numéros de compte EC2 qui auront les autorisations pour créer un nouveau système virtuel à partir de cette image. Vous pouvez également sélectionner Accorder l'accès à tout le monde si vous souhaitez que l'image soit accessible au public.
