Editar imagem EC2
Esta página mostra todas as informações disponíveis sobre uma imagem EC2 que você possui e permite controlar quem tem acesso a ela. O campo Concedido a contas pode ser usado para inserir uma lista de números de conta EC2 que terão permissões para criar um novo sistema virtual a partir desta imagem. Como alternativa, você pode selecionar Conceder acesso a todos se desejar que a imagem esteja disponível ao público.
