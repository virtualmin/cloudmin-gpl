Weisen Sie die EC2-Adresse zu
Sobald Sie eine oder mehrere statische EC2-IP-Adressen angefordert haben (auf der Seite Statische EC2-IP-Adressen ), kann eine auf dieser Seite einer vorhandenen Instanz zugewiesen werden. Wählen Sie es einfach aus dem IP- Adressmenü aus und klicken Sie auf die Schaltfläche unten im Formular. Die vollständige Anwendung kann einige Minuten dauern, da die Routen innerhalb des Amazon-Netzwerks angepasst werden müssen. Während dieser Zeit ist das System möglicherweise weder unter der alten noch unter der neuen Adresse von außen zugänglich.

Wenn dem ausgewählten System bereits eine statische Adresse zugewiesen ist, kann diese durch Auswahl der Option Keine aus dem Menü entfernt werden. EC2 wählt eine neue dynamische Adresse für das System aus (die möglicherweise nicht mit der ursprünglichen Adresse übereinstimmt) und weist sie innerhalb weniger Minuten zu.
