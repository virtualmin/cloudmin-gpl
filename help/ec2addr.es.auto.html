Asignar dirección EC2
Una vez que haya solicitado una o más direcciones IP estáticas EC2 (en la página Direcciones IP estáticas EC2 ), se puede asignar una a una instancia existente en esta página. Simplemente selecciónelo de la dirección IP para asignar el menú y haga clic en el botón en la parte inferior del formulario. Esto puede tardar varios minutos en aplicarse por completo, debido a la necesidad de ajustar las rutas dentro de la red de Amazon. Durante este tiempo, es posible que el sistema no sea accesible externamente en la dirección anterior o nueva.

Si el sistema seleccionado ya tiene una dirección estática asignada, se puede eliminar seleccionando la opción Ninguno del menú. EC2 seleccionará una nueva dirección dinámica para el sistema (que puede no ser la misma que su dirección original) y la asignará en unos minutos.
