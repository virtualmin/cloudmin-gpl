Atribuir endereço EC2
Depois de solicitar um ou mais endereços IP estáticos do EC2 (na página Endereços IP estáticos do EC2 ), um pode ser atribuído a uma instância existente nesta página. Simplesmente selecione-o no endereço IP para atribuir o menu e clique no botão na parte inferior do formulário. Isso pode levar alguns minutos para ser totalmente aplicado, devido à necessidade de ajustar as rotas na rede Amazon. Durante esse período, o sistema pode não estar acessível externamente no endereço antigo ou no novo.

Se o sistema selecionado já tiver um endereço estático atribuído, ele poderá ser removido selecionando a opção Nenhum no menu. O EC2 selecionará um novo endereço dinâmico para o sistema (que pode não ser o mesmo que o endereço original) e o atribuirá em alguns minutos.
