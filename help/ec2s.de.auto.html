EC2-Konten
EC2 ist ein von Amazon bereitgestellter Dienst zum Erstellen virtueller Systeme, die in ihrem Netzwerk ausgeführt werden und für die Benutzer pro Maschinenstunde berechnet werden. Cloudmin kann zum Erstellen und Verwalten von EC2-Instanzen verwendet werden, genau wie für Xen- und VServer-Instanzen, die auf Ihren eigenen Computern ausgeführt werden. Bevor Sie jedoch neue virtuelle Systeme über EC2 erstellen können, müssen Sie sich für ein Konto bei Amazon anmelden und Ihre Rechnungsdetails angeben. Dies kann auf der AWS-Website von Amazon erfolgen .

Wenn Sie ein EC2-Konto haben, registrieren Sie es auf dieser Seite, indem Sie auf den Link EC2-Konto hinzufügen klicken. Um ein vorhandenes Konto zu verwalten, klicken Sie auf die Beschreibung in der Liste. Um Konten zu entfernen, aktivieren Sie die Kontrollkästchen daneben und klicken Sie auf die Schaltfläche Ausgewählte Konten löschen. Sie können jedoch keine Konten entfernen, die von virtuellen Systemen verwendet werden.
