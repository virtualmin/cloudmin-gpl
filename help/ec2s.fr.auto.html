Comptes EC2
EC2 est un service fourni par Amazon pour créer des systèmes virtuels qui s'exécutent sur leur réseau, pour lesquels les utilisateurs sont facturés à l'heure de la machine. Cloudmin peut être utilisé pour créer et gérer des instances EC2, tout comme pour les instances Xen et VServer qui s'exécutent sur vos propres machines. Cependant, avant de pouvoir créer de nouveaux systèmes virtuels via EC2, vous devez vous inscrire à un compte avec Amazon et fournir vos détails de facturation. Cela peut être fait sur le site Web AWS d'Amazon .

Une fois que vous avez un compte EC2, enregistrez-le sur cette page en cliquant sur le lien Ajouter un compte EC2 . Pour gérer un compte existant, cliquez sur sa description dans la liste. Pour supprimer des comptes, cochez les cases à côté d'eux et cliquez sur le bouton Supprimer les comptes sélectionnés . Vous ne pourrez cependant pas supprimer les comptes utilisés par les systèmes virtuels.
