EC2 Accounts
EC2 is a service provided by Amazon for creating virtual systems that run on their network, for which users are charged by the machine-hour. Cloudmin can be used to create and manage EC2 instances, just like it can for Xen and VServer instances that run on your own machines. However, before you can create new virtual systems via EC2, you must sign up for an account with Amazon and provide your billing details. This can be done at Amazon's AWS website.

Once you have an EC2 account, register it on this page by clicking on the Add an EC2 account link. To manage an existing account, click on its description in the list. To remove accounts, select the checkboxes next to them and click the Delete Selected Accounts button. You will not be able to remove accounts that are in use by any virtual systems though.
