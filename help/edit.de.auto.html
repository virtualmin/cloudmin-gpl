System bearbeiten
Auf dieser Seite werden die Details eines vorhandenen verwalteten Systems angezeigt und einige seiner Einstellungen können geändert werden. Die allgemeinen Felder, die unabhängig vom Systemtyp angezeigt werden, sind:

Internet-Hostname
Dieser muss den DNS-auflösbaren Hostnamen oder die IP-Adresse des Systems enthalten. Es kann geändert werden, jedoch nur in einen anderen Hostnamen, der in dieselbe Adresse aufgelöst wird.
Beschreibung oder Kommentar
In dieses Feld können Sie eine eigene Beschreibung des Systems eingeben, z. B. Joes Webserver .
Betriebssystem
In diesem Menü sollten Sie die Betriebssystem- oder Linux-Distribution auswählen, die das verwaltete System ausführt. Cloudmin verwendet dies bei der Installation von Webmin oder anderen Paketen, um das richtige Paketformat zu ermitteln.
Systemgruppen
In diesem Abschnitt können Sie Systeme einer oder mehreren Gruppen zuweisen, um die Kategorisierung bei einer großen Anzahl von Systemen zu vereinfachen. Sie können entweder die Kontrollkästchen neben den Gruppennamen aktivieren (falls vorhanden) oder einen neuen Namen in das Feld Neue Gruppe eingeben.
Beim Host-Start starten?
Bei virtuellen Systemen, die Xen, VServer oder Zonen verwenden, steuert dieses Feld, ob das System beim Booten des Hostcomputers gestartet wird.
Letzter Status
Dieses Feld zeigt den Status des Systems an, der von Cloudmin bei der letzten geplanten oder manuellen Überprüfung ermittelt wurde. Weitere Informationen finden Sie auf der Hilfeseite zu Statusbeschreibungen .
Detaillierter Statusfehler
Wenn der Status auf einen Fehler bei der Kommunikation mit dem System hinweist, werden in diesem Feld weitere Details zu Fehlern angezeigt, z. B. warum SSH fehlgeschlagen ist oder warum Webmin nicht kontaktiert werden konnte.
Andere Felder hängen vom Typ des virtuellen Systems ab, umfassen jedoch normalerweise das Hostsystem, den verwendeten Speicher und den Instanznamen. Wenn Sie den Hostnamen, die Beschreibung, die Authentifizierungsoptionen oder andere Einstellungen ändern, klicken Sie auf die Schaltfläche Speichern , um sie zu aktivieren.
