Modifier le système
Cette page affiche les détails d'un système géré existant et permet de modifier certains de ses paramètres. Les champs communs qui apparaissent quel que soit le type de système sont:

Nom d'hôte Internet
Celui-ci doit contenir le nom d'hôte ou l'adresse IP résolvable DNS du système. Il peut être modifié, mais uniquement en un nom d'hôte différent qui se résout à la même adresse.
Description ou commentaire
Ce champ sert à entrer votre propre description du système, comme le serveur Web de Joe .
Système opérateur
Dans ce menu, vous devez sélectionner la distribution OS ou Linux que le système géré exécute. Cloudmin l'utilisera lors de l'installation de Webmin ou d'autres packages pour déterminer le format de package correct.
Groupes de systèmes
Cette section peut être utilisée pour affecter des systèmes à un ou plusieurs groupes, pour une catégorisation plus facile lorsque vous avez un grand nombre de systèmes. Vous pouvez soit cocher les cases à côté des noms de groupe (le cas échéant), soit entrer un nouveau nom dans le champ Nouveau groupe .
Commencer au démarrage de l'hôte?
Pour les systèmes virtuels utilisant Xen, VServers ou Zones, ce champ contrôle si le système est démarré au démarrage de la machine hôte.
Dernier statut
Ce champ affiche l'état du système, tel que déterminé par Cloudmin lors de la dernière vérification programmée ou manuelle. Consultez la page d'aide sur les descriptions d'état pour plus de détails.
Erreur d'état détaillée
Si l'état indique une erreur de communication avec le système, ce champ affichera plus de détails sur ce qui n'a pas fonctionné, par exemple pourquoi SSH a échoué ou pourquoi Webmin n'a pas pu être contacté.
Les autres champs dépendent du type de système virtuel, mais incluent généralement le système hôte, la mémoire utilisée et le nom de l'instance. Si vous modifiez le nom d'hôte, la description, les options d'authentification ou d'autres paramètres, cliquez sur le bouton Enregistrer pour les activer.
