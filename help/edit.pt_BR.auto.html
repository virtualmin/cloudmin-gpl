Sistema de Edição
Esta página exibe os detalhes de um sistema gerenciado existente e permite que algumas de suas configurações sejam alteradas. Os campos comuns que aparecem independentemente do tipo de sistema são:

Nome do host da Internet
Isso deve conter o nome do host ou o endereço IP do DNS resolvido. Pode ser alterado, mas apenas para um nome de host diferente que resolva para o mesmo endereço.
Descrição ou comentário
Este campo é para inserir sua própria descrição do sistema, como o servidor da web de Joe .
Sistema operacional
Nesse menu, você deve selecionar a distribuição do SO ou Linux que o sistema gerenciado executa. O Cloudmin usará isso ao instalar o Webmin ou outros pacotes para determinar o formato correto do pacote.
Grupos de sistemas
Esta seção pode ser usada para atribuir sistemas a um ou mais grupos, para facilitar a categorização quando você tiver um grande número de sistemas. Você pode marcar as caixas ao lado dos nomes dos grupos (se houver algum) ou inserir um novo nome no campo Novo grupo .
Iniciar no momento da inicialização do host?
Para sistemas virtuais usando Xen, VServers ou Zones, esse campo controla se o sistema é iniciado quando a máquina host é inicializada.
Último status
Este campo mostra o status do sistema, conforme determinado pelo Cloudmin na última verificação programada ou manual. Consulte a página de ajuda das descrições de status para obter mais detalhes.
Erro de status detalhado
Se o status indicar algum erro ao conversar com o sistema, esse campo mostrará mais detalhes sobre o que deu errado, como por que o SSH falhou ou por que o Webmin não pôde ser contatado.
Outros campos dependem do tipo de sistema virtual, mas geralmente incluem o sistema host, a memória usada e o nome da instância. Se você alterar o nome do host, a descrição, as opções de autenticação ou outras configurações, clique no botão Salvar para ativá-las.
