Authentication options
This section allows you to set the password and username that VM2 will use to login to this managed system via SSH and using Webmin. Note that changing these does not actually update the root or Webmin passwords on the system - instead, it just changes the credentials used by VM2.

If the new login details are incorrect, you will still be able to save them, but the status of the system will be updated to reflect the failure to login (such as SSH login failed or Webmin login failed).
