Authentication options
This section allows you to set the password and username that Cloudmin will use to login to this managed system via SSH and using Webmin. Note that changing these does not actually update the root or Webmin passwords on the system - instead, it just changes the credentials used by Cloudmin.

If the new login details are incorrect, you will still be able to save them, but the status of the system will be updated to reflect the failure to login (such as SSH login failed or Webmin login failed).

For systems that Cloudmin should not attempt to SSH into at all (perhaps because they are not fully under your control), select the Do not attempt SSH login option under SSH login mode. This will prevent Cloudmin from performing most system management tasks though.
