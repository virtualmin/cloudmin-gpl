Opções de autenticação
Esta seção permite que você defina a senha e o nome de usuário que o Cloudmin usará para efetuar login neste sistema gerenciado via SSH e usando o Webmin. Observe que alterar essas configurações não atualiza as senhas raiz ou Webmin no sistema - apenas altera as credenciais usadas pelo Cloudmin.

Se os novos detalhes de login estiverem incorretos, você ainda poderá salvá-los, mas o status do sistema será atualizado para refletir a falha no login (como falha no login SSH ou falha no login Webmin ).

Para sistemas nos quais o Cloudmin não deve tentar fazer o SSH (talvez porque eles não estejam totalmente sob seu controle), selecione a opção Não tentar o login do SSH no modo de login do SSH . Isso impedirá que o Cloudmin execute a maioria das tarefas de gerenciamento do sistema.
