Варианты аутентификации
Этот раздел позволяет вам установить пароль и имя пользователя, которые Cloudmin будет использовать для входа в эту управляемую систему через SSH и с помощью Webmin. Обратите внимание, что их изменение фактически не обновляет пароли root или Webmin в системе - вместо этого они просто изменяют учетные данные, используемые Cloudmin.

Если новые данные для входа неверны, вы все равно сможете их сохранить, но состояние системы будет обновлено, чтобы отразить сбой входа (например, сбой входа SSH или сбой входа Webmin ).

Для систем, в которые Cloudmin вообще не следует пытаться подключиться по SSH (возможно, из-за того, что они не находятся полностью под вашим контролем), выберите опцию Не пытаться войти по SSH в режиме входа по SSH . Это не позволит Cloudmin выполнять большинство задач управления системой.
