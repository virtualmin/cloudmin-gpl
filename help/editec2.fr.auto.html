Modifier le compte EC2
Cette page affiche les détails d'un compte EC2 déjà enregistré auprès de Cloudmin et vous permet de modifier la description et les détails d'authentification. Si la clé d'accès ou la clé secrète sont modifiées, Cloudmin vérifiera qu'elles sont valides lorsque le compte est enregistré.

Si un compte n'exécute aucune instance EC2 gérée par Cloudmin, vous pouvez le supprimer en cliquant sur le bouton Supprimer .
