Détails de l'image
Cette page affiche toutes les informations disponibles sur une image utilisée par Cloudmin pour créer de nouveaux systèmes virtuels. Si l'image a été téléchargée, vous pouvez utiliser le bouton Supprimer de ce système pour supprimer votre copie locale de celle-ci, afin de libérer de l'espace disque. Cela n'aura aucun effet sur les systèmes déjà créés à partir de l'image.
