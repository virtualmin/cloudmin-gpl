Edit SSH Key
This page allows you to change the details of an existing key registered with VM2. You should not do this unless you are sure that the new with will work on all systems that used the original key though, otherwise VM2 may be no longer able to manage them.

The key's human-readable description can be safely changed using the Key description field. To change the key itself, paste the new private key text into the Private key data field, and the corresponding public key (at seen in .ssh/authorized_keys files) into the Public key field.

Changing the public or private key text for an EC2-registered key is unlikely to work properly, as EC2 stores its own copy of your public key, which cannot be updated by VM2.
