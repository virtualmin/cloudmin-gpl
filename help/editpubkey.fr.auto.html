Modifier la clé publique SSH
Cette page vous permet de modifier les détails d'une clé publique SSH existante enregistrée auprès de Cloudmin. Les modifications apportées ici n'affecteront cependant pas les systèmes virtuels existants utilisant cette clé.

La description lisible par l'homme de la clé peut être modifiée en toute sécurité à l'aide du champ Description de la clé . Pour modifier la clé elle-même, collez le texte de la clé dans le champ Clé publique ou sélectionnez un autre emplacement de fichier de clés.
