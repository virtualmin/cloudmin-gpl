Detailed system status
This section shows more information about the health of a system, collected during the last regular or manual status update. If you login to Virtualmin on a system directly, you can see similar information in the right-hand frame. The status includes the CPU load, real and virtual memory used, disk space and the statuses of various servers configured by Virtualmin (Apache, Postfix, and so on). If the system has multiple IP addresses, a summary of their uses will also be displayed.

If this system has any package updates pending, they will also be shown in this section. Next to the list of updates will be a button for installing them all right now.
