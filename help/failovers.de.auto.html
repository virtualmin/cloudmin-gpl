Host-Failover-Gruppen
Eine Failover-Gruppe ist eine Sammlung von Hostsystemen, die Speicher für virtuelle Systeme gemeinsam nutzen und daher als Sicherungen für einander dienen können, wenn eines ausfällt. Auf diese Weise kann ein virtuelles System bei einem Hardwarefehler automatisch auf einem anderen Host mit denselben virtuellen Festplatten oder demselben Dateisystem neu gestartet werden.

Jede Failover-Gruppe ist für einen bestimmten Virtualisierungstyp (wie OpenVZ oder Xen) vorgesehen und muss mindestens zwei Hostsysteme enthalten, die diese Virtualisierungsmethode unterstützen. Damit Failover tatsächlich funktionieren, müssen alle virtuellen Systeme die Verzeichnisse mit ihren Dateisystemen oder Festplattenabbildern gemeinsam nutzen, entweder über NFS, Cluster LVM oder iSCSI.

Wenn eine Failover-Gruppe auf den automatischen Modus eingestellt ist, erkennt Cloudmin ausgefallene Hostsysteme und verschiebt virtuelle Systeme nach Möglichkeit auf neue Hosts in der Gruppe. Dies geschieht erst nach einer Ausfallzeit, die Sie pro Gruppe konfigurieren können.

Virtuelle Systeme können auch von einem ausgefallenen Host mit dem Element Failover erzwingen im linken Menü oder dem Befehl Failover-System- API zwangsweise ausgefallen sein.
