Grupos de conmutación por error del host
Un grupo de conmutación por error es una colección de sistemas host que comparten almacenamiento para sistemas virtuales y, por lo tanto, pueden actuar como copias de seguridad entre sí si uno falla. Esto permite que un sistema virtual se reinicie automáticamente en otro host con los mismos discos virtuales o sistema de archivos en caso de una falla de hardware.

Cada grupo de conmutación por error es para un tipo de virtualización específico (como OpenVZ o Xen) y debe contener al menos dos sistemas host que admitan ese método de virtualización. Para que los failovers realmente funcionen, todos los sistemas virtuales deben compartir los directorios que contienen sus sistemas de archivos o imágenes de disco, ya sea a través de NFS, Cluster LVM o iSCSI.

Cuando un grupo de conmutación por error se establece en modo automático, Cloudmin detectará los sistemas host que han fallado y moverá los sistemas virtuales fuera de ellos a nuevos hosts en el grupo, cuando sea posible. Esto solo sucederá después de un período de inactividad que puede configurar por grupo.

Los sistemas virtuales también se pueden forzar en un host inactivo utilizando el elemento Force Failover en el menú de la izquierda o el comando API del sistema de failover .
