Groupes de basculement d'hôte
Un groupe de basculement est un ensemble de systèmes hôtes qui partagent le stockage pour les systèmes virtuels et peuvent donc servir de sauvegardes les uns pour les autres en cas de panne. Cela permet de redémarrer automatiquement un système virtuel sur un autre hôte avec les mêmes disques virtuels ou système de fichiers en cas de panne matérielle.

Chaque groupe de basculement est pour un type de virtualisation spécifique (comme OpenVZ ou Xen) et doit contenir au moins deux systèmes hôtes qui prennent en charge cette méthode de virtualisation. Pour que les basculements fonctionnent réellement, tous les systèmes virtuels doivent partager les répertoires contenant leurs systèmes de fichiers ou leurs images de disque, via NFS, Cluster LVM ou iSCSI.

Lorsqu'un groupe de basculement est défini sur le mode automatique, Cloudmin détectera les systèmes hôtes qui ont échoué et les déplacera vers de nouveaux hôtes du groupe, si possible. Cela ne se produira qu'après une période d'indisponibilité que vous pouvez configurer par groupe.

Les systèmes virtuels peuvent également être forcés en cas de défaillance d'un hôte en panne à l'aide de l'élément Forcer le basculement dans le menu de gauche ou de la commande API de basculement du système .
