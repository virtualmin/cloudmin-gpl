Gruppi di failover host
Un gruppo di failover è una raccolta di sistemi host che condividono l'archiviazione per sistemi virtuali e pertanto possono fungere da backup l'uno per l'altro in caso di interruzione. Ciò consente di riavviare automaticamente un sistema virtuale su un altro host con gli stessi dischi o file system virtuali in caso di guasto hardware.

Ogni gruppo di failover è per un tipo di virtualizzazione specifico (come OpenVZ o Xen) e deve contenere almeno due sistemi host che supportano quel metodo di virtualizzazione. Perché i failover funzionino effettivamente, tutti i sistemi virtuali devono condividere le directory contenenti i loro filesystem o immagini del disco, tramite NFS, Cluster LVM o iSCSI.

Quando un gruppo di failover è impostato sulla modalità automatica, Cloudmin rileverà i sistemi host che hanno fallito e sposterà i sistemi virtuali da essi verso nuovi host nel gruppo, ove possibile. Ciò accadrà solo dopo un periodo di inattività che è possibile configurare in base al gruppo.

È inoltre possibile forzare il fallimento dei sistemi virtuali da un host inattivo utilizzando la voce Force Failover nel menu a sinistra o il comando API del sistema di failover .
