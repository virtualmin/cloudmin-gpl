Grupos de Failover de Host
Um grupo de failover é uma coleção de sistemas host que compartilham armazenamento para sistemas virtuais e, portanto, podem agir como backups um do outro se um deles for desativado. Isso permite que um sistema virtual seja reiniciado automaticamente em outro host com os mesmos discos ou sistema de arquivos virtuais no caso de uma falha de hardware.

Cada grupo de failover é para um tipo de virtualização específico (como OpenVZ ou Xen) e deve conter pelo menos dois sistemas host que suportam esse método de virtualização. Para que os failovers funcionem, todos os sistemas virtuais devem compartilhar os diretórios que contêm seus sistemas de arquivos ou imagens de disco, via NFS, Cluster LVM ou iSCSI.

Quando um grupo de failover é definido no modo automático, o Cloudmin detecta sistemas host que falharam e move os sistemas virtuais deles para novos hosts no grupo, sempre que possível. Isso só acontecerá após um período de inatividade que você pode configurar por grupo.

Os sistemas virtuais também podem ser executados com falha em um host inativo, usando o item Forçar Failover no menu à esquerda ou o comando API do sistema de failover .
