Standardfunktionen von Virtualmin
Auf dieser Seite können Sie steuern, welche Funktionen standardmäßig für neue Virtualmin-Domänen aktiviert sind, die über Cloudmin erstellt wurden. Außerdem wird angezeigt, welche Hostsysteme welche Funktionen unterstützen, sodass Sie sicher sein können, dass nur allgemein verfügbare Funktionen aktiviert sind.

Um Standardfunktionen auszuwählen, wählen Sie die Option Ausgewählt unten und aktivieren Sie die Kontrollkästchen neben den Funktionen, die neue Domänen verwenden sollen. Die Anmeldefunktionen Home-Verzeichnis , Administrationsbenutzer und Webmin sollten immer ausgewählt werden, da sie Voraussetzungen für das Web- oder E-Mail-Hosting sind.
