Características predeterminadas de Virtualmin
Esta página le permite controlar qué funciones están habilitadas de forma predeterminada para los nuevos dominios de Virtualmin creados a través de Cloudmin. También muestra qué sistemas host admiten qué características, para que pueda estar seguro de que solo se habilitan las funciones ampliamente disponibles.

Para seleccionar las funciones predeterminadas, elija la opción Seleccionada a continuación y luego marque las casillas junto a las funciones que desea que usen los nuevos dominios. El directorio de inicio , el usuario de administración y las características de inicio de sesión de Webmin siempre deben seleccionarse, ya que son requisitos previos para el alojamiento web o de correo.
