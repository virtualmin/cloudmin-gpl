Fonctionnalités Virtualmin par défaut
Cette page vous permet de contrôler les fonctionnalités activées par défaut pour les nouveaux domaines Virtualmin créés via Cloudmin. Il affiche également quels systèmes hôtes prennent en charge quelles fonctionnalités, de sorte que vous pouvez être sûr que seules les fonctionnalités largement disponibles sont activées.

Pour sélectionner les fonctionnalités par défaut, choisissez l'option Sélectionné ci-dessous , puis cochez les cases en regard des fonctionnalités que vous souhaitez que les nouveaux domaines utilisent. Le répertoire de base , l' utilisateur d'administration et les fonctionnalités de connexion à Webmin doivent toujours être sélectionnés, car ils sont pré-requis pour l'hébergement Web ou de messagerie.
