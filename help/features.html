Default Virtualmin Features
This page allows you to control which features are enabled by default for new Virtualmin domains created through Cloudmin. It also displays which host systems support which features, so that you can be sure that only widely available features are enabled.

To select default features, choose the Selected below option and then check the boxes next to the features you want new domains to use. The Home directory, Administration user and Webmin login features should always be selected, as they are pre-requistes for web or mail hosting.
