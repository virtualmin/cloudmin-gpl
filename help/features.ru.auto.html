Возможности Virtualmin по умолчанию
Эта страница позволяет вам контролировать, какие функции включены по умолчанию для новых доменов Virtualmin, созданных через Cloudmin. Он также отображает, какие хост-системы поддерживают какие функции, так что вы можете быть уверены, что включены только широко доступные функции.

Чтобы выбрать функции по умолчанию, выберите параметр «Выбрано ниже» и установите флажки рядом с функциями, которые вы хотите использовать в новых доменах. Домашний каталог , администратор и функции входа в систему Webmin всегда должны быть выбраны, так как они являются предварительными условиями для веб-хостинга или почтового хостинга.
