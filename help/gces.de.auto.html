GCE-Projekte
GCE (Google Compute Engine) ist ein Dienst von Google zum Erstellen virtueller Systeme, die in ihrem Netzwerk ausgeführt werden und für die Benutzer pro Maschinenstunde berechnet werden. Cloudmin kann zum Erstellen und Verwalten von GCE-Instanzen verwendet werden, genau wie für virtuelle Systeme, die auf Ihrer eigenen Hardware ausgeführt werden. Bevor Sie GCE verwenden können, müssen Sie sich jedoch zunächst unter https://cloud.google.com/products/compute-engine/ für ein Konto registrieren.

Wenn Sie ein GCE-Konto und mindestens ein Projekt erstellt haben, registrieren Sie es auf dieser Seite, indem Sie auf den Link GCE-Projekt hinzufügen klicken. Um ein vorhandenes Projekt zu verwalten, klicken Sie auf die Beschreibung in der Liste. Um Projekte zu entfernen, aktivieren Sie die Kontrollkästchen daneben und klicken Sie auf die Schaltfläche Ausgewählte Projekte löschen. Sie können jedoch keine Projekte entfernen, die von virtuellen Systemen verwendet werden.
