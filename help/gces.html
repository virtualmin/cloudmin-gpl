GCE Projects
GCE (Google Compute Engine) is a service run by Google for creating virtual systems that run on their network, for which users are charged by the machine-hour. Cloudmin can be used to create and manage GCE instances, just like it can for virtual sytems that run on your own hardware. However, before you can use GCE you must first register for an account at https://cloud.google.com/products/compute-engine/.

Once you've created a GCE account and at least one project, register it on this page by clicking on the Add a GCE project link. To manage an existing project, click on its description in the list. To remove projects, select the checkboxes next to them and click the Delete Selected Projects button. You will not be able to remove projects that are in use by any virtual systems though.
