Projetos GCE
O GCE (Google Compute Engine) é um serviço executado pelo Google para criar sistemas virtuais executados em sua rede, pelos quais os usuários são cobrados por hora de máquina. O Cloudmin pode ser usado para criar e gerenciar instâncias de GCE, assim como para sistemas virtuais executados em seu próprio hardware. No entanto, antes de poder usar o GCE, você deve primeiro se registrar para uma conta em https://cloud.google.com/products/compute-engine/ .

Depois de criar uma conta GCE e pelo menos um projeto, registre-a nesta página clicando no link Adicionar um projeto GCE . Para gerenciar um projeto existente, clique em sua descrição na lista. Para remover projetos, marque as caixas de seleção próximas a eles e clique no botão Excluir projetos selecionados. Você não poderá remover projetos que estão em uso por nenhum sistema virtual.
