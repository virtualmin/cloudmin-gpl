Add Public Key

Select the guest account above, then choose a saved key or paste public keys, one per line. Pasted keys must not include authorized_keys options. Click Add Public Key to add them. Pasted keys are added to this account without creating library entries.

Keys that match a library entry use that entry's name. Other keys show their comment, or their key type if there is no comment. Click a fingerprint to see the full key, including its original comment.

The virtual machine must be running, and its guest agent must support SSH key commands.

Existing keys and open sessions stay unchanged. Adding a key does not enable SSH key login if it is disabled for the account or SSH server.
