Netzwerkschnittstelle hinzufügen
Diese Seite dient zum Hinzufügen einer neuen Netzwerkschnittstelle zu einem virtuellen System oder zum Ändern der Einstellungen für eine vorhandene Schnittstelle. Beim Hinzufügen müssen Sie die folgenden Felder ausfüllen:

Host-Systemschnittstelle
Die Schnittstelle auf dem übergeordneten Hostsystem, unter der diese neue virtuelle Schnittstelle erstellt wird. Normalerweise möchten Sie bei der primären Ethernet-Verbindung wie eth0 oder bge0 .
IP Adresse
Wenn Automatisch zuweisen ausgewählt ist, wählt Cloudmin eine freie IP-Adresse aus dem für das Hostsystem definierten Bereich aus. Andernfalls können Sie eine IP Ihrer Wahl eingeben - stellen Sie nur sicher, dass sie keinem anderen System zugewiesen ist.
Netzmaske
Kann im Allgemeinen unverändert bleiben, es sei denn, Sie müssen eine Maske verwenden, die sich von der der primären Netzwerkschnittstelle des Hostsystems unterscheidet.
