Agregar interfaz de red
Esta página es para agregar una nueva interfaz de red a un sistema virtual o para cambiar la configuración de una interfaz existente. Al agregar, debe completar los siguientes campos:

Interfaz del sistema host
La interfaz en el sistema host principal bajo el cual se creará esta nueva interfaz virtual. Por lo general, querrá seguir con la conexión primaria de Ethernet, como eth0 o bge0 .
dirección IP
Si se selecciona Asignar automáticamente , Cloudmin seleccionará una dirección IP libre del rango definido para el sistema host. De lo contrario, puede ingresar una IP de su elección, solo asegúrese de que no esté asignada a ningún otro sistema.
Máscara de red
Por lo general, no se puede cambiar, a menos que necesite usar una máscara diferente de la de la interfaz de red principal del sistema host.
