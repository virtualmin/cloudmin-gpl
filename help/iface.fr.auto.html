Ajouter une interface réseau
Cette page sert à ajouter une nouvelle interface réseau à un système virtuel ou à modifier les paramètres d'une interface existante. Lors de l'ajout, vous devez remplir les champs suivants:

Interface du système hôte
L'interface sur le système hôte parent sous laquelle cette nouvelle interface virtuelle sera créée. En règle générale, vous souhaiterez vous en tenir à la connexion Ethernet principale, comme eth0 ou bge0 .
adresse IP
Si Allouer automatiquement est sélectionné, Cloudmin sélectionnera une adresse IP libre dans la plage définie pour le système hôte. Sinon, vous pouvez entrer une adresse IP de votre choix - assurez-vous simplement qu'elle n'est attribuée à aucun autre système.
Masque de réseau
Peut généralement rester inchangé, sauf si vous devez utiliser un masque différent de celui de l'interface réseau principale du système hôte.
