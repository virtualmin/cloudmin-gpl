Add Network Interface
This page is for adding a new network interface to a virtual system, or for changing the settings for an existing interface. When adding, you must complete the following fields :

Host system interface
The interface on the parent host system that this new virtual interface will be created under. Typically you will want to stick with the primary ethernet connection, like eth0 or bge0.
IP address
If Allocate automatically is selected, Cloudmin will select a free IP address from the range defined for the host system. Otherwise, you can enter an IP of your choice - just make sure that it is not allocated to any other system.
Netmask
Can generally be left un-changed, unless you need to use a mask different from that of the host system's primary network interface.
