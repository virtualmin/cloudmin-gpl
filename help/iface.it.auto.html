Aggiungi interfaccia di rete
Questa pagina serve per aggiungere una nuova interfaccia di rete a un sistema virtuale o per modificare le impostazioni di un'interfaccia esistente. Quando si aggiunge, è necessario completare i seguenti campi:

Interfaccia del sistema host
L'interfaccia sul sistema host principale in cui verrà creata questa nuova interfaccia virtuale. In genere si desidera utilizzare la connessione Ethernet primaria, come eth0 o bge0 .
indirizzo IP
Se Allocate viene selezionato automaticamente , Cloudmin selezionerà un indirizzo IP gratuito dall'intervallo definito per il sistema host. Altrimenti, puoi inserire un IP di tua scelta - assicurati solo che non sia assegnato a nessun altro sistema.
maschera di rete
In genere può essere lasciato invariato, a meno che non sia necessario utilizzare una maschera diversa da quella dell'interfaccia di rete principale del sistema host.
