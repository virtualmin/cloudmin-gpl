Adicionar interface de rede
Esta página é para adicionar uma nova interface de rede a um sistema virtual ou para alterar as configurações de uma interface existente. Ao adicionar, você deve preencher os seguintes campos:

Interface do sistema host
A interface no sistema host pai no qual essa nova interface virtual será criada. Normalmente, você desejará manter a conexão Ethernet principal, como eth0 ou bge0 .
endereço de IP
Se Alocar automaticamente for selecionado, o Cloudmin selecionará um endereço IP gratuito do intervalo definido para o sistema host. Caso contrário, você pode inserir um IP de sua escolha - apenas verifique se ele não está alocado para nenhum outro sistema.
Máscara de rede
Geralmente, pode ser deixado sem alterações, a menos que você precise usar uma máscara diferente da da interface de rede principal do sistema host.
