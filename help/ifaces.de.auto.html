Netzwerk Schnittstellen
Auf dieser Seite können Sie Netzwerkschnittstellen auf virtuellen Systemen erstellen und verwalten. Während einige Systemtypen (wie Xen und KVM) neue Schnittstellen auf dem System selbst erstellen können, wird dies nicht empfohlen, da sie möglicherweise durch die von Cloudmin eingerichtete IP-Spoofing-Firewall blockiert werden. Daher wird empfohlen, diese Seite für die gesamte Netzwerkschnittstellenverwaltung zu verwenden.

Die Liste auf dieser Seite zeigt alle Netzwerkschnittstellen an, die derzeit auf dem virtuellen System aktiv sind, und zeigt jeweils an, welche Virtualmin-Domänen sie gegebenenfalls verwenden. Unter der Liste befindet sich ein Formular zum Ändern des Standard-Gateways für das System für Typen, bei denen dies unabhängig vom Host verwaltet werden kann.

Um eine neue Schnittstelle aufzurufen, klicken Sie über oder unter der Tabelle auf den Link Neue Schnittstelle hinzufügen. Um die Adresse einer vorhandenen Schnittstelle zu ändern oder zu löschen, klicken Sie einfach auf deren IP-Adresse.
