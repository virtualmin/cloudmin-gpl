Interfaces de red
Esta página le permite crear y administrar interfaces de red en sistemas virtuales. Si bien algunos tipos de sistemas (como Xen y KVM) pueden crear nuevas interfaces en el propio sistema, esto no se recomienda, ya que pueden estar bloqueados por el firewall de falsificación de IP que configura Cloudmin. Por lo tanto, se recomienda utilizar esta página para toda la administración de la interfaz de red.

La lista en esta página muestra todas las interfaces de red actualmente activas en el sistema virtual, y para cada muestra qué dominios de Virtualmin las están utilizando, si corresponde. Debajo de la lista hay un formulario para cambiar la puerta de enlace predeterminada para el sistema, para los tipos en los que esto se puede administrar independientemente del host.

Para abrir una nueva interfaz, haga clic en el enlace Agregar una nueva interfaz arriba o debajo de la tabla. Para cambiar la dirección o eliminar una interfaz existente, simplemente haga clic en su dirección IP.
