Interfaces réseau
Cette page vous permet de créer et de gérer des interfaces réseau sur des systèmes virtuels. Bien que certains types de systèmes (tels que Xen et KVM) puissent créer de nouvelles interfaces sur le système lui-même, cela n'est pas recommandé car ils peuvent être bloqués par le pare-feu d'usurpation d'adresse IP configuré par Cloudmin. Il est donc recommandé d'utiliser cette page pour toute la gestion des interfaces réseau.

La liste de cette page affiche toutes les interfaces réseau actuellement actives sur le système virtuel et indique pour chacune les domaines Virtualmin qui les utilisent, le cas échéant. Sous la liste se trouve un formulaire pour changer la passerelle par défaut du système, pour les types où cela peut être géré indépendamment de l'hôte.

Pour afficher une nouvelle interface, cliquez sur le lien Ajouter une nouvelle interface au -dessus ou en dessous du tableau. Pour modifier l'adresse ou supprimer une interface existante, cliquez simplement sur son adresse IP.
