Network Interfaces
This page allows you to create and manage network interfaces on virtual systems. While some system types (such as Xen and KVM) can create new interfaces on the system itself, this is not recommended as they may be blocked by the IP spoofing firewall Cloudmin sets up. Hence it is recommended to use this page for all network interface management.

The list on this page displays all network interfaces currently active on the virtual system, and for each shows which Virtualmin domains are using them, if appropriate. Below the list is a form for changing the default gateway for the system, for types where this can be managed independently of the host.

To bring up a new interface, click on the Add a new interface link above or below the table. To change the address of or delete an existing interface, just click on its IP address.
