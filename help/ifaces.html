Network Interfaces
On VServers and Zones systems, Cloudmin can manage network interfaces as systems of these types are not able to bring up or configure their own interfaces directly - unlike real systems or those running under Xen. This section displays all network interfaces currently active on the virtual system, and for each shows which Virtualmin domains are using it.

To bring up a new interface, click on the Add a new interface link above or below the table. To change the address of or delete an existing interface, just click on its IP address.
