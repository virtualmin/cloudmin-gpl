Interfacce di rete
Questa pagina consente di creare e gestire interfacce di rete su sistemi virtuali. Mentre alcuni tipi di sistema (come Xen e KVM) possono creare nuove interfacce sul sistema stesso, ciò non è raccomandato in quanto potrebbero essere bloccati dal firewall di spoofing IP impostato da Cloudmin. Pertanto si consiglia di utilizzare questa pagina per tutta la gestione dell'interfaccia di rete.

L'elenco in questa pagina mostra tutte le interfacce di rete attualmente attive sul sistema virtuale e per ciascuna mostra quali domini Virtualmin le stanno usando, se appropriato. Sotto l'elenco è presente un modulo per modificare il gateway predefinito per il sistema, per i tipi in cui questo può essere gestito indipendentemente dall'host.

Per visualizzare una nuova interfaccia, fai clic sul link Aggiungi una nuova interfaccia sopra o sotto la tabella. Per modificare l'indirizzo o eliminare un'interfaccia esistente, basta fare clic sul suo indirizzo IP.
