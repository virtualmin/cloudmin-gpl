Interfaces de rede
Esta página permite criar e gerenciar interfaces de rede em sistemas virtuais. Embora alguns tipos de sistema (como Xen e KVM) possam criar novas interfaces no próprio sistema, isso não é recomendado, pois podem ser bloqueados pelo firewall de falsificação de IP que o Cloudmin configura. Portanto, é recomendável usar esta página para todo o gerenciamento de interface de rede.

A lista nesta página exibe todas as interfaces de rede atualmente ativas no sistema virtual e, para cada uma, mostra quais domínios do Virtualmin os estão usando, se apropriado. Abaixo da lista, há um formulário para alterar o gateway padrão do sistema, para tipos em que isso pode ser gerenciado independentemente do host.

Para abrir uma nova interface, clique no link Adicionar uma nova interface acima ou abaixo da tabela. Para alterar o endereço ou excluir uma interface existente, basta clicar no seu endereço IP.
