Сетевые интерфейсы
Эта страница позволяет создавать и управлять сетевыми интерфейсами в виртуальных системах. Хотя некоторые типы систем (например, Xen и KVM) могут создавать новые интерфейсы в самой системе, это не рекомендуется, поскольку они могут быть заблокированы брандмауэром IP-спуфинга, установленным Cloudmin. Следовательно, рекомендуется использовать эту страницу для управления всеми сетевыми интерфейсами.

Список на этой странице отображает все сетевые интерфейсы, которые в настоящее время активны в виртуальной системе, и для каждого показывает, какие домены Virtualmin используют их, если это необходимо. Ниже списка находится форма для изменения шлюза по умолчанию для системы, для типов, где этим можно управлять независимо от хоста.

Чтобы открыть новый интерфейс, нажмите ссылку Добавить новый интерфейс над или под таблицей. Чтобы изменить адрес или удалить существующий интерфейс, просто нажмите на его IP-адрес.
