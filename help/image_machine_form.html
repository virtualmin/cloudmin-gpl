Create Image

Capture a Linux system disk as a reusable QCOW2 image, including its software and data. New machines created from it receive a fresh identity. This is not a full-machine backup.

The source needs cloud-init and one virtio system disk. Remove additional disks and installation media first. New machines need at least the source disk's full capacity.

Login passwords, home-directory SSH credentials and standard shell histories are removed by default. Application secrets and credentials in custom locations remain, so review the image before sharing it. Supported software licenses are reset in the copy; each new machine needs its own license where required.
