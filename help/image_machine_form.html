Create Image

Create a reusable QCOW2 image from one Linux system disk. The image appears in Image Manager and in the Create Virtual Machine form. It contains the installed software and data. It is not a full-machine backup.

New virtual machines need disks at least as large as the source disk's capacity. Capturing an image does not shrink the disk.

The source must use a virtio system disk and have working cloud-init. Additional writable disks are rejected. Detach installation media and read-only data disks first; Cloudmin's own seed disk is omitted automatically.

Each virtual machine created from the image receives a fresh identity. Login credential removal is enabled by default. It removes Linux login password hashes, home-directory SSH credentials and standard shell histories for all local accounts. When disabled, these remain in the image. Credentials and histories in custom locations need separate review.

Copied license credentials for supported software are reset locally, without contacting license servers. Each new virtual machine needs appropriate licenses for its installed software.

Accounts, application data, certificates and other secrets remain in the image. Keep it private and review its contents before sharing it. New virtual machines use fresh firmware variables; custom UEFI settings are not copied.
