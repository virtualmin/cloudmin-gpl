Neue Systemabbilder
Ein Cloudmin-Systemabbild ist eine Datei, die alle Daten enthält, die zum Erstellen eines neuen virtuellen Systems erforderlich sind. In der Regel handelt es sich um eine TAR-Datei oder einen Dateisystem-Dump des gesamten virtuellen Betriebssystems, einschließlich aller Systembefehle, Server wie Apache und Postfix, Datendateien und Konfigurationsdateien. Wenn ein virtuelles System erstellt wird, kann ein Image verwendet werden, um das ursprüngliche Dateisystem für das virtuelle Betriebssystem zu füllen.

Für Xen-Instanzen muss zum Zeitpunkt der Erstellung ein Bild ausgewählt werden. Für VServer und Solaris-Zonen haben Sie die Möglichkeit, ein Image (empfohlen) zu verwenden oder die Software vom Hostsystem in das neue virtuelle System zu kopieren. Ein Image ist normalerweise schneller, da es lediglich aus einer TAR-Datei extrahiert werden muss, anstatt Pakete in das neue virtuelle Systemverzeichnis zu installieren oder zu kopieren.

Ein Cloudmin-Abonnement beinhaltet den Zugriff auf eine Reihe vorab erstellter Systemabbilder für Xen-, VServer- und Solaris-Zonen. Bevor Bilder verwendet werden können, müssen sie jedoch zuerst vom Cloudmin-Webserver auf Ihr Mastersystem heruntergeladen werden. Da Bilddateien normalerweise Hunderte von MB groß sind, sollten Sie nur die Dateien herunterladen, die Sie benötigen.

Um Bilder herunterzuladen, die als Nicht heruntergeladen oder neuere Version gekennzeichnet sind , aktivieren Sie die Kontrollkästchen daneben und klicken Sie auf die Schaltfläche Ausgewählte Bilder herunterladen . Abhängig von der Geschwindigkeit Ihrer Netzwerkverbindung kann der Download Minuten oder Stunden dauern.
