Nuevas imágenes del sistema
Una imagen del sistema Cloudmin es un archivo que contiene todos los datos necesarios para crear un nuevo sistema virtual. Por lo general, es un archivo TAR o un volcado del sistema de archivos de todo el sistema operativo virtual, incluidos todos los comandos del sistema, servidores como Apache y Postfix, archivos de datos y archivos de configuración. Cuando se crea un sistema virtual, se puede usar una imagen para llenar el sistema de archivos inicial para el SO virtual.

Para las instancias de Xen, se debe seleccionar una imagen en el momento de la creación. Para las zonas VServers y Solaris, tiene la opción de usar una imagen (recomendado) o copiar el software del sistema host al nuevo sistema virtual. Una imagen suele ser más rápida, ya que simplemente necesita extraerse de un archivo TAR, en lugar de instalar o copiar paquetes en el nuevo directorio del sistema virtual.

Una suscripción a Cloudmin incluye el acceso a una serie de imágenes del sistema creadas previamente para las zonas Xen, VServers y Solaris. Sin embargo, antes de poder usar las imágenes, primero deben descargarse a su sistema maestro desde el servidor web de Cloudmin. Debido a que los archivos de imagen suelen tener un tamaño de cientos de MB, solo debe descargar los que necesita.

Para descargar imágenes que están marcadas como No descarga o Existe una versión más nueva , marque las casillas junto a ellas y haga clic en el botón Descargar imágenes seleccionadas . Dependiendo de la velocidad de su conexión de red, la descarga puede llevar minutos u horas.
