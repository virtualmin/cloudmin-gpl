Image Manager

Import an operating-system image for reuse when creating virtual machines. Catalogue images are downloaded from their publishers and checked against the supplied checksum.

Custom imports accept standalone QCOW2 or raw disks and installer ISOs, from an HTTPS URL, browser upload or host file. Select the correct format and supply a checksum when available. Checksums detect corruption; Cloudmin does not verify digital signatures. Use sources you trust.

Choose an active directory, filesystem or NFS pool and allow space for both the image and temporary copies. Host-file imports need readable files and parent directories; use browser upload for private files.

Imports run in the background. After a failure, correct the cause and retry once cleanup finishes. Disabling a catalogue entry leaves downloaded images intact. Deleting an imported image removes its stored copy only when nothing uses it.
