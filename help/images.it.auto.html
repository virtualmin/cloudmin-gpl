Nuove immagini di sistema
Un'immagine di sistema Cloudmin è un file contenente tutti i dati necessari per creare un nuovo sistema virtuale. In genere si tratta di un dump di file TAR o file system dell'intero sistema operativo virtuale, inclusi tutti i comandi di sistema, server come Apache e Postfix, file di dati e file di configurazione. Quando viene creato un sistema virtuale, è possibile utilizzare un'immagine per popolare il filesystem iniziale per il sistema operativo virtuale.

Per le istanze di Xen, un'immagine deve essere selezionata al momento della creazione. Per VServers e Solaris Zones, è possibile utilizzare un'immagine (scelta consigliata) o copiare il software dal sistema host nel nuovo sistema virtuale. Un'immagine è in genere più veloce, poiché deve semplicemente essere estratta da un file TAR, anziché installare o copiare i pacchetti nella nuova directory del sistema virtuale.

Un abbonamento Cloudmin include l'accesso a una serie di immagini di sistema pre-create per Xen, VServers e Solaris Zones. Tuttavia, prima di poter utilizzare le immagini, queste devono essere scaricate sul sistema principale dal server Web Cloudmin. Poiché i file di immagine hanno in genere dimensioni di centinaia di MB, è necessario scaricare solo quelli necessari.

Per scaricare immagini contrassegnate come Non scaricare o Esiste una versione più recente , selezionare le caselle accanto ad esse e fare clic sul pulsante Scarica immagini selezionate . A seconda della velocità della connessione di rete, il download potrebbe richiedere minuti o ore.
