Novas imagens do sistema
Uma imagem do sistema Cloudmin é um arquivo que contém todos os dados necessários para criar um novo sistema virtual. Normalmente, é um arquivo TAR ou despejo de sistema de arquivos de todo o sistema operacional virtual, incluindo todos os comandos do sistema, servidores como Apache e Postfix, arquivos de dados e arquivos de configuração. Quando um sistema virtual é criado, uma imagem pode ser usada para preencher o sistema de arquivos inicial para o SO virtual.

Para instâncias do Xen, uma imagem deve ser selecionada no momento da criação. Para VServers e Solaris Zones, você tem a opção de usar uma imagem (recomendada) ou copiar o software do sistema host para o novo sistema virtual. Uma imagem geralmente é mais rápida, pois simplesmente precisa ser extraída de um arquivo TAR, em vez de instalar ou copiar pacotes no novo diretório do sistema virtual.

Uma assinatura do Cloudmin inclui acesso a várias imagens de sistema pré-criadas para Xen, VServers e Solaris Zones. No entanto, antes que as imagens possam ser usadas, elas devem primeiro ser baixadas para o seu sistema mestre a partir do servidor Cloudmin. Como os arquivos de imagem geralmente têm centenas de MB, você deve baixar apenas os necessários.

Para baixar imagens marcadas como Não baixar ou Existe uma versão mais recente , marque as caixas próximas a elas e clique no botão Baixar imagens selecionadas. Dependendo da velocidade da sua conexão de rede, o download pode levar minutos ou horas.
