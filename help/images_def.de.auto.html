Speichern Sie Bilder für gehostete Systeme in
Standardmäßig speichert Cloudmin jedes Mal, wenn ein System abgebildet wird, die resultierenden Bilddateien auf dem Mastersystem. Dies ist jedoch möglicherweise nicht ideal, wenn der Master weit von Ihren Hostsystemen entfernt ist. In diesem Fall ist die Übertragung der Image-Datei zum Master langsam.

In diesem Feld können Sie einen alternativen Speicherort für Bilder auswählen, die auf diesem Hostsystem erstellt wurden. Dies kann entweder ein anderes Verzeichnis auf dem Cloudmin-Master, ein Verzeichnis auf dem Host oder ein Pfad auf einem völlig anderen System sein. In allen Fällen können Bilder auf jedem Hostsystem verwendet werden.
