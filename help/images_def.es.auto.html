Almacenar imágenes para sistemas alojados en
Por defecto, cada vez que se crea una imagen de un sistema, Cloudmin almacenará los archivos de imagen resultantes en el sistema maestro. Sin embargo, esto puede no ser ideal si el maestro está muy lejos de sus sistemas host, en cuyo caso la transferencia del archivo de imagen al maestro será lenta.

Este campo le permite seleccionar una ubicación de almacenamiento alternativa para las imágenes creadas en este sistema host. Puede ser otro directorio en el maestro de Cloudmin, un directorio en el host o una ruta en un sistema completamente diferente. En todos los casos, las imágenes serán utilizables en cualquier sistema host.
