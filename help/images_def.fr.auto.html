Stocker des images pour les systèmes hébergés dans
Par défaut, chaque fois qu'un système est imagé, Cloudmin stockera les fichiers d'images résultants sur le système maître. Cependant, cela peut ne pas être idéal si le maître est loin de vos systèmes hôtes, auquel cas le transfert du fichier image vers le maître sera lent.

Ce champ vous permet de sélectionner un autre emplacement de stockage pour les images créées sur ce système hôte. Il peut s'agir d'un autre répertoire sur le maître Cloudmin, d'un répertoire sur l'hôte ou d'un chemin sur un système complètement différent. Dans tous les cas, les images seront utilisables sur tout système hôte.
