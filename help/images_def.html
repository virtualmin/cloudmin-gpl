Store images for hosted systems in
By default, whenever a system is imaged Cloudmin will store the resulting image files on the master system. However, this may not be ideal if the master is a long way from your host systems, in which case transferred the image file to the master will be slow.

This field lets you select an alternate storage location for images created on this host system. It can either be another directory on the Cloudmin master, a directory on the host, or a path on a completely different system. In all cases, images will be usable on any host system.
