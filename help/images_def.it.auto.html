Archivia le immagini per i sistemi ospitati in
Per impostazione predefinita, ogni volta che un sistema viene ripreso, Cloudmin memorizzerà i file di immagine risultanti sul sistema principale. Tuttavia, questo potrebbe non essere l'ideale se il master è molto lontano dai sistemi host, nel qual caso il trasferimento del file di immagine sul master sarà lento.

Questo campo consente di selezionare un percorso di archiviazione alternativo per le immagini create su questo sistema host. Può essere un'altra directory sul master Cloudmin, una directory sull'host o un percorso su un sistema completamente diverso. In tutti i casi, le immagini saranno utilizzabili su qualsiasi sistema host.
