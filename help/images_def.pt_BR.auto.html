Armazene imagens para sistemas hospedados em
Por padrão, sempre que um sistema é criado, o Cloudmin armazenará os arquivos de imagem resultantes no sistema mestre. No entanto, isso pode não ser o ideal se o mestre estiver longe dos sistemas host, nesse caso, a transferência do arquivo de imagem para o mestre será lenta.

Este campo permite selecionar um local de armazenamento alternativo para as imagens criadas neste sistema host. Pode ser outro diretório no Cloudmin master, um diretório no host ou um caminho em um sistema completamente diferente. Em todos os casos, as imagens serão utilizáveis em qualquer sistema host.
