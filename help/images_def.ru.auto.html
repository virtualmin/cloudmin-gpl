Хранить образы для размещенных систем в
По умолчанию каждый раз, когда создается образ системы, Cloudmin будет сохранять полученные файлы изображений в основной системе. Однако это может не быть идеальным, если мастер находится далеко от хост-систем, и в этом случае передача файла образа на мастер будет медленной.

Это поле позволяет выбрать альтернативное место хранения для изображений, созданных в этой хост-системе. Это может быть другой каталог на главном сервере Cloudmin, каталог на хосте или путь в совершенно другой системе. Во всех случаях образы можно будет использовать на любой хост-системе.
