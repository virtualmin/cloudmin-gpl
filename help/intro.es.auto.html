Cloudmin
Cloudmin proporciona una forma de administrar múltiples sistemas desde una única interfaz. Estos pueden ser máquinas reales o sistemas virtuales que se ejecutan bajo una tecnología de virtualización como Xen, VServers o Zonas Solaris. Por lo general, los sistemas administrados ejecutarán Virtualmin y todos los servidores asociados, como Apache, Postfix y MySQL.

La página principal de Cloudmin muestra una lista de sistemas registrados en la parte superior e iconos para varias configuraciones globales en la parte inferior. Puede editar los detalles de un solo sistema haciendo clic en él o realizar operaciones como reiniciar, eliminar y actualizar varios sistemas a la vez seleccionándolos y haciendo clic en el botón apropiado debajo de la lista.

Para cada sistema, se muestra el estado determinado por la última actualización automática o manual. Los sistemas pueden estar en varios estados, como Down para uno que está apagado, No Webmin para una instalación simple y Webmin y Virtualmin para uno con la pila Virtualmin completa. Se muestra una lista completa de posibles códigos de estado en la página de ayuda de descripciones de estado . Debido a que el estado solo se actualiza automáticamente una vez cada 5 minutos, el estado puede no ser exacto para los sistemas que se han iniciado o apagado fuera de Cloudmin.

Para agregar un nuevo sistema a la lista, use los enlaces debajo de las categorías Crear sistema o Agregar sistema en el menú de la izquierda. La creación es para construir sistemas virtuales como instancias de Xen, mientras que la adición es para poner los sistemas reales o virtuales existentes bajo el control de Cloudmin. Sin embargo, no puede crear sistemas virtuales hasta que se haya agregado al menos un sistema de alojamiento para ese tipo virtual, como en la página Xen Host Systems .

Los iconos debajo de la lista del sistema enlazan a una variedad de páginas para configuraciones que no son específicas de ningún sistema administrado. Si desea usar Cloudmin para crear instancias de Xen, VServer o Solaris Zone, primero debe agregarlas haciendo clic en el ícono de Host Systems apropiado. Del mismo modo, para crear sistemas EC2, primero debe agregar al menos una cuenta en la página Cuentas EC2 .
