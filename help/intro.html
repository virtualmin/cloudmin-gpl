Host Overview

Cloudmin manages virtual machines through libvirt. The first supported hypervisor is QEMU/KVM. The dashboard checks the local host and lists the virtual machines already defined in libvirt.

Host Readiness checks IPv4 forwarding and firewall rules for active local libvirt NAT and routed networks. Missing rules remain visible even when healthy host details are hidden. These checks do not test guest DNS or Internet access.

Restore network rules restarts the libvirt network service, enables IPv4 forwarding if needed and checks the rules again. Virtual machines keep running. Recovery requires host administrator access. Finish any virtual machine operations and pending bridge changes before using it. Recovery restores the active rules; another firewall reload can remove them again.

The virtual machine table shows IP addresses reported by the guest agent, libvirt DHCP leases, or the host's ARP table. Not reported means no address is available, including when a virtual machine is stopped. A reported address does not confirm that SSH or other services are ready.

Use Start, Shut down and Reboot in the table to control a virtual machine. Shutdown and reboot ask the guest operating system to stop cleanly and may take a little time. The state updates automatically while the page is visible.

Start at boot shows whether a virtual machine starts automatically when the host boots. Use the toggle to change it. A persistent virtual machine keeps its saved configuration, but only starts automatically when this separate setting is enabled.

Hosts and Virtual Machines jump to their sections on this page. Active Jobs opens a list of image imports and virtual machine operations in progress or needing recovery. Click a virtual machine job's name to view its progress. Available controls appear beside each job. During software setup, Cancel job stops setup and keeps the virtual machine. Cancel and clean up requests cancellation of an unfinished creation and removal of its guest and storage. Cleanup runs in the background. Changed disks, snapshots or another operation can block it. If cleanup fails, resolve the reported problem and use Retry recovery.

Host Action Log opens Webmin's action log for this module. Guest Action Log filters it by the selected virtual machine's name. These links require access to Webmin's log module. Opening an SSH terminal or graphical console does not add an action-log entry.

The module does not install or configure host packages while a page is loading. Use the Cloudmin installer and Cloudmin-Config to prepare the host, then return to this page to verify it.
