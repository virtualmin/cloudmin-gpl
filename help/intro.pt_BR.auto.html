Cloudmin
O Cloudmin fornece uma maneira de gerenciar vários sistemas a partir de uma única interface. Podem ser máquinas reais ou sistemas virtuais executando sob uma tecnologia de virtualização como Xen, VServers ou Solaris Zones. Normalmente, os sistemas gerenciados executam o Virtualmin e todos os servidores associados, como Apache, Postfix e MySQL.

A página principal do Cloudmin mostra uma lista de sistemas registrados na parte superior e ícones para várias configurações globais na parte inferior. Você pode editar os detalhes de um único sistema clicando nele ou executar operações como reinicializar, excluir e atualizar vários sistemas de uma só vez, selecionando-os e clicando no botão apropriado abaixo da lista.

Para cada sistema, o status determinado pela última atualização automática ou manual exibida. Os sistemas podem estar em vários estados, como Inativo para um desligado, Sem Webmin para uma instalação simples e Webmin e Virtualmin para um com a pilha Virtualmin completa. Uma lista completa de possíveis códigos de status é mostrada na página de ajuda das descrições de status . Como o status é atualizado automaticamente apenas uma vez a cada 5 minutos, o status pode não ser exato para sistemas que foram iniciados ou desligados fora do Cloudmin.

Para adicionar um novo sistema à lista, use os links nas categorias Criar sistema ou Adicionar sistema no menu esquerdo. A criação é para a construção de sistemas virtuais como instâncias Xen, enquanto a adição é para colocar sistemas reais ou virtuais existentes sob o controle do Cloudmin. No entanto, você não pode criar sistemas virtuais até que pelo menos um sistema de hospedagem para esse tipo virtual tenha sido adicionado, como na página Xen Host Systems .

Os ícones abaixo da lista do sistema apontam para uma variedade de páginas para configurações que não são específicas para nenhum sistema gerenciado. Se você deseja usar o Cloudmin para criar instâncias do Xen, VServer ou Solaris Zone, primeiro adicione-as clicando no ícone Host Systems apropriado. Da mesma forma, para criar sistemas EC2, você deve primeiro adicionar pelo menos uma conta na página Contas do EC2 .
