iSCSI-Server
Das iSCSI-Protokoll ermöglicht den Export von Festplatten, logischen Volumes und Dateien von einem Serversystem (auch als Ziel bezeichnet) als Blockgeräte an Clients (als Initiatoren bezeichnet). Bei den meisten Linux-Systemen ist die Software in ihrer Paketdatenbank enthalten, die als iSCSI-Client oder -Server erforderlich ist, obwohl sie möglicherweise nicht standardmäßig installiert ist.

Auf dieser Seite können Sie Systeme als iSCSI-Server festlegen, sodass sie entweder logische LVM-Volumes oder reguläre Dateien auf Hostsysteme exportieren können, um sie als Disk-Images für virtuelle Systeme zu verwenden. Dies hat den Vorteil, dass virtuelle Systeme zwischen Hosts verschoben werden können, ohne dass Disk-Images kopiert werden müssen. Außerdem können Sie den Speicher auf einem einzelnen Server zentralisieren, anstatt dass jeder Host über eigene große Festplatten oder Datenträgergruppen verfügt.
