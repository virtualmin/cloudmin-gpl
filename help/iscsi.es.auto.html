Servidores iSCSI
El protocolo iSCSI permite exportar discos, volúmenes lógicos y archivos desde un sistema de servidor (también conocido como destino) como dispositivos de bloque a clientes (conocidos como iniciadores). La mayoría de los sistemas Linux tienen el software incluido en su paquete de base de datos requerido para actuar como un cliente o servidor iSCSI, aunque es posible que no se instale de manera predeterminada.

Esta página le permite designar sistemas como servidores iSCSI, para que puedan exportar volúmenes lógicos LVM o archivos regulares a sistemas host para usarlos como imágenes de disco del sistema virtual. Esto tiene la ventaja de permitir que los sistemas virtuales se muevan entre hosts sin la necesidad de copiar imágenes de disco. También le permite centralizar el almacenamiento en un solo servidor, en lugar de requerir que cada host tenga sus propios discos grandes o grupos de volúmenes.
