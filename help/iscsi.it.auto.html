Server iSCSI
Il protocollo iSCSI consente di esportare dischi, volumi logici e file da un sistema server (noto anche come destinazione) come dispositivi a blocchi verso client (noti come iniziatori). La maggior parte dei sistemi Linux hanno il software incluso nel loro database dei pacchetti necessario per funzionare come client o server iSCSI, anche se potrebbe non essere installato per impostazione predefinita.

Questa pagina consente di designare i sistemi come server iSCSI, in modo che possano esportare volumi logici LVM o file regolari su sistemi host da utilizzare come immagini del disco di sistema virtuale. Ciò ha il vantaggio di consentire lo spostamento dei sistemi virtuali tra host senza la necessità di copiare le immagini del disco. Inoltre, consente di centralizzare l'archiviazione su un singolo server, anziché richiedere a ciascun host di disporre di dischi o gruppi di volumi di grandi dimensioni.
