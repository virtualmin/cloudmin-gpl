Servidores iSCSI
O protocolo iSCSI permite que discos, volumes lógicos e arquivos sejam exportados de um sistema de servidor (também conhecido como destino) como dispositivos de bloco para clientes (conhecidos como iniciadores). A maioria dos sistemas Linux possui o software incluído no banco de dados de pacotes necessário para atuar como um cliente ou servidor iSCSI, embora ele possa não estar instalado por padrão.

Esta página permite designar sistemas como servidores iSCSI, para que eles possam exportar volumes lógicos LVM ou arquivos regulares para sistemas host para uso como imagens de disco do sistema virtual. Isso tem a vantagem de permitir que sistemas virtuais sejam movidos entre hosts sem a necessidade de copiar imagens de disco. Ele também permite centralizar o armazenamento em um único servidor, em vez de exigir que cada host tenha seus próprios discos grandes ou grupo de volumes.
