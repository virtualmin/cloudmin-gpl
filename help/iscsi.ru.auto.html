Серверы iSCSI
Протокол iSCSI позволяет экспортировать диски, логические тома и файлы из серверной системы (также называемой целевой) в качестве блочных устройств для клиентов (известных как инициаторы). Большинство систем Linux имеют программное обеспечение, включенное в их базу данных пакетов, необходимое для работы в качестве клиента или сервера iSCSI, хотя оно может быть не установлено по умолчанию.

На этой странице вы можете назначить системы серверами iSCSI, чтобы они могли экспортировать логические тома LVM или обычные файлы в хост-системы для использования в качестве образов дисков виртуальной системы. Это имеет то преимущество, что позволяет перемещать виртуальные системы между хостами без необходимости копировать образы дисков. Это также позволяет вам централизовать хранилище на одном сервере, вместо того, чтобы каждый хост имел свои собственные большие диски или группу томов.
