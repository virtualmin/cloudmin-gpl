SSH-Schlüssel
Auf dieser Seite können Sie SSH-Schlüssel registrieren, die für den Zugriff auf neu erstellte virtuelle Systeme verwendet werden. Wenn eine Xen-Instanz, ein OpenVZ-Container, eine Solaris Zone oder ein VServer erstellt wird, können Sie auswählen, ob auf die Root- Anmeldung über ein Kennwort oder mit einem der Schlüssel auf dieser Seite zugegriffen werden soll. Für EC2-Instanzen muss mindestens ein Schlüssel registriert sein, bevor sie erstellt werden können, da EC2 nur für neue virtuelle Systeme den Zugriff über SSH-Schlüssel ermöglicht.

Um einen neuen Schlüssel zu erstellen, klicken Sie über oder unter der Tabelle der vorhandenen Schlüssel auf den Link Neuen SSH-Schlüssel hinzufügen. Um die Details einer bereits vorhandenen zu bearbeiten, klicken Sie auf deren Namen. Um Schlüssel zu entfernen, aktivieren Sie die Kontrollkästchen neben ihnen und klicken Sie auf die Schaltfläche Ausgewählte Schlüssel löschen. Sie können jedoch nur Schlüssel entfernen, die nicht zum Anmelden bei verwalteten Systemen verwendet werden.

Sie können dieser Liste auch Schlüssel hinzufügen, für die nur die öffentlichen Schlüsseldaten verfügbar sind, um sie als Sekundärschlüssel für neue Systeme zu verwenden. Dies ist nützlich, wenn Sie über einen vorhandenen Schlüssel (möglicherweise mit einer Passphrase) verfügen, mit dem Sie sich bei allen virtuellen Systemen anmelden möchten.
