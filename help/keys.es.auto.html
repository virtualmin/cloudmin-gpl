SSH Keys
Esta página le permite registrar claves SSH que se utilizan para acceder a sistemas virtuales recién creados. Cuando se crea una instancia de Xen, un contenedor OpenVZ, Solaris Zone o VServer, puede seleccionar si se debe acceder al inicio de sesión raíz mediante una contraseña o utilizando una de las teclas de esta página. Para las instancias EC2, debe tener al menos una clave registrada antes de que puedan crearse, ya que EC2 solo permite el acceso a través de claves SSH para nuevos sistemas virtuales.

Para crear una nueva clave, haga clic en el enlace Agregar una nueva clave SSH arriba o debajo de la tabla de claves existentes. Para editar los detalles de uno que ya existe, haga clic en su nombre. Para eliminar claves, marque las casillas junto a ellas y haga clic en el botón Eliminar claves seleccionadas . Sin embargo, solo puede eliminar las claves que no se utilizan para iniciar sesión en ningún sistema administrado.

También puede agregar claves para las cuales los datos de clave pública solo están disponibles en esta lista, para usar como claves secundarias para sistemas nuevos. Esto es útil si tiene una clave existente (tal vez con una frase de contraseña) que le gustaría poder iniciar sesión en todos los sistemas virtuales.
