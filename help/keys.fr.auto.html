Clés SSH
Cette page vous permet d'enregistrer les clés SSH utilisées pour accéder aux systèmes virtuels nouvellement créés. Lorsqu'une instance Xen, un conteneur OpenVZ, une zone Solaris ou un VServer est créé, vous pouvez sélectionner si sa connexion root doit être accessible via un mot de passe ou en utilisant l'une des clés de cette page. Pour les instances EC2, vous devez avoir enregistré au moins une clé avant de pouvoir les créer, car EC2 n'autorise l'accès via les clés SSH qu'aux nouveaux systèmes virtuels.

Pour créer une nouvelle clé, cliquez sur le lien Ajouter une nouvelle clé SSH au-dessus ou en dessous du tableau des clés existantes. Pour modifier les détails de celui qui existe déjà, cliquez sur son nom. Pour supprimer des clés, cochez les cases en regard et cliquez sur le bouton Supprimer les clés sélectionnées . Vous ne pouvez cependant supprimer que les clés qui ne sont pas utilisées pour vous connecter à un système géré.

Vous pouvez également ajouter des clés pour lesquelles seules les données de clé publique sont disponibles dans cette liste, à utiliser comme clés secondaires pour les nouveaux systèmes. Ceci est utile si vous avez une clé existante (peut-être avec une phrase secrète) que vous souhaitez pouvoir vous connecter à tous les systèmes virtuels.
