Chiavi SSH
Questa pagina consente di registrare le chiavi SSH utilizzate per accedere ai sistemi virtuali appena creati. Quando viene creata un'istanza Xen, un contenitore OpenVZ, Solaris Zone o VServer, è possibile selezionare se si deve accedere al suo login di root tramite una password o usando uno dei tasti in questa pagina. Per le istanze EC2, è necessario disporre di almeno una chiave registrata prima che possano essere create, poiché EC2 consente l'accesso solo tramite chiavi SSH per i nuovi sistemi virtuali.

Per creare una nuova chiave, fare clic sul collegamento Aggiungi una nuova chiave SSH sopra o sotto la tabella delle chiavi esistenti. Per modificare i dettagli di uno già esistente, fai clic sul suo nome. Per rimuovere le chiavi, seleziona le caselle accanto a esse e fai clic sul pulsante Elimina chiavi selezionate . Tuttavia, è possibile rimuovere solo le chiavi che non vengono utilizzate per accedere a nessun sistema gestito.

È inoltre possibile aggiungere chiavi per le quali solo i dati della chiave pubblica sono disponibili in questo elenco, da utilizzare come chiavi secondarie per i nuovi sistemi. Ciò è utile se si dispone di una chiave esistente (forse con una passphrase) che si desidera poter accedere a tutti i sistemi virtuali.
