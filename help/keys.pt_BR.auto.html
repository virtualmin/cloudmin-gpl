Chaves SSH
Esta página permite registrar chaves SSH usadas para acessar sistemas virtuais recém-criados. Quando uma instância Xen, um contêiner OpenVZ, Solaris Zone ou VServer é criada, você pode selecionar se o login raiz deve ser acessado por meio de uma senha ou usando uma das chaves nesta página. Para instâncias do EC2, você deve ter pelo menos uma chave registrada antes que elas possam ser criadas, pois o EC2 permite apenas o acesso via chaves SSH para novos sistemas virtuais.

Para criar uma nova chave, clique no link Adicionar uma nova chave SSH acima ou abaixo da tabela de chaves existentes. Para editar os detalhes de um que já existe, clique no seu nome. Para remover chaves, marque as caixas próximas a elas e clique no botão Excluir chaves selecionadas. Porém, você pode remover apenas as chaves que não estão sendo usadas para efetuar login em nenhum sistema gerenciado.

Você também pode adicionar chaves para as quais apenas os dados da chave pública estão disponíveis a esta lista, para uso como chaves secundárias em novos sistemas. Isso é útil se você tiver uma chave existente (talvez com uma senha) que você gostaria de poder acessar todos os sistemas virtuais.
