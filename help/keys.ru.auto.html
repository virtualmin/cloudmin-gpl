SSH ключи
На этой странице вы можете зарегистрировать ключи SSH, которые используются для доступа к вновь созданным виртуальным системам. Когда создается экземпляр Xen, контейнер OpenVZ, Solaris Zone или VServer, вы можете выбрать, следует ли осуществлять доступ к его корневому логину с помощью пароля или с помощью одного из ключей на этой странице. Для экземпляров EC2 необходимо зарегистрировать хотя бы один ключ, прежде чем их можно будет создать, поскольку EC2 разрешает доступ только через ключи SSH для новых виртуальных систем.

Чтобы создать новый ключ, нажмите ссылку Добавить новый ключ SSH над или под таблицей существующих ключей. Чтобы отредактировать детали уже существующего, нажмите на его название. Чтобы удалить ключи, установите флажки рядом с ними и нажмите кнопку «Удалить выбранные ключи» . Вы можете удалить только те ключи, которые не используются для входа в какие-либо управляемые системы.

Вы также можете добавить ключи, для которых данные открытого ключа доступны только для этого списка, для использования в качестве вторичных ключей для новых систем. Это полезно, если у вас есть существующий ключ (возможно, с парольной фразой), который вы хотели бы иметь возможность войти во все виртуальные системы.
