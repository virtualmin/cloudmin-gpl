KVM-Hostsysteme
Bevor Cloudmin virtuelle Systeme mit KVM-Instanzen erstellen kann, müssen Sie die Hostsysteme registrieren, auf denen KVM auf dieser Seite ausgeführt wird. Cloudmin verfügt über eine dreischichtige Architektur, in der das Mastersystem (auf dem die Cloudmin-Webmin-Schnittstelle ausgeführt wird) von den Systemen getrennt ist, auf denen KVM-Instanzen gehostet werden, die wiederum von den KVM-Systemen selbst getrennt sind.

Bevor ein KVM-Hostsystem hier registriert werden kann, müssen Sie es zunächst über den Link Physisches System hinzufügen unter System hinzufügen im linken Menü unter die Kontrolle von Cloudmin bringen. Es ist möglich, dass ein einzelnes System sowohl Virtualmin-Domänen als auch KVM-Instanzen hostet, obwohl dies aufgrund der von KVM auferlegten CPU-Last im Allgemeinen nicht empfohlen wird. Wählen Sie anschließend das System aus dem Menü Hostsystem zum Hinzufügen aus und klicken Sie auf Start Host hinzufügen .
