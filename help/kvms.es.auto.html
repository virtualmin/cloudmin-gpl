Sistemas host KVM
Antes de que Cloudmin pueda crear sistemas virtuales utilizando instancias de KVM, debe registrar los sistemas host en los que se ejecutará KVM utilizando esta página. Cloudmin tiene una arquitectura de tres capas, en la que el sistema maestro (en el que se ejecuta la interfaz de Cloudmin Webmin) está separado de los sistemas que alojan instancias KVM, que a su vez están separados de los propios sistemas KVM.

Antes de que un sistema host KVM pueda registrarse aquí, primero debe ponerlo bajo el control de Cloudmin usando el enlace Agregar sistema físico en Agregar sistema en el menú de la izquierda. Es posible que un solo sistema aloje dominios de Virtualmin e instancias de KVM, aunque esto generalmente no se recomienda debido a la carga de CPU que KVM puede imponer. Una vez hecho esto, seleccione el sistema desde el sistema Host para agregar el menú y haga clic en Iniciar Agregar Host .
