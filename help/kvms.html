KVM Host Systems
Before Cloudmin can create any virtual systems using KVM instances, you must register the host systems on which KVM will run using this page. Cloudmin has a three-layer architecture, in which the master system (on which the Cloudmin Webmin interface runs) is separate from the systems that host KVM instances, which are in turn separate from the KVM systems themselves.

Before a KVM host system can be registered here, you must first bring it under Cloudmin's control using the Add physical system link under Add system on the left menu. It is possible for a single system to both host Virtualmin domains and KVM instances, although this is not generally recommended due to the CPU load KVM can impose. Once this is done, select the system from the Host system to add menu, and click Start Adding Host.
