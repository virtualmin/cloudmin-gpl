Sistemi host KVM
Prima che Cloudmin possa creare qualsiasi sistema virtuale usando istanze KVM, è necessario registrare i sistemi host su cui verrà eseguito KVM usando questa pagina. Cloudmin ha un'architettura a tre livelli, in cui il sistema principale (su cui gira l'interfaccia Cloudmin Webmin) è separato dai sistemi che ospitano istanze KVM, che a loro volta sono separate dai sistemi KVM stessi.

Prima che un sistema host KVM possa essere registrato qui, devi prima portarlo sotto il controllo di Cloudmin usando il collegamento Aggiungi sistema fisico sotto Aggiungi sistema nel menu a sinistra. È possibile per un singolo sistema ospitare sia domini Virtualmin che istanze KVM, sebbene ciò non sia generalmente raccomandato a causa del carico della CPU che KVM può imporre. Al termine, selezionare il sistema dal sistema Host per aggiungere il menu e fare clic su Avvia aggiunta host .
