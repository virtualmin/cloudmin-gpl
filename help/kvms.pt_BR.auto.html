Sistemas host KVM
Antes de o Cloudmin criar qualquer sistema virtual usando instâncias KVM, você deve registrar os sistemas host nos quais o KVM será executado usando esta página. O Cloudmin possui uma arquitetura de três camadas, na qual o sistema principal (no qual a interface do Cloudmin Webmin é executada) é separado dos sistemas que hospedam instâncias KVM, que por sua vez são separadas dos próprios sistemas KVM.

Antes de um sistema host KVM poder ser registrado aqui, você deve colocá-lo sob o controle do Cloudmin usando o link Adicionar sistema físico em Adicionar sistema no menu esquerdo. É possível que um único sistema hospede domínios do Virtualmin e instâncias do KVM, embora isso geralmente não seja recomendado devido à carga da CPU que o KVM pode impor. Feito isso, selecione o sistema no sistema Host para adicionar menu e clique em Iniciar Adicionando Host .
