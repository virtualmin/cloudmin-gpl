Virtualmin-Lizenzen
Diese Seite listet alle Virtualmin-Seriennummern und Lizenzschlüssel auf, die bei Cloudmin registriert wurden. Wenn Sie ein virtuelles System aus einem Image erstellen, das Virtualmin enthält, oder Virtualmin auf einem leeren System installieren, wird eine Lizenz aus dieser Liste verwendet.

Jede Lizenz kann auf einer bestimmten Anzahl von Systemen verwendet werden - der billigste Wille gilt nur für einen einzelnen Computer, während teurere Lizenzen auf 10 oder sogar einer unbegrenzten Anzahl von Hosts verwendet werden können. Cloudmin verfolgt die Anzahl der verwalteten Systeme, die jede Lizenz verwenden, und weist nur diejenigen zu, auf denen noch freie Systeme vorhanden sind.

Wenn Cloudmin keine Lizenz mehr verwenden soll, aktivieren Sie das Kontrollkästchen neben der Seriennummer in der Liste und klicken Sie auf die Schaltfläche Ausgewählte Lizenzen entfernen . Dadurch wird die Lizenz nicht von vorhandenen Systemen entfernt, sie kann in Zukunft nicht mehr verwendet oder Rückerstattungen durchgeführt werden.

Um neue Lizenzen hinzuzufügen, müssen Sie diese zuerst auf der Virtualmin-Website virtualmin.com erwerben . Wenn Sie die Seriennummer und den Schlüssel haben, geben Sie diese in das Formular auf der zweiten Registerkarte ein und klicken Sie auf die Schaltfläche Lizenz hinzufügen.

Um mehrere Lizenzen hinzuzufügen, suchen Sie deren Seriennummern und Schlüssel und geben Sie sie in das Textfeld auf der dritten Registerkarte ein. Jede Lizenz sollte in einer separaten Zeile stehen, wobei die Seriennummer und der Schlüssel durch ein Leerzeichen getrennt sind. Wenn Sie auf die Schaltfläche Lizenzen hinzufügen klicken, wird jeder eingegebene Wert validiert und der Liste hinzugefügt. Sie können dann verwendet werden, um neue Systeme mit Virtualmin zu erstellen.

Wenn Sie eine große Anzahl von Lizenzen bei virtualmin.com erwerben , können Sie Cloudmin so konfigurieren, dass sie automatisch für verwaltete Virtualmin-Systeme gefunden und abgerufen werden. Dies kann auf der vierten Registerkarte erfolgen - die automatische Überprüfung erfolgt einmal pro Stunde.
