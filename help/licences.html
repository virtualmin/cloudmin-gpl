Virtualmin Licenses
This page lists all of the Virtualmin serial numbers and license keys that have been registered with VM2. Whenever you create a virtual system from an image that includes Virtualmin, or install Virtualmin on an empty system, a license from this list will be used.

Each license can be used on a certain number of systems - the cheapest will is only valid for a single machine, while more expensive licenses can be used on 10 or even an unlimited number of hosts. VM2 keeps track of the number of managed systems using each licence, and will allocate only those that have free systems remaining.

To add one or more new licenses, you must first purchase them at the Virtualmin website, virtualmin.com. Once you have the serial numbers and keys, enter them in the text box at the bottom of the page. Each license should be on a separate line, with the serial number and key separated by a space. When the Add Licenses button is clicked, each one entered will be validated and added to the list. They can then be used to create new systems with Virtualmin.

If you no longer want VM2 to use a licence, select the checkbox next to its serial number in the list, and click the Remove Selected Licences button. This will not remove the license from any existing systems, prevent it from being re-used in future, or perform any refunds.
