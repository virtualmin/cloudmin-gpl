Ressourcenlimits
Auf dieser Seite können Sie die einem virtuellen System zugewiesene Speichermenge und den Prozentsatz der auf dem Hosting-Server zugewiesenen CPU ändern. Die CPU wird als Prozentsatz eines Kerns ausgedrückt, sodass 100% nur die Hälfte der CPU-Kapazität eines Zwei-Kern-Hostsystems bedeuten würde.

Auf Xen-Systemen können Sie auch die CPU-Gewichtung festlegen, die verwendet wird, wenn die von allen Instanzen verbrauchte Gesamt-CPU die vom Host bereitgestellte überschreitet. Eine Instanz mit einem Gewicht von 512 erhält die doppelte CPU einer Instanz mit 256, vorausgesetzt, beide verarbeiten gleich viel.

Warnung : Wenn Sie den Speicher eines laufenden Systems unter den aktuellen Wert reduzieren, führt dies mit ziemlicher Sicherheit zum Absturz.

Auf Xen-, Zones- und Vservers-Systemen können Sie bei aktivierter Cloudmin-Bandbreitenüberwachung das Limit für den Datenverkehr festlegen, den dieses System während des aktuellen Abrechnungszeitraums (normalerweise des Kalendermonats) verbrauchen darf. Wenn Sie dieses Limit überschreiten, wird eine E-Mail ausgelöst und das System möglicherweise heruntergefahren.
