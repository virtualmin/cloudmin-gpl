Límites de recursos
Esta página le permite cambiar la cantidad de memoria asignada a un sistema virtual y el porcentaje de CPU que se asigna en el servidor de alojamiento. La CPU se expresa como un porcentaje de un núcleo, por lo que el 100% significaría solo la mitad de la capacidad de la CPU de un sistema host de dos núcleos.

En los sistemas Xen, también puede establecer la ponderación de la CPU, que se utiliza cuando la CPU total consumida por todas las instancias excede la proporcionada por el host. Una instancia con un peso de 512 obtendrá el doble de CPU que una con 256, suponiendo que ambos estén procesando cantidades iguales.

Advertencia : la reducción de la memoria de un sistema en ejecución por debajo de lo que está usando actualmente seguramente hará que se bloquee.

En los sistemas Xen, Zones y Vservers, cuando se habilita la supervisión del ancho de banda de Cloudmin, puede establecer el límite de la cantidad de tráfico de datos que este sistema puede consumir durante el período contable actual (generalmente el mes calendario). Exceder este límite activará un correo electrónico y posiblemente apagará el sistema.
