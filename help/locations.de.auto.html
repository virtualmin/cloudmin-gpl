Standortgruppen
Eine Standortgruppe ist eine Gruppe von Hostsystemen, die sich normalerweise am selben physischen Standort befinden und zum Zeitpunkt der Erstellung des virtuellen Systems ausgewählt werden können. Das tatsächliche Hostsystem wird dann aus den Mitgliedern der Standortgruppe ausgewählt. Zuordnung der Systeme zu Gruppen auf den Host - Systemen Seiten erfolgen auf.

Wenn Sie beispielsweise Hostsysteme an der Ost- und Westküste der USA hatten, können Sie für jede Küste eine Standortgruppe erstellen, damit virtuelle Systeme einfacher physisch verteilt werden können.
