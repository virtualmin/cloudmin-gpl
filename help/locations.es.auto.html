Grupos de ubicación
Un grupo de ubicaciones es un conjunto de sistemas host que generalmente se encuentran en la misma ubicación física, que se pueden seleccionar en el momento de la creación del sistema virtual. El sistema host real se elige entre los miembros del grupo de ubicación. La asignación de sistemas a grupos se realiza en las páginas de Sistemas host .

Por ejemplo, si tuviera sistemas host en las costas este y oeste de los EE. UU., Podría crear un grupo de ubicación para cada costa para permitir que los sistemas virtuales se distribuyan físicamente más fácilmente.
