Grupos de localização
Um grupo de locais é um conjunto de sistemas host que normalmente estão no mesmo local físico, que podem ser selecionados no momento da criação do sistema virtual. O sistema host real é então escolhido entre os membros do grupo de locais. A atribuição de sistemas a grupos é feita nas páginas Sistemas Host .

Por exemplo, se você tivesse sistemas host nas costas leste e oeste dos EUA, poderá criar um grupo de locais para cada costa para permitir que os sistemas virtuais sejam distribuídos fisicamente mais facilmente.
