Sistemas host LXC
Antes de que Cloudmin pueda crear sistemas virtuales utilizando contenedores LXC, debe registrar los sistemas host en los que se ejecutará LXC utilizando esta página. Cloudmin tiene una arquitectura de tres capas, en la que el sistema maestro (en el que se ejecuta la interfaz Cloudmin Webmin) está separado de los sistemas que alojan contenedores, que a su vez están separados de los contenedores LXC.

Antes de que un sistema host LXC pueda registrarse aquí, primero debe ponerlo bajo el control de Cloudmin usando el enlace Agregar sistema físico en Agregar sistema en el menú de la izquierda. Es posible que un solo sistema aloje dominios y contenedores de Virtualmin, siempre que tenga suficiente CPU y RAM. Una vez hecho esto, seleccione el sistema desde el sistema Host para agregar el menú y haga clic en Iniciar Agregar Host .
