Virtual Machine Details

Manage the machine's resources and devices here. Supported changes apply while it runs; others wait for a full shutdown and start. A guest reboot may not apply pending hardware changes.

CPU usage is relative to the assigned CPUs. Memory usage excludes reclaimable cache and needs a working balloon driver. Guest OS and filesystem details need a responding guest agent. Missing measurements mean unknown usage, not zero.

Growing a disk increases its capacity; expand partitions and filesystems inside the guest afterward. Network changes also require matching guest settings or a renewed DHCP lease. Snapshots and backup checkpoints must be removed before changing the disk layout.

Open Edit Virtual Machine > Access to manage guest passwords and, in Pro, SSH keys. Password resets require a running guest and a responding guest agent. They change an existing account's password, leaving SSH login settings and the Webmin password unchanged.

Forced power-off and hard reset skip clean shutdown and can lose data. Deletion permanently removes the selected disks. Keeping writable disks requires a clean shutdown; selecting all writable disks for deletion powers the machine off immediately. Shared disks and imported images are protected. Kept disks retain their data, but the deleted machine's snapshot history is removed.

Operations continue after you leave the page. If a change partly fails, use its recovery action in Active Jobs before trying again. Do not remove snapshot files manually.
