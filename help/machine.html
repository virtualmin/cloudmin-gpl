Virtual Machine Details

Manage the machine's resources and devices here. Supported changes apply while it runs. Others need a full shutdown and start. A guest reboot may not apply pending hardware changes.

The login account shown here was configured when Cloudmin created the machine. Later account changes inside the guest are not reflected here.

CPU usage is relative to the assigned CPUs. Memory usage excludes reclaimable cache and needs a working balloon driver. Guest OS and filesystem details need a responding guest agent. Missing readings mean unknown usage, not zero.

After growing a disk, expand its partitions and filesystems inside the guest. Network changes need matching guest settings or a renewed DHCP lease. Remove snapshots and backup checkpoints before changing the disk layout.

Ejecting an ISO empties the CD/DVD drive without removing it. If the running and saved drive settings differ, shut down the machine before changing its ISO.

The access section of the machine editor manages guest passwords and, in Pro, SSH keys. Password resets need a running machine and a responding guest agent. Choose an account or enter its name. The configured login and manual entry remain available if account discovery fails. SSH login settings stay unchanged. Services using that account's system password also use the new password.

Forced power-off and hard reset can lose data. Deletion permanently removes the selected disks. Keeping writable disks needs a clean shutdown. Deleting all writable disks powers the machine off immediately. Shared disks and imported images are protected. Kept disks retain their data, but the deleted machine's snapshot history is removed.

Operations continue after you leave this page. If a change partly fails, use its recovery action in Active Jobs before trying again. Do not remove snapshot files manually.
