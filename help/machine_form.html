Create Virtual Machine

Use a cloud image for automatic guest setup, or an installer ISO to install the operating system yourself. Templates supply image, login and network settings; plans supply CPU, memory and disk size. Review these defaults before creating the machine.

Cloud images configure the hostname, initial account and networking on first boot. Non-root administrators receive sudo access. The guest agent is installed automatically. For static networking, include address prefix lengths, gateways and DNS servers.

Missing catalogue images are downloaded and cached when creation starts. Installer ISOs boot into the graphical console and do not use cloud-init or managed SSH keys. After installation, eject the ISO or put the system disk first in the boot order.

Creation runs in the background, so you can leave the page and return through Active Jobs. A running machine or responding SSH service does not mean first-boot setup has finished.

Optional software setup requires a systemd cloud image, automatic startup and a managed SSH key. If it fails or is cancelled, the machine and installed software remain. Check /var/lib/cloudmin-install/install.log inside the guest, or cloud-init logs if setup failed earlier. Failed scripts are not repeated automatically.

If creation cleanup fails, recover the job before retrying. Cancelling creation does not cancel a shared image download; manage that separately in Image Manager.
