Packages

Enter package names separated by spaces or newlines. Cloudmin installs them inside the new virtual machine using its configured repositories. Use names available for the guest's operating system. When creating a virtual machine, leave this field empty to skip package installation.

In a machine template, choose Use Default Template to inherit its package list, None to skip packages, or Listed packages to enter a separate list. Inheritance follows later changes to Default Template. Default Template itself offers only None and Listed packages.

Enter names only, without command options, versions, wildcards or download URLs. You can specify up to 200 names, with a total length of 8,192 characters.

Package installation runs after the guest's initial setup and the Preparation script, if configured. The Final setup script runs after all selected software has been installed.

If a step fails, later steps do not run. The virtual machine is kept, and its creation job reports the failure. Details are in /var/lib/cloudmin-install/install.log inside the guest.

Software setup requires a cloud image with systemd, Start after creation and managed virtual machine SSH keys.
