Packages

Package names separated by spaces or newlines, from the guest's configured repositories. Names only: no versions, wildcards, command options or URLs. Up to 200 names and 8,192 characters are accepted.

An empty creation field skips extra packages. Templates can inherit the default list or explicitly select none. Packages install after the preparation script and before the final script.

Setup requires a systemd cloud image, automatic startup and a managed SSH key. Failure stops later steps and keeps the machine. See /var/lib/cloudmin-install/install.log inside the guest.
