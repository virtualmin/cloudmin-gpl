Scripts run once as root inside the new virtual machine after cloud-init finishes. They do not run on the Cloudmin host.

Preparation script runs before software installation. Use it to configure prerequisites, such as an extra package repository.

Final setup script runs after software installation succeeds. Use it to configure the installed software. If no software is selected, the two scripts still run in order.

  • None skips this script.
  • File on host reads a script from the Cloudmin host. Use the file chooser or enter an absolute path. Templates save the path; each creation job saves a copy of the file's contents when submitted. Later file edits do not affect that job. The source must be a regular UTF-8 text file of at most 16 KiB. File access uses your Webmin file permissions and configured Unix user.
  • Enter script saves the commands you enter, up to 16,384 characters. Indentation and line breaks are preserved.

Scripts use /bin/sh -e with no interactive input. Use POSIX shell syntax. An unhandled command failure stops setup and skips later steps. Failed or interrupted scripts are not retried automatically. The virtual machine is kept for inspection. Output is written to /var/lib/cloudmin-install/install.log inside the guest.

Scripts receive these environment variables:

  • CLOUDMIN_VM_UUID: the new virtual machine's UUID.
  • CLOUDMIN_HOSTNAME: its configured hostname.
  • CLOUDMIN_GUEST_USER: the initial guest account.

To run a command as the initial guest account, use runuser -u "$CLOUDMIN_GUEST_USER" -- command on guests that provide runuser. Do not put passwords or license keys in reusable scripts. Script contents are saved with the creation job and copied into the guest.

Software setup requires a cloud image with systemd, Start after creation and managed virtual machine SSH keys.
