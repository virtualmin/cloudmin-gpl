Scripts run once as root inside the new virtual machine after cloud-init finishes. The preparation script runs before software installation; the final script runs after it succeeds.

Use noninteractive POSIX shell commands. Scripts run with /bin/sh -e; a failed command stops setup. The machine is kept, and failed scripts are not repeated automatically. Output goes to /var/lib/cloudmin-install/install.log inside the guest.

Enter commands or select a UTF-8 file on this host. A template saves the path; each creation job copies the contents when submitted. Files are limited to 16 KiB and entered scripts to 16,384 characters.

Scripts receive CLOUDMIN_VM_UUID, CLOUDMIN_HOSTNAME and CLOUDMIN_GUEST_USER. Do not include reusable passwords or license keys: script contents are saved with the job and copied into the guest.

Setup requires a systemd cloud image, automatic startup and a managed SSH key.
