Virtualmin

Install Virtualmin GPL or Pro inside the new guest. Selecting none still allows extra packages and setup scripts.

Use a fresh image supported by the Virtualmin installer, with systemd, Internet access and a fully qualified hostname. Automatic startup and a managed SSH key are required. A full installation needs at least 2 GiB of RAM; minimal needs 1 GiB. Both need a 20 GiB disk.

Setup runs the preparation script, installs extra packages and Virtualmin, then runs the final script. After installation, complete the Virtualmin configuration wizard.

Pro credentials are entered separately for each new machine and are not saved in templates. Clones and captured images reset copied license credentials; each copy needs its own license or a switch to GPL.
