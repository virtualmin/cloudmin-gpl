Installation size

Full installation installs the standard hosting services, including web, mail, spam filtering and virus scanning. Cloudmin requires at least 2 GiB of memory for this choice.

Minimal installation installs web hosting software without local mail, spam filtering, virus scanning, DNS, FTP or Jailkit. Cloudmin requires at least 1 GiB of memory for this choice.

Both choices require a disk of at least 20 GiB. Set memory and disk size under Resources or in the selected resource plan. These are minimum creation requirements; allow more memory for the services and workloads you intend to run.
