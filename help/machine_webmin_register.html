Add to host's Webmin Servers Index

When enabled, Cloudmin adds this virtual machine to the host's Webmin Servers Index after guest software setup. This lets you use Open embedded Webmin on Remote Access → Webmin, including for guests behind NAT.

Open directly in new tab uses the guest's own address and needs no registration. Private addresses may be unreachable from your browser.

Registration is enabled by default. Change it in a template or when creating a virtual machine. Turning it off affects new virtual machines only. Cloudmin removes its server entry when it deletes the virtual machine.

Automatic login uses the initial guest username and password saved in the host's protected Servers Index configuration. No extra guest account is created. If the password changes, update it in Servers Index. If no password was saved, Servers Index asks for the guest login and remembers it for the browser session.

Only the host's root Webmin login can register guests or use Cloudmin's Webmin tab. Virtual machines created by other users skip registration. Servers Index permissions still apply. Use the embedded proxy only for fully trusted guests. Their pages share the host's browser origin and can use your session to compromise the host and other virtual machines.
