Add to host's Webmin Servers Index

Register the guest in this host's Webmin Servers Index for embedded access, including behind NAT. Enabled by default for new machines created by the host's root Webmin login.

Automatic login uses the initial guest username and password saved in Servers Index. Update the saved login there if the password changes. Without a saved password, the proxy asks for one.

Use embedded access only for fully trusted guests: their pages can use your host session to compromise this host and other machines. Direct access needs no registration but requires the guest address to be reachable from your browser.
