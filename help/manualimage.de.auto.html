Manuelles Erstellen eines Bildes
Auf dieser Seite können Sie ein Cloudmin-Image für eine vorhandene Datei erstellen, normalerweise einen Speicherauszug einer einzelnen Partition (für Xen) oder einer gesamten Festplatte (für KVM). Viele Websites wie stacklet.com bieten vorgefertigte Images mit einer Vielzahl von Linux-Distributionen, die Sie verwenden können.

Stellen Sie sicher, dass die von Ihnen ausgewählte Datei tatsächlich als Image für Xen oder KVM geeignet ist. Eine komprimierte TAR-Datei eines Dateisystems funktioniert nicht, eine Kopie der Festplatte oder der primären Partition eines realen Systems sollte jedoch funktionieren. Beachten Sie, dass Bilddateien von stacklet.com in einer bzipped-TAR-Datei gepackt sind und daher zuerst extrahiert werden müssen.

Um ein Bild zu erstellen, geben Sie zuerst den Pfad zur Quelldatei in das Feld Bildquelle ein. centos-5.5 dann eine ID wie centos-5.5 in das Feld Eindeutige ID und eine für Menschen lesbare Beschreibung in das Feld Beschreibung für Bild ein.

Wenn Sie auf die Schaltfläche Erstellen klicken, überprüft Cloudmin die Bilddatei und kopiert sie von der angegebenen Quelle an alle Standardspeicherorte. Das Image kann dann zum Erstellen virtueller Systeme verwendet werden.
