Crear imagen manualmente
Esta página le permite crear una imagen de Cloudmin para un archivo existente, generalmente un volcado de una sola partición (para Xen) o un disco completo (para KVM). Muchos sitios web como stacklet.com proporcionan imágenes precompiladas que contienen una variedad de distribuciones de Linux que puede usar.

Asegúrese de que el archivo que seleccione sea realmente adecuado para su uso como imagen para Xen o KVM. Un archivo tar comprimido de un sistema de archivos no funcionará, pero una copia del disco o partición primaria de un sistema real debería funcionar. Tenga en cuenta que los archivos de imagen de stacklet.com están empaquetados dentro de un archivo tar comprimido, por lo que deben extraerse primero.

Para crear una imagen, primero ingrese la ruta al archivo fuente en el campo Fuente de imagen . Luego ingrese un ID como centos-5.5 en el campo ID único , y una descripción legible por humanos en el campo Descripción para imagen .

Cuando hace clic en el botón Crear , Cloudmin validará el archivo de imagen y lo copiará de la fuente especificada a todas las ubicaciones de almacenamiento predeterminadas. La imagen se puede usar para crear sistemas virtuales.
