Créer manuellement une image
Cette page vous permet de créer une image Cloudmin pour un fichier existant, généralement un vidage d'une seule partition (pour Xen) ou d'un disque entier (pour KVM). De nombreux sites Web comme stacklet.com fournissent des images de pré-construction contenant une variété de distributions Linux que vous pouvez utiliser.

Assurez-vous que le fichier que vous sélectionnez est réellement utilisable comme image pour Xen ou KVM. Un fichier tar compressé d'un système de fichiers ne fonctionnera pas, mais une copie du disque ou de la partition principale d'un système réel devrait fonctionner. Sachez que les fichiers image de stacklet.com sont regroupés dans un fichier tar bzippé et doivent donc être extraits en premier.

Pour créer une image, entrez d'abord le chemin d'accès au fichier source dans le champ Source de l' image . Saisissez ensuite un ID tel que centos-5.5 dans le champ ID unique et une description lisible par l'homme dans le champ Description de l'image .

Lorsque vous cliquez sur le bouton Créer , Cloudmin valide le fichier image et le copie de la source spécifiée vers tous les emplacements de stockage par défaut. L'image peut ensuite être utilisée pour créer des systèmes virtuels.
