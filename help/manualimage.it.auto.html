Crea manualmente immagine
Questa pagina consente di creare un'immagine Cloudmin per un file esistente, in genere un dump di una singola partizione (per Xen) o di un intero disco (per KVM). Molti siti Web come stacklet.com forniscono immagini pre-build contenenti una varietà di distribuzioni Linux che è possibile utilizzare.

Assicurati che il file selezionato sia effettivamente adatto all'uso come immagine per Xen o KVM. Un file tar compresso di un filesystem non funzionerà, ma una copia del disco o della partizione primaria da un sistema reale dovrebbe funzionare. Essere consapevoli del fatto che i file di immagine da stacklet.com sono impacchettati all'interno di un file tar compresso in bzip e quindi devono essere estratti prima.

Per creare un'immagine, immettere innanzitutto il percorso del file di origine nel campo Origine immagine . Quindi immettere un ID come centos-5.5 nel campo ID univoco e una descrizione leggibile dall'uomo nel campo Descrizione per immagine .

Quando fai clic sul pulsante Crea , Cloudmin convaliderà il file di immagine e lo copierà dalla fonte specificata in tutte le posizioni di archiviazione predefinite. L'immagine può quindi essere utilizzata per creare sistemi virtuali.
