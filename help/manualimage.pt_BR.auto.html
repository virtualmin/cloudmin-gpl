Criar imagem manualmente
Esta página permite criar uma imagem do Cloudmin para um arquivo existente, normalmente um despejo de uma única partição (para Xen) ou de um disco inteiro (para KVM). Muitos sites como o stacklet.com fornecem imagens de pré-compilação que contêm uma variedade de distribuições Linux que você pode usar.

Certifique-se de que o arquivo selecionado seja realmente adequado para uso como imagem no Xen ou KVM. Um arquivo tar compactado de um sistema de arquivos não funcionará, mas uma cópia do disco ou partição primária de um sistema real deve. Esteja ciente de que os arquivos de imagem de stacklet.com são empacotados dentro de um arquivo tar compactado e, portanto, devem ser extraídos primeiro.

Para criar uma imagem, primeiro digite o caminho para o arquivo de origem no campo Origem da imagem . Em seguida, insira um ID como centos-5.5 no campo ID exclusivo e uma descrição legível por humanos no campo Descrição para imagem .

Quando você clica no botão Criar , o Cloudmin valida o arquivo de imagem e o copia da fonte especificada para todos os locais de armazenamento padrão. A imagem pode ser usada para criar sistemas virtuais.
