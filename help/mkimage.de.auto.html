System-Image erstellen
Auf dieser Seite können Sie ein neues Systemabbild aus einem vorhandenen virtuellen System erstellen, das von Cloudmin verwaltet wird. Der gesamte Inhalt des Dateisystems des Systems wird eingefroren und in eine Image-Datei auf dem Cloudmin-Mastersystem kopiert. Sie können dann neue virtuelle Systeme desselben Typs erstellen, indem Sie das erstellte Image instanziieren.

Das Erstellen eines Images ist eine hervorragende Möglichkeit, ein funktionierendes System zu klonen oder eine Vorlage zu erstellen, sobald Sie ein System nach Ihren Wünschen installiert und konfiguriert haben. Cloudmin löscht das Root-Passwort, die autorisierten SSH-Schlüssel und alle Virtualmin-Lizenzen vor dem Imaging vom Quellsystem und legt sie dann ordnungsgemäß fest, wenn aus dem Image ein neues System erstellt wird.

Da für die Bildgebung das gesamte Dateisystem der Quelle kopiert werden muss, kann das Quellsystem während des Bildgebungsprozesses heruntergefahren werden. Sobald dies abgeschlossen ist, wird es neu gestartet, wobei alle geänderten Dateien in ihren ursprünglichen Zustand zurückversetzt werden. Abhängig von der Geschwindigkeit Ihres Netzwerks und der Größe des Bildes kann der Vorgang 5-10 Minuten dauern.

Um ein Bild zu erstellen, müssen folgende Felder ausgefüllt werden:

Eindeutige ID für das Bild
Hier haben Sie zwei Möglichkeiten: Wählen Sie entweder Neues Bild und geben Sie eine ID ein, die noch nicht verwendet wird, oder Überschreiben Sie das alte Bild und wählen Sie ein zu ersetzendes Bild aus dem Menü. Normalerweise verwenden neue Cloudmin Bilder IDs im Format Typ - os - Software, wie xen-centos5-Lampe.
Beschreibung für Bild
In dieses Feld sollten Sie eine für Menschen lesbare Beschreibung eingeben, die angezeigt wird, wenn Sie das Bild zum Zeitpunkt der Systemerstellung auswählen.
Versionsnummer
Wenn Sie im Laufe der Zeit mehrere Bilder mit derselben ID erstellt haben, können Sie in diesem optionalen Feld eine Versionsnummer für das neue Bild festlegen. Wenn Sie mehrere Cloudmin-Mastersysteme ausführen und Bilder zwischen diesen kopieren, erleichtert eine Version das Verfolgen von Bildänderungen.
