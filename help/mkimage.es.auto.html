Crear imagen del sistema
Esta página le permite crear una nueva imagen del sistema a partir de un sistema virtual existente administrado por Cloudmin. Todo el contenido del sistema de archivos del sistema se congelará y copiará en un archivo de imagen en el sistema maestro de Cloudmin. Entonces podrá crear nuevos sistemas virtuales del mismo tipo al crear una instancia de la imagen creada.

Crear una imagen es una excelente manera de clonar un sistema de trabajo o de crear una plantilla una vez que haya instalado y configurado un sistema a su gusto. Cloudmin borrará la contraseña de root, las claves SSH autorizadas y cualquier licencia de Virtualmin del sistema de origen antes de crear imágenes, y luego las configurará correctamente cuando se cree un nuevo sistema a partir de la imagen.

La creación de imágenes requiere que se copie todo el sistema de archivos de la fuente, el sistema fuente puede cerrarse durante el proceso de creación de imágenes. Una vez que esté completo, se reiniciará con cualquier archivo modificado restaurado a su estado original. Dependiendo de la velocidad de su red y del tamaño de la imagen, el proceso puede demorar entre 5 y 10 minutos.

Para crear una imagen, se deben completar los siguientes campos:

ID única para imagen
Aquí tiene dos opciones: seleccionar Nueva imagen e ingresar una ID que aún no se esté utilizando, o Sobrescribir imagen antigua y elegir una imagen para reemplazar del menú. Por lo general, las nuevas imágenes de Cloudmin usan ID en el tipo de formato - os - software , como xen-centos5-lamp .
Descripción de imagen
En este campo, debe ingresar una descripción legible por humanos, que aparece cuando selecciona la imagen en el momento de la creación del sistema.
Número de versión
Si ha creado varias imágenes con la misma ID a lo largo del tiempo, este campo opcional se puede usar para establecer un número de versión para la nueva imagen. Si está ejecutando múltiples sistemas maestros de Cloudmin y copiando imágenes entre ellos, una versión facilita el seguimiento de los cambios de imagen.
