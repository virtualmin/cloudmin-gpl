Créer une image système
Cette page vous permet de créer une nouvelle image système à partir d'un système virtuel existant géré par Cloudmin. L'ensemble du contenu du système de fichiers du système sera gelé et copié dans un fichier image sur le système maître Cloudmin. Vous pourrez alors créer de nouveaux systèmes virtuels du même type en instanciant l'image créée.

La création d'une image est un excellent moyen de cloner un système fonctionnel ou de créer un modèle une fois que vous avez installé et configuré un système à votre convenance. Cloudmin effacera le mot de passe root, les clés SSH autorisées et toute licence Virtualmin du système source avant la création d'image, puis les définira correctement lorsqu'un nouveau système est créé à partir de l'image.

Parce que la création d'image nécessite que tout le système de fichiers de la source soit copié, le système source peut être arrêté pendant le processus de création d'image. Une fois terminé, il sera redémarré avec tous les fichiers modifiés restaurés à leur état d'origine. Selon la vitesse de votre réseau et la taille de l'image, le processus peut prendre 5 à 10 minutes.

Pour créer une image, les champs suivants doivent être remplis:

ID unique pour l'image
Ici, vous avez deux choix: sélectionnez Nouvelle image et entrez un ID qui n'est pas encore utilisé, ou Remplacez l'ancienne image et choisissez une image à remplacer dans le menu. En règle générale, les nouvelles images Cloudmin utilisent des identifiants au format de type - os - logiciel , comme xen-centos5-lamp .
Description de l'image
Dans ce champ, vous devez entrer une description lisible par l'homme, qui apparaît lorsque vous sélectionnez l'image au moment de la création du système.
Numéro de version
Si vous avez créé plusieurs images avec le même ID au fil du temps, ce champ facultatif peut être utilisé pour définir un numéro de version pour la nouvelle image. Si vous exécutez plusieurs systèmes maîtres Cloudmin et copiez des images entre eux, une version facilite le suivi des modifications d'image.
