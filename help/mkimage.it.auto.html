Crea immagine di sistema
Questa pagina consente di creare una nuova immagine di sistema da un sistema virtuale esistente gestito da Cloudmin. L'intero contenuto del filesystem del sistema verrà congelato e copiato in un file di immagine sul sistema principale Cloudmin. Sarai quindi in grado di creare nuovi sistemi virtuali dello stesso tipo creando un'istanza dell'immagine creata.

La creazione di un'immagine è un modo eccellente per clonare un sistema funzionante o per creare un modello dopo aver installato e configurato un sistema a proprio piacimento. Cloudmin cancella la password di root, le chiavi SSH autorizzate e qualsiasi licenza Virtualmin dal sistema di origine prima dell'imaging, quindi le imposta correttamente quando viene creato un nuovo sistema dall'immagine.

Perché l'imaging richiede che sia copiato l'intero filesystem della sorgente, il sistema sorgente potrebbe essere spento durante il processo di imaging. Una volta completato, verrà riavviato con tutti i file modificati ripristinati al loro stato originale. A seconda della velocità della rete e delle dimensioni dell'immagine, il processo potrebbe richiedere 5-10 minuti.

Per creare un'immagine, è necessario compilare i seguenti campi:

ID univoco per l'immagine
Qui hai due opzioni: seleziona Nuova immagine e inserisci un ID che non è ancora in uso, oppure Sovrascrivi vecchia immagine e scegli un'immagine da sostituire dal menu. In genere, le nuove immagini Cloudmin utilizzano ID del tipo di formato - os - software, come Xen-CentOS5-lampada.
Descrizione per l'immagine
In questo campo è necessario inserire una descrizione leggibile dall'uomo, che appare quando si seleziona l'immagine al momento della creazione del sistema.
Numero della versione
Se nel tempo sono state create più immagini con lo stesso ID, questo campo opzionale può essere utilizzato per impostare un numero di versione per la nuova immagine. Se si eseguono più sistemi master Cloudmin e si copiano le immagini tra loro, una versione semplifica il monitoraggio delle modifiche alle immagini.
