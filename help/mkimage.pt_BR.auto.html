Criar imagem do sistema
Esta página permite criar uma nova imagem do sistema a partir de um sistema virtual existente gerenciado pelo Cloudmin. Todo o conteúdo do sistema de arquivos do sistema será congelado e copiado em um arquivo de imagem no sistema mestre Cloudmin. Você poderá criar novos sistemas virtuais do mesmo tipo instanciando a imagem criada.

Criar uma imagem é uma excelente maneira de clonar um sistema em funcionamento ou criar um modelo depois de instalar e configurar um sistema ao seu gosto. O Cloudmin limpará a senha raiz, as chaves SSH autorizadas e qualquer licença do Virtualmin do sistema de origem antes da criação de imagens e as definirá corretamente quando um novo sistema for criado a partir da imagem.

Como a criação de imagens exige que todo o sistema de arquivos da fonte seja copiado, o sistema de origem pode ser desligado durante o processo de criação de imagens. Depois de concluído, será reiniciado com todos os arquivos alterados restaurados ao seu estado original. Dependendo da velocidade da sua rede e do tamanho da imagem, o processo pode levar de 5 a 10 minutos.

Para criar uma imagem, os seguintes campos devem ser preenchidos:

ID exclusivo para imagem
Aqui você tem duas opções: selecione Nova imagem e insira um ID que ainda não esteja sendo usado ou Substituir imagem antiga e escolha uma imagem para substituir no menu. Normalmente, as novas imagens do Cloudmin usam IDs no tipo de formato - os - software , como xen-centos5-lamp .
Descrição da imagem
Nesse campo, você deve inserir uma descrição legível por humanos, que aparece quando você seleciona a imagem no momento da criação do sistema.
Número da versão
Se você criou várias imagens com o mesmo ID ao longo do tempo, esse campo opcional pode ser usado para definir um número de versão para a nova imagem. Se você estiver executando vários sistemas principais do Cloudmin e copiando imagens entre eles, uma versão facilita o controle das alterações de imagem.
