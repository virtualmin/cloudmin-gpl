Virtuelles System verschieben
Mit diesem Befehl können Sie eine Xen-Instanz oder ein anderes unterstütztes virtuelles System von einem Hosting-Server auf einen anderen übertragen. Dies kann nützlich sein, wenn der ursprüngliche Host überlastet wird und Sie ein neues Hostsystem online geschaltet haben, um einen Teil der Last zu übernehmen.

Während des Verschiebevorgangs wird das System im Allgemeinen vorübergehend heruntergefahren und ist nicht verfügbar. Alle Datendateien werden auf den von Ihnen ausgewählten neuen Host kopiert und anschließend das virtuelle System neu gestartet.

Derzeit wird die IP-Adresse des Systems während des Verschiebungsprozesses nicht geändert. Dies bedeutet, dass sich das neue Hostsystem im selben Subnetz wie das ursprüngliche befinden muss.
