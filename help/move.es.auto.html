Mover sistema virtual
Este comando le permite transferir una instancia de Xen u otro sistema virtual compatible de un servidor de alojamiento a otro. Puede ser útil si el host original se está sobrecargando, y usted ha puesto en línea un nuevo sistema host para tomar parte de la carga.

Durante el proceso de traslado, el sistema generalmente se apagará temporalmente y no estará disponible. Todos los archivos de datos se copiarán en el nuevo host que seleccione y luego se reiniciará el sistema virtual.

Actualmente, la dirección IP del sistema no cambia durante el proceso de traslado. Esto significa que el nuevo sistema host debe estar en la misma subred que el original.
