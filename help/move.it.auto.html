Sposta sistema virtuale
Questo comando consente di trasferire un'istanza Xen o un altro sistema virtuale supportato da un server di hosting a un altro. Può essere utile se l'host originale si sta sovraccaricando e hai portato un nuovo sistema host online per prendere parte del carico.

Durante il processo di spostamento, il sistema sarà generalmente spento temporaneamente e non disponibile. Tutti i file di dati verranno copiati nel nuovo host selezionato, quindi il sistema virtuale verrà riavviato.

Attualmente, l'indirizzo IP del sistema non viene modificato durante il processo di spostamento. Ciò significa che il nuovo sistema host deve trovarsi sulla stessa sottorete dell'originale.
