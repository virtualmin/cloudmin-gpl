Przenieś system wirtualny
To polecenie pozwala przenieść instancję Xen lub inny obsługiwany system wirtualny z jednego serwera hosta na inny. Może to być przydatne, jeśli oryginalny host jest przeciążony, a nowy system hosta został włączony do trybu online, aby przejąć część obciążenia.

Podczas procesu przenoszenia system będzie na ogół tymczasowo wyłączany i niedostępny. Wszystkie pliki danych zostaną skopiowane na nowy host, który wybierzesz, a następnie system wirtualny uruchomi się ponownie.

Obecnie adres IP systemu nie jest zmieniany podczas procesu przenoszenia. Oznacza to, że nowy system hosta musi znajdować się w tej samej podsieci co oryginał.
