Mover sistema virtual
Este comando permite transferir uma instância do Xen ou outro sistema virtual suportado de um servidor de hospedagem para outro. Pode ser útil se o host original estiver sobrecarregado e você tiver colocado um novo sistema host online para carregar parte da carga.

Durante o processo de movimentação, o sistema geralmente será temporariamente desligado e indisponível. Todos os arquivos de dados serão copiados para o novo host que você selecionar e, em seguida, o sistema virtual será reiniciado.

Atualmente, o endereço IP do sistema não é alterado durante o processo de movimentação. Isso significa que o novo sistema host deve estar na mesma sub-rede que o original.
