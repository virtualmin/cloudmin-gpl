Massen-Upload-Datei
Auf dieser Seite können Sie eine einzelne Datei auf mehreren von Cloudmin verwalteten Systemen gleichzeitig an dasselbe Ziel hochladen. Sie müssen zuerst die Originaldatei in der Quelldatei - Abschnitt wählen, die entweder vom PC kommen kann , auf dem Ihr Browser oder dem Cloudmin Master - System ausgeführt wird . Sie können dann den Zielpfad in das Feld Zieldatei oder Verzeichnis eingeben und auf die Schaltfläche Jetzt hochladen klicken.

Das Hochladen erfolgt parallel zu allen ausgewählten Systemen, daher sollte die Zeit bis zur Fertigstellung unabhängig von der ausgewählten Anzahl ungefähr konstant sein. Sobald alle Uploads abgeschlossen sind, zeigt Cloudmin die Ergebnisse der einzelnen Systeme an.
