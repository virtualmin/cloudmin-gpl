Fichier de téléchargement en masse
Cette page peut être utilisée pour télécharger un seul fichier vers la même destination sur plusieurs systèmes gérés Cloudmin à la fois. Vous devez d'abord sélectionner le fichier d'origine dans la section Fichier source , qui peut provenir soit du PC sur lequel votre navigateur s'exécute, soit du système maître Cloudmin. Vous pouvez ensuite entrer le chemin de destination dans le champ Fichier ou répertoire de destination et appuyer sur le bouton Télécharger maintenant .

Les téléchargements sont effectués en parallèle à tous les systèmes sélectionnés, donc le temps nécessaire pour terminer doit être à peu près constant quel que soit le nombre sélectionné. Une fois tous les téléchargements effectués, Cloudmin affichera les résultats de chaque système.
