Mass Upload File
This page can be used to upload a single file to the same destination on multiple Cloudmin managed systems at once. You must first select the original file in the Source file section, which can come either from the PC on which your browser is running, or the Cloudmin master system. You can then enter the destination path into the Destination file or directory field, and hit the Upload Now button.

Uploads are done in parallel to all selected systems, so the time to complete should be roughly constant regardless of the number selected. Once all uploads are done, Cloudmin will display the results from each system.
