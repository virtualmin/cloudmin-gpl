File di caricamento di massa
Questa pagina può essere utilizzata per caricare un singolo file nella stessa destinazione su più sistemi gestiti Cloudmin contemporaneamente. È necessario innanzitutto selezionare il file originale nella sezione File di origine , che può provenire dal PC su cui è in esecuzione il browser o dal sistema principale Cloudmin. È quindi possibile immettere il percorso di destinazione nel campo File o directory di destinazione e premere il pulsante Carica ora .

I caricamenti vengono eseguiti in parallelo a tutti i sistemi selezionati, quindi il tempo necessario per il completamento dovrebbe essere approssimativamente costante indipendentemente dal numero selezionato. Al termine di tutti i caricamenti, Cloudmin mostrerà i risultati di ciascun sistema.
