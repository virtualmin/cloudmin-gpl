Crear imagen EC2
Esta página se puede usar para crear un sistema virtual EC2 en ejecución en una imagen (también conocida como AMI), que luego se puede usar para crear nuevas instancias de EC2. Estas imágenes son similares a las utilizadas por Cloudmin para crear sistemas Xen y VServer, pero se almacenan en el servicio S3 de Amazon, en lugar de en su sistema maestro Cloudmin.

Para crear una imagen, debe completar los siguientes campos:

Cubo S3 para imagen
Un depósito es como un directorio en su almacenamiento S3. En este campo, debe ingresar un nombre corto como centos-virtualmin-custom , que se creará cuando se haga la imagen. Cada depósito solo puede ser usado por una sola imagen EC2.
Guardar bajo cuenta S3
Si tiene más de una cuenta EC2, seleccione la cuenta que se utilizará para almacenar y poseer la nueva imagen desde este menú.
Tamaño del sistema de archivos de imagen
Cuando se crea un sistema a partir de su nueva imagen, su sistema de archivos raíz tendrá el tamaño ingresado aquí, y no se puede expandir. El tamaño es una compensación entre la cantidad de espacio en disco que necesitará para alojar dominios en los sistemas virtuales y la cantidad que le cobra Amazon por almacenar la imagen en S3.
¿Hacer pública la imagen?
Si se selecciona Sí , cualquier persona que conozca su número de cuenta EC2 podrá utilizar la nueva imagen. Esto no es recomendable si está creando una imagen que contiene software comercial como Virtualmin Pro.
Cuando se hace clic en el botón Crear imagen , comenzará el proceso de hacer una imagen desde el sistema. No se cerrará durante la generación de imágenes, pero se recomienda que minimice el uso del sistema de origen para reducir el cambio de archivos en un estado inconsistente.
