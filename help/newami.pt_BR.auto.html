Criar imagem EC2
Essa página pode ser usada para criar um sistema virtual EC2 em execução em uma imagem (também conhecida como AMI), que pode ser usada para criar novas instâncias do EC2. Essas imagens são semelhantes às usadas pelo Cloudmin para criar sistemas Xen e VServer, mas são armazenadas no serviço S3 da Amazon, em vez de no seu sistema mestre Cloudmin.

Para criar uma imagem, você deve preencher os seguintes campos:

Balde S3 para imagem
Um bucket é como um diretório em seu armazenamento S3. Nesse campo, você deve inserir um nome abreviado como centos-virtualmin-custom , que será criado quando a imagem for criada. Cada bucket pode ser usado apenas por uma única imagem EC2.
Salvar na conta S3
Se você tiver mais de uma conta do EC2, selecione a conta que será usada para armazenar e possuir a nova imagem neste menu.
Tamanho do sistema de arquivos de imagem
Quando um sistema é criado a partir da sua nova imagem, o sistema de arquivos raiz terá o tamanho digitado aqui - e não poderá ser expandido. O tamanho é uma troca entre a quantidade de espaço em disco necessária para hospedar domínios nos sistemas virtuais e a quantia cobrada pela Amazon pelo armazenamento da imagem no S3.
Tornar a imagem disponível ao público?
Se Sim estiver selecionado, a nova imagem poderá ser usada por qualquer pessoa que saiba o número da sua conta EC2. Isso não é aconselhável se você estiver criando uma imagem que contenha software comercial como o Virtualmin Pro.
Quando o botão Criar imagem é clicado, o processo de criação de uma imagem do sistema será iniciado. Ele não será desligado durante a criação de imagens, mas é recomendável minimizar o uso do sistema de origem para reduzir a alteração de arquivos em um estado inconsistente.
