Создать изображение EC2
Эта страница может использоваться для создания работающей виртуальной системы EC2 в образе (также известном как AMI), который затем можно использовать для создания новых экземпляров EC2. Эти изображения аналогичны тем, которые используются Cloudmin для создания систем Xen и VServer, но хранятся в сервисе Amazon S3, а не в основной системе Cloudmin.

Чтобы создать изображение, необходимо заполнить следующие поля:

S3 ведро для изображения
Ведро похоже на каталог в вашем хранилище S3. В этом поле вы должны ввести короткое имя, например centos-virtualmin-custom , которое будет создано при создании изображения. Каждое ведро может использоваться только одним изображением EC2.
Сохранить под учетной записью S3
Если у вас есть более одной учетной записи EC2, выберите учетную запись, которая будет использоваться для хранения и владения новым изображением из этого меню.
Размер файловой системы изображения
Когда система создается из вашего нового образа, ее корневая файловая система будет иметь размер, указанный здесь - и не может быть расширена. Размер представляет собой компромисс между объемом дискового пространства, которое вам потребуется для размещения доменов в виртуальных системах, и суммой, которую вы взимаете с Amazon за хранение образа в S3.
Сделать изображение общедоступным?
Если выбрано «Да» , новое изображение будет доступно любому, кто знает номер вашей учетной записи EC2. Это не рекомендуется, если вы создаете образ, содержащий коммерческое программное обеспечение, такое как Virtualmin Pro.
При нажатии кнопки «Создать изображение» начнется процесс создания изображения из системы. Он не будет закрыт во время создания образа, но рекомендуется минимизировать использование исходной системы, чтобы уменьшить изменение файлов, находящихся в несогласованном состоянии.
