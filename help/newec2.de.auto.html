Neues System erstellen
Auf dieser Seite können Sie ein neues virtuelles System erstellen, das auf dem EC2-Dienst von Amazon ausgeführt wird. Im Gegensatz zu den anderen von Cloudmin unterstützten virtuellen Systemtypen wird es nicht auf einem Hostsystem erstellt, das Ihnen gehört, oder aus einem der lokal gespeicherten Images. Stattdessen wird es aus einem AMI (Amazon Machine Image) erstellt, das auf dem S3-Dienst gehostet wird.

Die Felder in diesem Formular, die zum Erstellen einer EC2-Instanz ausgefüllt werden müssen, sind:

Systembeschreibung
Eine kurze, für Menschen lesbare Beschreibung für dieses neue virtuelle System wie Webserver auf EC2 .
SSH-Schlüssel für root
Auf neue EC2-Instanzen kann immer nur über einen SSH-Schlüssel und nicht über ein Kennwort zugegriffen werden. In diesem Menü müssen Sie einen Schlüssel auswählen, der bei Cloudmin und bei EC2 registriert wurde.
Erstellen von Virtualmin-Domänen zulassen?
Diese Einstellung bestimmt, ob dem neu erstellten System Virtualmin-Domänen hinzugefügt werden können. Normalerweise möchten Sie dieses Set auf Ja belassen .
Virtualmin-Pakete aktualisieren?
Wenn dies auf Ja gesetzt ist (wie standardmäßig) und Sie ein System aus einem AMI erstellen, das Virtualmin Pro enthält, werden alle von Virtualmin verwendeten Pakete nach Abschluss der Erstellung auf die neuesten verfügbaren Versionen aktualisiert.
EC2-Konto
Wenn Sie mehrere EC2-Konten bei Cloudmin registriert haben, müssen Sie in diesem Menü das Konto auswählen, dem diese neue Instanz gehört.
EC2-Image zum Starten
In diesem Menü werden alle EC2-Bilder (oder AMIs) aufgelistet, die Ihnen zur Verfügung stehen. Die Standardeinstellung ist ein Image, das den vollständigen Virtualmin-Stack enthält. Sie können jedoch auch Images mit verschiedenen Linux-Distributionen auswählen, die von Amazon und anderen Anbietern bereitgestellt werden.
EC2-Instanzgröße
Amazon bietet verschiedene virtuelle Systemtypen für EC2-Instanzen mit unterschiedlicher CPU-Geschwindigkeit, verfügbarem Speicher und Speicherplatz an. Die großen und extragroßen Größen können nur mit 64-Bit-Bildern verwendet werden und kosten mehr pro Instanzstunde als die kleinen Größen.
EC2-Sicherheitsgruppen
Jede EC2-Instanz kann Mitglied einer oder mehrerer Sicherheitsgruppen sein, die die Ports und Hosts bestimmen, die eine Verbindung zu ihr herstellen dürfen. Wenn Standard ausgewählt ist, wird die von Cloudmin erstellte virtualmin- Gruppe verwendet - oder Sie können unten Ausgewählt auswählen und die Kontrollkästchen neben einer oder mehreren Ihrer eigenen Gruppen aktivieren.
Wenn Sie auf die Schaltfläche Erstellen klicken, kontaktiert Cloudmin Amazon, um den Erstellungsprozess zu starten. Dies kann je nach Bildgröße zwischen 5 und 10 Minuten dauern. Der DNS-Hostname des neu erstellten Systems wird von Amazon zugewiesen, kann jedoch später geändert werden, sobald Sie Ihrer eigenen DNS-Domäne einen Eintrag für dieselbe IP-Adresse hinzugefügt haben.
