Crear nuevo sistema
Esta página le permite crear un nuevo sistema virtual que se ejecuta en el servicio EC2 de Amazon. A diferencia de los otros tipos de sistemas virtuales admitidos por Cloudmin, no se crea en un sistema host propiedad de usted o de una de las imágenes almacenadas localmente, sino que se crea a partir de un AMI (Amazon Machine Image) alojado en el servicio S3.

Los campos en este formulario que deben completarse para crear una instancia EC2 son:

Descripción del sistema
Una breve descripción legible por humanos para este nuevo sistema virtual, como Webserver en EC2 .
Clave SSH para root
Siempre se puede acceder a las nuevas instancias EC2 a través de una clave SSH, en lugar de con una contraseña. En este menú, debe seleccionar una clave que se haya registrado con Cloudmin y con EC2.
¿Permitir la creación de dominios de Virtualmin?
Esta configuración determina si el sistema recién creado puede tener dominios de Virtualmin agregados. Por lo general, querrá dejar este conjunto en Sí .
¿Actualizar paquetes de Virtualmin?
Cuando se establece en Sí (como lo está por defecto) y está creando un sistema a partir de un AMI que incluye Virtualmin Pro, todos los paquetes utilizados por Virtualmin se actualizarán a las últimas versiones disponibles una vez que se complete la creación.
Cuenta EC2
Si tiene varias cuentas EC2 registradas en Cloudmin, debe seleccionar la que será propietaria de esta nueva instancia desde este menú.
Imagen EC2 para comenzar
Este menú enumera todas las imágenes EC2 (o AMI) que están disponibles para usted. El valor predeterminado será una imagen que contiene la pila completa de Virtualmin, pero también puede elegir imágenes con varias distribuciones de Linux proporcionadas por Amazon y otros proveedores.
Tamaño de instancia EC2
Amazon ofrece varios tipos de sistemas virtuales diferentes para instancias EC2, con velocidad de CPU variable, memoria disponible y espacio en disco. Los tamaños grandes y extragrandes solo se pueden usar con imágenes de 64 bits y cuestan más por hora hora que el tamaño pequeño.
Grupos de seguridad EC2
Cada instancia de EC2 puede ser miembro de uno o más grupos de seguridad, que determinan los puertos y hosts a los que se les permite conectarse. Si se selecciona Predeterminado, se usará el grupo virtualmin creado por Cloudmin, o puede elegir Seleccionado a continuación y marcar las casillas junto a uno o más de sus propios grupos.
Cuando se hace clic en el botón Crear , Cloudmin se pondrá en contacto con Amazon para iniciar el proceso de creación. Dependiendo del tamaño de la imagen, esto puede tomar entre 5 y 10 minutos. Amazon asigna el nombre de host DNS del sistema recién creado, pero se puede cambiar más adelante una vez que haya agregado una entrada para la misma dirección IP a su propio dominio DNS.
