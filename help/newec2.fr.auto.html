Créer un nouveau système
Cette page vous permet de créer un nouveau système virtuel fonctionnant sur le service EC2 d'Amazon. Contrairement aux autres types de systèmes virtuels pris en charge par Cloudmin, il n'est pas créé sur un système hôte appartenant à vous ou à partir d'une des images stockées localement - au lieu de cela, il est créé à partir d'une AMI (Amazon Machine Image) hébergée sur le service S3.

Les champs de ce formulaire qui doivent être remplis pour créer une instance EC2 sont:

Description du système
Une courte description lisible par l'homme pour ce nouveau système virtuel, comme Webserver sur EC2 .
Clé SSH pour root
Les nouvelles instances EC2 ne sont toujours accessibles que via une clé SSH, plutôt qu'avec un mot de passe. Dans ce menu, vous devez sélectionner une clé qui a été enregistrée avec Cloudmin et avec EC2.
Autoriser la création de domaines Virtualmin?
Ce paramètre détermine si le système nouvellement créé peut avoir des domaines Virtualmin ajoutés. En règle générale, vous souhaiterez laisser cet ensemble à Oui .
Mettre à jour les packages Virtualmin?
Lorsque ce paramètre est défini sur Oui (comme c'est le cas par défaut) et que vous créez un système à partir d'une AMI qui inclut Virtualmin Pro, tous les packages utilisés par Virtualmin seront mis à jour vers les dernières versions disponibles une fois la création terminée.
Compte EC2
Si vous avez plusieurs comptes EC2 enregistrés auprès de Cloudmin, vous devez sélectionner celui qui possédera cette nouvelle instance dans ce menu.
Image EC2 pour démarrer
Ce menu répertorie toutes les images EC2 (ou AMI) dont vous disposez. La valeur par défaut sera une image contenant la pile Virtualmin complète, mais vous pouvez également choisir des images avec diverses distributions Linux fournies par Amazon et d'autres fournisseurs.
Taille d'instance EC2
Amazon propose plusieurs types de systèmes virtuels différents pour les instances EC2, avec une vitesse de processeur, une mémoire disponible et un espace disque variables. Les tailles grandes et très grandes ne peuvent être utilisées qu'avec des images 64 bits et coûtent plus cher par heure d'instance que la petite taille.
Groupes de sécurité EC2
Chaque instance EC2 peut être membre d'un ou plusieurs groupes de sécurité, qui déterminent les ports et les hôtes autorisés à s'y connecter. Si Par défaut est sélectionné, le groupe virtualmin créé par Cloudmin sera utilisé - ou vous pouvez choisir Sélectionné ci - dessous et cocher les cases à côté d'un ou plusieurs de vos propres groupes.
Lorsque le bouton Créer est cliqué, Cloudmin contactera Amazon pour démarrer le processus de création. Selon la taille de l'image, cela peut prendre entre 5 et 10 minutes. Le nom d'hôte DNS du système nouvellement créé est attribué par Amazon, mais peut être modifié ultérieurement une fois que vous avez ajouté une entrée pour la même adresse IP à votre propre domaine DNS.
