Criar novo sistema
Esta página permite criar um novo sistema virtual em execução no serviço EC2 da Amazon. Ao contrário dos outros tipos de sistemas virtuais suportados pelo Cloudmin, ele não é criado em um sistema host de sua propriedade ou de uma das imagens armazenadas localmente; em vez disso, é criado a partir de uma AMI (Amazon Machine Image) hospedada no serviço S3.

Os campos deste formulário que precisam ser preenchidos para criar uma instância do EC2 são:

Descrição do sistema
Uma breve descrição legível por humanos para este novo sistema virtual, como Webserver no EC2 .
Chave SSH para raiz
Novas instâncias do EC2 sempre são acessíveis apenas por uma chave SSH, e não por uma senha. Nesse menu, você deve selecionar uma chave que foi registrada no Cloudmin e no EC2.
Permitir a criação de domínios do Virtualmin?
Essa configuração determina se o sistema recém-criado pode ter domínios do Virtualmin adicionados a ele. Normalmente, você deseja deixar esse conjunto como Sim .
Atualizar pacotes do Virtualmin?
Quando estiver definido como Sim (como é o padrão) e você estiver criando um sistema a partir de uma AMI que inclua o Virtualmin Pro, todos os pacotes usados pelo Virtualmin serão atualizados para as últimas versões disponíveis após a conclusão da criação.
Conta EC2
Se você tiver várias contas EC2 registradas no Cloudmin, deverá selecionar a que possuir esta nova instância neste menu.
Imagem EC2 para iniciar
Este menu lista todas as imagens EC2 (ou AMIs) disponíveis para você. O padrão será uma imagem contendo a pilha Virtualmin completa, mas você também pode escolher imagens com várias distribuições Linux fornecidas pela Amazon e outros fornecedores.
Tamanho da instância do EC2
A Amazon oferece vários tipos diferentes de sistemas virtuais para instâncias do EC2, com velocidade variável da CPU, memória disponível e espaço em disco. Os tamanhos grande e extra grande só podem ser usados com imagens de 64 bits e custam mais por instância-hora que o tamanho pequeno.
Grupos de segurança EC2
Cada instância do EC2 pode ser membro de um ou mais grupos de segurança, que determinam as portas e os hosts com permissão para se conectar a ela. Se Padrão for selecionado, o grupo virtualmin criado pelo Cloudmin será usado - ou você pode escolher Selecionado abaixo e marcar as caixas ao lado de um ou mais de seus próprios grupos.
Quando o botão Criar é clicado, o Cloudmin entra em contato com a Amazon para iniciar o processo de criação. Dependendo do tamanho da imagem, isso pode levar entre 5 e 10 minutos. O nome do host DNS do sistema recém-criado é atribuído pela Amazon, mas pode ser alterado posteriormente depois de adicionar uma entrada para o mesmo endereço IP ao seu próprio domínio DNS.
