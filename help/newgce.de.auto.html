Neues System erstellen
Auf dieser Seite können Sie ein neues virtuelles System erstellen, das auf dem GCE-Dienst von Google ausgeführt wird. Im Gegensatz zu den anderen von Cloudmin unterstützten virtuellen Systemtypen wird es nicht auf einem Hostsystem erstellt, das Ihnen gehört, oder aus einem der lokal gespeicherten Bilder. Stattdessen wird es aus einem von Google oder Ihnen selbst bereitgestellten Bild erstellt.

Die Felder in diesem Formular, die zum Erstellen einer GCE-Instanz ausgefüllt werden müssen, sind:

Internet-Hostname
Der Hostname, der von dieser Instanz verwendet wird, z . B. mymachine .
Systembeschreibung
Eine kurze, für Menschen lesbare Beschreibung für dieses neue virtuelle System wie Webserver auf GCE .
SSH-Schlüssel für root
Auf neue GCE-Instanzen kann immer nur über einen SSH-Schlüssel und nicht über ein Kennwort zugegriffen werden.
Erstellen von Virtualmin-Domänen zulassen?
Diese Einstellung bestimmt, ob dem neu erstellten System Virtualmin-Domänen hinzugefügt werden können. Normalerweise möchten Sie dieses Set auf Ja belassen .
Virtualmin-Pakete aktualisieren?
Wenn dies auf Ja gesetzt ist (wie standardmäßig) und Sie ein System aus einem AMI erstellen, das Virtualmin Pro enthält, werden alle von Virtualmin verwendeten Pakete nach Abschluss der Erstellung auf die neuesten verfügbaren Versionen aktualisiert.
GCE-Projekt
Wenn Sie mehrere GCE-Projekte bei Cloudmin registriert haben, müssen Sie in diesem Menü das auswählen, dem diese neue Instanz gehört.
GCE-Systemabbild
In diesem Menü werden alle von Ihnen erstellten GCE-Images sowie die von Google bereitgestellten öffentlichen Linux-Images aufgelistet.
GCE-Instanzgröße
Die Größe einer Instanz bestimmt, wie viel RAM, CPU und lokale Festplatte verfügbar sind. Die Ausführung größerer Instanzen kostet mehr pro Stunde.
Wenn Sie auf die Schaltfläche Erstellen klicken, ruft Cloudmin die GCE-API auf, um den Erstellungsprozess zu starten. Dies kann je nach Bildgröße zwischen 1 und 5 Minuten dauern. Der Hostname des neu erstellten Systems ist nur die von Google zugewiesene IP-Adresse. Er kann jedoch später geändert werden, sobald Sie Ihrer eigenen DNS-Domain einen Eintrag für dieselbe IP-Adresse hinzugefügt haben.
