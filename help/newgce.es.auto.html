Crear nuevo sistema
Esta página le permite crear un nuevo sistema virtual que se ejecuta en el servicio GCE de Google. A diferencia de los otros tipos de sistemas virtuales admitidos por Cloudmin, no se crea en un sistema host propiedad de usted o de una de las imágenes almacenadas localmente, sino que se crea a partir de una imagen proporcionada por Google o usted mismo.

Los campos en este formulario que deben completarse para crear una instancia de GCE son:

Nombre de host de Internet
El nombre de host que utilizará esta instancia, como mymachine .
Descripción del sistema
Una breve descripción legible para humanos de este nuevo sistema virtual, como Webserver en GCE .
Clave SSH para root
Las nuevas instancias de GCE siempre son accesibles solo a través de una clave SSH, en lugar de con una contraseña.
¿Permitir la creación de dominios de Virtualmin?
Esta configuración determina si el sistema recién creado puede tener dominios de Virtualmin agregados. Por lo general, querrá dejar este conjunto en Sí .
¿Actualizar paquetes de Virtualmin?
Cuando se establece en Sí (como lo está por defecto) y está creando un sistema a partir de un AMI que incluye Virtualmin Pro, todos los paquetes utilizados por Virtualmin se actualizarán a las últimas versiones disponibles una vez que se complete la creación.
Proyecto CME
Si tiene varios proyectos GCE registrados en Cloudmin, debe seleccionar el que será el propietario de esta nueva instancia desde este menú.
Imagen del sistema GCE
Este menú enumera todas las imágenes GCE que ha creado y las imágenes públicas de Linux proporcionadas por Google.
Tamaño de instancia de la CME
El tamaño de una instancia determina la cantidad de RAM, CPU y disco local que tiene disponible. Las instancias más grandes cuestan más por hora de ejecución.
Cuando se hace clic en el botón Crear , Cloudmin llamará a la API de GCE para comenzar el proceso de creación. Dependiendo del tamaño de la imagen, esto puede tomar entre 1 y 5 minutos. El nombre de host del sistema recién creado será solo la IP asignada por Google, pero puede cambiarse más tarde una vez que haya agregado una entrada para la misma dirección IP a su propio dominio DNS.
