Créer un nouveau système
Cette page vous permet de créer un nouveau système virtuel fonctionnant sur le service GCE de Google. Contrairement aux autres types de systèmes virtuels pris en charge par Cloudmin, il n'est pas créé sur un système hôte appartenant à vous ou à partir d'une des images stockées localement - au lieu de cela, il est créé à partir d'une image fournie par Google ou vous-même.

Les champs de ce formulaire qui doivent être remplis pour créer une instance GCE sont:

Nom d'hôte Internet
Le nom d'hôte qui sera utilisé par cette instance, comme mymachine .
Description du système
Une courte description lisible par l'homme pour ce nouveau système virtuel, comme Webserver sur GCE .
Clé SSH pour root
Les nouvelles instances GCE ne sont toujours accessibles que via une clé SSH, plutôt qu'avec un mot de passe.
Autoriser la création de domaines Virtualmin?
Ce paramètre détermine si le système nouvellement créé peut avoir des domaines Virtualmin ajoutés. En règle générale, vous souhaiterez laisser cet ensemble à Oui .
Mettre à jour les packages Virtualmin?
Lorsque ce paramètre est défini sur Oui (comme c'est le cas par défaut) et que vous créez un système à partir d'une AMI qui inclut Virtualmin Pro, tous les packages utilisés par Virtualmin seront mis à jour vers les dernières versions disponibles une fois la création terminée.
Projet GCE
Si vous avez plusieurs projets GCE enregistrés auprès de Cloudmin, vous devez sélectionner celui qui possédera cette nouvelle instance dans ce menu.
Image du système GCE
Ce menu répertorie toutes les images GCE que vous avez créées et les images Linux publiques fournies par Google.
Taille d'instance GCE
La taille d'une instance détermine la quantité de RAM, de CPU et de disque local dont elle dispose. Les instances plus volumineuses coûtent plus cher par heure.
Lorsque le bouton Créer est cliqué, Cloudmin appellera l'API GCE pour démarrer le processus de création. Selon la taille de l'image, cela peut prendre entre 1 et 5 minutes. Le nom d'hôte du système nouvellement créé sera uniquement l'IP attribué par Google, mais peut être modifié plus tard une fois que vous avez ajouté une entrée pour la même adresse IP à votre propre domaine DNS.
