Criar novo sistema
Esta página permite criar um novo sistema virtual em execução no serviço GCE do Google. Ao contrário dos outros tipos de sistemas virtuais suportados pelo Cloudmin, ele não é criado em um sistema host de sua propriedade ou de uma das imagens armazenadas localmente; em vez disso, é criado a partir de uma imagem fornecida pelo Google ou por você.

Os campos deste formulário que precisam ser preenchidos para criar uma instância do GCE são:

Nome do host da Internet
O nome do host que será usado por esta instância, como mymachine .
Descrição do sistema
Uma breve descrição legível por humanos para este novo sistema virtual, como Webserver no GCE .
Chave SSH para raiz
As novas instâncias do GCE sempre são acessíveis apenas por uma chave SSH, e não por uma senha.
Permitir a criação de domínios do Virtualmin?
Essa configuração determina se o sistema recém-criado pode ter domínios do Virtualmin adicionados a ele. Normalmente, você deseja deixar esse conjunto como Sim .
Atualizar pacotes do Virtualmin?
Quando estiver definido como Sim (como é o padrão) e você estiver criando um sistema a partir de uma AMI que inclua o Virtualmin Pro, todos os pacotes usados pelo Virtualmin serão atualizados para as últimas versões disponíveis após a conclusão da criação.
Projeto GCE
Se você tiver vários projetos GCE registrados no Cloudmin, deverá selecionar o que será o proprietário dessa nova instância neste menu.
Imagem do sistema GCE
Este menu lista todas as imagens GCE que você criou e imagens públicas do Linux fornecidas pelo Google.
Tamanho da instância GCE
O tamanho de uma instância determina a quantidade de RAM, CPU e disco local disponível. Instâncias maiores custam mais por hora de execução.
Quando o botão Criar é clicado, o Cloudmin chama a API do GCE para iniciar o processo de criação. Dependendo do tamanho da imagem, isso pode levar entre 1 e 5 minutos. O nome do host do sistema recém-criado será apenas o IP atribuído pelo Google, mas poderá ser alterado posteriormente depois de adicionar uma entrada para o mesmo endereço IP ao seu próprio domínio DNS.
