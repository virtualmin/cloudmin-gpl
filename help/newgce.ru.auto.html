Создать новую систему
Эта страница позволяет вам создать новую виртуальную систему, работающую на службе Google GCE. В отличие от других типов виртуальных систем, поддерживаемых Cloudmin, он не создается на хост-системе, принадлежащей вам, или на одном из локально сохраненных образов - вместо этого он создается на основе изображения, предоставленного Google или вами.

Поля в этой форме, которые необходимо заполнить для создания экземпляра GCE:

Интернет-хост
Имя хоста, которое будет использоваться этим экземпляром, например, mymachine .
Описание системы
Краткое удобочитаемое описание для этой новой виртуальной системы, такой как Webserver на GCE .
SSH ключ для root
Новые экземпляры GCE всегда доступны только через ключ SSH, а не через пароль.
Разрешить создание доменов Virtualmin?
Этот параметр определяет, могут ли новые создаваемые системы добавлять к нему домены Virtualmin. Обычно вы хотите оставить этот набор на Да .
Обновить пакеты Virtualmin?
Если для этого параметра установлено значение Да (как по умолчанию), и вы создаете систему из AMI, которая включает Virtualmin Pro, все пакеты, используемые Virtualmin, будут обновлены до последних доступных версий после завершения создания.
Проект GCE
Если у вас есть несколько проектов GCE, зарегистрированных с Cloudmin, вы должны выбрать тот, который будет владельцем этого нового экземпляра из этого меню.
Образ системы GCE
В этом меню перечислены все созданные вами изображения GCE, а также общедоступные образы Linux, предоставленные Google.
Размер экземпляра GCE
Размер экземпляра определяет, сколько оперативной памяти, процессора и локального диска у него есть. Большие экземпляры стоят больше в час, чтобы бежать.
При нажатии кнопки «Создать» Cloudmin вызывает GCE API для запуска процесса создания. В зависимости от размера изображения это может занять от 1 до 5 минут. В качестве имени хоста вновь созданной системы будет использоваться только IP-адрес, назначенный Google, но его можно изменить позже, когда вы добавите запись для того же IP-адреса в свой собственный домен DNS.
