Neue KVM-Instanz erstellen
Auf dieser Seite können Sie ein neues virtuelles System erstellen, das in einer KVM-Instanz ausgeführt wird. Da Cloudmin immer neue KVM-Systeme aus Images erstellt, müssen Sie mindestens ein Image über die Seite New System Images heruntergeladen haben, bevor eine Instanz erstellt werden kann.

Die Felder in diesem Formular, die zum Erstellen einer KVM-Instanz ausgefüllt werden müssen, sind:

Systemhostname
Dies muss der Name der neu zu erstellenden KVM-Instanz sein, die keinen Domänennamen enthalten darf. Geeignete Instanznamen sind wie centos1 oder xen-foocorp . Beim endgültigen Hostnamen der Instanz wird der DNS-Domänenname für das angehängte Hostsystem ausgewählt.
Systembeschreibung
Eine kurze, für Menschen lesbare Beschreibung für dieses neue virtuelle System wie Webserver for Foo Corp.
Erstes Systemabbild
In diesem Menü müssen Sie das KVM-Betriebssystem-Image auswählen, mit dem Sie das neue System starten möchten. Cloudmin bietet zwei Arten von Images - Basisbetriebssysteme und vollständige Stapel mit Virtualmin. In den meisten Fällen möchten Sie Letzteres auswählen.
Root-Anmeldemodus
In diesem Feld können Sie das Anfangskennwort für die neue KVM-Instanz festlegen. In der Regel wählen Sie Kennwort verwenden aus und geben ein Kennwort in das nebenstehende Textfeld ein, das dann an jeden weitergegeben werden kann, der den Server verwaltet. Alternativ können Sie , wenn Sie irgendwelche SSH - Schlüssel registriert mit Cloudmin haben wählen Sie SSH - Schlüssel verwenden und einen Schlüssel aus dem Menü wählen , daneben. Sobald die Instanz erstellt wurde, wird sie so konfiguriert, dass mit diesem Schlüssel kennwortlose Anmeldungen möglich sind.
Erstellen von Virtualmin-Domänen zulassen?
Diese Einstellung bestimmt, ob dem neu erstellten System Virtualmin-Domänen hinzugefügt werden können. Normalerweise möchten Sie dieses Set auf Ja belassen .
Virtualmin-Pakete aktualisieren?
Wenn dies auf Ja gesetzt ist (wie standardmäßig) und Sie ein System aus einem Image erstellen, das Virtualmin Pro enthält, werden alle von Virtualmin verwendeten Pakete nach Abschluss der Erstellung auf die neuesten verfügbaren Versionen aktualisiert.
KVM-Hosting-System
In diesem Menü müssen Sie das physische System auswählen, auf dem die KVM-Instanz erstellt werden soll.
IP-Adresse für die KVM-Instanz
Jedes neue KVM-System erhält eine private IP-Adresse, die entweder automatisch aus dem für das Hostsystem definierten Bereich zugewiesen oder manuell durch Auswahl der Option Adresse eingegeben werden kann.
Wenn der Cloudmin-Master einen DNS-Server ausführt (dringend empfohlen), wird der für das KVM-Hostsystem ausgewählten DNS-Zone ein Eintrag für den vollständigen Hostnamen und die IP-Adresse der KVM-Instanz hinzugefügt.
Der Instanz zugewiesener Speicher
KVM-Instanzen haben eine feste Obergrenze für die Menge an Speicher, die sie verwenden können, was durch diese Option gesteuert wird. 256 ist das Minimum für ein Web-Webhosting-System mit Virtualmin, aber 512 wird empfohlen.
Tauschen Sie beispielsweise die Dateigröße aus
Standardmäßig erstellt Cloudmin KVM-Instanzen mit regelmäßig zugewiesenem Speicher, jedoch ohne Swap-Speicherplatz. Sie können hier jedoch das zweite Optionsfeld auswählen und die Menge des (virtuellen) Swap-Speichers in MB eingeben, damit Prozesse in der Instanz auf Kosten der Leistung mehr als den zugewiesenen RAM verwenden können. Da der Auslagerungsspeicher in einer Datei auf dem Hostsystem derselben Größe gespeichert ist, empfiehlt es sich, diesen auf das Doppelte des regulären Speichers zu beschränken.
Der Instanz zugewiesener Speicherplatz
Im Gegensatz zu einigen anderen Typen virtueller Maschinen speichert KVM das Dateisystem jeder Instanz in einer einzelnen Datei auf dem Host, bei der es sich um ein Disk-Image im EXT3-Format handelt. Die Größe des Dateisystems innerhalb der Instanz ist daher auf die Größe des Festplattenabbilds beschränkt.
Standardmäßig hängt die Größe der Festplattendatei vom ausgewählten Systemabbild ab. Alle Images, die den vollständigen Virtualmin-Stack enthalten, haben 2 GB, während diejenigen mit nur dem Basisbetriebssystem 1 GB haben. Da dies für ein System, das mehrere Websites hostet, möglicherweise nicht ausreicht, können Sie mit dieser Option eine größere Größe in MB eingeben, und das Festplatten-Image wird während des Instanzerstellungsprozesses auf diese Größe vergrößert.
Wenn Sie auf die Schaltfläche Erstellen klicken, startet Cloudmin den KVM-Setup-Prozess. Bei jedem Schritt werden Statusmeldungen angezeigt. Die Gesamtzeit hängt von der Größe des Images, der Geschwindigkeit des Hostsystems und der Geschwindigkeit des Netzwerks zwischen dem Host und dem Cloudmin-Master ab. Der Durchschnitt liegt jedoch bei etwa fünf Minuten.
