Lizenz für Virtualmin vom Image
Wenn Sie ein System aus einem Image mit installiertem Virtualmin Pro erstellen, müssen Sie in diesem Abschnitt eine Lizenz auswählen. Die möglichen Optionen sind:
  • Virtualmin ist nicht installiert
    Wählen Sie diese Option, wenn das Image Virtualmin überhaupt nicht enthält oder wenn es bereits eine gültige Seriennummer und einen gültigen Schlüssel im Dateisystem des Images hat.
  • Seriennummer und Schlüssel
    Mit dieser Option können Sie eine von Virtualmin gekaufte Lizenzserie und einen Schlüssel manuell eingeben.
  • Entspricht der Cloudmin-Lizenz
    Wenn Ihr Cloudmin-Abonnement eine Virtualmin-Lizenz enthält, verwenden Sie diese Option, um sie für das neue System zu verwenden.
  • Zuweisen aus Lizenzpool
    Wenn Sie auf der Seite Virtualmin-Lizenzen einige Seriennummern und Schlüssel registriert haben, wählen Sie diese Option aus, damit Cloudmin die erste Lizenz mit mindestens einem freien System auswählt.
Wenn das Image kein Virtualmin Pro enthält oder Sie nicht aus einem Image erstellen, spielt es keine Rolle, was Sie hier auswählen.
