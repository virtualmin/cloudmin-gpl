License for Virtualmin from image
If creating a system from an image with Virtualmin Pro installed, you must use this section to select a license. The possible options are :
  • Virtualmin is not installed
    Select this if the image does not contain Virtualmin at all, or if it already has a valid serial number and key in the image's filesystem.
  • Serial number and key
    This option can be used to manually enter a licence serial and key purchased from Virtualmin.
  • Same as VM2 license
    If your VM2 subscription includes a Virtualmin license, use this option to make use of it for the new system.
  • Allocate from licence pool
    If you have registered some serial numbers and keys on the Virtualmin Licences page, select this option to have VM2 choose the first licence with at least one free system.
If the image does not contain Virtualmin Pro or you are not creating from an image, it doesn't matter what you select here.
