Licencia para Virtualmin de imagen
Si crea un sistema a partir de una imagen con Virtualmin Pro instalado, debe usar esta sección para seleccionar una licencia. Las posibles opciones son:
  • Virtualmin no está instalado
    Seleccione esto si la imagen no contiene Virtualmin en absoluto, o si ya tiene un número de serie válido e ingrese el sistema de archivos de la imagen.
  • Número de serie y clave
    Esta opción se puede usar para ingresar manualmente una serie de licencia y una clave comprada en Virtualmin.
  • Igual que la licencia de Cloudmin
    Si su suscripción a Cloudmin incluye una licencia de Virtualmin, use esta opción para usarla para el nuevo sistema.
  • Asignar del grupo de licencias
    Si ha registrado algunos números de serie y claves en la página de Licencias de Virtualmin, seleccione esta opción para que Cloudmin elija la primera licencia con al menos un sistema libre.
Si la imagen no contiene Virtualmin Pro o no está creando a partir de una imagen, no importa lo que seleccione aquí.
