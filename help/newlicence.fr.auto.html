Licence pour Virtualmin à partir de l'image
Si vous créez un système à partir d'une image avec Virtualmin Pro installé, vous devez utiliser cette section pour sélectionner une licence. Les options possibles sont:
  • Virtualmin n'est pas installé
    Sélectionnez cette option si l'image ne contient pas du tout Virtualmin ou si elle possède déjà un numéro de série valide et saisissez le système de fichiers de l'image.
  • Numéro de série et clé
    Cette option peut être utilisée pour saisir manuellement une licence de série et une clé achetées auprès de Virtualmin.
  • Identique à la licence Cloudmin
    Si votre abonnement Cloudmin comprend une licence Virtualmin, utilisez cette option pour l'utiliser pour le nouveau système.
  • Allouer à partir du pool de licences
    Si vous avez enregistré des numéros de série et des clés sur la page Licences Virtualmin, sélectionnez cette option pour que Cloudmin choisisse la première licence avec au moins un système gratuit.
Si l'image ne contient pas Virtualmin Pro ou si vous ne créez pas à partir d'une image, peu importe ce que vous sélectionnez ici.
