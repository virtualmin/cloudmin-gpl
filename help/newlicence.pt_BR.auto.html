Licença para Virtualmin a partir da imagem
Se você estiver criando um sistema a partir de uma imagem com o Virtualmin Pro instalado, use esta seção para selecionar uma licença. As opções possíveis são:
  • Virtualmin não está instalado
    Selecione isso se a imagem não contiver o Virtualmin, ou se já tiver um número de série válido e digite o sistema de arquivos da imagem.
  • Número de série e chave
    Esta opção pode ser usada para inserir manualmente um serial e uma chave de licença adquiridos no Virtualmin.
  • Igual à licença Cloudmin
    Se sua assinatura do Cloudmin incluir uma licença do Virtualmin, use esta opção para usá-la no novo sistema.
  • Alocar do pool de licenças
    Se você registrou alguns números de série e chaves na página Licenças do Virtualmin, selecione esta opção para que o Cloudmin escolha a primeira licença com pelo menos um sistema gratuito.
Se a imagem não contiver o Virtualmin Pro ou você não estiver criando a partir de uma imagem, não importa o que você selecionar aqui.
