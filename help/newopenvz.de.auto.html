Erstellen Sie ein neues OpenVZ-System
Auf dieser Seite können Sie ein neues virtuelles System erstellen, das in einem OpenVZ-Container ausgeführt wird. Da Cloudmin OpenVZ-Systeme normalerweise aus Images erstellt, müssen Sie mindestens ein Image über die Seite Neue System-Images heruntergeladen haben, bevor eine Instanz erstellt werden kann.

Die Felder in diesem Formular, die zum Erstellen einer Xen-Instanz ausgefüllt werden müssen, sind:

Systemhostname
Dies muss der Name des neu zu erstellenden Containers sein, der keinen Domänennamen enthalten darf. Geeignete Instanznamen sind wie centos1 oder xen-foocorp . Beim endgültigen Hostnamen der Instanz wird der DNS-Domänenname für das angehängte Hostsystem ausgewählt.
Systembeschreibung
Eine kurze, für Menschen lesbare Beschreibung für dieses neue virtuelle System wie Webserver for Foo Corp.
Erstes Systemabbild
In diesem Menü müssen Sie das OpenVZ-Betriebssystem-Image auswählen, mit dem Sie das neue System starten möchten. Cloudmin bietet zwei Arten von Images - Basisbetriebssysteme und vollständige Stapel mit Virtualmin. In den meisten Fällen möchten Sie Letzteres auswählen.
Root-Anmeldemodus
In diesem Feld können Sie das anfängliche Kennwort für die neue OpenVZ-Instanz festlegen. In der Regel wählen Sie Kennwort verwenden aus und geben ein Kennwort in das nebenstehende Textfeld ein, das dann an jeden weitergegeben werden kann, der den Server verwaltet. Alternativ können Sie , wenn Sie irgendwelche SSH - Schlüssel registriert mit Cloudmin haben wählen Sie SSH - Schlüssel verwenden und einen Schlüssel aus dem Menü wählen , daneben. Sobald die Instanz erstellt wurde, wird sie so konfiguriert, dass mit diesem Schlüssel kennwortlose Anmeldungen möglich sind.
Erstellen von Virtualmin-Domänen zulassen?
Diese Einstellung bestimmt, ob dem neu erstellten System Virtualmin-Domänen hinzugefügt werden können. Normalerweise möchten Sie dieses Set auf Ja belassen .
Virtualmin-Pakete aktualisieren?
Wenn dies auf Ja gesetzt ist (wie standardmäßig) und Sie ein System aus einem Image erstellen, das Virtualmin Pro enthält, werden alle von Virtualmin verwendeten Pakete nach Abschluss der Erstellung auf die neuesten verfügbaren Versionen aktualisiert.
OpenVZ-Hosting-System
In diesem Menü müssen Sie das physische System auswählen, auf dem die OpenVZ-Instanz erstellt werden soll.
IP-Adresse für die OpenVZ-Instanz
Jedes neue OpenVZ-System erhält eine private IP-Adresse, die entweder automatisch aus dem für das Hostsystem definierten Bereich zugewiesen oder manuell durch Auswahl der Option Adresse eingegeben werden kann.
Wenn der Cloudmin-Master einen DNS-Server ausführt (dringend empfohlen), wird der für das OpenVZ-Hostsystem ausgewählten DNS-Zone ein Eintrag für den vollständigen Hostnamen und die Xen-Instanz-IP-Adresse hinzugefügt.
Der Instanz zugewiesener Speicher
OpenVZ-Instanzen können eine feste Obergrenze für die Menge an Speicher haben, die sie verwenden können, was durch diese Option gesteuert wird. 256 ist das Minimum für ein Web-Webhosting-System mit Virtualmin, aber 512 wird empfohlen.
Der Instanz zugewiesener Speicherplatz
In diesem Feld können Sie eine Grenze für den Speicherplatz festlegen, den der neue OpenVZ-Container aus dem Dateisystem des Hostsystems belegen kann.
Wenn Sie auf die Schaltfläche Erstellen klicken, startet Cloudmin den OpenVZ-Setup-Prozess. Bei jedem Schritt werden Statusmeldungen angezeigt. Die Gesamtzeit hängt von der Größe des Images, der Geschwindigkeit des Hostsystems und der Geschwindigkeit des Netzwerks zwischen dem Host und dem Cloudmin-Master ab. Der Durchschnitt liegt jedoch bei etwa fünf Minuten.
