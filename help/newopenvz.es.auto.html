Crear nuevo sistema OpenVZ
Esta página le permite crear un nuevo sistema virtual, que se ejecuta dentro de un contenedor OpenVZ. Debido a que Cloudmin generalmente crea sistemas OpenVZ a partir de imágenes, debe haber descargado al menos una imagen usando la página Nuevas imágenes del sistema antes de que se pueda crear una instancia.

Los campos en este formulario que deben completarse para crear una instancia de Xen son:

Nombre de host del sistema
Este debe ser el nombre del nuevo contenedor a crear, que no debe incluir un nombre de dominio. Los nombres de instancia adecuados son como centos1 o xen-foocorp . El nombre de host final de la instancia tendrá el nombre de dominio DNS seleccionado para el sistema host adjunto.
Descripción del sistema
Una breve descripción legible para humanos de este nuevo sistema virtual, como Webserver para Foo Corp.
Imagen inicial del sistema
En este menú, debe seleccionar la imagen del sistema operativo OpenVZ para iniciar el nuevo sistema. Cloudmin proporciona dos tipos de imágenes: sistemas operativos básicos y pilas completas con Virtualmin. En la mayoría de los casos, querrá seleccionar el último.
Modo de inicio de sesión raíz
Este campo le permite establecer la contraseña inicial para la nueva instancia de OpenVZ. Por lo general, seleccionará Usar contraseña e ingresará una contraseña en el cuadro de texto adyacente, que luego se le puede dar a quien administre el servidor. Alternativamente, si tiene alguna clave SSH registrada en Cloudmin, puede seleccionar Usar clave SSH y elegir una clave del menú que se encuentra al lado. Una vez que se crea la instancia, se configurará para permitir inicios de sesión sin contraseña utilizando esa clave.
¿Permitir la creación de dominios de Virtualmin?
Esta configuración determina si el sistema recién creado puede tener dominios de Virtualmin agregados. Por lo general, querrá dejar este conjunto en Sí .
¿Actualizar paquetes de Virtualmin?
Cuando se establece en Sí (como lo está por defecto) y está creando un sistema a partir de una imagen que incluye Virtualmin Pro, todos los paquetes utilizados por Virtualmin se actualizarán a las últimas versiones disponibles una vez que se complete la creación.
Sistema de alojamiento OpenVZ
En este menú, debe seleccionar el sistema físico en el que desea crear la instancia de OpenVZ.
Dirección IP para la instancia de OpenVZ
Cada nuevo sistema OpenVZ recibe una dirección IP privada, que puede asignarse automáticamente desde el rango definido para el sistema host o ingresarse manualmente seleccionando la opción Dirección .
Si el maestro de Cloudmin ejecuta un servidor DNS (muy recomendable), se agregará una entrada a la zona DNS seleccionada para el sistema host OpenVZ para el nombre de host completo y la dirección IP de la instancia de Xen.
Memoria asignada a instancia
Las instancias de OpenVZ pueden tener un límite superior fijo en la cantidad de memoria que pueden usar, que está controlada por esta opción. 256 es el mínimo para un sistema de alojamiento web con Virtualmin, pero se recomienda 512.
Espacio en disco asignado a la instancia
Este campo se puede usar para establecer un límite en el espacio en disco que el nuevo contenedor OpenVZ puede consumir del sistema de archivos del sistema host.
Cuando se hace clic en el botón Crear , Cloudmin iniciará el proceso de configuración de OpenVZ. Los mensajes de estado se mostrarán a medida que se realiza cada paso. El tiempo total depende del tamaño de la imagen, la velocidad del sistema host y la velocidad de la red entre el host y el maestro de Cloudmin, pero parece que el promedio es de unos cinco minutos.
