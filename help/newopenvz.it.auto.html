Crea un nuovo sistema OpenVZ
Questa pagina consente di creare un nuovo sistema virtuale, in esecuzione all'interno di un contenitore OpenVZ. Poiché Cloudmin di solito crea sistemi OpenVZ dalle immagini, è necessario aver scaricato almeno un'immagine utilizzando la pagina Nuove immagini di sistema prima di poter creare un'istanza.

I campi in questo modulo che devono essere compilati per creare un'istanza Xen sono:

Nome host del sistema
Questo deve essere il nome del nuovo contenitore da creare, che non deve includere un nome di dominio. I nomi di istanza adatti sono centos1 o xen-foocorp . Il nome host finale dell'istanza avrà il nome di dominio DNS selezionato per il sistema host aggiunto.
Descrizione del sistema
Una breve descrizione leggibile dall'uomo per questo nuovo sistema virtuale, come Webserver per Foo Corp.
Immagine di sistema iniziale
Da questo menu è necessario selezionare l'immagine del sistema operativo OpenVZ per avviare il nuovo sistema. Cloudmin offre due tipi di immagini: sistemi operativi di base e stack completi con Virtualmin. Nella maggior parte dei casi, dovrai selezionare quest'ultimo.
Modalità di accesso root
Questo campo consente di impostare la password iniziale per la nuova istanza OpenVZ. In genere si seleziona Usa password e si immette una password nella casella di testo adiacente, che può quindi essere data a chiunque gestirà il server. In alternativa, se si dispone di chiavi SSH registrate con Cloudmin, è possibile selezionare Utilizza chiave SSH e scegliere una chiave dal menu accanto ad essa. Una volta creata, l'istanza verrà configurata per consentire accessi senza password utilizzando quella chiave.
Consentire la creazione di domini Virtualmin?
Questa impostazione determina se al nuovo sistema creato possono essere aggiunti domini Virtualmin. In genere si desidera lasciare questo set su Sì .
Aggiornare i pacchetti Virtualmin?
Quando è impostato su Sì (per impostazione predefinita) e si sta creando un sistema da un'immagine che include Virtualmin Pro, tutti i pacchetti utilizzati da Virtualmin verranno aggiornati alle ultime versioni disponibili al termine della creazione.
Sistema di hosting OpenVZ
Da questo menu è necessario selezionare il sistema fisico su cui si desidera creare l'istanza OpenVZ.
Indirizzo IP per istanza OpenVZ
A ogni nuovo sistema OpenVZ viene assegnato un indirizzo IP privato, che può essere allocato automaticamente dall'intervallo definito per il sistema host o immesso manualmente selezionando l'opzione Indirizzo .
Se il master Cloudmin esegue un server DNS (altamente raccomandato), verrà aggiunta una voce alla zona DNS selezionata per il sistema host OpenVZ per il nome host completo e l'indirizzo IP dell'istanza Xen.
Memoria allocata all'istanza
Le istanze OpenVZ possono avere un limite superiore fisso sulla quantità di memoria che possono usare, che è controllata da questa opzione. 256 è il minimo per un sistema di web hosting Web con Virtualmin, ma si consiglia 512.
Spazio su disco allocato all'istanza
Questo campo può essere utilizzato per impostare un limite sullo spazio su disco che il nuovo contenitore OpenVZ può utilizzare dal filesystem del sistema host.
Quando si fa clic sul pulsante Crea , Cloudmin avvierà il processo di configurazione di OpenVZ. I messaggi di stato verranno visualizzati al termine di ogni passaggio. Il tempo totale dipende dalla dimensione dell'immagine, dalla velocità del sistema host e dalla velocità della rete tra l'host e il master Cloudmin, ma circa cinque minuti sembrano essere la media.
