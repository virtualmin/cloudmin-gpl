Criar novo sistema OpenVZ
Esta página permite criar um novo sistema virtual, executando dentro de um contêiner OpenVZ. Como o Cloudmin geralmente cria sistemas OpenVZ a partir de imagens, você deve ter baixado pelo menos uma imagem usando a página Novas Imagens de Sistema antes que uma instância possa ser criada.

Os campos deste formulário que precisam ser preenchidos para criar uma instância do Xen são:

Nome do host do sistema
Esse deve ser o nome do novo contêiner a ser criado, que não deve incluir um nome de domínio. Os nomes de instância adequados são como centos1 ou xen-foocorp . O nome do host final da instância terá o nome de domínio DNS selecionado para o sistema host anexado.
Descrição do sistema
Uma breve descrição legível por humanos para este novo sistema virtual, como Webserver for Foo Corp.
Imagem inicial do sistema
Nesse menu, você deve selecionar a imagem do sistema operacional OpenVZ para iniciar o novo sistema. O Cloudmin fornece dois tipos de imagens - sistemas operacionais básicos e pilhas completas com o Virtualmin. Na maioria dos casos, você desejará selecionar o último.
Modo de login raiz
Este campo permite definir a senha inicial para a nova instância do OpenVZ. Normalmente, você seleciona Usando senha e insere uma senha na caixa de texto adjacente, que pode ser fornecida a quem gerenciar o servidor. Como alternativa, se você tiver alguma chave SSH registrada no Cloudmin, poderá selecionar Usando chave SSH e escolher uma chave no menu ao lado. Depois que a instância for criada, ela será configurada para permitir logins sem senha usando essa chave.
Permitir a criação de domínios do Virtualmin?
Essa configuração determina se o sistema recém-criado pode ter domínios do Virtualmin adicionados a ele. Normalmente, você deseja deixar esse conjunto como Sim .
Atualizar pacotes do Virtualmin?
Quando isso é definido como Sim (como é o padrão) e você está criando um sistema a partir de uma imagem que inclui o Virtualmin Pro, todos os pacotes usados pelo Virtualmin serão atualizados para as últimas versões disponíveis após a conclusão da criação.
Sistema de hospedagem OpenVZ
Nesse menu, você deve selecionar o sistema físico no qual deseja que a instância do OpenVZ seja criada.
Endereço IP para a instância do OpenVZ
Cada novo sistema OpenVZ recebe um endereço IP privado, que pode ser alocado automaticamente a partir do intervalo definido para o sistema host ou inserido manualmente, selecionando a opção Endereço .
Se o mestre do Cloudmin executar um servidor DNS (altamente recomendado), uma entrada será adicionada à zona DNS selecionada para o sistema host OpenVZ para o nome completo do host e o endereço IP da instância do Xen.
Memória alocada para a instância
As instâncias do OpenVZ podem ter um limite superior fixo na quantidade de memória que podem usar, que é controlada por esta opção. 256 é o mínimo para um sistema de hospedagem na web com o Virtualmin, mas recomenda-se 512.
Espaço em disco alocado para a instância
Este campo pode ser usado para definir um limite no espaço em disco que o novo contêiner OpenVZ pode consumir no sistema de arquivos do sistema host.
Quando o botão Criar é clicado, o Cloudmin inicia o processo de configuração do OpenVZ. As mensagens de status serão exibidas à medida que cada etapa é concluída. O tempo total depende do tamanho da imagem, da velocidade do sistema host e da velocidade da rede entre o host e o mestre do Cloudmin, mas cerca de cinco minutos parece ser a média.
