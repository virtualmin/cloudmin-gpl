Создать новую систему OpenVZ
Эта страница позволяет вам создать новую виртуальную систему, работающую внутри контейнера OpenVZ. Поскольку Cloudmin обычно создает системы OpenVZ из образов, вы должны загрузить хотя бы одно изображение с помощью страницы «Новые образы системы», прежде чем можно будет создать экземпляр.

Поля в этой форме, которые необходимо заполнить для создания экземпляра Xen:

Имя хоста системы
Это должно быть имя нового контейнера для создания, который не должен включать доменное имя. Подходящие имена экземпляров похожи на centos1 или xen-foocorp . Окончательное имя хоста экземпляра будет иметь добавленное доменное имя DNS для хост-системы.
Описание системы
Краткое понятное человеку описание этой новой виртуальной системы, такой как Webserver для Foo Corp.
Исходный образ системы
В этом меню вы должны выбрать образ операционной системы OpenVZ, чтобы запустить новую систему. Cloudmin предоставляет два типа образов - базовые операционные системы и полные стеки с Virtualmin. В большинстве случаев вам захочется выбрать последнее.
Режим рут-входа
Это поле позволяет вам установить начальный пароль для нового экземпляра OpenVZ. Обычно вы выбираете «Использовать пароль» и вводите пароль в смежное текстовое поле, которое затем может быть передано тому, кто будет управлять сервером. В качестве альтернативы, если у вас есть какие-либо SSH-ключи, зарегистрированные в Cloudmin, вы можете выбрать «Использовать SSH-ключ» и выбрать ключ в меню рядом с ним. После того, как экземпляр создан, он будет настроен для входа без пароля с использованием этого ключа.
Разрешить создание доменов Virtualmin?
Этот параметр определяет, могут ли новые создаваемые системы добавлять к нему домены Virtualmin. Обычно вы хотите оставить этот набор на Да .
Обновить пакеты Virtualmin?
Если для этого параметра установлено значение Да (как по умолчанию), и вы создаете систему из образа, содержащего Virtualmin Pro, все пакеты, используемые Virtualmin, будут обновлены до последних доступных версий после завершения создания.
Хостинг система OpenVZ
В этом меню вы должны выбрать физическую систему, в которой вы хотите создать экземпляр OpenVZ.
IP-адрес для экземпляра OpenVZ
Каждой новой системе OpenVZ присваивается частный IP-адрес, который может быть либо назначен автоматически из диапазона, определенного для хост-системы, либо введен вручную, выбрав опцию «Адрес» .
Если мастер Cloudmin запускает DNS-сервер (настоятельно рекомендуется), в зону DNS, выбранную для хост-системы OpenVZ, будет добавлена запись для полного имени хоста и IP-адреса экземпляра Xen.
Память, выделенная для экземпляра
Экземпляры OpenVZ могут иметь фиксированную верхнюю границу объема памяти, которую они могут использовать, что контролируется этой опцией. 256 - минимум для системы веб-хостинга с Virtualmin, но рекомендуется 512.
Дисковое пространство, выделенное для экземпляра
Это поле может использоваться для установки предела дискового пространства, которое новый контейнер OpenVZ может потреблять из файловой системы хост-системы.
При нажатии кнопки «Создать» Cloudmin запускает процесс установки OpenVZ. Сообщения о состоянии будут отображаться по мере выполнения каждого шага. Общее время зависит от размера образа, скорости хост-системы и скорости сети между хостом и мастером Cloudmin, но в среднем около пяти минут.
