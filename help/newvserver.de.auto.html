Neues Vserver-System erstellen
Auf dieser Seite können Sie ein neues virtuelles System erstellen, das in einer Linux VServer-Instanz ausgeführt wird. Sie haben die Möglichkeit, Cloudmin das System 'manuell' mit dem Befehl vserver build oder aus einem von Virtualmin bereitgestellten Image erstellen zu lassen.

Die Felder in diesem Formular, die zum Erstellen einer VServer-Instanz ausgefüllt werden müssen, sind:

Systemhostname
Dies muss der Name der neuen VServer-Instanz sein, die erstellt werden soll und die keinen Domänennamen enthalten darf. Geeignete Instanznamen sind wie ubuntu1 oder vserver-foocorp . An den endgültigen Hostnamen der Instanz wird der DNS-Domänenname für das angehängte Hostsystem angehängt.
Systembeschreibung
Eine kurze, für Menschen lesbare Beschreibung für dieses neue virtuelle System wie Webserver for Foo Corp.
Erstes Systemabbild
In diesem Menü können Sie das VServer-Betriebssystem-Image auswählen, das in das Dateisystem der neuen Instanz kopiert werden soll, oder Keine auswählen, damit das System im Rahmen des Installationsprozesses erstellt wird. Die letztere Option ist jedoch im Allgemeinen langsamer.
Root-Anmeldemodus
In diesem Feld können Sie das anfängliche Kennwort für die neue VServer-Instanz festlegen. In der Regel wählen Sie Kennwort verwenden aus und geben ein Kennwort in das nebenstehende Textfeld ein, das dann an jeden weitergegeben werden kann, der den Server verwaltet. Alternativ können Sie , wenn Sie irgendwelche SSH - Schlüssel registriert mit Cloudmin haben wählen Sie SSH - Schlüssel verwenden und einen Schlüssel aus dem Menü wählen , daneben. Sobald die Instanz erstellt wurde, wird sie so konfiguriert, dass mit diesem Schlüssel kennwortlose Anmeldungen möglich sind.
Webmin-Installationsmodus
Wenn Sie eine VServer-Instanz aus einem Image erstellen, das Virtualmin enthält, können Sie in diesem Feld die Option Webmin nicht installieren festlegen , da die Webmin-Anmeldung mit der SSH-Anmeldung von root identisch ist. Andernfalls können Sie Installieren auswählen und die Anmeldung auf root mit dem oben angegebenen Kennwort setzen , damit Webmin im Rahmen des VServer-Erstellungsprozesses heruntergeladen und installiert werden muss.
Erstellen von Virtualmin-Domänen zulassen?
Diese Einstellung bestimmt, ob dem neu erstellten System Virtualmin-Domänen hinzugefügt werden können. Normalerweise möchten Sie dieses Set auf Ja belassen .
Virtualmin-Pakete aktualisieren?
Wenn dies auf Ja gesetzt ist (wie standardmäßig) und Sie ein System aus einem Image erstellen, das Virtualmin Pro enthält, werden alle von Virtualmin verwendeten Pakete nach Abschluss der Erstellung auf die neuesten verfügbaren Versionen aktualisiert.
VServer-Hosting-System
In diesem Menü müssen Sie das physische System auswählen, auf dem die VServer-Instanz erstellt werden soll.
IP-Adresse für die VServer-Instanz
Jedes neue VServer-System erhält eine private IP-Adresse, die entweder automatisch aus dem für das Hostsystem definierten Bereich zugewiesen oder manuell durch Auswahl der Option Adresse eingegeben werden kann.
Wenn der Cloudmin-Master einen DNS-Server ausführt (dringend empfohlen), wird der für das VServer-Hostsystem ausgewählten DNS-Zone ein Eintrag für den vollständigen Hostnamen und die IP-Adresse der VServer-Instanz hinzugefügt.
Wenn Sie auf die Schaltfläche Erstellen klicken, startet Cloudmin den VServer-Setup-Prozess. Bei jedem Schritt werden Statusmeldungen angezeigt. Die Gesamtzeit kann variieren, je nachdem, ob Sie aus einem Image erstellen oder eine manuelle Erstellung durchführen. Im ersteren Fall werden 5-10 Minuten erwartet, im letzteren Fall kann es je nach Hardware etwa 30 Minuten dauern.
