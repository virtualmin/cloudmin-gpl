Crear nuevo sistema de Vserver
Esta página le permite crear un nuevo sistema virtual, que se ejecuta dentro de una instancia de Linux VServer. Tiene la opción de hacer que Cloudmin cree el sistema 'manualmente' usando el comando vserver build , o desde una imagen proporcionada por Virtualmin.

Los campos en este formulario que deben completarse para crear una instancia de VServer son:

Nombre de host del sistema
Este debe ser el nombre de la nueva instancia de VServer para crear, que no debe incluir un nombre de dominio. Los nombres de instancia adecuados son como ubuntu1 o vserver-foocorp . El nombre de host final de la instancia tendrá el nombre de dominio DNS seleccionado para el sistema host agregado.
Descripción del sistema
Una breve descripción legible para humanos de este nuevo sistema virtual, como Webserver para Foo Corp.
Imagen inicial del sistema
Desde este menú, puede seleccionar la imagen del sistema operativo VServer para copiar en el sistema de archivos de la nueva instancia, o seleccionar Ninguno para que el sistema se compile como parte del proceso de instalación. Sin embargo, la última opción es generalmente más lenta.
Modo de inicio de sesión raíz
Este campo le permite establecer la contraseña inicial para la nueva instancia de VServer. Por lo general, seleccionará Usar contraseña e ingresará una contraseña en el cuadro de texto adyacente, que luego se le puede dar a quien administre el servidor. Alternativamente, si tiene alguna clave SSH registrada en Cloudmin, puede seleccionar Usar clave SSH y elegir una clave del menú que se encuentra al lado. Una vez que se crea la instancia, se configurará para permitir inicios de sesión sin contraseña utilizando esa clave.
Modo de instalación de Webmin
Si está creando una instancia de VServer a partir de una imagen que incluye Virtualmin, este campo puede dejarse configurado en No instalar Webmin , ya que el inicio de sesión de Webmin será el mismo que el inicio de sesión SSH de la raíz . De lo contrario, puede seleccionar Instalar y establecer el inicio de sesión en root con la contraseña anterior para tener que descargar e instalar Webmin como parte del proceso de creación de VServer.
¿Permitir la creación de dominios de Virtualmin?
Esta configuración determina si el sistema recién creado puede tener dominios de Virtualmin agregados. Por lo general, querrá dejar este conjunto en Sí .
¿Actualizar paquetes de Virtualmin?
Cuando se establece en Sí (como lo está por defecto) y está creando un sistema a partir de una imagen que incluye Virtualmin Pro, todos los paquetes utilizados por Virtualmin se actualizarán a las últimas versiones disponibles una vez que se complete la creación.
Sistema de alojamiento VServer
En este menú, debe seleccionar el sistema físico en el que desea crear la instancia de VServer.
Dirección IP para la instancia de VServer
Cada nuevo sistema VServer recibe una dirección IP privada, que puede asignarse automáticamente desde el rango definido para el sistema host o ingresarse manualmente seleccionando la opción Dirección .
Si el maestro de Cloudmin ejecuta un servidor DNS (muy recomendable), se agregará una entrada a la zona DNS seleccionada para el sistema host de VServer para el nombre de host completo y la dirección IP de la instancia de VServer.
Cuando se hace clic en el botón Crear , Cloudmin iniciará el proceso de configuración de VServer. Los mensajes de estado se mostrarán a medida que se realiza cada paso. El tiempo total puede variar dependiendo de si está creando a partir de una imagen o haciendo una compilación manual. En el primer caso, se esperan de 5 a 10 minutos, pero en el último puede tomar alrededor de 30 minutos, dependiendo de su hardware.
