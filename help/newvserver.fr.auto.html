Créer un nouveau système Vserver
Cette page vous permet de créer un nouveau système virtuel, fonctionnant à l'intérieur d'une instance Linux VServer. Vous avez la possibilité de demander à Cloudmin de créer le système «manuellement» à l'aide de la commande vserver build ou à partir d'une image fournie par Virtualmin.

Les champs de ce formulaire qui doivent être remplis pour créer une instance VServer sont:

Nom d'hôte du système
Il doit s'agir du nom de la nouvelle instance VServer à créer, qui ne doit pas inclure de nom de domaine. Les noms d'instance appropriés sont comme ubuntu1 ou vserver-foocorp . Le nom d'hôte final de l'instance aura le nom de domaine DNS sélectionné pour le système hôte ajouté.
Description du système
Une courte description lisible par l'homme pour ce nouveau système virtuel, comme Webserver for Foo Corp.
Image système initiale
À partir de ce menu, vous pouvez sélectionner l'image du système d'exploitation VServer à copier dans le système de fichiers de la nouvelle instance, ou sélectionner Aucun pour que le système soit intégré au processus d'installation. Cependant, cette dernière option est généralement plus lente.
Mode de connexion root
Ce champ vous permet de définir le mot de passe initial pour la nouvelle instance VServer. En règle générale, vous sélectionnez Utiliser un mot de passe et entrez un mot de passe dans la zone de texte adjacente, qui peut ensuite être donnée à la personne qui gérera le serveur. Alternativement, si vous avez des clés SSH enregistrées auprès de Cloudmin, vous pouvez sélectionner Utiliser la clé SSH et choisir une clé dans le menu à côté. Une fois l'instance créée, elle sera configurée pour autoriser les connexions sans mot de passe à l'aide de cette clé.
Mode d'installation de Webmin
Si vous créez une instance VServer à partir d'une image qui inclut Virtualmin, ce champ peut être laissé défini sur Ne pas installer Webmin , car la connexion Webmin sera la même que la connexion SSH de la racine . Sinon, vous pouvez sélectionner Installer et définir la connexion à root avec le mot de passe ci-dessus pour que Webmin soit téléchargé et installé dans le cadre du processus de création de VServer.
Autoriser la création de domaines Virtualmin?
Ce paramètre détermine si le système nouvellement créé peut avoir des domaines Virtualmin ajoutés. En règle générale, vous souhaiterez laisser cet ensemble à Oui .
Mettre à jour les packages Virtualmin?
Lorsque ce paramètre est défini sur Oui (comme c'est le cas par défaut) et que vous créez un système à partir d'une image qui inclut Virtualmin Pro, tous les packages utilisés par Virtualmin seront mis à jour vers les dernières versions disponibles une fois la création terminée.
Système d'hébergement VServer
Dans ce menu, vous devez sélectionner le système physique sur lequel vous souhaitez créer l'instance VServer.
Adresse IP pour l'instance VServer
Chaque nouveau système VServer reçoit une adresse IP privée, qui peut être attribuée automatiquement à partir de la plage définie pour le système hôte, ou saisie manuellement en sélectionnant l'option Adresse .
Si le maître Cloudmin exécute un serveur DNS (hautement recommandé), une entrée sera ajoutée à la zone DNS sélectionnée pour le système hôte VServer pour le nom d'hôte complet et l'adresse IP de l'instance VServer.
Lorsque vous cliquez sur le bouton Créer , Cloudmin démarre le processus de configuration de VServer. Des messages d'état seront affichés à chaque étape. Le temps total peut varier selon que vous créez à partir d'une image ou que vous effectuez une construction manuelle. Dans le premier cas, 5 à 10 minutes sont attendues, mais dans le second, cela peut prendre environ 30 minutes, selon votre matériel.
