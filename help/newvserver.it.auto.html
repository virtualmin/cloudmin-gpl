Crea nuovo sistema Vserver
Questa pagina consente di creare un nuovo sistema virtuale, in esecuzione all'interno di un'istanza VServer Linux. Hai la possibilità che Cloudmin crei il sistema 'manualmente' usando il comando build vserver o da un'immagine fornita da Virtualmin.

I campi in questo modulo che devono essere compilati per creare un'istanza VServer sono:

Nome host del sistema
Questo deve essere il nome della nuova istanza VServer da creare, che non deve includere un nome di dominio. I nomi di istanza adatti sono come ubuntu1 o vserver-foocorp . Il nome host finale dell'istanza avrà il nome di dominio DNS selezionato per il sistema host aggiunto.
Descrizione del sistema
Una breve descrizione leggibile dall'uomo per questo nuovo sistema virtuale, come Webserver per Foo Corp.
Immagine di sistema iniziale
Da questo menu è possibile selezionare l'immagine del sistema operativo VServer da copiare nel filesystem della nuova istanza oppure selezionare Nessuno per far sì che il sistema venga compilato come parte del processo di installazione. Quest'ultima opzione è generalmente più lenta.
Modalità di accesso root
Questo campo consente di impostare la password iniziale per la nuova istanza VServer. In genere si seleziona Usa password e si immette una password nella casella di testo adiacente, che può quindi essere data a chiunque gestirà il server. In alternativa, se si dispone di chiavi SSH registrate con Cloudmin, è possibile selezionare Utilizza chiave SSH e scegliere una chiave dal menu accanto ad essa. Una volta creata, l'istanza verrà configurata per consentire accessi senza password utilizzando quella chiave.
Modalità di installazione di Webmin
Se si sta creando un'istanza VServer da un'immagine che include Virtualmin, questo campo può essere lasciato impostato su Non installare Webmin , poiché il login Webmin sarà lo stesso del login SSH di root . Altrimenti, è possibile selezionare Installa e impostare il login su root con la password sopra per avere Webmin scaricato e installato come parte del processo di creazione di VServer.
Consentire la creazione di domini Virtualmin?
Questa impostazione determina se al nuovo sistema creato possono essere aggiunti domini Virtualmin. In genere si desidera lasciare questo set su Sì .
Aggiornare i pacchetti Virtualmin?
Quando è impostato su Sì (per impostazione predefinita) e si sta creando un sistema da un'immagine che include Virtualmin Pro, tutti i pacchetti utilizzati da Virtualmin verranno aggiornati alle ultime versioni disponibili al termine della creazione.
Sistema di hosting VServer
Da questo menu è necessario selezionare il sistema fisico su cui si desidera creare l'istanza VServer.
Indirizzo IP per istanza VServer
A ogni nuovo sistema VServer viene assegnato un indirizzo IP privato, che può essere allocato automaticamente dall'intervallo definito per il sistema host o immesso manualmente selezionando l'opzione Indirizzo .
Se il master Cloudmin esegue un server DNS (altamente raccomandato), verrà aggiunta una voce alla zona DNS selezionata per il sistema host VServer per il nome host completo e l'indirizzo IP dell'istanza VServer.
Quando si fa clic sul pulsante Crea , Cloudmin avvierà il processo di installazione di VServer. I messaggi di stato verranno visualizzati al termine di ogni passaggio. Il tempo totale può variare in base alla creazione da un'immagine o alla creazione manuale. Nel primo caso, sono previsti 5-10 minuti, ma nel secondo possono essere necessari circa 30 minuti, a seconda dell'hardware.
