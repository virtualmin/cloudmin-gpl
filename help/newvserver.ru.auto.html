Создать новую систему Vserver
Эта страница позволяет вам создать новую виртуальную систему, работающую внутри экземпляра Linux VServer. У вас есть возможность заставить Cloudmin создать систему «вручную» с помощью команды сборки vserver или из образа, предоставленного Virtualmin.

Поля этой формы, которые необходимо заполнить для создания экземпляра VServer:

Имя хоста системы
Это должно быть имя нового экземпляра VServer, который не должен включать доменное имя. Подходящие имена экземпляров похожи на ubuntu1 или vserver-foocorp . К окончательному имени хоста экземпляра будет добавлено DNS-имя домена, выбранного для хост-системы.
Описание системы
Краткое понятное человеку описание этой новой виртуальной системы, такой как Webserver для Foo Corp.
Исходный образ системы
В этом меню вы можете выбрать образ операционной системы VServer для копирования в файловую систему нового экземпляра или выбрать «Нет», чтобы сборка системы была частью процесса установки. Последний вариант, как правило, медленнее, хотя.
Режим рут-входа
Это поле позволяет вам установить начальный пароль для нового экземпляра VServer. Обычно вы выбираете «Использовать пароль» и вводите пароль в смежное текстовое поле, которое затем может быть передано тому, кто будет управлять сервером. В качестве альтернативы, если у вас есть какие-либо SSH-ключи, зарегистрированные в Cloudmin, вы можете выбрать «Использовать SSH-ключ» и выбрать ключ в меню рядом с ним. После того, как экземпляр создан, он будет настроен для входа без пароля с использованием этого ключа.
Режим установки Webmin
Если вы создаете экземпляр VServer из образа, содержащего Virtualmin, в этом поле можно оставить значение «Не устанавливать Webmin» , поскольку имя входа Webmin будет таким же, как имя входа root SSH. В противном случае вы можете выбрать «Установить» и установить для входа в систему пользователя root с паролем, указанным выше , чтобы Webmin загружался и устанавливался как часть процесса создания VServer.
Разрешить создание доменов Virtualmin?
Этот параметр определяет, могут ли новые создаваемые системы добавлять к нему домены Virtualmin. Обычно вы хотите оставить этот набор на Да .
Обновить пакеты Virtualmin?
Если для этого параметра установлено значение Да (как по умолчанию), и вы создаете систему из образа, содержащего Virtualmin Pro, все пакеты, используемые Virtualmin, будут обновлены до последних доступных версий после завершения создания.
Хостинг-система VServer
В этом меню вы должны выбрать физическую систему, в которой вы хотите создать экземпляр VServer.
IP-адрес для экземпляра VServer
Каждой новой системе VServer присваивается частный IP-адрес, который может быть либо назначен автоматически из диапазона, определенного для хост-системы, либо введен вручную, выбрав опцию Адрес .
Если мастер Cloudmin запускает DNS-сервер (настоятельно рекомендуется), в зону DNS, выбранную для хост-системы VServer, будет добавлена запись для полного имени хоста и IP-адреса экземпляра VServer.
При нажатии кнопки «Создать» Cloudmin запускает процесс установки VServer. Сообщения о состоянии будут отображаться по мере выполнения каждого шага. Общее время может варьироваться в зависимости от того, создаете ли вы из изображения или выполняете сборку вручную. В первом случае ожидается 5-10 минут, но во втором это может занять около 30 минут, в зависимости от вашего оборудования.
