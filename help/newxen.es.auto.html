Crear nuevo sistema Xen
Esta página le permite crear un nuevo sistema virtual, que se ejecuta dentro de una instancia de Xen. Debido a que Cloudmin siempre crea nuevos sistemas Xen a partir de imágenes, debe haber descargado al menos una imagen usando la página Nuevas imágenes del sistema antes de que se pueda crear una instancia.

Los campos en este formulario que deben completarse para crear una instancia de Xen son:

Nombre de host del sistema
Este debe ser el nombre de la nueva instancia de Xen para crear, que no debe incluir un nombre de dominio. Los nombres de instancia adecuados son como centos1 o xen-foocorp . El nombre de host final de la instancia tendrá el nombre de dominio DNS seleccionado para el sistema host adjunto.
Descripción del sistema
Una breve descripción legible para humanos de este nuevo sistema virtual, como Webserver para Foo Corp.
Imagen inicial del sistema
En este menú, debe seleccionar la imagen del sistema operativo Xen para iniciar el nuevo sistema. Cloudmin proporciona dos tipos de imágenes: sistemas operativos básicos y pilas completas con Virtualmin. En la mayoría de los casos, querrá seleccionar el último.
Modo de inicio de sesión raíz
Este campo le permite establecer la contraseña inicial para la nueva instancia de Xen. Por lo general, seleccionará Usar contraseña e ingresará una contraseña en el cuadro de texto adyacente, que luego se le puede dar a quien administre el servidor. Alternativamente, si tiene alguna clave SSH registrada en Cloudmin, puede seleccionar Usar clave SSH y elegir una clave del menú que se encuentra al lado. Una vez que se crea la instancia, se configurará para permitir inicios de sesión sin contraseña utilizando esa clave.
¿Permitir la creación de dominios de Virtualmin?
Esta configuración determina si el sistema recién creado puede tener dominios de Virtualmin agregados. Por lo general, querrá dejar este conjunto en Sí .
¿Actualizar paquetes de Virtualmin?
Cuando se establece en Sí (como lo está por defecto) y está creando un sistema a partir de una imagen que incluye Virtualmin Pro, todos los paquetes utilizados por Virtualmin se actualizarán a las últimas versiones disponibles una vez que se complete la creación.
Sistema de alojamiento Xen
En este menú, debe seleccionar el sistema físico en el que desea crear la instancia de Xen.
Dirección IP para instancia de Xen
Cada nuevo sistema Xen recibe una dirección IP privada, que puede asignarse automáticamente desde el rango definido para el sistema host, o ingresarse manualmente seleccionando la opción Dirección .
Si el maestro de Cloudmin ejecuta un servidor DNS (muy recomendable), se agregará una entrada a la zona DNS seleccionada para el sistema host Xen para el nombre de host completo y la dirección IP de la instancia Xen.
Memoria asignada a instancia
Las instancias de Xen tienen un límite superior fijo en la cantidad de memoria que pueden usar, que está controlada por esta opción. 256 es el mínimo para un sistema de alojamiento web con Virtualmin, pero se recomienda 512.
Cambiar tamaño de archivo, por ejemplo
De manera predeterminada, Cloudmin creará instancias de Xen con memoria regular asignada, pero sin espacio de intercambio. Sin embargo, puede seleccionar el segundo botón de radio aquí e ingresar la cantidad de memoria de intercambio (virtual) para asignar en MB, lo que permitirá que los procesos en la instancia utilicen más que la RAM asignada, a costa del rendimiento. Debido a que el espacio de intercambio se almacena en un archivo en el sistema host del mismo tamaño, es una buena idea limitar esto al doble de la cantidad de memoria normal.
Espacio en disco asignado a la instancia
A diferencia de otros tipos de máquinas virtuales, Xen almacena el sistema de archivos de cada instancia dentro de un único archivo en el host, que es una imagen de disco en formato EXT3. El tamaño del sistema de archivos dentro de la instancia se limita así al tamaño de la imagen del disco.
Por defecto, el tamaño del archivo del disco depende de la imagen del sistema seleccionada. Todas las imágenes que contienen la pila Virtualmin completa son de 2 GB, mientras que las que tienen solo el sistema operativo base son de 1 GB. Debido a que esto puede no ser suficiente para un sistema que alojará múltiples sitios web, puede ingresar un tamaño mayor en MB usando esta opción, y la imagen del disco crecerá a ese tamaño durante el proceso de creación de la instancia.
Cuando se hace clic en el botón Crear , Cloudmin iniciará el proceso de configuración de Xen. Los mensajes de estado se mostrarán a medida que se realiza cada paso. El tiempo total depende del tamaño de la imagen, la velocidad del sistema host y la velocidad de la red entre el host y el maestro de Cloudmin, pero parece que el promedio es de unos cinco minutos.
