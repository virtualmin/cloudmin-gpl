Créer un nouveau système Xen
Cette page vous permet de créer un nouveau système virtuel, fonctionnant à l'intérieur d'une instance Xen. Étant donné que Cloudmin crée toujours de nouveaux systèmes Xen à partir d'images, vous devez avoir téléchargé au moins une image à l'aide de la page Nouvelles images système avant de pouvoir créer une instance.

Les champs de ce formulaire qui doivent être remplis pour créer une instance Xen sont:

Nom d'hôte du système
Il doit s'agir du nom de la nouvelle instance Xen à créer, qui ne doit pas inclure de nom de domaine. Les noms d'instance appropriés sont comme centos1 ou xen-foocorp . Le nom d'hôte final de l'instance aura le nom de domaine DNS sélectionné pour le système hôte ajouté.
Description du système
Une courte description lisible par l'homme pour ce nouveau système virtuel, comme Webserver for Foo Corp.
Image système initiale
Dans ce menu, vous devez sélectionner l'image du système d'exploitation Xen avec laquelle démarrer le nouveau système. Cloudmin fournit deux types d'images: les systèmes d'exploitation de base et les piles complètes avec Virtualmin. Dans la plupart des cas, vous voudrez sélectionner ce dernier.
Mode de connexion root
Ce champ vous permet de définir le mot de passe initial pour la nouvelle instance Xen. En règle générale, vous sélectionnez Utiliser un mot de passe et entrez un mot de passe dans la zone de texte adjacente, qui peut ensuite être donnée à la personne qui gérera le serveur. Alternativement, si vous avez des clés SSH enregistrées auprès de Cloudmin, vous pouvez sélectionner Utiliser la clé SSH et choisir une clé dans le menu à côté. Une fois l'instance créée, elle sera configurée pour autoriser les connexions sans mot de passe à l'aide de cette clé.
Autoriser la création de domaines Virtualmin?
Ce paramètre détermine si le système nouvellement créé peut avoir des domaines Virtualmin ajoutés. En règle générale, vous souhaiterez laisser cet ensemble à Oui .
Mettre à jour les packages Virtualmin?
Lorsque ce paramètre est défini sur Oui (comme c'est le cas par défaut) et que vous créez un système à partir d'une image qui inclut Virtualmin Pro, tous les packages utilisés par Virtualmin seront mis à jour vers les dernières versions disponibles une fois la création terminée.
Système d'hébergement Xen
Dans ce menu, vous devez sélectionner le système physique sur lequel vous souhaitez créer l'instance Xen.
Adresse IP pour l'instance Xen
Chaque nouveau système Xen reçoit une adresse IP privée, qui peut être attribuée automatiquement à partir de la plage définie pour le système hôte, ou saisie manuellement en sélectionnant l'option Adresse .
Si le maître Cloudmin exécute un serveur DNS (hautement recommandé), une entrée sera ajoutée à la zone DNS sélectionnée pour le système hôte Xen pour le nom d'hôte complet et l'adresse IP de l'instance Xen.
Mémoire allouée à l'instance
Les instances Xen ont une limite supérieure fixe sur la quantité de mémoire qu'ils peuvent utiliser, qui est contrôlée par cette option. 256 est le minimum pour un système d'hébergement Web avec Virtualmin, mais 512 est recommandé.
Changer la taille du fichier par exemple
Par défaut, Cloudmin créera des instances Xen avec de la mémoire régulière allouée, mais pas d'espace d'échange. Cependant, vous pouvez sélectionner le deuxième bouton radio ici et entrer la quantité de mémoire d'échange (virtuelle) à allouer en Mo, ce qui permettra aux processus de l'instance d'utiliser plus que la RAM allouée, au détriment des performances. Étant donné que l'espace d'échange est stocké dans un fichier sur le système hôte de la même taille, il est judicieux de limiter cela à deux fois la quantité de mémoire normale.
Espace disque alloué à l'instance
Contrairement à certains autres types de machines virtuelles, Xen stocke le système de fichiers de chaque instance dans un seul fichier sur l'hôte, qui est une image disque au format EXT3. La taille du système de fichiers au sein de l'instance est donc limitée à la taille de l'image disque.
Par défaut, la taille du fichier disque dépend de l'image système sélectionnée. Toutes les images qui contiennent la pile Virtualmin complète sont de 2 Go, tandis que celles avec uniquement le système d'exploitation de base sont de 1 Go. Étant donné que cela peut ne pas être suffisant pour un système qui hébergera plusieurs sites Web, vous pouvez entrer une taille plus grande en Mo à l'aide de cette option, et l'image disque sera agrandie à cette taille pendant le processus de création d'instance.
Lorsque vous cliquez sur le bouton Créer , Cloudmin démarre le processus de configuration de Xen. Des messages d'état seront affichés à chaque étape. Le temps total dépend de la taille de l'image, de la vitesse du système hôte et de la vitesse du réseau entre l'hôte et le maître Cloudmin, mais environ cinq minutes semblent être la moyenne.
