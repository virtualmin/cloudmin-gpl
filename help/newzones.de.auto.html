Erstellen Sie ein neues Solaris Zones-System
Auf dieser Seite können Sie ein neues virtuelles System erstellen, das in einer Solaris-Zone ausgeführt wird. Sie haben die Möglichkeit, Cloudmin das System 'manuell' mit dem Befehl zoneadm install oder aus einem von Virtualmin bereitgestellten Image erstellen zu lassen.

Die Felder in diesem Formular, die zum Erstellen einer Zone ausgefüllt werden müssen, sind:

Systemhostname
Dies muss der Name der neu zu erstellenden Zone sein, die keinen Domänennamen enthalten darf. Geeignete Instanznamen sind wie solaris1 oder zone-foocorp . An den endgültigen Hostnamen der Instanz wird der DNS-Domänenname für das angehängte Hostsystem angehängt.
Systembeschreibung
Eine kurze, für Menschen lesbare Beschreibung für dieses neue virtuelle System wie Webserver for Foo Corp.
Erstes Systemabbild
In diesem Menü können Sie das Solaris-Betriebssystem-Image auswählen, das in das Dateisystem der neuen Instanz kopiert werden soll, oder Keine auswählen, damit das System im Rahmen des Installationsprozesses erstellt wird. Die letztere Option ist jedoch im Allgemeinen langsamer.
Stellen Sie sicher, dass Sie ein Image mit derselben Architektur wie das Zones-Hostsystem (X86 oder Sparc) auswählen, da ein Image des falschen Typs nicht gestartet werden kann.
Root-Anmeldemodus
In diesem Feld können Sie das ursprüngliche Kennwort für die neue Zone festlegen. In der Regel wählen Sie Kennwort verwenden aus und geben ein Kennwort in das nebenstehende Textfeld ein, das dann an jeden weitergegeben werden kann, der den Server verwaltet. Alternativ können Sie , wenn Sie irgendwelche SSH - Schlüssel registriert mit Cloudmin haben wählen Sie SSH - Schlüssel verwenden und einen Schlüssel aus dem Menü wählen , daneben. Sobald die Instanz erstellt wurde, wird sie so konfiguriert, dass mit diesem Schlüssel kennwortlose Anmeldungen möglich sind.
Erstellen von Virtualmin-Domänen zulassen?
Diese Einstellung bestimmt, ob dem neu erstellten System Virtualmin-Domänen hinzugefügt werden können. Normalerweise möchten Sie dieses Set auf Ja belassen .
Virtualmin-Pakete aktualisieren?
Wenn dies auf Ja gesetzt ist (wie standardmäßig) und Sie ein System aus einem Image erstellen, das Virtualmin Pro enthält, werden alle von Virtualmin verwendeten Pakete nach Abschluss der Erstellung auf die neuesten verfügbaren Versionen aktualisiert.
Hosting-System von Solaris Zones
In diesem Menü müssen Sie das physische System auswählen, auf dem die Zone erstellt werden soll.
IP-Adresse für Zone
Jede neue Zone erhält eine private IP-Adresse, die entweder automatisch aus dem für das Hostsystem definierten Bereich zugewiesen oder manuell durch Auswahl der Option Adresse eingegeben werden kann.
Wenn der Cloudmin-Master einen DNS-Server ausführt (dringend empfohlen), wird der für das Zonensystem ausgewählten DNS-Zone ein Eintrag für den vollständigen Hostnamen und die IP-Adresse der Zone hinzugefügt.
Wenn Sie auf die Schaltfläche Erstellen klicken, startet Cloudmin den Einrichtungsprozess für die Zone. Bei jedem Schritt werden Statusmeldungen angezeigt. Die Gesamtzeit kann variieren, je nachdem, ob Sie aus einem Image erstellen oder eine manuelle Erstellung durchführen. Im ersteren Fall werden 5-10 Minuten erwartet, im letzteren Fall kann es je nach Hardware etwa 30 Minuten dauern.
