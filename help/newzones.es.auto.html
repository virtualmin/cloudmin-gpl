Crear nuevo sistema de zonas Solaris
Esta página le permite crear un nuevo sistema virtual, que se ejecuta dentro de una zona Solaris. Tiene la opción de hacer que Cloudmin cree el sistema 'manualmente' usando el comando de instalación zoneadm , o desde una imagen proporcionada por Virtualmin.

Los campos en este formulario que deben completarse para crear una zona son:

Nombre de host del sistema
Este debe ser el nombre de la nueva zona a crear, que no debe incluir un nombre de dominio. Los nombres de instancia adecuados son como solaris1 o zone-foocorp . El nombre de host final de la instancia tendrá el nombre de dominio DNS seleccionado para el sistema host agregado.
Descripción del sistema
Una breve descripción legible para humanos de este nuevo sistema virtual, como Webserver para Foo Corp.
Imagen inicial del sistema
Desde este menú puede seleccionar la imagen del sistema operativo Solaris para copiar en el sistema de archivos de la nueva instancia, o seleccionar Ninguno para que el sistema se compile como parte del proceso de instalación. Sin embargo, la última opción es generalmente más lenta.
Asegúrese de seleccionar una imagen de la misma arquitectura que el sistema host Zones (X86 o Sparc), ya que una imagen del tipo incorrecto no se iniciará.
Modo de inicio de sesión raíz
Este campo le permite establecer la contraseña inicial para la nueva zona. Por lo general, seleccionará Usar contraseña e ingresará una contraseña en el cuadro de texto adyacente, que luego se le puede dar a quien administre el servidor. Alternativamente, si tiene alguna clave SSH registrada en Cloudmin, puede seleccionar Usar clave SSH y elegir una clave del menú que se encuentra al lado. Una vez que se crea la instancia, se configurará para permitir inicios de sesión sin contraseña utilizando esa clave.
¿Permitir la creación de dominios de Virtualmin?
Esta configuración determina si el sistema recién creado puede tener dominios de Virtualmin agregados. Por lo general, querrá dejar este conjunto en Sí .
¿Actualizar paquetes de Virtualmin?
Cuando se establece en Sí (como lo está por defecto) y está creando un sistema a partir de una imagen que incluye Virtualmin Pro, todos los paquetes utilizados por Virtualmin se actualizarán a las últimas versiones disponibles una vez que se complete la creación.
Sistema de alojamiento de zonas Solaris
Desde este menú debe seleccionar el sistema físico en el que desea crear la zona.
Dirección IP para zona
Cada nueva zona recibe una dirección IP privada, que puede asignarse automáticamente desde el rango definido para el sistema host o ingresarse manualmente seleccionando la opción Dirección .
Si el maestro de Cloudmin ejecuta un servidor DNS (muy recomendable), se agregará una entrada a la zona DNS seleccionada para el sistema de zona para el nombre de host completo y la dirección IP de la zona.
Cuando se hace clic en el botón Crear , Cloudmin iniciará el proceso de configuración de la zona. Los mensajes de estado se mostrarán a medida que se realiza cada paso. El tiempo total puede variar dependiendo de si está creando a partir de una imagen o haciendo una compilación manual. En el primer caso, se esperan de 5 a 10 minutos, pero en el último puede tomar alrededor de 30 minutos, dependiendo de su hardware.
