Crea un nuovo sistema di zone Solaris
Questa pagina consente di creare un nuovo sistema virtuale, in esecuzione all'interno di una zona Solaris. Hai la possibilità che Cloudmin crei il sistema 'manualmente' usando il comando zoneadm install o da un'immagine fornita da Virtualmin.

I campi in questo modulo che devono essere compilati per creare una zona sono:

Nome host del sistema
Questo deve essere il nome della nuova zona da creare, che non deve includere un nome di dominio. I nomi di istanza adatti sono come solaris1 o zone-foocorp . Il nome host finale dell'istanza avrà il nome di dominio DNS selezionato per il sistema host aggiunto.
Descrizione del sistema
Una breve descrizione leggibile dall'uomo per questo nuovo sistema virtuale, come Webserver per Foo Corp.
Immagine di sistema iniziale
Da questo menu è possibile selezionare l'immagine del sistema operativo Solaris da copiare nel filesystem della nuova istanza oppure selezionare Nessuno per far sì che il sistema venga compilato durante il processo di installazione. Quest'ultima opzione è generalmente più lenta.
Assicurati di selezionare un'immagine della stessa architettura del sistema host Zones (X86 o Sparc), poiché non verrà avviata un'immagine di tipo errato.
Modalità di accesso root
Questo campo consente di impostare la password iniziale per la nuova zona. In genere si seleziona Usa password e si immette una password nella casella di testo adiacente, che può quindi essere data a chiunque gestirà il server. In alternativa, se si dispone di chiavi SSH registrate con Cloudmin, è possibile selezionare Utilizza chiave SSH e scegliere una chiave dal menu accanto ad essa. Una volta creata, l'istanza verrà configurata per consentire accessi senza password utilizzando quella chiave.
Consentire la creazione di domini Virtualmin?
Questa impostazione determina se al nuovo sistema creato possono essere aggiunti domini Virtualmin. In genere si desidera lasciare questo set su Sì .
Aggiornare i pacchetti Virtualmin?
Quando è impostato su Sì (per impostazione predefinita) e si sta creando un sistema da un'immagine che include Virtualmin Pro, tutti i pacchetti utilizzati da Virtualmin verranno aggiornati alle ultime versioni disponibili al termine della creazione.
Sistema di hosting delle zone Solaris
Da questo menu è necessario selezionare il sistema fisico su cui si desidera creare la zona.
Indirizzo IP per zona
A ogni nuova zona viene assegnato un indirizzo IP privato, che può essere allocato automaticamente dall'intervallo definito per il sistema host o immesso manualmente selezionando l'opzione Indirizzo .
Se il master Cloudmin esegue un server DNS (altamente raccomandato), verrà aggiunta una voce alla zona DNS selezionata per il sistema di zona per il nome host completo e l'indirizzo IP della zona.
Quando si fa clic sul pulsante Crea , Cloudmin avvierà il processo di configurazione della zona. I messaggi di stato verranno visualizzati al termine di ogni passaggio. Il tempo totale può variare in base alla creazione da un'immagine o alla creazione manuale. Nel primo caso, sono previsti 5-10 minuti, ma nel secondo possono essere necessari circa 30 minuti, a seconda dell'hardware.
