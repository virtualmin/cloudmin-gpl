Criar novo sistema Solaris Zones
Esta página permite criar um novo sistema virtual, executando dentro de uma zona Solaris. Você tem a opção de fazer com que o Cloudmin crie o sistema 'manualmente' usando o comando zoneadm install ou a partir de uma imagem fornecida pelo Virtualmin.

Os campos deste formulário que precisam ser preenchidos para criar uma zona são:

Nome do host do sistema
Esse deve ser o nome da nova zona a ser criada, que não deve incluir um nome de domínio. Os nomes de instância adequados são como solaris1 ou zone-foocorp . O nome do host final da instância terá o nome de domínio DNS selecionado para o sistema host anexado.
Descrição do sistema
Uma breve descrição legível por humanos para este novo sistema virtual, como Webserver for Foo Corp.
Imagem inicial do sistema
Nesse menu, você pode selecionar a imagem do sistema operacional Solaris para copiar no sistema de arquivos da nova instância ou selecionar Nenhum para que o sistema seja construído como parte do processo de instalação. A última opção é geralmente mais lenta.
Certifique-se de selecionar uma imagem da mesma arquitetura que o sistema host de zonas (X86 ou Sparc), pois uma imagem do tipo errado não será inicializada.
Modo de login raiz
Este campo permite que você defina a senha inicial para a nova zona. Normalmente, você seleciona Usando senha e insere uma senha na caixa de texto adjacente, que pode ser fornecida a quem gerenciar o servidor. Como alternativa, se você tiver alguma chave SSH registrada no Cloudmin, poderá selecionar Usando chave SSH e escolher uma chave no menu ao lado. Depois que a instância for criada, ela será configurada para permitir logins sem senha usando essa chave.
Permitir a criação de domínios do Virtualmin?
Essa configuração determina se o sistema recém-criado pode ter domínios do Virtualmin adicionados a ele. Normalmente, você deseja deixar esse conjunto como Sim .
Atualizar pacotes do Virtualmin?
Quando isso é definido como Sim (como é o padrão) e você está criando um sistema a partir de uma imagem que inclui o Virtualmin Pro, todos os pacotes usados pelo Virtualmin serão atualizados para as últimas versões disponíveis após a conclusão da criação.
Sistema de hospedagem Solaris Zones
Nesse menu, você deve selecionar o sistema físico no qual deseja que a zona seja criada.
Endereço IP para zona
Cada nova zona recebe um endereço IP privado, que pode ser alocado automaticamente a partir do intervalo definido para o sistema host ou inserido manualmente, selecionando a opção Endereço .
Se o mestre do Cloudmin executar um servidor DNS (altamente recomendado), uma entrada será adicionada à zona DNS selecionada para o sistema de zonas para o nome completo do host e o endereço IP da região.
Quando o botão Criar é clicado, o Cloudmin inicia o processo de configuração da zona. As mensagens de status serão exibidas à medida que cada etapa é concluída. O tempo total pode variar dependendo de você estar criando a partir de uma imagem ou fazendo uma construção manual. No primeiro caso, são esperados 5 a 10 minutos, mas no último pode demorar cerca de 30 minutos, dependendo do seu hardware.
