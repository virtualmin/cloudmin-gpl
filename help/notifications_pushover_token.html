Pushover application token

Create an application in your Pushover account and enter its API token. The token contains 30 letters and digits and is case-sensitive. Cloudmin needs both this token and a user or group key to send notifications.

Messages use normal priority. Titles are limited to 250 characters and message text to 1024 characters. Longer text is shortened before sending. Invalid requests and exhausted quotas stop delivery without automatic retries. Correct the destination or restore its quota before retrying from History.
