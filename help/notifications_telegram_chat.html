Chat ID

Enter the numeric Telegram chat ID, including its minus sign for a group or channel, or a public supergroup or channel username starting with @. Usernames accept 4 to 32 letters, digits or underscores. For a private chat, the user must first start the bot. For a group, add the bot and allow it to send messages. For a channel, give it permission to post.

To find a numeric ID, send a command to your bot and read message.chat.id in its getUpdates response. In a group, address the command to the bot, such as /start@your_bot. For a channel, read channel_post.chat.id after posting a message. If the bot already receives updates through a webhook, read those updates instead. Cloudmin does not discover IDs automatically.
