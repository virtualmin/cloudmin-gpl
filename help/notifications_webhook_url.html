Webhook URL

Enter the receiving URL for the chosen delivery method. Use an incoming webhook for Slack or Discord, a Teams workflow URL, or an ntfy topic URL. Generic webhook receivers must accept Cloudmin's JSON event format.

Slack, Discord and Teams URLs require HTTPS and may contain signed query strings. Generic webhook and ntfy URLs cannot contain a query string. Usernames, passwords and fragments are not accepted in URLs. Certificates are checked and redirects are rejected. Private chat URLs are shown only when editing the destination.
