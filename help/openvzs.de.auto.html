OpenVZ-Hostsysteme
Bevor Cloudmin virtuelle Systeme mit Linux OpenVZ-Containern erstellen kann, müssen Sie die Hostsysteme registrieren, auf denen OpenVZ auf dieser Seite ausgeführt wird. Cloudmin verfügt über eine dreischichtige Architektur, in der das Mastersystem (auf dem die Cloudmin-Webmin-Schnittstelle ausgeführt wird) von den Systemen getrennt ist, auf denen OpenVZ-Container gehostet werden, die wiederum von den OpenVZ-Systemen selbst getrennt sind.

Bevor ein OpenVZ-Hostsystem hier registriert werden kann, müssen Sie es zunächst über den Link Physisches System hinzufügen unter System hinzufügen im linken Menü unter die Kontrolle von Cloudmin bringen. Wählen Sie anschließend das System aus dem Menü Hostsystem zum Hinzufügen aus und klicken Sie auf Start Host hinzufügen .
