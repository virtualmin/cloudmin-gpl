Sistemi host OpenVZ
Prima che Cloudmin possa creare qualsiasi sistema virtuale utilizzando i contenitori OpenVZ di Linux, è necessario registrare i sistemi host su cui OpenVZ verrà eseguito utilizzando questa pagina. Cloudmin ha un'architettura a tre livelli, in cui il sistema master (su cui gira l'interfaccia Cloudmin Webmin) è separato dai sistemi che ospitano container OpenVZ, che a loro volta sono separati dai sistemi OpenVZ stessi.

Prima che un sistema host OpenVZ possa essere registrato qui, è necessario portarlo sotto il controllo di Cloudmin usando il collegamento Aggiungi sistema fisico sotto Aggiungi sistema nel menu a sinistra. Al termine, selezionare il sistema dal sistema Host per aggiungere il menu e fare clic su Avvia aggiunta host .
