Sistemas host OpenVZ
Antes de o Cloudmin criar qualquer sistema virtual usando contêineres Linux OpenVZ, você deve registrar os sistemas host nos quais o OpenVZ será executado usando esta página. O Cloudmin possui uma arquitetura de três camadas, na qual o sistema principal (no qual a interface do Cloudmin Webmin é executada) é separado dos sistemas que hospedam os contêineres OpenVZ, que por sua vez são separados dos próprios sistemas OpenVZ.

Para que um sistema host OpenVZ possa ser registrado aqui, primeiro você deve colocá-lo sob o controle do Cloudmin usando o link Adicionar sistema físico em Adicionar sistema no menu esquerdo. Feito isso, selecione o sistema no sistema Host para adicionar menu e clique em Iniciar Adicionando Host .
