Passwort ändern
Auf dieser Seite können Sie entweder das root Passwort eines Systems (das für SSH-Anmeldungen verwendet wird), das Webmin-Passwort oder beides ändern. Dies kann erforderlich sein, wenn Sie ein System an einen anderen Benutzer oder Kunden übergeben oder wenn das ursprüngliche Kennwort zu schwach ist oder kompromittiert wurde.

Sie können auch einen SSH-Schlüssel verwenden, um sich bei diesem System anzumelden, den /root/.ssh/authorized_keys bei Bedarf zu seiner Datei /root/.ssh/authorized_keys hinzufügt. Dies ist jedoch nur möglich, wenn auf der Seite SSH-Schlüssel Schlüssel hinzugefügt wurden und Sie diese verwenden dürfen.

Wenn Sie das Webmin-Kennwort ändern, können Sie es mit dem Unix- root Kennwort identisch machen. Dies erfolgt durch Konfigurieren von Webmin auf dem System für die Verwendung von PAM oder das Lesen der Datei /etc/shadow , wenn sich root anmeldet, damit zukünftige Änderungen am SSH-Kennwort übereinstimmen.

Virtuelle KVM- und Xen-Systeme verfügen über eine remote zugängliche grafische Konsole, die durch ein Kennwort geschützt ist, das auch über diese Seite geändert werden kann. Standardmäßig entspricht das Kennwort dem Kennwort, das dem root Benutzer beim Erstellen des Systems zugewiesen wurde. Möglicherweise möchten Sie dies jedoch ändern, um den Zugriff auf das System weiter zu sperren.
