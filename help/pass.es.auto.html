Cambia la contraseña
Esta página se puede usar para cambiar la contraseña root un sistema (utilizada para inicios de sesión SSH), su contraseña de Webmin o ambas. Esto puede ser necesario cuando entregue un sistema a otro usuario o cliente, o si la contraseña original es demasiado débil o se ha visto comprometida.

También puede seleccionar usar una clave SSH para iniciar sesión en este sistema, que Cloudmin agregará a su archivo /root/.ssh/authorized_keys si es necesario. Sin embargo, esto solo es posible si se han agregado claves en la página Claves SSH , y si tiene permiso para usarlas.

Al cambiar la contraseña de Webmin, tiene una opción para que sea la misma que la contraseña de root Unix. Esto se realiza configurando Webmin en el sistema para usar PAM o leer el /etc/shadow cuando root inicia sesión, de modo que cualquier cambio futuro a la contraseña SSH coincida.

Los sistemas virtuales KVM y Xen tienen una consola gráfica accesible remotamente que está protegida por una contraseña que también se puede cambiar usando esta página. Por defecto la contraseña es lo mismo que lo que estaba asignado a la root de usuario que se creó el sistema, pero es posible que desee modificar esto para más de bloqueo hacia abajo acceso al sistema.
