Changer le mot de passe
Cette page peut être utilisée pour modifier le mot de passe root un système (utilisé pour les connexions SSH), son mot de passe Webmin ou les deux. Cela peut être nécessaire lorsque vous remettez un système à un autre utilisateur ou client, ou si le mot de passe d'origine est trop faible ou a été compromis.

Vous pouvez également choisir d'utiliser une clé SSH pour vous connecter à ce système, que Cloudmin ajoutera à son fichier /root/.ssh/authorized_keys si nécessaire. Cela n'est possible que si des clés ont été ajoutées sur la page Clés SSH et si vous êtes autorisé à les utiliser.

Lorsque vous modifiez le mot de passe Webmin, vous avez la possibilité de le rendre identique au mot de passe root Unix. Cela se fait en configurant Webmin sur le système pour utiliser PAM ou lire le fichier /etc/shadow lorsque root connecte, afin que toutes les futures modifications du mot de passe SSH correspondent.

Les systèmes virtuels KVM et Xen ont une console graphique accessible à distance qui est protégée par un mot de passe qui peut également être modifié à l'aide de cette page. Par défaut, le mot de passe est le même que celui qui a été attribué à l'utilisateur root lors de la création du système, mais vous souhaiterez peut-être le modifier pour verrouiller davantage l'accès au système.
