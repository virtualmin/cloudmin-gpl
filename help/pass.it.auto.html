Cambia la password
Questa pagina può essere utilizzata per modificare la password di root un sistema (utilizzata per gli accessi SSH), la sua password Webmin o entrambe. Ciò può essere necessario quando si passa un sistema a un altro utente o cliente o se la password originale è troppo debole o è stata compromessa.

Puoi anche selezionare di utilizzare una chiave SSH per accedere a questo sistema, che Cloudmin aggiungerà al suo file /root/.ssh/authorized_keys se necessario. Questo è possibile solo se le chiavi sono state aggiunte nella pagina Chiavi SSH e se ti è permesso usarle.

Quando si modifica la password di Webmin, è disponibile un'opzione per renderla uguale alla password di root Unix. Questo viene fatto configurando Webmin sul sistema per usare PAM o leggere il /etc/shadow quando si accede al root , in modo che tutte le future modifiche alla password SSH corrispondano.

I sistemi virtuali KVM e Xen dispongono di una console grafica accessibile da remoto, protetta da una password che può essere modificata anche tramite questa pagina. Per impostazione predefinita, la password è la stessa di qualsiasi cosa sia stata assegnata all'utente root momento della creazione del sistema, ma è possibile modificarla per bloccare ulteriormente l'accesso al sistema.
