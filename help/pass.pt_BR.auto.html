Mudar senha
Esta página pode ser usada para alterar a senha root um sistema (usada para logins SSH), sua senha Webmin ou ambas. Isso pode ser necessário quando você estiver transferindo um sistema para outro usuário ou cliente, ou se a senha original estiver muito fraca ou tiver sido comprometida.

Você também pode optar por usar uma chave SSH para acessar este sistema, que Cloudmin irá adicionar à sua /root/.ssh/authorized_keys arquivo, se necessário. Isso só é possível se as chaves tiverem sido adicionadas na página Chaves SSH e se você tiver permissão para usá-las.

Ao alterar a senha do Webmin, você tem a opção de torná-la igual à senha root do Unix. Isso é feito configurando o Webmin no sistema para usar o PAM ou ler o arquivo /etc/shadow quando o root efetuar login, para que quaisquer alterações futuras na senha do SSH sejam correspondentes.

Os sistemas virtuais KVM e Xen possuem um console gráfico acessível remotamente, protegido por uma senha que também pode ser alterada usando esta página. Por padrão, a senha é a mesma que foi atribuída ao usuário root quando o sistema foi criado, mas você pode modificá-la para bloquear ainda mais o acesso ao sistema.
