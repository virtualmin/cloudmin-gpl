Cambia la contraseña
Esta página se puede usar para cambiar la contraseña que Cloudmin usa para iniciar sesión en un sistema a través de SSH y posiblemente a través de Webmin. No cambia las contraseñas reales del sistema; eso solo es posible si Cloudmin ya tiene acceso al sistema o si puede manipular directamente su sistema de archivos.

Los sistemas virtuales KVM y Xen tienen una consola gráfica accesible remotamente que está protegida por una contraseña que también se puede cambiar usando esta página. De manera predeterminada, la contraseña es la misma que se asignó al usuario raíz cuando se creó el sistema, pero es posible que desee modificar esto para bloquear aún más el acceso al sistema.
