Changer le mot de passe
Cette page peut être utilisée pour modifier le mot de passe utilisé par Cloudmin pour se connecter à un système via SSH et éventuellement via Webmin. Il ne modifie pas les mots de passe réels du système - cela n'est possible que si Cloudmin a déjà accès au système, ou peut manipuler directement son système de fichiers.

Les systèmes virtuels KVM et Xen ont une console graphique accessible à distance qui est protégée par un mot de passe qui peut également être modifié à l'aide de cette page. Par défaut, le mot de passe est le même que celui qui a été attribué à l'utilisateur racine lors de la création du système, mais vous souhaiterez peut-être le modifier pour verrouiller davantage l'accès au système.
