Bytt passord
Denne siden kan brukes til å endre passordet Cloudmin bruker for å logge inn på et system via SSH og muligens via Webmin. Det endrer ikke systemets faktiske passord - det er bare mulig hvis Cloudmin allerede har tilgang til systemet, eller direkte kan manipulere filsystemet.

KVM og Xen virtuelle systemer har en ekstern tilgjengelig grafisk konsoll som er beskyttet av et passord som også kan endres ved hjelp av denne siden. Som standard er passordet det samme som hva som ble tilordnet rotbrukeren da systemet ble opprettet, men det kan være lurt å endre dette for å låse tilgangen til systemet ytterligere.
