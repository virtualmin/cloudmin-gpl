Mudar senha
Esta página pode ser usada para alterar a senha que o Cloudmin usa para efetuar login em um sistema via SSH e possivelmente via Webmin. Ele não altera as senhas reais do sistema - isso só é possível se o Cloudmin já tiver acesso ao sistema ou puder manipular diretamente seu sistema de arquivos.

Os sistemas virtuais KVM e Xen possuem um console gráfico acessível remotamente, protegido por uma senha que também pode ser alterada usando esta página. Por padrão, a senha é a mesma que foi atribuída ao usuário raiz quando o sistema foi criado, mas você pode modificá-la para bloquear ainda mais o acesso ao sistema.
