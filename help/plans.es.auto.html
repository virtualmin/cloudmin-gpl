Planes de cuenta
Un plan de cuenta define límites en la cantidad de sistemas virtuales y los recursos que pueden consumir, que se aplican a los propietarios del sistema. Le permiten otorgar a diferentes clientes los derechos para crear sistemas usando Cloudmin, hasta límites predefinidos para que no usen todos los discos o RAM disponibles.

Los planes se pueden usar para restringir los siguientes recursos:

  • Número de sistemas virtuales : el propietario del sistema no podrá crear ninguna instancia virtual nueva una vez que el número que posee alcance este límite.
  • RAM para sistemas virtuales : el límite total de RAM asignado a todas las instancias virtuales del propietario no podrá exceder este límite. Esto se aplica tanto en el momento de la creación como al cambiar el límite de RAM en un sistema existente.
  • Disco para sistemas virtuales : no se permitirá que el espacio total ocupado por todos los discos en todas las instancias virtuales supere este límite. Esto se aplica tanto en el momento de la creación como al agregar o expandir discos en un sistema existente.
  • CPU para sistemas virtuales : los límites de porcentaje de tiempo total de CPU para todas las instancias virtuales del propietario no podrán exceder este límite. Esto se aplica tanto en el momento de la creación como al cambiar el límite de CPU en un sistema existente.
