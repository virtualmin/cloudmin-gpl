Resource Plans

Plans supply CPU, memory and system disk defaults for new machines. They are not quotas, and changing a plan does not resize existing machines.

The supplied default uses 2 CPUs, 2 GiB of RAM and a 20 GiB disk, reduced to 1 CPU on a one-CPU host. You can edit it or select another default.

Creation still checks host capacity, available storage and the image's minimum disk size. Use whole MiB for memory and whole GiB for disk sizes.
