Account Plans
An account plan defines limits on the number of virtual systems and the resources they can consume, which apply to system owners. They allow you to give different customers the rights to create systems using Cloudmin, up to pre-defined limits so that they do not use up all available disk or RAM.

Plans can be used to restrict the following resources :

  • Number of virtual systems - The system owner will not be able to create any new virtual instances once the number he owns hits this limit.
  • RAM for virtual systems - The total RAM limit assigned to all the owner's virtual instances will not be allowed to exceed this limit. This applies both at creation time and when changing the RAM limit on an existing system.
  • Disk for virtual systems - The total space occupied by all disks on all virtual instances will not be allowed to exceed this limit. This applies both at creation time and when adding or expanding disks on an existing system.
  • CPU for virtual systems - The total CPU-time percentage limits for all the owner's virtual instances will not be allowed to exceed this limit. This applies both at creation time and when changing the CPU limit on an existing system.
