Resource Plans

A plan saves the CPU count, memory and system disk size used when creating a virtual machine. Select a plan on the creation form, then adjust the values as needed. These changes apply only to the new virtual machine; they do not change the saved plan.

Open System Settings → Resource Plans. The editor groups the name, description and resource settings under Basic plan details.

Use Copy in the editor to make a similar plan. Select a plan in the list and click Make Default to select it on new creation forms. Deleting a custom default selects Default Plan again.

Cloudmin includes an editable Default Plan with 2 CPUs, 2 GiB of memory and a 20 GiB system disk. On a one-CPU host, the unedited Default Plan uses 1 CPU. This plan cannot be deleted.

Plans accept 1–1024 CPUs, 256 MiB–1 PiB of memory and 1 GiB–1 PiB of disk space. Saved memory must be a whole number of MiB and disk space a whole number of GiB. Creation also checks the host's CPU and memory capacity, available storage and the selected image's minimum disk size.

Plans are creation defaults, not quotas. Editing or deleting one does not resize existing virtual machines or change already submitted jobs. Host administrators can manage plans. In read-only mode, they can only view them.
