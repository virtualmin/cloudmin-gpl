Planos de conta
Um plano de conta define limites para o número de sistemas virtuais e os recursos que eles podem consumir, aplicáveis aos proprietários do sistema. Eles permitem que você conceda a diferentes clientes o direito de criar sistemas usando o Cloudmin, até limites predefinidos para que eles não usem todo o disco ou RAM disponível.

Os planos podem ser usados para restringir os seguintes recursos:

  • Número de sistemas virtuais - O proprietário do sistema não poderá criar nenhuma nova instância virtual depois que o número que ele possui atingir esse limite.
  • RAM para sistemas virtuais - o limite total de RAM atribuído a todas as instâncias virtuais do proprietário não poderá exceder esse limite. Isso se aplica no momento da criação e ao alterar o limite de RAM em um sistema existente.
  • Disco para sistemas virtuais - O espaço total ocupado por todos os discos em todas as instâncias virtuais não poderá exceder esse limite. Isso se aplica no momento da criação e ao adicionar ou expandir discos em um sistema existente.
  • CPU para sistemas virtuais - não será permitido que os limites percentuais totais de tempo de CPU para todas as instâncias virtuais do proprietário excedam esse limite. Isso se aplica no momento da criação e ao alterar o limite da CPU em um sistema existente.
