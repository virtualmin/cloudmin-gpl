Cloudmin Plugins
Ein Plugin ist ein Webmin-Modul, das Cloudmin zusätzliche Funktionen hinzufügt, z. B. Links im linken Menü oder Felder im Erstellungsformular für das virtuelle System. Auf dieser Seite werden alle installierten Plugins aufgelistet und Sie können diejenigen auswählen, die mithilfe von Kontrollkästchen in der ersten Spalte aktiviert werden sollen. Cloudmin verwendet nur aktivierte Plugins.
