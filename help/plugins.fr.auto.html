Plugins Cloudmin
Un plugin est un module Webmin qui ajoute des fonctionnalités supplémentaires à Cloudmin, telles que des liens dans le menu de gauche ou des champs sur le formulaire de création de système virtuel. Cette page répertorie tous les plugins installés et vous permet de sélectionner ceux qui doivent être activés à l'aide des cases à cocher dans la première colonne. Seuls les plugins activés sont réellement utilisés par Cloudmin.
