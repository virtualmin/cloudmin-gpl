Remote Access

SSH needs guest networking. The serial and graphical consoles can reach a running machine even when its network is unavailable.

For SSH, use the guest account with a password or Cloudmin-managed key. Verify an unfamiliar host-key fingerprint before accepting it. The last successful SSH port is shared by all users of that machine.

The serial console needs a guest login prompt or boot output on the serial port. Only one connection can use it at a time, and a previous login may remain active. Recorded output can include echoed commands. Graphical access needs a VNC display and is useful during installation.

Direct Webmin access opens the guest address, which must be reachable from your browser. Embedded access works behind NAT and uses Servers Index credentials. Update those credentials if the guest password changes.

Embedded Webmin is available only to the host's root Webmin login. Use it only for fully trusted guests: their pages can use your host session to compromise this host and other machines. Confirm changed guest addresses before connecting.
