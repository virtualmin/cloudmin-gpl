Remote Access

Choose a tab to connect to a running virtual machine. Only tabs you have permission to use appear. Leaving a console tab disconnects it; select it again to reconnect.

Remote Access remembers your last selected tab, including when you open another virtual machine. Each Webmin user has a separate saved choice. Turn off Remember the last remote connection tab? in Module Configuration to open SSH first when permitted. Links to a specific tab override the saved choice.

SSH terminal

Connect using the guest's IP address, username and SSH port. Choose its host-managed SSH key, if available, or enter a password in the terminal. Passwords entered there are not saved or logged.

SSH defaults to port 22. After a successful login, Cloudmin saves that virtual machine's port as the default for all Webmin users and for the SSH service card. If the guest's SSH port changes, enter the new port and log in once to save it. Failed logins leave the saved port unchanged. An SSH response does not mean first-boot setup has finished.

Turn on Connect automatically when opening the SSH tab? in Module Configuration to skip the form. It is off by default. Automatic connection uses the shared SSH port and your saved username and authentication method. These login choices are saved separately for each user and virtual machine. The first attempt uses the form defaults.

Failed logins return to the form. Failed or unfinished attempts pause automatic connection until a login succeeds. Use Connection settings above the terminal to change your username, port or login method.

On first connection, confirm the guest's SSH host key. Cloudmin remembers it for your Webmin account and blocks connections if it changes.

Serial console

Use the guest's text console without networking or SSH. The guest must send boot output or a login prompt to its serial port. Log in with a guest username and password; SSH keys cannot be used here.

When recording is enabled, recent output appears as you connect without sending keystrokes. Cloudmin enables recording on supported ports when starting a fully stopped virtual machine. A guest reboot or resume from a managed save does not enable it. If no history is available, press Enter only when it is safe to submit pending input. A previous login may still be active.

Private logs on the host keep serial output, including echoed commands. The logs rotate to limit disk use. A cold start clears the previous recording; deleting the virtual machine through Cloudmin removes its logs.

Only one connection can use the serial port. Use Disconnect serial console in the connected tab to release it without leaving the page. Select the Serial console tab again to reconnect. An interrupted connection clears within about a minute.

If text wraps incorrectly after resizing, run stty rows 24 cols 80 inside the guest, using the dimensions you need.

Graphical console

Use the guest's screen, keyboard and mouse, including during boot or without networking. A VNC display is required, but no separate VNC password is needed. Use the keyboard menu to send shortcuts such as Ctrl+Alt+Delete.

Console controls

Serial and graphical consoles require a local libvirt connection. Use Fullscreen for a larger view.

Click inside the console, then use Command + / − on macOS or Ctrl + / − on Linux to zoom. Use Command 0 or Ctrl 0 to reset. Serial zoom changes text size; graphical zoom scales the display without changing the guest's resolution.

Webmin

Open directly in new tab opens the guest's own HTTPS address. Sign in with a guest Webmin account. Private addresses may be unreachable from your browser.

Open embedded Webmin also works behind NAT. Read the orange warning before using it: a compromised guest can compromise the host and other virtual machines through your host session. Use this mode only for a fully trusted guest.

By default, opening the Webmin tab shows the connection choices without loading the guest's pages. Click the tab again to return to these choices from the embedded view. Use Fullscreen for a larger view. Embedded pages follow the host's colors; direct tabs use the guest's preferences.

Disabling Show Webmin connection choices and a trust warning? in Module Configuration opens registered guests in the embedded view immediately. Disable it only for fully trusted virtual machines. Changed IP addresses still require confirmation.

  • Embedded login: The host's Servers Index uses its saved guest credentials, or asks for a guest login if none were saved. Choose Open embedded Webmin to retry a failed registration after setup finishes.
  • Password changed? Update the saved login in the host's Webmin Servers Index.
  • IP changed? An alert shows both addresses and whether the new one matches the host's static configuration or a DHCP lease for this virtual machine's MAC address. Confirm the address before opening embedded Webmin.

Only the host's root Webmin login can use this tab. Servers Index permissions still apply. A proxy URL shares the host's browser origin even when opened in another tab.
