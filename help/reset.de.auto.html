Vom Bild zurücksetzen
Auf dieser Seite können Sie ein virtuelles System auf den Zustand zurücksetzen, in dem es sich befand, als es ursprünglich aus einem Systemabbild erstellt wurde. Alle seitdem hinzugefügten oder geänderten Dateien gehen verloren und alle gelöschten Dateien werden wiederhergestellt. Darüber hinaus gehen alle auf dem System gehosteten virtuellen Virtualmin-Server verloren.
