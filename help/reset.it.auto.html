Ripristina dall'immagine
Questa pagina consente di ripristinare un sistema virtuale allo stato in cui si trovava quando originariamente creato da un'immagine di sistema. Tutti i file aggiunti o modificati da allora andranno persi e tutti i file eliminati verranno ripristinati. Inoltre, tutti i server virtuali Virtualmin ospitati sul sistema andranno persi.
