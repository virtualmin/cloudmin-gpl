Restore a Virtual Machine

Select the backup source and archive filename, then choose Read Backup Contents. Cloudmin downloads and checks the archive before showing its machine name, UUID and disk count.

Review these details, choose a storage pool and confirm that the original machine will not run alongside the restored copy. Then choose Restore Now. The restored machine stays stopped until you start it. Automatic startup is disabled.

Restore keeps the original identity, network settings and credentials. It refuses to overwrite a machine with the same name or UUID. Use Clone virtual machine when you need another machine with a new identity.

The host must support the archived machine's architecture and firmware, and provide its network or bridge attachments. Allow enough space for downloads, extracted disks and the final volumes. Disks can need their full logical size; do not estimate space from the compressed archive size alone.
