Restore a Virtual Machine

Read the archive first, then review its contents and choose a storage pool. Restore creates a stopped machine with automatic startup disabled.

The original identity, network settings and credentials are preserved. Keep the original machine off before starting the restored copy, even if it is on another host. Existing machines with the same name or UUID are never overwritten.

The host must support the archived architecture and firmware and provide its networks or bridges. Allow space for temporary extraction and the disks' full capacities, not just the compressed archive. Use cloning when you want a separate identity.
