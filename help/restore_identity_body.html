The displayed name and UUID identify the machine stored in the archive. They are preserved on restore, as are its hostname, machine ID, host ID, MAC addresses, IP settings, passwords, SSH keys and license files.

Restore stops if a machine with the same name or UUID already exists. It creates a stopped machine with automatic startup disabled. Existing guests are never overwritten or merged.

By confirming, you agree to keep the original machine off when starting the restored copy, even if the original is on another host. Running both can cause address conflicts and duplicate license use. Restore does not replace or deregister software licenses.

Use Clone virtual machine when you want another machine with a separate identity.
