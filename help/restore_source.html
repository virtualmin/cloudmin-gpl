Backup source

Select the location containing the Cloudmin archive. The connection settings are the same as for a backup destination, but the account needs permission to read the selected file. Enter its directory or folder separately from the archive filename.

When restoring from Saved Backups, Cloudmin uses that backup's recorded location and credentials. To use another location or updated credentials, open Restore a Virtual Machine and enter them directly.

Read Backup Contents downloads and verifies the archive; it does not create or start a machine. The temporary download is removed after restore. Unused inspections expire after a day; read the archive again if it has expired.
