Adressen umkehren
Auf dieser Seite können Sie die Hostnamen konfigurieren, die als Antwort auf die umgekehrte Suche der IP-Adresse (n) Ihres virtuellen Systems zurückgegeben werden. Wenn Sie eine Website oder E-Mail-Domain auf dem System hosten, sollten diese normalerweise in die DNS-Domain der primären Website aufgelöst werden, z. B. example.com .
