DNS Roundrobins
Cette page vous permet de créer et de gérer des entrées DNS qui sont automatiquement mises à jour pour résoudre les adresses IP de plusieurs systèmes, sélectionnées en fonction de leur état de santé ou d'autres critères. Ceux-ci peuvent être utilisés pour équilibrer le trafic Web entre plusieurs serveurs, tout en supprimant automatiquement les systèmes en panne.

Pour créer une nouvelle table ronde, cliquez sur le lien Ajouter une nouvelle table ronde DNS sur cette page. Sur le formulaire qui apparaît, vous devrez sélectionner un ou plusieurs systèmes gérés que l'entrée DNS de la table ronde résoudra, ce qui peut être fait par système, par groupe ou par propriétaire. Vous devrez également sélectionner la zone DNS à laquelle ajouter l'enregistrement roundrobin et entrer un nom d'hôte dans la zone.

Après la création d'une table ronde, elle peut être modifiée à partir de cette page en cliquant sur le nom de domaine. Une ou plusieurs tables rondes peuvent également être supprimées en cochant les cases en regard du nom et en cliquant sur Supprimer les tables rondes sélectionnées . Cela supprimera également l'enregistrement DNS.

Les tables rondes seront mises à jour après chacune des vérifications de l'état d'arrière-plan de Cloudmin, qui se produisent par défaut toutes les 5 minutes. Vous pouvez également forcer une mise à jour immédiate avec le bouton Actualiser les Roundrobins .
