DNS Roundrobins
Эта страница позволяет создавать и управлять записями DNS, которые автоматически обновляются для разрешения IP-адресов нескольких систем, выбранных на основе их работоспособности или других критериев. Их можно использовать для балансировки веб-трафика между несколькими серверами, автоматически удаляя те системы, которые вышли из строя.

Чтобы создать новый циклический круг, нажмите ссылку Добавить новый круговой список DNS на этой странице. В появившейся форме вам нужно будет выбрать одну или несколько управляемых систем, к которым будет разрешена запись в циклическом DNS, что может быть сделано для каждой системы, группой или владельцем. Вам также нужно будет выбрать зону DNS, в которую вы хотите добавить запись Roundrobin, и ввести имя хоста внутри зоны.

После создания циклического заголовка его можно изменить на этой странице, щелкнув имя домена. Одну или несколько круглых крышек также можно удалить, установив флажки рядом с именем и нажав «Удалить выбранные круглые корзины» . Это также удалит запись DNS.

Раундробины будут обновляться после каждой проверки статуса Cloudmin в фоновом режиме, которая по умолчанию выполняется каждые 5 минут. Вы также можете вызвать немедленное обновление с помощью кнопки Обновить круглые .
