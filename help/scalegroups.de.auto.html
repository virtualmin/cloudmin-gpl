Auto-Scaling-Gruppen
Auto-Scaling-Gruppen sind Cloudmins Methode, um die Anzahl der Systeme zu erhöhen, die als Reaktion auf das Laden einen Dienst bereitstellen. Sie werden normalerweise verwendet, wenn Sie mehrere virtuelle Systeme mit identischen Konfigurationen haben, die denselben Dienst bereitstellen, z. B. eine Website, einen Mailserver oder Datenbankreplikate. Wenn die CPU-Auslastung oder eine andere Metrik auf einigen oder allen Systemen einen konfigurierbaren Schwellenwert überschreitet, werden zusätzliche Systeme erstellt, um die Auslastung zu bewältigen. Umgekehrt kann eine Gruppe verkleinert werden, wenn ein zweiter Satz von Schwellenwerten erreicht wird.

Auf dieser Seite werden alle vorhandenen Gruppen für die automatische Skalierung aufgelistet und Sie können eine neue Gruppe für virtuelle Systeme eines bestimmten Typs erstellen. Beim Hinzufügen einer Gruppe können Sie das maximale und minimale System in der Gruppe, eine Vorlage für den Hostnamen neuer Systeme und eine oder mehrere Bedingungen auswählen, die steuern, wann die Gruppe vergrößert (durch Hinzufügen eines Systems) oder verkleinert wird.

Jedes neue System in der Gruppe wird durch Klonen eines vorhandenen Vorlagensystems erstellt, genauso wie Systeme manuell aus Cloudmin heraus geklont werden können. Die Ausnahme bilden automatische Skalierungsgruppen von Amazon EC2, die Systeme aus AMIs erstellen.

Sobald eine Gruppe erstellt wurde, wird sie von Cloudmin regelmäßig ausgewertet, um festzustellen, ob mehr oder weniger Systeme benötigt werden. Für jede Gruppe können Sie steuern, wer wie oft über Gruppenänderungen benachrichtigt wird.

Sobald eine oder mehrere Gruppen vorhanden sind, können Sie diese Seite verwenden, um sie manuell zu vergrößern oder zu verkleinern oder eine sofortige Bewertung ihrer Skalierungsregeln zu erzwingen. Für eine neue Gruppe sollten Sie nach der Erstellung in der Regel mindestens ein System mit der Schaltfläche " Gruppen vergrößern" hinzufügen, damit die Regeln über ein System verfügen, an dem gearbeitet werden kann.
