Grupos de autoescalado
Los grupos de autoescalado son la forma en que Cloudmin aumenta el número de sistemas que brindan algún servicio en respuesta a la carga. Por lo general, se usan cuando tiene múltiples sistemas virtuales con configuraciones idénticas que brindan el mismo servicio, como un sitio web, un servidor de correo o réplicas de bases de datos. Cuando la carga de la CPU o alguna otra métrica excede un umbral configurable en algunos o en todos los sistemas, se crean sistemas adicionales para manejar la carga. Por el contrario, se puede reducir el tamaño de un grupo cuando se alcanza un segundo conjunto de umbrales.

Esta página enumera todos los grupos de autoescalado existentes y le permite crear uno nuevo para sistemas virtuales de algún tipo. Al agregar un grupo, puede seleccionar los sistemas máximos y mínimos en el grupo, una plantilla para el nombre de host de los nuevos sistemas y una o más condiciones que controlan cuándo el grupo se amplía (agregando un sistema) o se reduce.

Cada nuevo sistema en el grupo se crea clonando un sistema de plantilla existente, de la misma manera que los sistemas se pueden clonar manualmente desde Cloudmin. La excepción son los grupos de escalado automático de Amazon EC2, que crean sistemas a partir de AMI.

Una vez que se crea un grupo, Cloudmin lo evaluará periódicamente para determinar si se necesitan más o menos sistemas. Para cada grupo, puede controlar quién recibe la notificación sobre los cambios del grupo y con qué frecuencia.

Una vez que existan uno o más grupos, esta página se puede usar para escalarlos manualmente o para forzar la evaluación inmediata de sus reglas de escala. Para un grupo nuevo, normalmente debe agregar al menos un sistema con el botón Escalar grupos después de la creación, para que las reglas tengan un sistema en el que trabajar.
