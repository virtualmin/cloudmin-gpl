Grupos de dimensionamento automático
Grupos de dimensionamento automático são a maneira do Cloudmin de aumentar o número de sistemas que fornecem algum serviço em resposta ao carregamento. Eles geralmente são usados quando você possui vários sistemas virtuais com configurações idênticas que fornecem o mesmo serviço, como um site, servidor de correio ou réplicas de banco de dados. Quando a carga da CPU ou alguma outra métrica excede um limite configurável em alguns ou todos os sistemas, sistemas adicionais são criados para lidar com a carga. Por outro lado, um grupo pode ser reduzido em tamanho quando um segundo conjunto de limites é atingido.

Esta página lista todos os grupos de dimensionamento automático existentes e permite criar um novo para sistemas virtuais de algum tipo. Ao adicionar um grupo, você pode selecionar os sistemas máximo e mínimo no grupo, um modelo para o nome do host de novos sistemas e uma ou mais condições que controlam quando o grupo é ampliado (adicionando um sistema) ou diminuído.

Cada novo sistema no grupo é criado pela clonagem de um sistema de modelos existente, da mesma maneira que os sistemas podem ser clonados manualmente a partir do Cloudmin. A exceção são os grupos de dimensionamento automático do Amazon EC2, que criam sistemas a partir de AMIs.

Depois que um grupo é criado, ele é avaliado periodicamente pelo Cloudmin para determinar se são necessários mais ou menos sistemas. Para cada grupo, você pode controlar quem é notificado sobre as alterações do grupo e com que frequência.

Depois que um ou mais grupos existirem, esta página poderá ser usada para escalá-los manualmente para cima ou para baixo ou forçar uma avaliação imediata de suas regras de dimensionamento. Para um novo grupo, você normalmente deve adicionar pelo menos um sistema a ele com o botão Expandir Grupos após a criação, para que as regras tenham um sistema no qual trabalhar.
