Suchen Sie nach EC2-Instanzen
Wenn bereits viele Systeme unter EC2 ausgeführt werden, können auf dieser Seite alle Instanzen eines Kontos unter die Verwaltung von Cloudmin gestellt werden.

Die folgenden Felder werden im Formular angezeigt:

EC2-Konto
Das Konto, dessen Systeme Sie importieren möchten.
SSH-Anmeldeschlüssel
Um ein System zu verwalten, muss sich Cloudmin über SSH remote bei ihm anmelden. In diesem Menü müssen Sie den EC2-SSH-Schlüssel auswählen, mit dem die Systeme erstellt wurden.
SSH-Protokollversion
Standardmäßig verwendet Cloudmin das neuere und fast universell bereitgestellte SSH-Protokoll der Version 2, um eine Verbindung zu verwalteten Systemen herzustellen. Wenn das hinzugefügte System jedoch nur SSH 1 unterstützt, können Sie es hier auswählen.
SSH-Benutzername
Dies ist normalerweise root , aber wenn das System einen anderen Benutzer mit UID 0 hat, den Sie stattdessen verwenden möchten, geben Sie ihn hier ein.
Webmin-Anmeldemodus
Wenn Webmin oder Virtualmin bereits auf dem hinzugefügten System installiert ist, müssen Sie in diesem Abschnitt die richtigen Authentifizierungsdaten auswählen. Wenn das Webmin-Kennwort mit dem Unix- Root- Konto identisch ist, wählen Sie Anmelden als Root mit demselben Kennwort wie im Unix- Modus. Wenn Webmin eine andere Anmeldung verwendet, wählen Sie Anmelden als und geben Sie den richtigen Benutzernamen und das richtige Kennwort ein.
Wenn Webmin im SSL-Modus ausgeführt wird, müssen Sie das Kontrollkästchen SSL für die Verbindung mit Webmin verwenden aktivieren. Dies ist die Standardeinstellung für die meisten Installationen, insbesondere wenn Webmin als Teil des Virtualmin-Stacks eingerichtet wird.
Webmin-Port
Wenn Webmin auf dem Standardport 10000 ausgeführt wird, können Sie dieses Feld unverändert lassen. Andernfalls müssen Sie die richtige Portnummer eingeben.
