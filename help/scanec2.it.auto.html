Trova istanze EC2
Se disponi già di molti sistemi in esecuzione su EC2, questa pagina può essere utilizzata per portare tutte le istanze di proprietà di alcuni account nella gestione di Cloudmin.

I seguenti campi sono visualizzati nel modulo:

Conto EC2
L'account di cui desideri importare i sistemi.
Chiave di accesso SSH
Per gestire un sistema, Cloudmin deve effettuare l'accesso remoto tramite SSH. Da questo menu è necessario scegliere la chiave SS2 EC2 utilizzata per creare i sistemi.
Versione protocollo SSH
Per impostazione predefinita, Cloudmin utilizza il protocollo SSH versione 2 più recente e distribuito quasi universalmente per connettersi ai sistemi gestiti, ma se il sistema che stai aggiungendo supporta solo SSH 1, puoi selezionarlo qui.
Nome utente SSH
Questo è normalmente root , ma se il sistema ha un altro utente con UID 0 che si desidera utilizzare, immetterlo qui.
Modalità di accesso Webmin
Se Webmin o Virtualmin sono già installati sul sistema da aggiungere, è necessario selezionare le credenziali di autenticazione corrette in questa sezione. Se la password Webmin è la stessa dell'account root Unix, selezionare Accedi come root con la stessa password della modalità Unix . Se Webmin utilizza un altro accesso, selezionare Accedi come e immettere il nome utente e la password corretti.
Se Webmin è in esecuzione in modalità SSL, sarà necessario selezionare la casella Usa SSL per connettersi a Webmin . Questo è il valore predefinito per la maggior parte delle installazioni, specialmente quando Webmin è configurato come parte dello stack Virtualmin.
Porta Webmin
Se Webmin è in esecuzione sulla porta predefinita 10000, è possibile lasciare questo campo invariato. Altrimenti, è necessario inserire il numero di porta corretto.
