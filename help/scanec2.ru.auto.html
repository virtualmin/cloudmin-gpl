Найти экземпляры EC2
Если у вас уже есть много систем, работающих под EC2, эту страницу можно использовать для передачи всех экземпляров, принадлежащих какой-либо учетной записи, под управление Cloudmin.

В форме отображаются следующие поля:

EC2 аккаунт
Учетная запись, системы которой вы хотите импортировать.
SSH ключ входа
Для управления системой Cloudmin необходимо удаленно войти в систему через SSH. В этом меню вы должны выбрать ключ ECH SSH, который использовался для создания систем.
Версия протокола SSH
По умолчанию Cloudmin использует более новый и почти универсально развернутый протокол SSH версии 2 для подключения к управляемым системам, но если добавляемая система поддерживает только SSH 1, вы можете выбрать его здесь.
Имя пользователя SSH
Обычно это root , но если в системе есть другой пользователь с UID 0, который вы хотели бы использовать вместо этого, введите его здесь.
Режим входа в Webmin
Если Webmin или Virtualmin уже установлены в добавляемой системе, вы должны выбрать правильные учетные данные для аутентификации в этом разделе. Если пароль Webmin совпадает с корневой учетной записью Unix, выберите «Вход в систему как root» с тем же паролем, что и в режиме Unix . Если Webmin использует другой логин, выберите Login as и введите правильное имя пользователя и пароль.
Если Webmin работает в режиме SSL, вам необходимо установить флажок Использовать SSL для подключения к Webmin . Это значение по умолчанию для большинства установок, особенно когда Webmin настроен как часть стека Virtualmin.
Webmin порт
Если Webmin работает на порте по умолчанию 10000, вы можете оставить это поле без изменений. В противном случае вы должны ввести правильный номер порта.
