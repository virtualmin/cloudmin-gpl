Finden Sie GCE-Instanzen
Wenn bereits viele Systeme unter GCE ausgeführt werden, können auf dieser Seite alle Instanzen eines Projekts unter die Verwaltung von Cloudmin gestellt werden.

Die folgenden Felder werden im Formular angezeigt:

GCE-Projekt
In diesem Menü müssen Sie das Google-Konto und das GCE-Projekt auswählen, dem die hinzuzufügenden Instanzen gehören.
SSH-Anmeldeschlüssel
Um ein System zu verwalten, muss sich Cloudmin über SSH remote bei ihm anmelden. GCE unterstützt die Anmeldung über ein Kennwort nicht, daher muss dieser Schlüssel bereits bei GCE registriert sein.
SSH-Benutzername
Dies muss entweder root sein oder ein Benutzer, der die Berechtigung hat, sudo to root zu verwenden.
Webmin-Anmeldemodus
Wenn Webmin oder Virtualmin bereits auf dem hinzugefügten System installiert ist, müssen Sie in diesem Abschnitt die richtigen Authentifizierungsdaten auswählen. Da GCE-Instanzen immer Schlüssel für SSH verwenden, müssen Sie hier ein Login und ein Passwort für Webmin eingeben.
Wenn Webmin im SSL-Modus ausgeführt wird, müssen Sie das Kontrollkästchen SSL für die Verbindung mit Webmin verwenden aktivieren. Dies ist die Standardeinstellung für die meisten Installationen, insbesondere wenn Webmin als Teil des Virtualmin-Stacks eingerichtet wird.
Webmin-Port
Wenn Webmin auf dem Standardport 10000 ausgeführt wird, können Sie dieses Feld unverändert lassen. Andernfalls müssen Sie die richtige Portnummer eingeben.
