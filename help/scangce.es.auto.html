Encuentre instancias de GCE
Si ya tiene muchos sistemas ejecutándose bajo GCE, esta página se puede usar para reunir todas las instancias de algún proyecto bajo la administración de Cloudmin.

Los siguientes campos se muestran en el formulario:

Proyecto CME
En este menú, debe seleccionar la cuenta de Google y el proyecto GCE que posee las instancias para agregar.
Clave de inicio de sesión SSH
Para administrar un sistema, Cloudmin necesita iniciar sesión de forma remota a través de SSH. GCE no admite el inicio de sesión mediante una contraseña, por lo que esta clave ya debe estar registrada con GCE.
Nombre de usuario SSH
Debe ser root o un usuario que tenga permisos para sudo a root.
Modo de inicio de sesión de Webmin
Si Webmin o Virtualmin ya está instalado en el sistema que se está agregando, debe seleccionar las credenciales de autenticación correctas en esta sección. Dado que las instancias de GCE siempre usan claves para SSH, debe ingresar un nombre de usuario y contraseña para Webmin aquí.
Si Webmin se está ejecutando en modo SSL, deberá marcar la casilla Usar SSL para conectarse a Webmin . Este es el valor predeterminado para la mayoría de las instalaciones, especialmente cuando Webmin se configura como parte de la pila de Virtualmin.
Puerto Webmin
Si Webmin se ejecuta en el puerto predeterminado 10000, puede dejar este campo sin cambios. De lo contrario, debe ingresar el número de puerto correcto.
