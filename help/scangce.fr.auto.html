Rechercher des instances GCE
Si vous avez déjà de nombreux systèmes fonctionnant sous GCE, cette page peut être utilisée pour mettre toutes les instances appartenant à un projet sous la gestion de Cloudmin.

Les champs suivants sont affichés sur le formulaire:

Projet GCE
Dans ce menu, vous devez sélectionner le compte Google et le projet GCE qui possèdent les instances à ajouter.
Clé de connexion SSH
Pour gérer un système, Cloudmin doit s'y connecter à distance via SSH. GCE ne prend pas en charge la connexion via un mot de passe, cette clé doit donc être déjà enregistrée auprès de GCE.
Nom d'utilisateur SSH
Il doit s'agir de root , ou d'un utilisateur qui a les droits de sudo pour rooter.
Mode de connexion Webmin
Si Webmin ou Virtualmin est déjà installé sur le système en cours d'ajout, vous devez sélectionner les informations d'authentification correctes dans cette section. Étant donné que les instances GCE utilisent toujours des clés pour SSH, vous devez saisir ici un identifiant et un mot de passe pour Webmin.
Si Webmin s'exécute en mode SSL, vous devrez cocher la case Utiliser SSL pour vous connecter à Webmin . Il s'agit de la valeur par défaut pour la plupart des installations, en particulier lorsque Webmin est configuré dans le cadre de la pile Virtualmin.
Port Webmin
Si Webmin s'exécute sur le port par défaut 10000, vous pouvez laisser ce champ inchangé. Sinon, vous devez entrer le bon numéro de port.
