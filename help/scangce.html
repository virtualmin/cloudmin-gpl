Find GCE Instances
If you have many systems running under GCE already, this page can be used to bring all instances owned by some project under Cloudmin's management.

The following fields are displayed on the form :

GCE project
From this menu you must select the Google account and GCE project that owns the instances to add.
SSH login key
In order to manage a system, Cloudmin needs to remotely login to it via SSH. GCE does not support logging in via a password, so this key must be already registered with GCE.
SSH username
This must be either root, or a user who has permissions to sudo to root.
Webmin login mode
If Webmin or Virtualmin is already installed on the system being added, you must select the correct authentication credentials in this section. Since GCE instances always use keys for SSH, you must enter a login and password for Webmin here.
If Webmin is running in SSL mode, you will need to check the Use SSL to connect to Webmin box. This is the default for most installs, especially when Webmin is setup as part of the Virtualmin stack.
Webmin port
If Webmin is running on the default port 10000, you can leave this field un-changed. Otherwise, you must enter the correct port number.
