Trova istanze GCE
Se hai già molti sistemi in esecuzione su GCE, questa pagina può essere utilizzata per portare tutte le istanze di proprietà di alcuni progetti sotto la gestione di Cloudmin.

I seguenti campi sono visualizzati nel modulo:

Progetto GCE
Da questo menu è necessario selezionare l'account Google e il progetto GCE che possiede le istanze da aggiungere.
Chiave di accesso SSH
Per gestire un sistema, Cloudmin deve effettuare l'accesso remoto tramite SSH. GCE non supporta l'accesso tramite password, quindi questa chiave deve essere già registrata con GCE.
Nome utente SSH
Deve essere root o un utente che dispone delle autorizzazioni per eseguire sudo to root.
Modalità di accesso Webmin
Se Webmin o Virtualmin sono già installati sul sistema da aggiungere, è necessario selezionare le credenziali di autenticazione corrette in questa sezione. Poiché le istanze GCE utilizzano sempre le chiavi per SSH, è necessario immettere un account di accesso e una password per Webmin qui.
Se Webmin è in esecuzione in modalità SSL, sarà necessario selezionare la casella Usa SSL per connettersi a Webmin . Questo è il valore predefinito per la maggior parte delle installazioni, specialmente quando Webmin è configurato come parte dello stack Virtualmin.
Porta Webmin
Se Webmin è in esecuzione sulla porta predefinita 10000, è possibile lasciare questo campo invariato. Altrimenti, è necessario inserire il numero di porta corretto.
