Localizar instâncias GCE
Se você já possui muitos sistemas em execução no GCE, esta página pode ser usada para colocar todas as instâncias pertencentes a algum projeto ao gerenciamento do Cloudmin.

Os seguintes campos são exibidos no formulário:

Projeto GCE
Nesse menu, você deve selecionar a conta do Google e o projeto GCE que possui as instâncias a serem adicionadas.
Chave de login SSH
Para gerenciar um sistema, o Cloudmin precisa fazer login remotamente via SSH. O GCE não suporta o login via senha, portanto, essa chave já deve estar registrada no GCE.
Nome de usuário SSH
Deve ser raiz ou um usuário que tenha permissões de sudo para raiz.
Modo de login do Webmin
Se o Webmin ou o Virtualmin já estiver instalado no sistema que está sendo adicionado, você deverá selecionar as credenciais de autenticação corretas nesta seção. Como as instâncias do GCE sempre usam chaves para SSH, você deve inserir um login e senha para o Webmin aqui.
Se o Webmin estiver em execução no modo SSL, você precisará marcar a caixa Usar SSL para se conectar ao Webmin . Esse é o padrão para a maioria das instalações, especialmente quando o Webmin é configurado como parte da pilha do Virtualmin.
Porta Webmin
Se o Webmin estiver em execução na porta 10000 padrão, você poderá deixar esse campo sem alterações. Caso contrário, você deve inserir o número da porta correto.
