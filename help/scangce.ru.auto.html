Найти экземпляры GCE
Если у вас уже много систем, работающих под GCE, эту страницу можно использовать для передачи всех экземпляров, принадлежащих какому-либо проекту, под управление Cloudmin.

В форме отображаются следующие поля:

Проект GCE
В этом меню вы должны выбрать учетную запись Google и проект GCE, которому принадлежат экземпляры для добавления.
SSH ключ входа
Для управления системой Cloudmin необходимо удаленно войти в систему через SSH. GCE не поддерживает вход через пароль, поэтому этот ключ должен быть уже зарегистрирован в GCE.
Имя пользователя SSH
Это должен быть либо пользователь root , либо пользователь, у которого есть права на sudo для root.
Режим входа в Webmin
Если Webmin или Virtualmin уже установлены в добавляемой системе, вы должны выбрать правильные учетные данные для аутентификации в этом разделе. Поскольку экземпляры GCE всегда используют ключи для SSH, вы должны здесь ввести логин и пароль для Webmin.
Если Webmin работает в режиме SSL, вам необходимо установить флажок Использовать SSL для подключения к Webmin . Это значение по умолчанию для большинства установок, особенно когда Webmin настроен как часть стека Virtualmin.
Webmin порт
Если Webmin работает на порте по умолчанию 10000, вы можете оставить это поле без изменений. В противном случае вы должны ввести правильный номер порта.
