Encontre sistemas existentes
Se você possui muitos sistemas físicos existentes em sua rede que deseja colocar sob o controle do Cloudmin, qual página pode ser usada, verifique uma variedade de endereços IP e adicione sistemas encontrados.

Os seguintes campos são exibidos no formulário:

Intervalo de IP a pesquisar
Iniciando e finalizando endereços IP para varredura, inclusive.
Modo de login raiz
Para gerenciar um sistema, o Cloudmin precisa fazer login remotamente via SSH. Nesta seção, você deve inserir a senha raiz do SSH ou selecionar uma chave registrada no Cloudmin que a conta raiz esteja configurada para aceitar.
Versão do protocolo SSH
Por padrão, o Cloudmin usa o protocolo SSH versão 2 mais recente e quase universalmente implantado para conectar-se a sistemas gerenciados, mas se o sistema que você está adicionando suporta apenas o SSH 1, você pode selecioná-lo aqui.
Nome de usuário SSH
Normalmente, isso é raiz , mas se o sistema tiver outro usuário com UID 0 que você gostaria de usar, digite-o aqui.
Modo de login do Webmin
Se o Webmin ou o Virtualmin já estiver instalado no sistema que está sendo adicionado, você deverá selecionar as credenciais de autenticação corretas nesta seção. Se a senha do Webmin for a mesma da conta raiz do Unix, selecione Login como root com a mesma senha do modo Unix . Se o Webmin usar um login diferente, escolha Login como e digite o nome de usuário e a senha corretos.
Se o Webmin estiver em execução no modo SSL, você precisará marcar a caixa Usar SSL para se conectar ao Webmin . Esse é o padrão para a maioria das instalações, especialmente quando o Webmin é configurado como parte da pilha do Virtualmin.
Porta Webmin
Se o Webmin estiver em execução na porta 10000 padrão, você poderá deixar esse campo sem alterações. Caso contrário, você deve inserir o número da porta correto.
