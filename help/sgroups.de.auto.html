EC2-Sicherheitsgruppen
Eine EC2-Sicherheitsgruppe besteht im Wesentlichen aus einer Reihe von Firewall-Regeln, die auf mehrere EC2-Instanzen angewendet werden können. Jede Gruppe definiert eine Liste von Ports und optional Hosts, die mit dieser Gruppe eine Verbindung zu Instanzen herstellen dürfen. Gruppen können auch Mitgliedern anderer Gruppen Zugriff gewähren und so die Kommunikation zwischen EC2-Systemen ermöglichen.

Diese Seite listet alle Sicherheitsgruppen auf, die Ihren EC2-Konten zugeordnet sind. Anfangs gibt es nur eine einzige Standardgruppe. Wenn Sie jedoch Instanzen erstellt haben, gibt es auch eine virtualmin- Gruppe, die den Zugriff auf Ports ermöglicht, die für das Web- und E-Mail-Hosting verwendet werden.

Um eine vorhandene Gruppe zu bearbeiten, klicken Sie einfach auf ihren Namen. Um eine oder mehrere Gruppen zu entfernen, die nicht verwendet werden, aktivieren Sie die Kontrollkästchen neben ihnen und klicken Sie auf die Schaltfläche Löschen .
