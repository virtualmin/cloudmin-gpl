Instantâneos de disco
No Cloudmin, um instantâneo é uma cópia de todos os discos virtuais que compõem um sistema. A captura instantânea só é possível para discos armazenados em grupos de volumes LVM e hospedados em sistemas cujo kernel inclui o recurso de mesclagem de captura instantânea. A qualquer momento após a criação de um instantâneo, o sistema virtual pode ser revertido para o estado em que seus discos estavam no momento em que o instantâneo foi obtido.

Esta página lista todos os instantâneos associados ao sistema virtual, se houver. Para reverter para um instantâneo, clique nele e, em seguida, clique no botão Reverter . Para remover um ou mais instantâneos, marque as caixas ao lado deles e clique no botão Excluir .

Um novo instantâneo pode ser criado usando o formulário na parte inferior da página. Se a porcentagem estiver definida como algo menor que 100, é possível que o instantâneo seja completamente preenchido se houver muitas alterações no sistema de arquivos dos sistemas virtuais. Quando isso acontecer, não será mais possível reverter para o estado no instantâneo.
