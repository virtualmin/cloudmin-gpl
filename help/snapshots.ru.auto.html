Снимки диска
В Cloudmin снимок - это копия всех виртуальных дисков, составляющих систему. Снимок возможен только для дисков, которые хранятся в группах томов LVM и размещены в системах, ядро которых включает функцию слияния снимков. В любое время после создания моментального снимка виртуальная система может быть возвращена в состояние, в котором находились ее диски на момент создания моментального снимка.

На этой странице перечислены все снимки, связанные с виртуальной системой, если таковые имеются. Чтобы вернуться к снимку, щелкните по нему, а затем нажмите кнопку «Восстановить» . Чтобы удалить один или несколько снимков, установите флажки рядом с ними и нажмите кнопку «Удалить» .

Новый снимок может быть создан с помощью формы внизу страницы. Если для процента задано значение меньше 100, снимок может полностью заполниться, если в файловой системе виртуальных систем слишком много изменений. Как только это произойдет, больше не будет возможности вернуться к состоянию в снимке.
