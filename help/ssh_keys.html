SSH Keys

Save public keys to reuse when creating virtual machines, or generate a key pair and download its private key. Protect private keys like passwords.

Select saved keys from the menu below the public key field on creation, clone and template forms. Automatic keys are added to new virtual machines created from cloud images and to prepared clones. They appear with an Automatic badge and do not need to be selected. If password login is selected, it stays enabled. ISO installs and unchanged clones do not receive new keys.

Only generated private keys are saved on this host and available to download. Imported private keys must be unencrypted; only their public key is saved. To replace a key, add a new entry. Deleting an entry leaves keys on existing virtual machines and in templates unchanged.
