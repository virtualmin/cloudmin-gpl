Statusbeschreibungen
Die möglichen Status für jedes virtuelle System sind:
Nieder
Das virtuelle System wurde heruntergefahren oder ein physisches System reagiert nicht auf Pings.
Der übergeordnete Host ist ausgefallen
Bei einem virtuellen System ist die Maschine, auf der es gehostet wird, ausgefallen.
Kein SSH
Das virtuelle System scheint aktiv zu sein, aber SSH-Verbindungen schlagen fehl oder es tritt eine Zeitüberschreitung auf.
SSH-Anmeldung fehlgeschlagen
Das System und SSH werden ausgeführt, aber die Cloudmin bekannten Root- Anmeldeinformationen sind falsch.
Kein Webmin
Das System ist betriebsbereit, aber Webmin ist nicht installiert.
Webmin runter
Das System ist aktiv und Webmin ist installiert, läuft jedoch nicht.
Webmin-Anmeldung fehlgeschlagen
Das System ist aktiv und Webmin wird ausgeführt, aber die Cloudmin bekannten Anmeldeinformationen dafür sind falsch.
Webmin aber kein Virtualmin
Das System ist aktiv und Webmin ist installiert und läuft, aber das Virtualmin-Modul fehlt.
Webmin und Virtualmin
Das System ist aktiv und sowohl Webmin als auch Virtualmin sind installiert und verfügbar.
Auf einigen Seiten enthält der Status zusätzliche Informationen, z. B. die Anzahl der gehosteten Domänen oder Probleme mit der Virtualmin-Konfiguration.
