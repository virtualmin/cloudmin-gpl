Descripciones de estado
Los posibles estados para cada sistema virtual son:
Abajo
El sistema virtual se ha apagado o un sistema físico no responde a los pings.
El host principal está caído
Para un sistema virtual, la máquina que lo aloja está inactiva.
No SSH
El sistema virtual parece estar activo, pero las conexiones SSH fallan o se agota el tiempo de espera.
Error de inicio de sesión SSH
El sistema y SSH se están ejecutando, pero las credenciales de inicio de sesión raíz conocidas por Cloudmin son incorrectas.
No webmin
El sistema está en funcionamiento, pero Webmin no está instalado.
Webmin abajo
El sistema está activo y Webmin está instalado, pero no se está ejecutando.
Error de inicio de sesión de Webmin
El sistema está funcionando y Webmin se está ejecutando, pero las credenciales para lo que Cloudmin conoce son incorrectas.
Webmin pero no Virtualmin
El sistema está activo y Webmin está instalado y ejecutándose, pero falta el módulo Virtualmin.
Webmin y Virtualmin
El sistema está activo, y tanto Webmin como Virtualmin están instalados y disponibles.
En algunas páginas, el estado incluye información adicional, como la cantidad de dominios alojados o problemas encontrados con la configuración de Virtualmin.
