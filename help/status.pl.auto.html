Opisy statusu
Możliwe statusy dla każdego systemu wirtualnego to:
Na dół
System wirtualny został zamknięty lub system fizyczny nie reaguje na polecenia ping.
Host nadrzędny nie działa
W przypadku systemu wirtualnego hostująca go maszyna jest wyłączona.
Bez SSH
Wygląda na to, że system wirtualny działa, ale połączenia SSH nie działają lub upłynął limit czasu.
Logowanie SSH nie powiodło się
System i SSH są uruchomione, ale dane logowania do roota znane Cloudminowi są nieprawidłowe.
Brak Webmina
System jest uruchomiony, ale Webmin nie jest zainstalowany.
Webmin w dół
System jest uruchomiony, a Webmin jest zainstalowany, ale nie działa.
Logowanie Webmina nie powiodło się
System jest uruchomiony, a Webmin działa, ale dane uwierzytelniające dla Cloudmin są niepoprawne.
Webmin, ale brak Virtualmin
System jest uruchomiony, a Webmin jest zainstalowany i działa, ale brakuje modułu Virtualmin.
Webmin i Virtualmin
System działa, a Webmin i Virtualmin są zainstalowane i dostępne.
Na niektórych stronach status zawiera dodatkowe informacje, takie jak liczba hostowanych domen lub problemy znalezione w konfiguracji Virtualmin.
