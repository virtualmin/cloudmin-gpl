Descrições de status
Os status possíveis para cada sistema virtual são:
Baixa
O sistema virtual foi desligado ou um sistema físico não está respondendo a pings.
O host pai está inativo
Para um sistema virtual, a máquina que o hospeda está inativa.
Sem SSH
O sistema virtual parece estar ativo, mas as conexões SSH falham ou atingem o tempo limite.
Falha no login do SSH
O sistema e o SSH estão em execução, mas as credenciais de login raiz conhecidas pelo Cloudmin estão incorretas.
Sem Webmin
O sistema está instalado e funcionando, mas o Webmin não está instalado.
Webmin inativo
O sistema está instalado e o Webmin está instalado, mas não está em execução.
Falha no login no Webmin
O sistema está instalado e o Webmin está em execução, mas as credenciais conhecidas pelo Cloudmin estão incorretas.
Webmin, mas não Virtualmin
O sistema está instalado e o Webmin está instalado e em execução, mas o módulo Virtualmin está ausente.
Webmin e Virtualmin
O sistema está ativo e o Webmin e o Virtualmin estão instalados e disponíveis.
Em algumas páginas, o status inclui informações adicionais, como o número de domínios hospedados ou problemas encontrados na configuração do Virtualmin.
