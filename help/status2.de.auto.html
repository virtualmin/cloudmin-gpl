Detaillierter Systemstatus
Diese Seite enthält weitere Informationen zum Zustand eines Systems, die während der letzten regulären oder manuellen Statusaktualisierung erfasst wurden. Wenn Sie sich auf einem System direkt bei Virtualmin anmelden, werden ähnliche Informationen im rechten Rahmen angezeigt. Der Status umfasst die CPU-Auslastung, den verwendeten realen und virtuellen Speicher, den Speicherplatz und den Status verschiedener von Virtualmin konfigurierter Server (Apache, Postfix usw.). Wenn das System über mehrere IP-Adressen verfügt, wird auch eine Zusammenfassung ihrer Verwendung angezeigt.

Wenn für dieses System Paketaktualisierungen ausstehen, werden diese auch in diesem Abschnitt angezeigt. Neben der Liste der Updates befindet sich eine Schaltfläche, mit der Sie alle Updates installieren können.
