Speicherorte für Bilder
Auf dieser Seite werden Speicherorte aufgelistet, an die alle neuen Images des virtuellen Systems kopiert werden, einschließlich der von Virtualmin heruntergeladenen und der von virtuellen Systemen erstellten. Standardmäßig werden Bilder nur auf dem Cloudmin-Master gespeichert. Sie können jedoch zusätzliche Speicherorte hinzufügen, z. B. auf einem dedizierten Bildspeicherhost.

Wenn Sie Hostsysteme an verschiedenen geografischen Standorten haben, möchten Sie möglicherweise eine zusätzliche Kopie aller Bilder an jedem Standort aufbewahren, um die Übertragung beim Erstellen von Systemen zu beschleunigen. Ein Bildspeicherort kann auch auf nur Hostsysteme in einigen Standortgruppen beschränkt werden, sodass keine Bilder empfangen werden, die von anderen virtuellen Systemen erstellt wurden.
