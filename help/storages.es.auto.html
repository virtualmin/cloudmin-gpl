Ubicaciones de almacenamiento de imágenes
Esta página enumera las ubicaciones en las que se copiarán todas las imágenes nuevas del sistema virtual, incluidas las descargadas de Virtualmin y las que cree desde sistemas virtuales. De manera predeterminada, las imágenes se almacenan solo en el maestro de Cloudmin; sin embargo, puede agregar ubicaciones adicionales, como en un host de almacenamiento de imágenes dedicado.

Si tiene sistemas host en diferentes ubicaciones geográficas, es posible que desee conservar una copia adicional de todas las imágenes en cada ubicación para acelerar las transferencias al crear sistemas. Una ubicación de almacenamiento de imágenes también se puede restringir solo a sistemas host en algunos grupos de ubicaciones, de modo que no recibirá imágenes creadas a partir de sistemas virtuales en otros lugares.
