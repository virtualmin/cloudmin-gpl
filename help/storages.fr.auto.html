Emplacements de stockage d'images
Cette page répertorie les emplacements vers lesquels toutes les nouvelles images de système virtuel seront copiées, y compris celles téléchargées à partir de Virtualmin et celles que vous créez à partir de systèmes virtuels. Par défaut, les images sont stockées uniquement sur le maître Cloudmin - cependant, vous pouvez ajouter des emplacements supplémentaires, comme sur un hôte de stockage d'images dédié.

Si vous avez des systèmes hôtes dans des emplacements géographiques différents, vous souhaiterez peut-être conserver une copie supplémentaire de toutes les images dans chaque emplacement pour accélérer les transferts lors de la création de systèmes. Un emplacement de stockage d'images peut également être limité aux seuls systèmes hôtes de certains groupes d'emplacements, de sorte qu'il ne recevra pas d'images créées à partir de systèmes virtuels ailleurs.
