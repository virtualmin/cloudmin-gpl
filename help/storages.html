Image Storage Locations
This page lists locations that all new virtual system images will be copied to, including those downloaded from Virtualmin and those you create from virtual systems. By default, images are stored only on the Cloudmin master - however, you can add additional locations, such as on a dedicated image storage host.

If you have host systems in different geographical locations, you may want to keep an additional copy of all images in each location to speed up transfers when creating systems. An image storage location can also be restricted to only host systems in some location groups, so that it will not receive images created from virtual systems elsewhere.
