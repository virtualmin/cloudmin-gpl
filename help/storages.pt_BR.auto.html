Locais de armazenamento de imagens
Esta página lista os locais para os quais todas as novas imagens do sistema virtual serão copiadas, incluindo aquelas baixadas do Virtualmin e aquelas criadas a partir de sistemas virtuais. Por padrão, as imagens são armazenadas apenas no Cloudmin master - no entanto, você pode adicionar locais adicionais, como em um host de armazenamento de imagens dedicado.

Se você possui sistemas host em diferentes localizações geográficas, convém manter uma cópia adicional de todas as imagens em cada local para acelerar as transferências ao criar sistemas. Um local de armazenamento de imagens também pode ser restrito a apenas sistemas host em alguns grupos de locais, para que não receba imagens criadas a partir de sistemas virtuais em outros lugares.
