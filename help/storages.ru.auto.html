Места хранения изображений
На этой странице перечислены местоположения, в которые будут скопированы все новые образы виртуальной системы, включая загруженные из Virtualmin и созданные из виртуальных систем. По умолчанию изображения хранятся только на главном устройстве Cloudmin, однако вы можете добавить дополнительные места, например, на выделенный хост для хранения изображений.

Если у вас есть хост-системы в разных географических местоположениях, вы можете сохранить дополнительную копию всех изображений в каждом местоположении, чтобы ускорить передачу при создании систем. Местоположение хранения изображений также может быть ограничено только хост-системами в некоторых группах местоположений, чтобы оно не получало изображения, созданные из виртуальных систем в других местах.
