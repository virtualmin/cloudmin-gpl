Machine Templates

Templates supply image, storage, login, network, software and boot defaults for new machines. Unset fields inherit from Default Template, including later changes to it. Editing a template does not change existing machines or submitted jobs.

Enter each machine's name, password and individual network addresses when creating it. A template can set static addressing, gateways and DNS, but cannot assign every machine the same IP.

Catalogue images download when creation starts, not when a template is saved. ISO templates do not automate the operating-system installer.

Optional setup runs the preparation script, installs software, then runs the final script inside the guest. Scripts run as root and must be noninteractive. Do not store reusable secrets in them. Setup requires a systemd cloud image, automatic startup and a managed SSH key.

Default Template cannot be deleted because other templates depend on it. Other templates can be deleted only when no machine or pending creation uses them.
