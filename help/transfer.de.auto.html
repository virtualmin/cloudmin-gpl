Dateien übertragen
Auf dieser Seite können Sie entweder Dateien auf ein von Cloudmin verwaltetes System hochladen oder eine Datei von einem System herunterladen. Es gibt eine separate Registerkarte für jede Funktion:
Datei hochladen
Beim Hochladen, kann die Datei entweder aus dem PC , auf das Sie Ihren Web - Browser ausgeführt wird , oder aus dem Cloudmin Master - System, je nach Auswahl in Feld Quelldatei. Die Datei oder der Pfad, in die auf dem verwalteten System hochgeladen werden soll, muss in das Feld Zieldatei oder Verzeichnis eingegeben werden.

Download-Datei
Beim Herunterladen müssen Sie zuerst den vollständigen Pfad zu einer vorhandenen Datei auf dem verwalteten System in das Feld Quelldatei zum Herunterladen eingeben. Um die Datei in Ihrem Browser anzuzeigen oder auf Ihrem PC zu speichern, wählen Sie Im Browser anzeigen . Um auf dem Cloudmin-Mastersystem zu speichern, wählen Sie In Cloudmin-Master speichern unter und geben Sie einen Datei- oder Verzeichnisnamen in das nebenstehende Textfeld ein.
