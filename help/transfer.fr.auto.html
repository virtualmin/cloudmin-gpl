Transférer des fichiers
Cette page peut être utilisée pour télécharger des fichiers vers un système géré Cloudmin ou pour télécharger un fichier depuis un système. Il a un onglet séparé pour chaque fonction:
Téléverser un fichier
Lors du téléchargement, le fichier peut provenir soit du PC sur lequel vous exécutez votre navigateur Web, soit du système maître Cloudmin, selon votre sélection dans le champ Fichier source . Le fichier ou le chemin à télécharger sur le système géré doit être entré dans le champ Fichier ou répertoire de destination .

Télécharger un fichier
Lors du téléchargement, vous devez d'abord saisir le chemin d'accès complet à un fichier existant sur le système géré dans le champ Fichier source à télécharger . Pour afficher le fichier dans votre navigateur ou l'enregistrer sur votre PC, sélectionnez Afficher dans le navigateur . Pour enregistrer sur le système maître Cloudmin, sélectionnez Enregistrer sur le maître Cloudmin sous et entrez un nom de fichier ou de répertoire dans la zone de texte adjacente.
