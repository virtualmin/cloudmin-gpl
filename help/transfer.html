Transfer Files
This page can be used to either upload files to a Cloudmin managed system, or to download a file from a system. It has a separate tab for each function :
Upload File
When uploading, the file can come either from the PC on which you are running your web browser, or from the Cloudmin master system, depending on your selection in the Source file field. The file or path to upload into on the managed system must be entered in the Destination file or directory field.

Download File
When downloading, you must first enter the full path to an existing file on the managed system in the Source file to download field. To display the file in your browser or save it on your PC, select Display in browser. To save on the Cloudmin master system, select Save to Cloudmin master as and enter a file or directory name into the adjacent text box.
