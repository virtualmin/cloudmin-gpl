Trasferisci file
Questa pagina può essere utilizzata per caricare file su un sistema gestito Cloudmin o per scaricare un file da un sistema. Ha una scheda separata per ogni funzione:
Caricare un file
Durante il caricamento, il file può provenire dal PC su cui si sta eseguendo il browser Web o dal sistema master Cloudmin, a seconda della selezione effettuata nel campo File di origine . Il file o il percorso da caricare nel sistema gestito deve essere inserito nel campo File o directory di destinazione .

Download file
Durante il download, è necessario innanzitutto immettere il percorso completo di un file esistente sul sistema gestito nel campo File di origine da scaricare . Per visualizzare il file nel browser o salvarlo sul PC, selezionare Visualizza nel browser . Per salvare sul sistema principale Cloudmin, selezionare Salva su Master Cloudmin come e immettere un nome di file o directory nella casella di testo adiacente.
