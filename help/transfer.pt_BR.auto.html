Transferir arquivos
Esta página pode ser usada para fazer upload de arquivos para um sistema gerenciado Cloudmin ou para baixar um arquivo de um sistema. Possui uma guia separada para cada função:
Subir arquivo
Ao fazer o upload, o arquivo pode vir do PC no qual você está executando seu navegador da Web ou do sistema mestre Cloudmin, dependendo da sua seleção no campo Arquivo de origem . O arquivo ou caminho para o qual fazer upload no sistema gerenciado deve ser inserido no campo Arquivo ou diretório de destino .

⇬ Fazer download do arquivo
Ao fazer o download, você deve primeiro inserir o caminho completo para um arquivo existente no sistema gerenciado no campo Arquivo de origem para download . Para exibir o arquivo no seu navegador ou salvá-lo no seu PC, selecione Exibir no navegador . Para salvar no sistema mestre do Cloudmin, selecione Salvar no mestre do Cloudmin como e insira um nome de arquivo ou diretório na caixa de texto adjacente.
