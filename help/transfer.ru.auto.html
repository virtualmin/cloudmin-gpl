Передача файлов
Эта страница может использоваться для загрузки файлов в управляемую систему Cloudmin или для загрузки файла из системы. Он имеет отдельную вкладку для каждой функции:
Загрузить файл
При загрузке файл может поступать либо с ПК, на котором вы используете веб-браузер, либо из основной системы Cloudmin, в зависимости от вашего выбора в поле «Исходный файл» . Файл или путь для загрузки в управляемой системе должны быть введены в поле «Целевой файл или каталог» .

Загрузить файл
При загрузке сначала необходимо ввести полный путь к существующему файлу в управляемой системе в поле «Исходный файл для загрузки» . Чтобы отобразить файл в браузере или сохранить его на ПК, выберите «Показать в браузере» . Чтобы сохранить в основной системе Cloudmin, выберите «Сохранить в мастер Cloudmin как» и введите имя файла или каталога в соседнем текстовом поле.
