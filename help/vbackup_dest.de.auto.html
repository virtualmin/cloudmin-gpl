Ziel-URLs sichern
Sicherungsziele müssen in dem Format eingegeben werden, das vom Befehl virtualmin backup-domain API verwendet wird. Beispielsweise :
  • Eine lokale Datei wie /backup/yourdomain.com.tgz

  • Ein FTP-Ziel wie ftp://login:pass\@server/backup/domain.com.tgz

  • Ein SSH-Ziel wie ssh://login:pass\@server/backup/domain.com.tgz

  • Ein S3-Bucket wie s3://accesskey:secretkey@bucket/domain.com.tgz

  • Ein Rackspace-Container wie rs://user:apikey@container/domain.com.tgz

  • Ein Google Cloud Storage-Bucket wie gcs://bucket/domain.com.tgz

  • Ein Dropbox-Ordner wie dropbox://folder/domain.com.tgz
Jedes Ziel, das mit tar.gz oder zip endet, wird als einzelne Datei angenommen, die alle ausgewählten Domänen enthält. Alles andere wird als Verzeichnis behandelt, das eine Datei pro Domain erhält.

Für Dropbox- und GCS-Sicherungen muss auf jedem Virtualmin-System bereits ein Konto beim konfigurierten Speicheranbieter vorhanden sein.

Sie können die Tags ${HOST} und ${IP} in Sicherungszielen verwenden, die für jedes System durch den Hostnamen und die IP-Adresse des Quellsystems ersetzt werden. Dadurch können verschiedene Systeme in verschiedenen Endverzeichnissen sichern.
