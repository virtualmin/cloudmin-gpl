Virtuelle Server-Backups
Auf dieser Seite können Sie die Sicherung virtueller Virtualmin-Server oder globale Einstellungen auf mehreren verwalteten Systemen konfigurieren. Es kann verwendet werden, um eine konsistente Replikationsrichtlinie auf allen Computern einzurichten, auf denen Virtualmin ausgeführt wird, anstatt jede einzeln zu konfigurieren. Klicken Sie zum Einrichten einer Sicherung auf den Link Neue Virtualmin-Sicherung hinzufügen . Wenn Sie bereits einige definiert haben, klicken Sie auf eine in der Liste, um sie zu bearbeiten, zu löschen oder auszuführen.

Für jede Sicherungskonfiguration können Sie die Quellsysteme auswählen und einen oder mehrere Zielpfade eingeben. Sie können auch auswählen, welche Virtualmin-Domänen oder globalen Einstellungen einbezogen werden sollen. Backups können so konfiguriert werden, dass sie regelmäßig (z. B. täglich oder stündlich) ausgeführt oder bei Bedarf ausgelöst werden. Für jede Konfiguration kann eine E-Mail-Adresse eingegeben werden, die im Fehlerfall benachrichtigt werden soll.
