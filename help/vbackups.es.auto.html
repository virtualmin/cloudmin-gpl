Copias de seguridad del servidor virtual
Esta página le permite configurar la copia de seguridad de los servidores virtuales de Virtualmin o la configuración global en múltiples sistemas administrados. Se puede usar para configurar una política de replicación coherente en todas las máquinas que ejecutan Virtualmin, en lugar de configurarlas individualmente. Para configurar una copia de seguridad, haga clic en el enlace Agregar una nueva copia de seguridad de Virtualmin . Si ya ha definido alguno, haga clic en uno de la lista para editarlo, eliminarlo o ejecutarlo.

Para cada configuración de respaldo, puede seleccionar los sistemas de origen e ingresar una o más rutas de destino. También puede elegir qué dominios de Virtualmin o configuraciones globales incluir. Las copias de seguridad pueden configurarse para ejecutarse en un horario regular (como diario o por hora), o activarse a pedido. Para cada configuración se puede ingresar una dirección de correo electrónico para notificar en caso de falla.
