Sauvegardes de serveur virtuel
Cette page vous permet de configurer la sauvegarde des serveurs virtuels Virtualmin ou les paramètres globaux sur plusieurs systèmes gérés. Il peut être utilisé pour configurer une politique de réplication cohérente sur toutes vos machines exécutant Virtualmin, plutôt que de les configurer individuellement. Pour configurer une sauvegarde, cliquez sur le lien Ajouter une nouvelle sauvegarde Virtualmin . Si vous en avez déjà défini, cliquez sur l'un dans la liste pour le modifier, le supprimer ou l'exécuter.

Pour chaque configuration de sauvegarde, vous pouvez sélectionner les systèmes source et entrer un ou plusieurs chemins de destination. Vous pouvez également choisir les domaines Virtualmin ou les paramètres globaux à inclure. Les sauvegardes peuvent être configurées pour s'exécuter selon un horaire régulier (comme quotidiennement ou toutes les heures) ou déclenchées à la demande. Pour chaque configuration, une adresse e-mail à notifier en cas de panne peut être saisie.
