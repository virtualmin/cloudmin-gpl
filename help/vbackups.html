Virtual Server Backups
This page allows you to configure backup of Virtualmin virtual servers or global settings on managed multiple systems. It can be used to setup a consistent replication policy across all your machines running Virtualmin, rather than configuring each individually. To setup a backup, click the Add a new Virtualmin backup link. If you have defined some already, click on one in the list to edit, delete or run it.

For each backup configuration you can select the source systems, and enter one or more destination paths. You can also choose which Virtualmin domains or global settings to include. Backups can be configured to run on a regular schedule (like daily or hourly), or triggered on demand. For each config an email address to notify in the case of a failure can be entered.
