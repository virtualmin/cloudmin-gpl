Virtuelle CPUs verwalten
Auf dieser Seite können Sie auswählen, wie viele virtuelle CPUs ein System anscheinend ausführen muss, um darin ausgeführt zu werden, und optional, wie sie mit realen CPUs auf dem Hostsystem verknüpft sind. Das Anheften eines virtuellen Systems an bestimmte Host-CPUs kann die Isolation zwischen Systemen verbessern, wenn sich mehrere ausgelastete virtuelle Maschinen auf demselben Host befinden.
