Gérer les CPU virtuels
Cette page vous permet de sélectionner le nombre de processeurs virtuels qu'un système semblera avoir pour les processus qui s'exécutent en son sein, et éventuellement comment ils sont associés aux vrais processeurs sur le système hôte. L'épinglage d'un système virtuel sur certains CPU hôtes peut améliorer l'isolation entre les systèmes lorsque plusieurs machines virtuelles sont occupées sur le même hôte.
