Gestisci CPU virtuali
Questa pagina consente di selezionare il numero di CPU virtuali che un sistema sembrerà dover avviare al suo interno e, facoltativamente, il modo in cui sono associate a CPU reali sul sistema host. Il blocco di un sistema virtuale su determinate CPU host può migliorare l'isolamento tra i sistemi quando si hanno più macchine virtuali occupate sullo stesso host.
