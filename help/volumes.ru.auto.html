Тома EC2
Amazon Elastic Block Store (EBS) предоставляет тома хранилищ на уровне блоков для использования с экземплярами Amazon EC2. Тома Amazon EBS являются хранилищем вне экземпляра, которое сохраняется независимо от срока службы экземпляра.

На этой странице перечислены все существующие тома, созданные с использованием ваших учетных записей EC2, и любые снимки этих томов. Вы можете создать том, используя форму сведений о новом томе , которую затем можно прикрепить к работающему экземпляру EC2. Тома, которые больше не нужны, можно выбрать из списка и удалить с помощью кнопки «Удалить выбранные тома» .

Снимок - это копия тома, которая хранится в S3 и может использоваться для создания новых томов. Если у вас есть хотя бы один том, эту страницу можно использовать для создания из него снимков и для удаления существующих снимков.

Помните, что Amazon взимает плату за тома на основе их размера, количества времени, в течение которого они существуют, и уровня дискового ввода-вывода. Снимки оплачиваются по обычным ценам хранения S3.
