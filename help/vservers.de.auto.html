VServer-Hostsysteme
Bevor Cloudmin virtuelle Systeme mit Linux VServer-Instanzen erstellen kann, müssen Sie die Hostsysteme registrieren, auf denen VServer auf dieser Seite ausgeführt werden. Cloudmin verfügt über eine dreischichtige Architektur, in der das Mastersystem (auf dem die Cloudmin-Webmin-Schnittstelle ausgeführt wird) von den Systemen getrennt ist, auf denen VServer-Instanzen gehostet werden, die wiederum von den VServer-Systemen selbst getrennt sind.

Bevor ein VServer-Hostsystem hier registriert werden kann, müssen Sie es zunächst über den Link Physisches System hinzufügen unter System hinzufügen im linken Menü unter die Kontrolle von Cloudmin bringen. Es ist möglich, dass ein einzelnes System sowohl Virtualmin-Domänen als auch VServer-Instanzen hostet. Dies ist jedoch fast immer eine schlechte Idee, da für das virtuelle Hosting verwendete VServer erfordern, dass das Host-System keine Serverprozesse hat, die Verbindungen auf allen Netzwerkschnittstellen akzeptieren.

Wenn Cloudmin ein System bekannt ist, verwenden Sie den Link System für VServer-Hosting registrieren, um den Registrierungsprozess zu starten.
