Sistemas host VServer
Antes de que Cloudmin pueda crear sistemas virtuales utilizando instancias de Linux VServer, debe registrar los sistemas host en los que VServers se ejecutará utilizando esta página. Cloudmin tiene una arquitectura de tres capas, en la que el sistema maestro (en el que se ejecuta la interfaz de Cloudmin Webmin) está separado de los sistemas que alojan instancias de VServer, que a su vez están separados de los propios sistemas de VServer.

Antes de que un sistema host VServer pueda registrarse aquí, primero debe ponerlo bajo el control de Cloudmin usando el enlace Agregar sistema físico en Agregar sistema en el menú de la izquierda. Es posible que un solo sistema aloje dominios de Virtualmin e instancias de VServer, aunque esto es casi siempre una mala idea ya que los VServers utilizados para el alojamiento virtual requieren que el sistema host no tenga ningún proceso de servidor que acepte conexiones en todas las interfaces de red.

Una vez que Cloudmin conoce un sistema, use el enlace Registrar un sistema para el alojamiento de VServer para iniciar el proceso de registro.
