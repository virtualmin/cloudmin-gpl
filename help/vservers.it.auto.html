Sistemi host VServer
Prima che Cloudmin possa creare qualsiasi sistema virtuale utilizzando istanze VServer di Linux, è necessario registrare i sistemi host su cui VServers verrà eseguito utilizzando questa pagina. Cloudmin ha un'architettura a tre livelli, in cui il sistema principale (su cui gira l'interfaccia Cloudmin Webmin) è separato dai sistemi che ospitano istanze VServer, che a loro volta sono separate dai sistemi VServer stessi.

Prima che un sistema host VServer possa essere registrato qui, è necessario portarlo sotto il controllo di Cloudmin usando il collegamento Aggiungi sistema fisico sotto Aggiungi sistema nel menu a sinistra. È possibile per un singolo sistema ospitare sia domini Virtualmin che istanze VServer, sebbene questa sia quasi sempre una cattiva idea poiché VServers utilizzato per l'hosting virtuale richiede che il sistema host non abbia alcun processo server che accetti connessioni su tutte le interfacce di rete.

Una volta che un sistema è noto a Cloudmin, utilizzare il collegamento Registra un sistema per l'hosting VServer per avviare il processo di registrazione.
