VServer Host Systems
Aby Cloudmin mógł utworzyć jakiekolwiek systemy wirtualne przy użyciu instancji Linux VServer, musisz zarejestrować systemy hosta, na których VServers będzie działał na tej stronie. Cloudmin ma trójwarstwową architekturę, w której system główny (na którym działa interfejs Cloudmin Webmin) jest niezależny od systemów, które obsługują instancje VServer, które z kolei są oddzielne od samych systemów VServer.

Zanim system hosta VServer będzie mógł zostać tutaj zarejestrowany, musisz najpierw przejąć kontrolę nad Cloudmin za pomocą linku Dodaj fizyczny system w Dodaj system w menu po lewej stronie. Możliwe jest, aby jeden system hostował domeny Virtualmin i instancje VServer, chociaż prawie zawsze jest to zły pomysł, ponieważ VServers używane do hostingu wirtualnego wymagają, aby system hosta nie miał procesów serwera przyjmujących połączenia na wszystkich interfejsach sieciowych.

Gdy system będzie znany Cloudmin, użyj łącza Zarejestruj system dla VServer, aby rozpocząć proces rejestracji.
