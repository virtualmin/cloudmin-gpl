Sistemas host do VServer
Antes de o Cloudmin criar qualquer sistema virtual usando instâncias do Linux VServer, você deve registrar os sistemas host nos quais os VServers serão executados usando esta página. O Cloudmin possui uma arquitetura de três camadas, na qual o sistema mestre (no qual a interface do Cloudmin Webmin é executada) é separado dos sistemas que hospedam instâncias do VServer, que por sua vez são separados dos próprios sistemas do VServer.

Para que um sistema host do VServer possa ser registrado aqui, primeiro você deve colocá-lo sob o controle do Cloudmin usando o link Adicionar sistema físico em Adicionar sistema no menu esquerdo. É possível que um único sistema hospede domínios do Virtualmin e instâncias do VServer, embora isso quase sempre seja uma má idéia, pois os servidores VS usados para hospedagem virtual exigem que o sistema host não tenha nenhum processo de servidor que aceite conexões em todas as interfaces de rede.

Quando um sistema for conhecido pelo Cloudmin, use o link Registrar um sistema para hospedagem do VServer para iniciar o processo de registro.
