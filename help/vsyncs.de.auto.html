Replikation des virtuellen Servers
Auf dieser Seite können Sie die Einwegreplikation von virtuellen Virtualmin-Servern oder globale Einstellungen zwischen mehreren Systemen konfigurieren. Es kann verwendet werden, um virtuelle Server zu spiegeln oder Einstellungen wie Pläne und Vorlagen von einer Master-Maschine an mehrere Slaves zu verteilen.

Klicken Sie zum Einrichten der Replikation auf den Link Neue Replikationskonfiguration hinzufügen . Wenn Sie bereits einige definiert haben, klicken Sie auf eine in der Liste, um sie zu bearbeiten, zu löschen oder auszuführen.

Für jede Replikationskonfiguration können Sie das Quellsystem und ein oder mehrere Zielsysteme auswählen. Sie können auch auswählen, welche Virtualmin-Domänen oder globalen Einstellungen repliziert werden sollen und welche Funktionen in diese Domänen aufgenommen werden sollen.

Die Replikation kann so konfiguriert werden, dass sie regelmäßig (z. B. täglich oder stündlich) ausgeführt oder bei Bedarf ausgelöst wird. Für jede Konfiguration kann eine E-Mail-Adresse eingegeben werden, die im Fehlerfall benachrichtigt werden soll.
