Replicación de servidor virtual
Esta página le permite configurar la replicación unidireccional de los servidores virtuales de Virtualmin o la configuración global entre múltiples sistemas. Se puede usar para duplicar servidores virtuales o para distribuir configuraciones como planes y plantillas desde una máquina maestra a varios esclavos.

Para configurar la replicación, haga clic en el enlace Agregar una nueva configuración de replicación . Si ya ha definido alguno, haga clic en uno de la lista para editarlo, eliminarlo o ejecutarlo.

Para cada configuración de replicación, puede seleccionar el sistema de origen y uno o más sistemas de destino. También puede elegir qué dominios de Virtualmin o configuraciones globales para replicar y qué características incluir en esos dominios.

La replicación puede configurarse para ejecutarse en un horario regular (como diario o por hora), o activarse a pedido. Para cada configuración se puede ingresar una dirección de correo electrónico para notificar en caso de falla.
