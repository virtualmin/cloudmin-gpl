Réplication de serveur virtuel
Cette page vous permet de configurer la réplication unidirectionnelle des serveurs virtuels Virtualmin ou les paramètres globaux entre plusieurs systèmes. Il peut être utilisé pour mettre en miroir des serveurs virtuels ou pour distribuer des paramètres tels que des plans et des modèles d'une machine maître à plusieurs esclaves.

Pour configurer la réplication, cliquez sur le lien Ajouter une nouvelle configuration de réplication . Si vous en avez déjà défini, cliquez sur l'un dans la liste pour le modifier, le supprimer ou l'exécuter.

Pour chaque configuration de réplication, vous pouvez sélectionner le système source et un ou plusieurs systèmes de destination. Vous pouvez également choisir les domaines Virtualmin ou les paramètres globaux à répliquer et les fonctionnalités à inclure dans ces domaines.

La réplication peut être configurée pour s'exécuter selon un horaire régulier (comme quotidiennement ou toutes les heures), ou être déclenchée à la demande. Pour chaque configuration, une adresse e-mail à notifier en cas de panne peut être saisie.
