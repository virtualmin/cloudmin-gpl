Virtual Server Replication
This page allows you to configure one-way replication of Virtualmin virtual servers or global settings between multiple systems. It can be used to mirror virtual servers, or to distribute settings like plans and templates from a master machine to several slaves.

To setup replication, click the Add a new replication configuration link. If you have defined some already, click on one in the list to edit, delete or run it.

For each replication configuration you can select the source system, and one or more destination systems. You can also choose which Virtualmin domains or global settings to replicate, and which features to include in those domains.

Replication can be configured to run on a regular schedule (like daily or hourly), or triggered on demand. For each config an email address to notify in the case of a failure can be entered.
