Xen-Hostsysteme
Bevor Cloudmin virtuelle Systeme mit Xen-Instanzen erstellen kann, müssen Sie die Hostsysteme registrieren, auf denen Xen auf dieser Seite ausgeführt wird. Cloudmin verfügt über eine dreischichtige Architektur, in der das Mastersystem (auf dem die Cloudmin-Webmin-Oberfläche ausgeführt wird) von den Systemen getrennt ist, auf denen Xen-Instanzen gehostet werden, die wiederum von den Xen-Systemen selbst getrennt sind.

Bevor ein Xen-Hostsystem hier registriert werden kann, müssen Sie es zunächst über den Link Physisches System hinzufügen unter System hinzufügen im linken Menü unter die Kontrolle von Cloudmin bringen. Es ist möglich, dass ein einzelnes System sowohl Virtualmin-Domänen als auch Xen-Instanzen hostet, obwohl dies aufgrund der von Xen auferlegten CPU-Auslastung im Allgemeinen nicht empfohlen wird. Wählen Sie anschließend das System aus dem Menü Hostsystem zum Hinzufügen aus und klicken Sie auf Start Host hinzufügen .
