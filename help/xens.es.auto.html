Xen Host Systems
Antes de que Cloudmin pueda crear sistemas virtuales utilizando instancias de Xen, debe registrar los sistemas host en los que Xen se ejecutará utilizando esta página. Cloudmin tiene una arquitectura de tres capas, en la que el sistema maestro (en el que se ejecuta la interfaz Cloudmin Webmin) está separado de los sistemas que alojan instancias de Xen, que a su vez están separados de los propios sistemas de Xen.

Antes de que un sistema host Xen pueda registrarse aquí, primero debe ponerlo bajo el control de Cloudmin usando el enlace Agregar sistema físico en Agregar sistema en el menú de la izquierda. Es posible que un solo sistema aloje dominios de Virtualmin e instancias de Xen, aunque esto no se recomienda generalmente debido a la carga de CPU que Xen puede imponer. Una vez hecho esto, seleccione el sistema desde el sistema Host para agregar el menú y haga clic en Iniciar Agregar Host .
