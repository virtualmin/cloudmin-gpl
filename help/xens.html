Xen Host Systems
Before Cloudmin can create any virtual systems using Xen instances, you must register the host systems on which Xen will run using this page. Cloudmin has a three-layer architecture, in which the master system (on which the Cloudmin Webmin interface runs) is separate from the systems that host Xen instances, which are in turn separate from the Xen systems themselves.

Before a Xen host system can be registered here, you must first bring it under Cloudmin's control using the Add physical system link under Add system on the left menu. It is possible for a single system to both host Virtualmin domains and Xen instances, although this is not generally recommended due to the CPU load Xen can impose. Once this is done, use the Register a system for Xen hosting link to start the registration process.
