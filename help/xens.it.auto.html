Sistemi host Xen
Prima che Cloudmin possa creare qualsiasi sistema virtuale utilizzando istanze Xen, è necessario registrare i sistemi host su cui verrà eseguito Xen utilizzando questa pagina. Cloudmin ha un'architettura a tre livelli, in cui il sistema master (su cui gira l'interfaccia Cloudmin Webmin) è separato dai sistemi che ospitano istanze Xen, che a loro volta sono separati dai sistemi Xen stessi.

Prima che un sistema host Xen possa essere registrato qui, è necessario portarlo sotto il controllo di Cloudmin usando il collegamento Aggiungi sistema fisico sotto Aggiungi sistema nel menu a sinistra. È possibile per un singolo sistema ospitare sia domini Virtualmin che istanze Xen, sebbene ciò non sia generalmente raccomandato a causa del carico della CPU che Xen può imporre. Al termine, selezionare il sistema dal sistema Host per aggiungere il menu e fare clic su Avvia aggiunta host .
