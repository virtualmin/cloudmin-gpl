Sistemas host Xen
Antes de o Cloudmin criar qualquer sistema virtual usando instâncias do Xen, você deve registrar os sistemas host nos quais o Xen será executado usando esta página. O Cloudmin possui uma arquitetura de três camadas, na qual o sistema mestre (no qual a interface do Cloudmin Webmin é executado) é separado dos sistemas que hospedam instâncias do Xen, que por sua vez são separados dos próprios sistemas Xen.

Para que um sistema host Xen possa ser registrado aqui, primeiro você deve colocá-lo sob o controle do Cloudmin usando o link Adicionar sistema físico em Adicionar sistema no menu esquerdo. É possível que um único sistema hospede domínios do Virtualmin e instâncias do Xen, embora isso geralmente não seja recomendado devido à carga da CPU que o Xen pode impor. Feito isso, selecione o sistema no sistema Host para adicionar menu e clique em Iniciar Adicionando Host .
