Solaris Zones-Hostsysteme
Bevor Cloudmin mithilfe von Solaris-Zonen virtuelle Systeme erstellen kann, müssen Sie auf dieser Seite die Hostsysteme registrieren, auf denen Zonen ausgeführt werden. Cloudmin verfügt über eine dreischichtige Architektur, in der das Mastersystem (auf dem die Cloudmin-Webmin-Oberfläche ausgeführt wird) von den Systemen getrennt ist, auf denen Zonen gehostet werden, die wiederum von den Zonen selbst getrennt sind.

Bevor ein Zones-System hier registriert werden kann, müssen Sie es zunächst über den Link Physisches System hinzufügen unter System hinzufügen im linken Menü unter die Kontrolle von Cloudmin bringen. Es ist möglich, dass ein einzelnes System sowohl Virtualmin-Domänen als auch Solaris auf einem ausreichend leistungsstarken System hostet. Sie können sowohl Solaris X86- als auch Sparc-Systeme registrieren, sofern Solaris 10 oder höher ausgeführt wird. Verwenden Sie anschließend den Link Registrieren eines Systems für das Hosting von Solaris Zones , um den Registrierungsprozess zu starten.
