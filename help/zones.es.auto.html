Sistemas host de zonas Solaris
Antes de que Cloudmin pueda crear sistemas virtuales utilizando las zonas de Solaris, debe registrar los sistemas host en los que se ejecutarán las zonas utilizando esta página. Cloudmin tiene una arquitectura de tres capas, en la que el sistema maestro (en el que se ejecuta la interfaz de Cloudmin Webmin) está separado de los sistemas que alojan zonas, que a su vez están separadas de las zonas mismas.

Antes de que un sistema de Zonas se pueda registrar aquí, primero debe ponerlo bajo el control de Cloudmin usando el enlace Agregar sistema físico en Agregar sistema en el menú de la izquierda. Es posible que un solo sistema aloje dominios de Virtualmin y Solaris, en un sistema lo suficientemente potente. Puede registrar los sistemas Solaris X86 y Sparc, siempre que ejecuten Solaris 10 o posterior. Una vez hecho esto, use el enlace Registrar un sistema para el alojamiento de Zonas de Solaris para iniciar el proceso de registro.
