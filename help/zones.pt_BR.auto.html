Sistemas host do Solaris Zones
Antes de o Cloudmin criar qualquer sistema virtual usando o Solaris Zones, você deve registrar os sistemas host nos quais as zonas serão executadas usando esta página. O Cloudmin possui uma arquitetura de três camadas, na qual o sistema principal (no qual a interface do Cloudmin Webmin é executada) é separado dos sistemas que hospedam zonas, que por sua vez são separadas das próprias zonas.

Para que um sistema de zonas possa ser registrado aqui, você deve colocá-lo sob o controle do Cloudmin usando o link Adicionar sistema físico em Adicionar sistema no menu esquerdo. É possível que um único sistema hospede domínios do Virtualmin e Solaris, em um sistema suficientemente poderoso. Você pode registrar os sistemas Solaris X86 e Sparc, desde que estejam executando o Solaris 10 ou posterior. Feito isso, use o link Registrar um sistema para hospedagem do Solaris Zones para iniciar o processo de registro.
